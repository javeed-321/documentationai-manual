### Generating Customized MS Word Report using algoQA via Command Prompt

Perform the following:

<Steps>
  <Step title="In the algoQA script-generated folder structure, navigate to the algoReport folder." title-type="p">
    <Image src="https://s3-ap-south-1.amazonaws.com/ind-cdn.freshdesk.com/data/helpdesk/attachments/production/1070006407665/original/OGTi4qPncrvIHYLy5DKo0wJVQn2JsJSGxA.png?1714297255" width="479" height="124" alt="Windows File Explorer address bar with algoReport folder selected in TestComplete script directory" caption=" " />
  </Step>

  <Step title="Click the address bar at the top of the folder path to highlight the path." title-type="p">

  </Step>

  <Step title="Type 'cmd' in the address bar to launch Command Prompt." title-type="p">
    <Image src="https://s3-ap-south-1.amazonaws.com/ind-cdn.freshdesk.com/data/helpdesk/attachments/production/1070006407772/original/bZiZ2BC_RzpqIc-ZPOOoOvcYDRdbYERDHQ.gif?1714297678" width="490" height="292" alt="File Explorer showing algoReport application inside AlgoAFScript TestComplete folder" caption=" " />
  </Step>

  <Step title="Run the following command to generate the MS Word report in the 'GenerateWordReport' folder." title-type="p">
    ```bash
    algoreport.exe "wordReport" "reportStoragepath"
    ```

    This command instructs the algoreport.exe program to generate a report based on the provided Word document configuration and store it in the specified storage path.
