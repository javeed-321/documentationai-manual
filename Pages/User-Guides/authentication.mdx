## Overview

Wholechain requires authentication for all API requests to ensure secure access to your data. Use API keys with Bearer tokens in the `Authorization` header. Each key has scopes that define permissions, such as read or write access to events and products.

Generate keys in your dashboard at `https://dashboard.example.com`. Keys support rate limits to prevent abuse.

<Callout kind="alert">
  Never expose API keys in client-side code or public repositories. Rotate keys regularly and use environment variables.
</Callout>

## Generating API Keys

Follow these steps to create a new API key.

<Steps>
  <Step title="Log In" icon="log-in">
    Access `https://dashboard.example.com` and sign in with your credentials.
  </Step>
  <Step title="Navigate to Keys" icon="key">
    Go to **Account** > **API Keys**.
  </Step>
  <Step title="Create Key" icon="plus">
    Click **Generate New Key**, select scopes, and copy the key value immediately—it won't show again.
  </Step>
</Steps>

## Authentication Header

Include the Bearer token in every request.

<ParamField header="Authorization" param-type="string" required="true">
  Format: `Bearer YOUR_API_KEY`. Replace `YOUR_API_KEY` with your generated key.
</ParamField>

<ParamField header="Content-Type" param-type="string" required="false">
  Use `application/json` for request bodies.
</ParamField>

## API Request Examples

Send authenticated requests to endpoints like `/v1/events`.

<Request tabs="JavaScript,Python,cURL">
  ```javascript
  const response = await fetch('https://api.example.com/v1/events', {
    method: 'GET',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    }
  });
  const data = await response.json();
  ```
  ```python
  import requests

  headers = {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
  }
  response = requests.get('https://api.example.com/v1/events', headers=headers)
  data = response.json()
  ```
  ```bash
  curl -X GET https://api.example.com/v1/events \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json"
  ```
</Request>

<Response tabs="200,401">
  ```json
  {
    "events": [
      {
        "id": "evt_123",
        "type": "shipment",
        "status": "completed"
      }
    ]
  }
  ```
  ```json
  {
    "error": {
      "code": "unauthorized",
      "message": "Invalid API key"
    }
  }
  ```
</Response>

## Scopes and Permissions

API keys have granular scopes. Assign only necessary permissions.

<Tabs>
  <Tab title="Read Only" icon="eye">
    Grants `events:read` and `products:read`. Ideal for reporting tools.
  </Tab>
  <Tab title="Full Access" icon="shield">
    Includes `events:write`, `locations:manage`. Use for production integrations.
  </Tab>
  <Tab title="Custom" icon="settings">
    Select specific scopes like `trade_partners:read` during key creation.
  </Tab>
</Tabs>

<Expandable title="Common Scopes Reference" default-open="true">
  | Scope              | Description                          |
  |--------------------|--------------------------------------|
  | `events:read`     | List and view events                 |
  | `events:write`    | Create and update events             |
  | `products:read`   | Access product details               |
  | `locations:manage`| Create/update locations and partners |
</Expandable>

## Rate Limits

Wholechain enforces rate limits to maintain service reliability.

<Callout kind="info">
  Limits: 100 requests per minute for sandbox, 5000 for production. Check `X-RateLimit-Remaining` header.
</Callout>

Exceeding limits returns HTTP 429. Implement exponential backoff.

```javascript
// Example backoff
async function requestWithBackoff(url) {
  let retries = 0;
  while (retries < 3) {
    const res = await fetch(url);
    if (res.status === 429) {
      await new Promise(r => setTimeout(r, 2 ** retries * 1000));
      retries++;
    } else {
      return res;
    }
  }
}
```
