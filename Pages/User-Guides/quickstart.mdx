## Prerequisites

Before integrating with the Wholechain API, ensure you have the following:

<Callout kind="info" collapsed="false">
  - A Wholechain account (sign up at `https://app.wholechain.com`)
  - Node.js (v18+) or Python (v3.8+) for client examples
  - cURL or Postman for testing
  - Access to the sandbox environment
</Callout>

## Set Up Your Sandbox Environment

Follow these steps to create a sandbox and obtain your API credentials.

<Steps>
  <Step title="Create Sandbox" icon="cloud" title-type="p">
    Log in to your Wholechain dashboard at `https://dashboard.example.com`.

    Navigate to **Account Settings** > **Sandboxes** > **Create New Sandbox**.

    Name it `My Test Sandbox` and select the default configuration.
  </Step>

  <Step title="Generate API Key" icon="key" title-type="p">
    In your sandbox dashboard, go to **API Keys** > **Generate New Key**.

    Copy the generated key (format: `wc_sandbox_...`).

    <Callout kind="tip" collapsed="false">
      Store your `API_KEY` securely. Do not share it publicly.
    </Callout>
  </Step>
</Steps>

Authorize Swagger using your API key:

```typescript
Bearer YOUR_API_KEY
```

## Make Your First API Call

Retrieve a list of events from your sandbox.

<Tabs>
  <Tab title="cURL" icon="terminal">
    ```bash
    curl -X GET \
      https://sandbox-api.example.com/v2/events \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json"
    ```
  </Tab>

  <Tab title="JavaScript" icon="code">
    ```javascript
    const response = await fetch('https://sandbox-api.example.com/v2/events', {
      method: 'GET',
      headers: {
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json',
      },
    });

    const events = await response.json();
    console.log(events);
    ```
  </Tab>

  <Tab title="Python" icon="python">
    ```python
    import requests

    headers = {
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json',
    }

    response = requests.get('https://sandbox-api.example.com/v2/events', headers=headers)
    events = response.json()
    print(events)
    ```
  </Tab>
</Tabs>

<Callout kind="success" collapsed="false">
  Success! You should see a JSON array of events. Each event includes details like `id`, `type`, and `timestamp`.
</Callout>

<Expandable title="Troubleshooting Common Issues" default-open="false">
  **No events returned?**

  - Verify your `API_KEY` is for the correct sandbox.
  - Check HTTP status: `401` means invalid auth, `404` means wrong endpoint.

  **Rate limited?**
  Sandbox limits: 100 requests per minute. Upgrade for production.
</Expandable>
