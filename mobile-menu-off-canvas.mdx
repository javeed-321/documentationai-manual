## Overview

The WPTE Builder lets you design fully customizable mobile menus and off canvas panels using Elementor, so you can create modern, responsive navigation and slide-in content areas tailored for both mobile and desktop visitors.

## Prerequisites

Before you start building a mobile menu or off canvas panel, confirm that:

- The latest version of the [Travel Monster theme](https://wptravelengine.com/wordpress-travel-themes/travel-monster/) is installed and activated
- The Elementor plugin is installed and activated
- The [WTE Elementor](https://wordpress.org/plugins/wte-elementor-widgets/) plugin is installed and activated

## Building a mobile menu

The Mobile Menu Builder lets you replace the theme's default mobile menu with a custom layout you design yourself.

<Steps title-type="h3">
  <Step title="Create a mobile menu">
    Go to **WPTE Builder > Mobile Menu**, click **Add New**, enter a name for your mobile menu, and click **Publish**.

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2026/03/Screenshot_032726_025550_PM-1024x373.jpg" alt="Creating a new mobile menu in WPTE Builder" width="1024" height="373" />
  </Step>

  <Step title="Edit with Elementor">
    Click **Edit with Elementor** to launch the Elementor editor, where you can design your mobile menu using drag-and-drop widgets.
  </Step>

  <Step title="Add the recommended widgets">
    Use these widgets to assemble a typical mobile menu:

    - **Navigation Menu** – displays your site menu
    - **Site Logo** – adds your branding
    - **Off Canvas** – adds a toggle that opens a slide-in menu
    - **Search** – adds search functionality

    <Callout kind="info">
      You can also add any other Elementor widget — buttons, social icons, announcements, or promotional messages — to your mobile menu layout.
    </Callout>

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2025/12/Screenshot_122625_113731_AM.jpg" alt="Recommended widgets for a mobile menu layout in Elementor" width="1200" height="675" />
  </Step>

  <Step title="Apply the mobile menu">
    Once your design is ready, apply it as the active mobile header:

    - Navigate to **Appearance > Customize > Main Header > Header Builder**
    - Under **Type of Header**, select **Builder**
    - Choose the mobile menu you created

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2026/03/Screenshot_033026_100425_AM.jpg" alt="Applying a custom mobile menu under Header Builder settings" width="1200" height="675" />

    Your custom header applies automatically once **Builder** is selected as the layout option.
  </Step>
</Steps>

## Building an off canvas panel

The Off Canvas Builder lets you create reusable slide-in panels — mobile menus, sidebars, or contact panels — that can be triggered from anywhere on your site.

### How it works

Off canvas panels use a two-step system:

1. Create the panel layout in the **Off Canvas Builder**
2. Display it using the **Off Canvas widget**

### Creating an off canvas template

<Steps title-type="h4">
  <Step title="Create the template">
    Go to **WPTE Builder > Off Canvas Builder**, click **Add New**, enter a template name (for example, _Mobile Menu Panel_), and publish it.

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2026/03/Screenshot_032726_030530_PM-1024x253.jpg" alt="Creating a new off canvas template in WPTE Builder" width="1024" height="253" />
  </Step>

  <Step title="Design the panel">
    Click **Edit with Elementor** and design your panel using widgets such as:

    - Navigation Menu
    - Logo
    - Social Icons
    - Contact Info

    Click **Publish** when you're done.

    <Callout kind="info">
      Only published templates are available for selection in the Off Canvas widget.
    </Callout>
  </Step>
</Steps>

## Configuring the Off Canvas widget

Once your template is published, add the **Off Canvas** widget to your mobile menu (or anywhere else on your site) and configure the following settings.

### Toggle button

Controls how the button that opens the panel looks:

- **Icon** – select a menu icon (defaults to a hamburger icon)
- **Text** – an optional label shown next to the icon
- **Icon Position** – place the icon before or after the text

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2026/03/image-8.png" alt="Toggle button settings for the Off Canvas widget" width="800" height="500" />

### Panel settings

Controls how the slide-in panel behaves and which template it displays:

- **Panel Side** – open the panel from the left or right
- **Show Overlay** – enable a background overlay while the panel is open
- **Close on Overlay Click** – let visitors close the panel by clicking the overlay
- **Off Canvas Content** – select which published template to display inside the panel

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2026/03/image-9.png" alt="Panel settings for the Off Canvas widget" width="800" height="500" />

### Close button

Controls the button visitors use to dismiss the panel:

- **Icon** – select a close icon (defaults to an X icon)
- **Label** – an optional text label

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2026/03/image-10.png" alt="Close button settings for the Off Canvas widget" width="800" height="500" />
