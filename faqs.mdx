<ExpandableGroup>
  <Expandable title="Can I run a trip at multiple times in one day? #" default-open="false">
    &#x20;Yes. Add multiple time slots for the same date.
  </Expandable>

  <Expandable title="What happens when all seats are sold out?" default-open="false">
    &#x20;The system automatically marks the trip as Sold Out.
  </Expandable>

  <Expandable title="How do repeating schedules stop? " default-open="false">
    &#x20;You can stop with an end date or a repeat limit.
  </Expandable>

  <Expandable title="Can I list all trips with fixed dates on one page?" default-open="false">
    &#x20;Yes, use **\[WTE\_TRIPS\_FIXED\_STARTING\_DATES]**
  </Expandable>

  <Expandable title="What happens if I leave an attribute out of the Departure Calendar shortcode?" default-open="false">
    Leaving an attribute out or providing an empty value will make the calendar fall back to the **global settings** for that value.
  </Expandable>

  <Expandable title="How do I find a trip’s ID for the include/exclude shortcode attributes?" default-open="false">
    Go to your **WordPress Dashboard > Trips**. Hover over the trip title and look at the URL preview in the bottom-left of your browser. The link will contain something like post=1234; the number after post= is the trip ID you need.


  </Expandable>
</ExpandableGroup>
