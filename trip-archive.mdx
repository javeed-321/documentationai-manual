---
title: Trip Archive
description: >-
  These settings control how departure dates appear on trip cards when
  travellers browse your archive pages.
---

- **Show trips with fixed starting dates**: Enable this so only trips with set dates appear on trip archive pages.
- **Show Dates on Cards**: This option lets you manage whether departure dates are displayed directly on trip cards. If you turn this off, the date section will not appear on the trip cards of the archive page.
- **No. of Dates on Cards**: This setting decides how many upcoming departure dates should be shown on each trip card. For example, if you set this to 3, travellers will see the next three departure dates listed under each trip.
