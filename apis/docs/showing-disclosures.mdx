To open a brokerage account with DriveWealth, customers are required to review and consent to a set of predefined disclaimers and disclosures. The specific documents presented vary based on factors such as the account type, the customer’s geographic location, and other criteria outlined below.

Clients have the option to either embed the applicable disclosure URLs directly within their user interface or host them on their own web pages, depending on their preferred integration approach.

## Standard language presented

Fundamentally, a customer must be prompted on the platform that they have read and agreed to the agreements provided to them prior to continuing through the onboarding process. Agreement can be identified by having the customer digitally sign their full legal name, or through a checkbox. Through either path, typical language includes the following pattern:

> :exclamation: "By checking the box below you acknowledge that you have read and agree to all disclaimers and disclosures presented

<Callout kind="alert">
  Prior to exposing any disclosure language, review all material with legal counsel to ensure it complies with local regulations.
</Callout>

## Passing acceptance through the API

Once a customer has acknowledged that they have read and accepted all the applicable agreements, the `DISCLOSURES` and `MARGIN_DISCLOSURE`objects used to create the customer should have all required fields set to `true`.

:exclamation: Exception: The `findersFee` field must always be set to false.

Additionally, the API request requires a digital signature. This should be the customer's full legal name, passed as a string within the `signedBy`parameter, as demonstrated in the example below:

```json
{
  "type": "DISCLOSURES",
  "data": {
    "termsOfUse": true,
    "customerAgreement": true,
    "marketDataAgreement": true,
    "rule14b": true,
    "findersFee": false,
    "privacyPolicy": true,
    "dataSharing": true,
    "extendedHoursAgreement": true,    //optional
    "iraAgreement": true,              //optional 
    "optionsAgreement":true,           //optional
    "signedBy": "Calvin Broadus Jr."
  }
},
{
      "type": "MARGIN_DISCLOSURE",
      "data": {
        "marginAgreement": true       //optional
      }
    }
```
