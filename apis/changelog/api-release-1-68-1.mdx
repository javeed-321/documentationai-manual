# 🚀 New features

## Health savings accounts (HSA)

We are super excited to announce the launch of our Health Savings Account (HSA) **investing** account. With this new account [type](https://developer.drivewealth.com/apis/reference/enums#account-type), customers will be able to use HSA funds to make investments in their HSA account; to use towards furture medical expenses. We are offering the flowing investment flows for HSA accounts: Self directed, Robo Advisory, and Managed. To learn more about these different types of investment flows, [see here](https://developer.drivewealth.com/apis/reference/enums).

In order to get started with HSA accounts, please contact your relations manager or email us directly at [RMteam@drivewealth.com](mailto:rmteam@drivewealth.com). Please be aware this account type is only for U.S. residents whom have a valid social security number.

# 🎉 Feature enhancements

## Countries

We are now introducing a feature where users that trying to be onboarded from a [non active country](https://developer.drivewealth.com/apis/reference/get_countries), the user is automatically rejected from being created on the platform.

## ACATs

We enhanced our [asset transfer](https://developer.drivewealth.com/apis/reference/post_asset-transfers-acats) api. Starting this release, if an incorrect DTCC code known as `clearingNo` is passed; we will now reject the api request.

## KYC

We enhanced the ability to send users to phsyical document review if the user is living in the United State but has a citizenship in a DOC country list.

# 👠🐛 Squashing bugs

## One Settlement

We had an issue with [One Settlement](https://developer.drivewealth.com/apis/reference/get_settlements-settlementid). When settlement reports finished processing they would stay in `PENDING` and not move into a `SUCCESSFUL` state. We corrected that issue with this release.
