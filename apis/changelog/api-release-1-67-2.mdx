# 🚀 New features

We add a new field `cashPendingSettlement` to [Account summary](https://developer.drivewealth.com/apis/reference/get_accounts-accountid-summary) endpoint. `cashPendingSettlement` is the amount of unsettled cash not included in cash available to trade.
