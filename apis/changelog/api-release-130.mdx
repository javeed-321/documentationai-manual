## Features and Enhancements

### **Ability for Existing Users to Change Domicile and Address to Unsupported Country**

Existing users can now update their address and domicile to unsupported countries.

If an existing user changes to an unsupported country:

- The account `status` will be moved to `OPEN_NO_NEW_TRADES`
- The `closingReason` will be updated to `LEGAL_AML`
- The `statusComment ` will be updated to `Unsupported domicile country`

A new field `supportDomicile` has been added to the [List Allowed Countries](https://developer.drivewealth.com/reference/list-all-countries) API to support this change

New users will continue to receive an error message if they try to create an account with an unsupported country.

This change is not applicable to citizenship.

## Bug Fixes

- `timeInForce` field in notification event for `orders.created` now displays enum value as opposed to numeric value
- Fixed bug where KYC was triggered when not required
- Updated the logic in determining whether an automated wire transfer could be processed
