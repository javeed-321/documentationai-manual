Build travel and tour pages by clicking, dragging, and dropping WP Travel Engine's pre-made blocks — no coding required. This page covers how to enable the Full Site Editing (FSE) templates, how to edit the Single Trip template with WP Travel Engine blocks, and how to use the built-in Trip Review patterns.

<Callout kind="info">
  Need help with a specific step? Jump to a section using the table of contents, or open a [support ticket](https://wptravelengine.com/support-ticket/) and the WP Travel Engine team will help you out.
</Callout>

## Enable FSE templates

Starting with WP Travel Engine 5.9.0, you can enable dedicated FSE templates for your Single Trip, Trip Archive, Trip Search Result, and Taxonomy pages.

<Steps title-type="h3">
  <Step title="Open Display Settings">
    Go to **WP Travel Engine > Settings > Miscellaneous > Display Settings**.
  </Step>

  <Step title="Enable the FSE template option">
    Turn on the FSE template setting. This automatically assigns the new FSE templates to your Single Trip, Trip Archive, and Trip Search Result pages.

    <Callout kind="alert">
      Skip this step if you're using a WP Travel Engine–compatible FSE theme such as Travelverse — the templates are already wired up for you.
    </Callout>
  </Step>

  <Step title="Assign a template to Taxonomy pages">
    Taxonomy pages (like Destination or Activity) and the Trip Search Result page aren't assigned automatically. For each one:

    1. Create a new page with the title you want (for example, "Destination").
    2. Open the page in the editor, click **Pages**, then **Swap Template**.
    3. In the popup, choose the WP Travel Engine template you want to use.
    4. Confirm your selection.
  </Step>
</Steps>

## Edit the Single Trip template

WP Travel Engine currently ships flexible blocks only for the Single Trip template — you won't need to touch any other FSE template.

<Steps title-type="h3">
  <Step title="Open the Site Editor">
    From your WordPress dashboard, go to the **Editor**.
  </Step>

  <Step title="Go to Templates">
    In the Site Editor sidebar, select **Templates**.
  </Step>

  <Step title="Select the Single Trip template">
    You'll see the full list of FSE templates provided by WP Travel Engine. Open the **Single Trip** template.
  </Step>

  <Step title="Customize the blocks">
    The template loads with sample data so you can preview the layout. Click any block to adjust its color, spacing, typography, and other style options.

    <Callout kind="tip">
      Sample data only appears in the editor. Open any real trip on the frontend to see your actual trip content in the same layout.
    </Callout>
  </Step>
</Steps>

## Available Single Trip blocks

Each block below can be added, rearranged, or restyled independently on the Single Trip template.

### Trip Booking block

Displays the trip's price, discount badge, global highlights, and booking button as one composed block, each with its own text, styling, and behavior.

- **Booking button** — set a custom background color, border color, and font style.
- **Discount badge** — surface discounts or special offers to catch a traveler's attention.
- **Pricing** — choose whether to show the regular price, sale price, or both.
- **Global highlights** — call out the trip's key attractions right next to the booking button.

### Trip Duration block

Shows the trip's duration anywhere on the page. Pick from several built-in styles to match your site's design.

### Trip Description block

Displays the trip's description with full control over font, color, and styling so the content matches your site's branding.

### Trip Highlights block

Turns trip highlights into an eye-catching bulleted list. Customize icon size, color, and spacing.

### Trip Facts block

Shows key trip details — trip type, meals, transportation, and more — as a clear, icon-led list. Icons can be restyled to match your branding.

### Trip Gallery block

Presents the trip's best photos in a gallery layout, built in just a few clicks.

### Cost Excludes block

Lists what's not included in the trip price, each item paired with an icon. Customize icon size, color, and spacing.

### Cost Includes block

Lists what's included in the trip price, each item paired with an icon. Customize icon size, color, and spacing.

### Trip FAQs block

Adds a customizable FAQ section to the trip page — useful for answering common traveler questions and improving page SEO.

### Trip Itinerary block

Builds a timeline-style itinerary. Add and edit titles, descriptions, icons, and dates for each itinerary item.

### Trip Itinerary Altitude Chart block

Plots the trip's altitude changes across the itinerary as a chart. Customize chart colors, altitude unit, axis, and line tension.

<Callout kind="info">
  This block requires the **Advanced Itinerary Builder** add-on.
</Callout>

### Trip Map block

Embeds an interactive map with adjustable pin locations. Visitors can zoom and pan, and you can adjust the map height.

### Trip Enquiry block

Adds a trip enquiry form so visitors can reach out directly from the trip page. Style the form to match your site's branding.

### WP Travel Engine Tab block

Organizes trip information into tabs. Configure color, typography, and the padding and margin between elements.

### Trip Fixed Starting Dates block

Displays a trip's fixed starting dates with automated scheduling behavior. Customize the color scheme, font styles, and layout.

<Callout kind="info">
  This block requires the **Fixed Starting Dates** add-on.
</Callout>

### Trip Rating block

Covers three related blocks, grouped together because they all surface review data on the trip page:

- **Star Rating block** — displays a star rating to build credibility and trust.
- **Trip Ratings block** — displays the average customer rating (for example, 4 or 5 stars).
- **Reviews Count block** — shows the total number of reviews to reinforce social proof.

<Callout kind="info">
  These blocks require the **Trip Review** add-on.
</Callout>

### Stars Bar Graph block

Turns customer star ratings into a bar graph. Customize bar colors, fonts, and spacing.

<Callout kind="info">
  This block requires the **Trip Review** add-on.
</Callout>

### Trip Review Form block

Adds a pre-designed form travelers can use to submit a review. Style the form to match your site's branding.

<Callout kind="info">
  This block requires the **Trip Review** add-on.
</Callout>

## Use the Trip Review patterns

WP Travel Engine includes four built-in patterns for displaying trip reviews. Like the review-related blocks above, these patterns require the **Trip Review** add-on.

<Columns cols="2">
  <Card title="Review Block pattern" href="#" icon="star">
    Displays a single trip review as a self-contained block, ready to drop anywhere on the page.
  </Card>

  <Card title="Aggregate Reviews pattern" href="#" icon="layers">
    Rolls up review data across a trip into one aggregated summary view.
  </Card>

  <Card title="Average Ratings pattern" href="#" icon="star-half">
    Shows the trip's average rating at a glance.
  </Card>

  <Card title="Review List pattern" href="#" icon="list">
    Lists multiple trip reviews in a scrollable, structured layout.
  </Card>
</Columns>

You can insert any of these patterns from the block inserter's **Patterns** tab while editing a page or template that supports them.
