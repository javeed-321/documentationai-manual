## Overview

The Featured Trip widget lets you showcase a single trip on any page using Elementor.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/featured-trip-1024x406.png" alt="Featured Trip widget rendered on a page" width="1024" height="406" />

## Layout settings

- **Widget Layout** – select from three layout options to display the trip; each customizes the appearance of the Featured Trip widget

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/layout-5.png" alt="Layout options for the Featured Trip widget" width="800" height="500" />

## Query settings

- **Show Featured Trip** – select the featured trip you want to display

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/query-5.png" alt="Query settings for the Featured Trip widget" width="800" height="500" />

## Additional settings

- **Featured Ribbon** – displays a "featured" ribbon on the trip
- **Discount** – displays the discount percentage
- **Review** – displays trip reviews
- **Location** – displays the trip's location
- **Title** – displays the trip title
- **Sub Title** – displays the trip's subtitle
- **Trip Meta** – adds the title meta to display for the trip
- **Price** – displays the trip price
- **Show Striked Price on Sale** – displays the struck-through original price for trips on sale
- **Duration Type** – choose whether trip duration displays in days or nights
- **Price Label** – sets the price label text
- **Wishlist** – displays the wishlist icon
- **View Details Button** – displays a "View Details" button
- **Button Label** – sets the text for the button label

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/Additional-5.png" alt="Additional settings for the Featured Trip widget" width="800" height="500" />

## General style settings

- **Background Color** – sets the background color for the widget section
- **Padding** – adjusts the padding around the content within the widget section
- **Border Radius** – controls the roundness of the corners
- **Border Type** – sets the border type for the widget section
- **Box Shadow** – configures the box shadow effect for the trip card within the widget section

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/General-2.png" alt="General style settings for the Featured Trip widget" width="800" height="500" />
