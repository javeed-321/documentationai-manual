## Install Travel Monster on your WordPress site

Travel Monster ships as a downloadable theme .zip file that you upload through the WordPress admin. Follow these steps to get it installed and activated.

<Steps title-type="h3">
  <Step title="Download the theme file">
    Go to the [Travel Monster theme page](https://wptravelengine.com/wordpress-travel-themes/travel-monster/) and click **Get it Now** to download the installation file to your computer.
  </Step>

  <Step title="Open the Themes screen">
    Log in to your WordPress website's admin dashboard and go to **Appearance > Themes**.
  </Step>

  <Step title="Start a new theme upload">
    Click **Add New**, then click **Upload Theme**.
  </Step>

  <Step title="Select the downloaded file">
    Choose the `.zip` file you downloaded in the first step.
  </Step>

  <Step title="Install the theme">
    Click **Install Now** and wait for WordPress to finish uploading and installing the theme files.
  </Step>

  <Step title="Activate Travel Monster">
    Once installation completes, click **Activate** to make Travel Monster your site's active theme.
  </Step>
</Steps>

## Verify installation

After activation, **Travel Monster** appears as the active theme on the **Appearance > Themes** screen, and your site's front end reflects the theme's default layout.

<Callout kind="alert">
  If you're using Safari on macOS to download the theme file, Safari may automatically unzip it after downloading. WordPress requires the theme file to be uploaded as a `.zip`, so if this happens, you'll need to [stop Safari from automatically unzipping downloaded files](https://apple.stackexchange.com/questions/961/how-to-stop-safari-from-unzipping-files-after-download) before re-downloading and uploading it.
</Callout>
