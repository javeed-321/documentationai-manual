# Akamai Functions Documentation

> Akamai Functions uses Spin to run edge native applications on Akamai Cloud. As a globally distributed PaaS Akamai Functions offers: Fast and resilient hosting for Spin applications, no maintenance tasks for infrastructure, fast application execution and availability in multiple regions across the world, automatic distribution and availability in multiple regions, and a URL that persists across deployments.
