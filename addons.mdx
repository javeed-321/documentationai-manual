## Overview

WP Travel Engine pro addons unlock advanced capabilities for your travel booking site. You can enable installment payments, manage waitlists for popular trips, integrate webhooks for real-time notifications, configure file downloads for itineraries, add travel insurance options, send WhatsApp alerts, and create private trips. These addons integrate seamlessly with your WordPress setup to enhance user experience and streamline operations.

<Callout kind="info">
Review your WP Travel Engine Pro license to access these addons. Install them via the WordPress admin under Plugins > Add New.
</Callout>

## Setting Up Webhooks and API Integrations

Configure webhooks to receive real-time events like new bookings or cancellations.

<Steps>
  <Step title="Enable Webhooks" icon="settings">
    Navigate to WP Travel Engine > Settings > Integrations > Webhooks. Add your endpoint URL, such as `https://your-webhook-url.com/webhook`.
  </Step>
  <Step title="Select Events" icon="zap">
    Choose events: `booking.created`, `booking.updated`, `booking.cancelled`.
  </Step>
  <Step title="Test Integration" icon="play">
    Create a test booking and verify the payload at your endpoint.
  </Step>
</Steps>

Here is a sample webhook payload for a new booking:

<CodeGroup tabs="JSON">
  ```json
  {
    "event": "booking.created",
    "trip_id": 123,
    "customer": {
      "name": "John Doe",
      "email": "john@example.com"
    },
    "total": 299.99
  }
  ```
</CodeGroup>

For API integrations, use the REST endpoints at `https://yoursite.com/wp-json/wte/v1/trips`.

<ParamField path="trip_id" param-type="integer" required="true">
  Unique trip identifier.
</ParamField>

<ParamField query="api_key" param-type="string" required="true">
  Your API authentication key.
</ParamField>

## Configuring File Downloads and Travel Insurance

<Tabs>
  <Tab title="File Downloads" icon="download">
    Enable itinerary PDFs in WP Travel Engine > Settings > File Downloads.

    <Steps>
      <Step title="Upload Template">
        Upload a custom PDF template for trip details.
      </Step>
      <Step title="Set Access">
        Restrict downloads to logged-in users only.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Travel Insurance" icon="shield">
    Activate in Checkout > Addons > Insurance.

    Set provider details and commission rates. Customers see options at checkout.

    ```php
    // Shortcode to display insurance form
    [wte_insurance_form]
    ```
  </Tab>
</Tabs>

## Enabling WhatsApp Notifications and Private Trips

<Expandable title="WhatsApp Setup" default-open="true">
  Integrate WhatsApp Business API.

  1. Get your WhatsApp Business API credentials.
  2. Add to WP Travel Engine > Settings > Notifications > WhatsApp.
  3. Map phone numbers to customer profiles.

  Test with a sample message:

  ````bash
  curl -X POST https://api.whatsapp.com/send \
    -d "phone=1234567890&text=Booking confirmed for Trip ID: 123"
  ````
</Expandable>

<Expandable title="Private Trips">
  Create exclusive trips visible only to specific users.

  In Trip Edit > Visibility > Private. Share access via unique links or user roles.
</Expandable>
