# API Definitions Documentation

> Akamai's API Definitions lets you register, manage, and deliver your APIs via Akamai in an efficient and secure manner.  Several products and features utilize API definitions, including: API Acceleration, API Discovery, API Gateway, Bot Manager, Kona Site Defender, and API protector with ASM module.

## API Reference: Resources and operations

- [List resources and operations](https://techdocs.akamai.com/api-definitions/reference/get-resources-and-operations.md): List all of your resources and resource operations for an API endpoint.
- [Create a resource operation](https://techdocs.akamai.com/api-definitions/reference/post-resource-operation.md): Create a resource operation. These operations define the purposes of your API resources. Use them to identify the expected usage of your resources to protect endpoints from bot traffic.
- [List resource operations](https://techdocs.akamai.com/api-definitions/reference/get-resource-operations.md): List all of your resource operations and their resources.
- [Get a resource operation](https://techdocs.akamai.com/api-definitions/reference/get-resource-operation.md): Get details about a specific resource operation.
- [Update a resource operation](https://techdocs.akamai.com/api-definitions/reference/put-resource-operation.md): Update details about a resource operation. You can change the operation's name, method, purpose, and more.
- [Delete a resource operation](https://techdocs.akamai.com/api-definitions/reference/delete-resource-operation.md): Remove a specific resource operation.
- [Query operations](https://techdocs.akamai.com/api-definitions/reference/post-search-operation.md): Get a filtered list of operations and their endpoints and resources. You can filter by date ranges, activation statuses, API Endpoint hostnames, and resource paths. For a simpler search, run [Search operations](/reference/get-search-operations).
- [Search operations](https://techdocs.akamai.com/api-definitions/reference/get-search-operations.md): Get a filtered list of operations and their endpoints and resources. Use `queryType` to filter by date ranges or activation statuses. For more complex queries, run [Query operations](/reference/post-search-operation).
- [Verify existing operations](https://techdocs.akamai.com/api-definitions/reference/post-operation.md): Verify that operations exist. Specify a list of operation summaries and receive a list of matching operations and their details, along with any submission errors.
