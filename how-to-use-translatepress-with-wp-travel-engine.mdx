## Overview

WP Travel Engine emails can be sent automatically in your customer's preferred language when you translate them with TranslatePress. This guide walks through installing TranslatePress, translating each email template type, and verifying the translation works end to end.

## Prerequisites

Before you begin, make sure you have:

- A WordPress website with WP Travel Engine installed and activated.
- The TranslatePress plugin installed and activated.
- The languages you want to support already added in TranslatePress (for example, French, Spanish, or German).

<Callout kind="info" collapsed="false">
  TranslatePress's free version supports up to two languages. To add more than two languages, you need the premium version of TranslatePress.
</Callout>

### Install and set up TranslatePress

<Steps>
  <Step title="Upload the plugin" title-type="p">
    Go to **Plugins → Add New → Upload Plugin**, then upload the TranslatePress plugin file.
  </Step>

  <Step title="Activate TranslatePress" title-type="p">
    Install and activate the plugin.
  </Step>

  <Step title="Add your languages" title-type="p">
    Go to **Settings → TranslatePress** and add the languages you want to support. Configure the language switcher here as well if you want visitors to switch languages on the front end.
  </Step>

  <Step title="Enable automatic translation (optional)" title-type="p">
    Turn on automatic translation if you want TranslatePress to pre-translate content before you review it.
  </Step>
</Steps>

## Configure email translation for WP Travel Engine

To make sure booking emails go out in each customer's preferred language, translate the WP Travel Engine email templates through TranslatePress. Follow the steps below carefully.

### Step 1: Open email notification settings

1. Go to your WordPress dashboard.
2. Navigate to **WP Travel Engine → Settings → Extensions → Emails → Notifications**.
3. Review the list of available templates, grouped under **Admin Emails** and **Customer Emails**.

Above the template list, you'll see an **Email Language** dropdown.

### Step 2: Select the language

Click the **Email Language** dropdown above the templates list and select the language you want to translate into — for example, Nepali, French, or Spanish. Selecting a language switches the templates into that language's editing mode so you can add translations.

### Step 3: Translate email templates

1. Choose the template you want to translate (for example, **Booking Confirmation** or **Payment Confirmation**).
2. Open the template and manually translate the subject line and email content into the selected language.
3. Save your changes.

Repeat this process for every template you want to translate.

<Callout kind="alert" collapsed="false">
  Always leave text inside curly braces, like `{trip_name}`, exactly as it is. Modifying or removing a tag stops the dynamic information from displaying correctly in the email.
</Callout>

### Step 4: Test your translations

<Steps>
  <Step title="Switch the site language" title-type="p">
    Switch your website to the translated language using the TranslatePress language switcher.
  </Step>

  <Step title="Make a test booking" title-type="p">
    Complete a test booking on the front end to trigger the automated emails.
  </Step>

  <Step title="Verify the email" title-type="p">
    Confirm that the subject and content appear in the selected language, that dynamic information such as trip name, customer name, and booking details display correctly, and that formatting like bold text and links remains intact.
  </Step>
</Steps>

Emails are sent automatically in the language selected during the booking process.

<Callout kind="info" collapsed="false">
  Dynamic tags such as `{trip_booking_details}` generate content like the package name, trip start date, and trip end date. TranslatePress can't translate the words generated inside these dynamic tags. Use Loco Translate instead for those strings — see [how to translate themes and plugins using Loco Translate](/article/how-to-translate-themes-and-plugins-using-loco-translate).
</Callout>

## Translating emails using Advanced Email Automator

Automated emails created with Advanced Email Automator follow the same language selection process as standard notifications.

1. Go to **WP Travel Engine → Settings → Extensions → Emails → Notifications**.
2. Use the **Email Language** dropdown above the template list to select the language you want to translate into.
3. Locate the automated email template you created with Advanced Email Automator.
4. Translate the subject and content, then click **Save Changes**.

Once saved, the automated email sends in the selected language whenever the automation triggers.

## Translating emails using Email Customizer

Emails built with Email Customizer also follow the same language selection process.

1. Go to **WP Travel Engine → Email Customizer**.
2. Use the **Email Language** dropdown next to the template selection dropdown to choose the language you want to translate into.
3. Translate the email content, then click **Save Changes**.
4. Make a test booking and check the email to confirm the content appears in the selected language.

Emails are sent automatically in the language selected at the time of booking.

## Translating emails using Per Trip Email

Per-trip emails follow the same language selection process as the other email types.

1. Go to **WP Travel Engine → Per Trip Email**.
2. Open an email template.
3. Use the Language dropdown shown above the trip selection field.
4. Translate the email content, then click **Save Changes**.
5. Make a test booking and check the email to confirm the content appears in the selected language.

Emails are sent automatically in the language selected during booking.
