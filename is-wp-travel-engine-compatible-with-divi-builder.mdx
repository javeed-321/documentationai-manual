---
title: Is WP Travel Engine Compatible with Divi Builder?
description: >-
  WP Travel Engine hasn't been specifically tested with the Divi theme, but it's
  expected to work smoothly, with the possibility of minor layout differences.
type: guide
---
WP Travel Engine hasn't been specifically tested against the Divi theme, but it's expected to function smoothly with it. Because Divi generates its own theme-level markup and styling, you may see minor layout differences depending on how a given Divi theme is coded.

<Callout kind="tip">
  If you run into a layout issue on a Divi-built site, it's typically a CSS conflict rather than a functional incompatibility. Hiring a freelancer familiar with Divi's theme structure is usually the fastest way to resolve design-specific issues.
</Callout>
