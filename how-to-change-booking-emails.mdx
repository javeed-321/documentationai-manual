---
title: How to Change Booking Emails
description: >-
  Update the email address that receives admin booking notifications in WP
  Travel Engine.
type: guide
---
You can change the booking email via **Dashboard → WP Travel Engine → Settings → Emails → Settings → Admin Notification Emails**.

You can add multiple email addresses separated by a comma (`,`) with no spaces.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/11/image-1024x490.png" width="1024" height="490" alt="Admin Notification Emails field under Emails settings" />

<Callout kind="info">
  The same field also handles the Enquiry Email address.
</Callout>
