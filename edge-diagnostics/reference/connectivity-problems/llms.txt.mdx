# Edge Diagnostics Documentation

> Edge Diagnostics allows you to diagnose your server, DNS, and network problems from Akamai servers around the world.

## API Reference: Connectivity problems

- [Run the Connectivity problems scenario](https://techdocs.akamai.com/edge-diagnostics/reference/post-connectivity-problems.md): Launches an [asynchronous](/reference/asynchronous-processes) request to simultaneously run [Launch a GREP request](/reference/post-grep), [Request content with cURL](/reference/post-curl), and [Test network connectivity with MTR](/reference/post-mtr) operations for a URL. It may help you diagnose issues with slow download and high response time. Successful operations return fetched GREP, cURL, and MTR data.
- [Get the Connectivity problems scenario response](https://techdocs.akamai.com/edge-diagnostics/reference/get-connectivity-problems-request.md): Returns the status of the [asynchronous](/reference/asynchronous-processes) [Run the connectivity problems scenario](/reference/post-connectivity-problems) request. Operations with the `SUCCESS` status include also fetched GREP, cURL, and MTR data.
