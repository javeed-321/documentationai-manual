# Edge Diagnostics Documentation

> Edge Diagnostics allows you to diagnose your server, DNS, and network problems from Akamai servers around the world.

## API Reference: Edge server locations

- [List available edge server locations](https://techdocs.akamai.com/edge-diagnostics/reference/get-edge-locations.md): Lists active edge server locations you can use to run [Request content with cURL](/reference/post-curl), [Get domain details with dig](/reference/post-dig), [Test network connectivity with MTR](/reference/post-mtr), [Run the URL health check](/reference/post-url-health-check), [Run the connectivity problems scenario](/reference/post-connectivity-problems), and [Run the content problems scenario](/reference/post-content-problems) operations. To get a subset of edge servers supporting metadata tracer, run the [List available edge server locations for metadata tracing](/reference/get-mdt-locations) operation.
