# Edge Diagnostics Documentation

> Edge Diagnostics allows you to diagnose your server, DNS, and network problems from Akamai servers around the world.

## API Reference: IPA hostnames

- [List IP acceleration hostnames](https://techdocs.akamai.com/edge-diagnostics/reference/get-ipa-hostnames.md): Lists IP acceleration (IPA) hostnames you have  access to and can [generate a diagnostic link](/reference/post-user-diagnostic-data-groups) to collect  diagnostic data.
