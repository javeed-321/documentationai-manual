# Edge Diagnostics Documentation

> Edge Diagnostics allows you to diagnose your server, DNS, and network problems from Akamai servers around the world.

## API Reference: ARL translator

- [Translate an Akamaized URL](https://techdocs.akamai.com/edge-diagnostics/reference/post-translated-url.md): Provides basic information about a specific hostname or domain name, such as typecode, origin server, CP code, serial number, and TTL. A URL becomes an [Akamaized URL (ARL)](/docs/arl-syntax) once it's on an edge server.
