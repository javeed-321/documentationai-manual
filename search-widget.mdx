## Overview

The Search widget adds a search option to your pages using Elementor. You can enable or disable the search box and customize the appearance of the search icon to match your site design.

## Style settings

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2025/12/Screenshot_122425_031724_PM.jpg" alt="Search widget style settings in Elementor" width="294" height="387" />

### Enable search box

Toggle this option to show or hide the search box:

- **Yes** – displays the search box on the page
- **No** – hides the search box

### Icon color

Set the default color of the search icon.

### Icon hover color

Choose the color of the search icon when a visitor hovers over it.

### Icon size

Adjust the size of the search icon to fit your layout and design.
