## Plan richer trip pages with day-by-day detail

Use Advanced Itinerary Builder to turn a basic trip outline into a full daily plan that travelers can trust. You can show where guests stay each night, which meals are included, how long each day takes, and even how the altitude changes across the trip.&#x20;

An add-on is a small extension that adds more features to WP Travel Engine. If you run treks, tours, or multi-day packages, this add-on helps you present each day in a way that feels clear and professional.

You do not need to know WordPress deeply to use it. You will work from your WordPress dashboard, which is the main admin area with the menu on the left side of the screen.

<Callout kind="info" collapsed="false">
  Perfect for trekking and mountaineering companies, multi-day tour operators, adventure travel agencies, educational travel programs, and pilgrimage and cultural tours.
</Callout>

## What this add-on does

- **Day-by-day itinerary** - Add a title and description for each day of the trip.
- **Sleep modes and meals** - Show where travelers stay and which meals are included each day.
- **Extra itinerary details** - Add useful fields like walking distance, activities, or daily highlights.
- **Elevation charts** - Show altitude changes across the trip so travelers know what to expect.
- **Image galleries** - Add multiple photos to each day to make the itinerary more visual.

## What you'll need before you start

A plugin is a tool you install in WordPress to add features to your site.

- You have WP Travel Engine installed and activated on your WordPress site (Version 4.3.0 or higher).
- You have installed and activated the Advanced Itinerary Builder add-on.

Once those are ready, you can check what this add-on will help you show on your trip pages.

## Installing the Advanced Itinerary Builder add-on

This part gets the add-on ready inside WordPress so you can start using the extra itinerary fields on your trip pages.

<Callout kind="info" collapsed="false">
  See [how to activate a Pro add-on license key](/article/activate-pro-addon-license-key/) for the full installation and activation walkthrough.
</Callout>

That guide shows you how to install the add-on, activate it, and connect the license key so it works properly on your site.

### Checking that it's working

It is worth checking this before you start building trips. That way, you know the add-on is active and the extra fields are ready to use.

<Steps>
  <Step title="Open the Extensions area" title-type="p">
    Go to your WordPress dashboard. Then use the left sidebar and open **WP Travel Engine → Settings → Extensions**.

    You should see the Advanced Itinerary Builder tab under Extensions.
  </Step>

  <Step title="Open any trip and check the Itinerary tab" title-type="p">
    Edit any trip on your site. Then open the **Itinerary** tab on the trip edit screen.

    You should now see extra fields like Duration, Sleep Mode, Meals, Start Location, Altitude, and Itinerary Info.
  </Step>
</Steps>

If you can see those fields, the add-on is ready. Next, you can set up the options that will apply across all your trips.

## Configuring the global settings for Advanced Itinerary Builder

Global settings are site-wide settings. That means they affect all trips, not only one trip.

You can find them in your WordPress dashboard under **WP Travel Engine > Settings > Extensions > Advanced Itinerary Builder** on the left sidebar. Set these up first so your trip editors have the options they need later.

### Always Show All Itinerary

This setting controls how your itinerary looks when a traveler first opens a trip page. If you turn it on, every day opens by default. If you turn it off, travelers can open days one by one.

Say you run a long 12-day trek. Keeping all days collapsed can make the page feel shorter and easier to scan.

<Steps>
  <Step title="Open the Advanced Itinerary Builder settings" title-type="p">
    In your WordPress dashboard, go to **WP Travel Engine → Settings → Extensions → Advanced Itinerary Builder**.
  </Step>

  <Step title="Find the Always Show All Itinerary option" title-type="p">
    Look for **Always Show All Itinerary** in the settings page.
  </Step>

  <Step title="Choose how your itineraries should open" title-type="p">
    Turn the setting on if you want every day expanded on the frontend.

    Turn the setting off if you want travelers to click and open each day as needed.
  </Step>
</Steps>

### Sleep Mode Fields

Sleep modes are the accommodation choices you can pick for each itinerary day. This helps you show whether guests stay in a hotel, lodge, tent, guesthouse, or something else.

For example, if you run both luxury cultural tours and mountain treks, you might create options like "5 Stars Hotel," "Tea House," and "Camping." Then you can choose the right one for each day of each trip.

<Steps>
  <Step title="Open the sleep mode settings" title-type="p">
    Go to **WP Travel Engine → Settings → Extensions → Advanced Itinerary Builder** and look for **Sleep Mode Fields for Itinerary**.
  </Step>

  <Step title="Review the options you already have" title-type="p">
    Check the list of existing sleep modes. These are the accommodation types available when you edit a trip day later.
  </Step>

  <Step title="Add a new accommodation type" title-type="p">
    Click **Add Sleep Mode** near the bottom of the section.

    Then enter the name you want to use, such as "3 Stars Hotel," "Tea House," or "Homestay."

## Advanced Itinerary Builder trip-specific settings

These settings are for one trip at a time. You will add them when you edit a trip in WordPress.

The regular itinerary builder already gives you title and description fields for each day. This add-on adds more fields beside those, so you can show accommodation, meals, altitude, photos, and extra day-by-day details.

### Itinerary Title

This is the main name for the day. Use a short title that tells travelers what happens that day.

For example, you might write "Drive to Pokhara" or "Trek to Ghorepani." A clear title helps travelers scan the itinerary quickly.

<Steps>
  <Step title="Open the trip you want to edit" title-type="p">
    In your WordPress dashboard, open the trip from the left sidebar area where your trips are managed.

    Then go to the **Itinerary** tab in the trip editor.
  </Step>

  <Step title="Enter a clear title for the day" title-type="p">
    Type the day title into the **Itinerary Title** field.

    Use wording that matches the actual experience for that day.
  </Step>
</Steps>

<Image src="https://blob-cdn.documentation.ai/org-fd8ba769-7008-47cf-98f1-e0d78d98350b/doc-08c376b3-8054-4dc6-b874-0c65a04a623e/1786687649743-fzxl9qreaft-Itinerary-Title.Itinerary Title?fm=auto&auto=compress%2Cformat" width="1024" height="429" alt="" />

Once the title is in place, you can adjust how the day label appears.

### Days Label

This field lets you rename the day label. You are not limited to names like Day 1 or Day 2.

This is helpful when a day is different from the normal trip flow. For example, you might use "Arrival Day," "Optional Day," or "Rest Day."

<Steps>
  <Step title="Find the Days Label field" title-type="p">
    Open the itinerary day you want to edit and look for **Days Label**.
  </Step>

  <Step title="Enter the label you want travelers to see" title-type="p">
    Type a label such as "Day 1," "Rest Day," or "Optional Excursion."
  </Step>
</Steps>

### Duration

Use this field to show how long the day's activity takes. This helps travelers understand the pace of the trip.

For a walking tour, you might enter 4 hours. For a short transfer or local activity, you might use minutes instead.

<Steps>
  <Step title="Enter the time for the day's activity" title-type="p">
    Add the number in the **Duration** field.
  </Step>

  <Step title="Choose the right time unit" title-type="p">
    Select **Hour(s)** for longer activities such as trekking or touring.

    Select **Minute(s)** for shorter activities.
  </Step>
</Steps>

This is where you describe the day in full. You can include the route, key stops, activities, and anything guests should know.

<Steps>
  <Step title="Write the day's description" title-type="p">
    Add the main details into the **Itinerary Content** editor.

    Focus on what the traveler will do, see, and experience that day.
  </Step>

  <Step title="Format the important parts" title-type="p">
    Use the editor tools to add bold text, bullet lists, or links where needed.

    This is helpful for things like route highlights, packing reminders, or activity breakdowns.
  </Step>
</Steps>

  <Step title="Select the meals provided" title-type="p">
    Check **Breakfast**, **Lunch**, and **Dinner** as needed for that day.

For example, you might enter "Namche Bazaar" as the start location and 3440 as the altitude if your global settings use meters.

  </Step>

  <Step title="Enter the altitude value" title-type="p">
    In **Altitude**, enter the elevation number using the same unit you set in the global settings.
  </Step>
</Steps>

<Callout kind="info" collapsed="false">

## The elevation chart isn't showing up on my trip page

Check the **Start Location** and **Altitude** fields for your itinerary days. You need to fill in both fields for at least two days before the chart can appear.

If one of those fields is blank, the chart will not show. Start there first.

## The extra itinerary info fields aren't appearing

Go to the global settings at **WP Travel Engine → Settings → Extensions → Advanced Itinerary Builder** and make sure **Show Itinerary Info** is turned on.

Then open the trip and check that you entered values for those fields on the specific itinerary days. If a field is empty for a day, it will not appear on that day's page.

## Meals aren't showing for one of my days

Open that trip and edit the correct itinerary day. Then check the **Meals Included** section and make sure the right meal boxes are selected for that day.

Meals only show when they are checked on that specific day.

## I don't see the Advanced Itinerary Builder settings when I edit my trip

First, make sure the add-on is installed and activated. Then go to your WordPress dashboard and check **WP Travel Engine → Settings → Extensions** on the left sidebar.

If the add-on is active, you should see the Advanced Itinerary Builder settings there. If you do not, the add-on may not be installed or activated yet.

## My sleep mode options aren't showing up when I edit a trip

Sleep mode options do not appear automatically. You need to create them first in the global settings.

Go to **WP Travel Engine → Settings → Extensions → Advanced Itinerary Builder** and add your sleep modes under **Sleep Mode Fields**. After that, those options will appear when you edit each trip day.

## All my itinerary days are expanded and I want them collapsed

Open the global settings at **WP Travel Engine → Settings → Extensions → Advanced Itinerary Builder** and turn off **Always Show All Itinerary**.

That makes the itinerary days stay collapsed by default on the frontend. Travelers can still open them when they want.
