Travel Monster Pro lets you import a premium starter template to lay the foundation for your new website. The process is the same as importing the free starter template that ships with the base Travel Monster theme.

## Before you begin

<Callout kind="alert" collapsed="false">
  You need both of the following before you can import a premium starter template:

  - The [Demo Importer Plus](https://wordpress.org/plugins/demo-importer-plus/) plugin installed and activated
  - An [activated Travel Monster Pro license key](/install-and-activate-travel-monster-pro-license)
</Callout>

## Import a premium starter template

<Steps>
  <Step title="Open the Demo Importer Plus panel" title-type="p">
    Navigate to **Admin Dashboard > Appearance > Demo Importer Plus**. You'll see a list of available templates.

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/11/1-1024x493.png" width="1024" height="493" alt="Demo Importer Plus panel showing available Travel Monster starter templates" />
  </Step>

  <Step title="Choose a template" title-type="p">
    Pick the premium template you want to import. You can import the complete site or a single template individually.

    <Callout kind="tip" collapsed="false">
      If you're starting a new site, import the complete site so you get all the styles, settings, and demo content in one go.
    </Callout>
  </Step>

  <Step title="Start the import" title-type="p">
    Click **Import Complete Site** and follow the on-screen process.

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/11/1-1-1024x476.png" width="1024" height="476" alt="Import Complete Site button in the Demo Importer Plus interface" />
  </Step>
</Steps>

<Callout kind="info" collapsed="false">
  The import can take a few minutes depending on your host's performance. Don't navigate away — you'll be notified once the process completes.
</Callout>

## Server requirements for a smooth import

The more images a starter site has, the longer the import takes. If the import fails partway through, it's usually because your server's `max_execution_time` setting is too low.

Make sure your hosting provider supports the following PHP configuration:

```php
php_value upload_max_filesize 128M
php_value post_max_size 128M
php_value max_execution_time 300
php_value max_input_time 300
```

<Callout kind="tip" collapsed="false">
  If you're not familiar with editing PHP settings, your hosting company can configure these values for you.
</Callout>
