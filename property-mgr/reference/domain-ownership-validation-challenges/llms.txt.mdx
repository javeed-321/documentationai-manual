# Property Manager Documentation

> Property Manager is a configuration tool that you use with other Akamai products to start serving the traffic to your site or application through the Akamai edge network.

## API Reference: Domain ownership validation challenges

- [Generate challenges to verify domain ownership](https://techdocs.akamai.com/property-mgr/reference/post-domain-ownership-challenges.md): Confirm you own all the domains for property hostnames you configure. This keeps your domains safe and prevents other customers from using them to serve traffic over the Akamai edge network. You need to complete this validation before activating your property.
