# Property Manager Documentation

> Property Manager is a configuration tool that you use with other Akamai products to start serving the traffic to your site or application through the Akamai edge network.

## API Reference: Includes

- [Create or clone an include](https://techdocs.akamai.com/property-mgr/reference/post-includes.md): **Limited availability** This operation either creates a new include from scratch or bases one on another include's rule tree. Version 1 of a new include is created automatically.
- [List includes](https://techdocs.akamai.com/property-mgr/reference/get-includes.md): **Limited availability** This operation lists includes available for the current contract and group. Use optional query parameters to only show includes that were modified within a specified time range or on a selected network. If you specify the `modifiedSince` parameter, `contractId` and `groupId` become optional. If you don't identify a contract and group, the operation lists all includes you have access to, modified within a specified time range.
- [Validate an include](https://techdocs.akamai.com/property-mgr/reference/get-include-validation.md): **Limited availability** Gets the results of an include validation against the specified parent property version that references the include.
- [Get an include](https://techdocs.akamai.com/property-mgr/reference/get-include.md): **Limited availability** This operation gets a specific include. You can call this operation by specifying any of the `includeId` members from a [list of includes](/reference/get-includes), or by running a GET on the `includeLink` response when [creating a new include](/reference/post-includes).
- [Remove an include](https://techdocs.akamai.com/property-mgr/reference/delete-include.md): **Limited availability** Removes a specific include, which you can only do if none of its versions are currently active. A successful DELETE results in a 200 response and a confirmation message. Attempting to delete an active include results in a 500 error. Attempting to delete an unknown include results in a 404 error.
- [List parent properties](https://techdocs.akamai.com/property-mgr/reference/get-include-parents.md): **Limited availability** Lists all active properties that reference a specific include. Combine optional query parameters to paginate, sort, and filter the results. Specify any `includeId` you get from a [list of includes](/reference/get-includes).
- [Activate or deactivate an include](https://techdocs.akamai.com/property-mgr/reference/post-include-activation.md): **Limited availability** This operation creates a new include activation, which deactivates any current activation. After a necessary delay, this activates your version's rule tree modifying how your edge content responds to end-user requests.   > **Note:** To reduce errors, avoid calling PAPI with separate clients on the same data. Avoid frequently polling status values. Instead, progressively increase the delay between calls.
- [List include's activations](https://techdocs.akamai.com/property-mgr/reference/get-include-activations.md): **Limited availability** This lists all activations for all versions of an include, on both production and staging networks.
- [Get an include activation](https://techdocs.akamai.com/property-mgr/reference/get-include-activation.md): **Limited availability** Gets details about an activation. The response also shows the results of a validation against the rule trees of active parent properties that reference the include. While you can ignore any warnings that indicate non-blocking, logical inconsistencies, you need to resolve all errors to activate an include.   You typically get a single activation from an `activationLink` when [launching a new activation](/reference/post-include-activation), and you follow up to poll its `status`. For activations whose `status` is `PENDING`, a `Retry-After` header provides an estimate for when it's likely to go live.  > **Note:** To reduce errors, avoid calling PAPI with separate clients on the same data. Avoid frequently polling status values. Instead, progressively increase the delay between calls.
- [Cancel an include's pending activation](https://techdocs.akamai.com/property-mgr/reference/delete-include-activation.md): **Limited availability** If you detect a problem with an include version while its activation is still `PENDING`, use this operation to cancel it. Make a DELETE request on the `activationLink` you get from the [Activate an include](/reference/post-include-activation) operation's response. Once you DELETE the activation, it no longer appears in the [list of activations](/reference/get-include-activations), but you can still [access it individually](/reference/get-include-activation).
- [Create a new include version](https://techdocs.akamai.com/property-mgr/reference/post-include-versions.md): **Limited availability** Create a new include version based on any previous version. All data from the `createFromVersion` populates the new version. Specify `createFromVersionEtag` if you want to ensure you're creating from a version that hasn't changed since you fetched it.
- [List include versions](https://techdocs.akamai.com/property-mgr/reference/get-include-versions.md): **Limited availability** Lists the include's versions, with results limited to the 500 most recent versions. Optionally paginate the results. Each include version indicates an activation status on different networks, and an `etag` digest useful when [cloning the include](/reference/post-includes).
- [Get the latest include version](https://techdocs.akamai.com/property-mgr/reference/get-latest-include-version.md): **Limited availability** This operation provides either the latest include version overall, or the latest one active on the production or staging networks. By default, the response yields the include version with the highest number. Specifying an `activatedOn` of `STAGING` or `PRODUCTION` yields the version that's currently active on either network.
- [Get an include version](https://techdocs.akamai.com/property-mgr/reference/get-include-version.md): **Limited availability** This polls the state of a specific include version, for example to check its activation status. When specifying `Accept: text/xml`, this operation provides the Akamai _metadata_ configuration data that's distributed to edge servers when you activate an include version. This XML data encapsulates the include version's component rules and is available on a read-only basis. Contact your Akamai representative if you need help interpreting it.
- [List available behaviors for an include](https://techdocs.akamai.com/property-mgr/reference/get-include-available-behaviors.md): **Limited availability** Lists the set of [behaviors](/reference/ga-behaviors) you may apply within an include version's rules. The available set depends on the product under which you created the property and any additional modules enabled under your account.
- [List available criteria for an include](https://techdocs.akamai.com/property-mgr/reference/get-include-available-criteria.md): **Limited availability** Lists the set of [criteria](/reference/ga-criteria) you may apply within an include version's rules. The available set depends on the product under which you created the property and any additional modules enabled under your account.
- [Get an include's rule tree](https://techdocs.akamai.com/property-mgr/reference/get-include-version-rules.md): **Limited availability** Gets the entire rule tree for an include version. See the [Rule Trees](/reference/rule-trees) section for details on the response object's structure. Also use this operation to update from one rule format to another more recent version, incrementing the assigned set of features. See [Update rules to a newer set of features](/reference/rule-format-schemas#update-rules-to-a-newer-set-of-features).
- [Update an include's rule tree](https://techdocs.akamai.com/property-mgr/reference/put-include-version-rules.md): **Limited availability** To write a rule tree to an include version, make a PUT request to the same resource as the GET request that reads it, passing in the rule object in the body of the request. See the [Rule Trees](/reference/rule-trees) section for details on the rule tree's structure. Use this operation also to [freeze a set of rules](/reference/rule-format-schemas#freeze-a-feature-set-for-a-rule-tree) to a rule format version to ensure no change in a deployed activation's behavior. Set the `validateRules` query parameter to `false` to bypass a set of validation tests that may significantly slow this operation's execution time. See [Validation best practices](/reference/validation-best-practices) for guidance on when to defer validation. See [Rule tree errors and warnings](/reference/rule-tree-errors-and-warnings) and [Validation errors](/reference/validation-errors) for information on how validation data is embedded within the response object.
- [Patch an include's rule tree](https://techdocs.akamai.com/property-mgr/reference/patch-include-version-rules.md): **Limited availability** Selectively modify a rule tree using [JSON patch](http://jsonpatch.com) syntax. Set the `validateRules` query parameter to `false` to bypass a set of validation tests that may significantly slow this operation's execution time. See [Validation best practices](/reference/validation-best-practices) for guidance on when to defer validation. See [Rule tree errors and warnings](/reference/rule-tree-errors-and-warnings) and [Validation errors](/reference/validation-errors) for information on how validation data is embedded within the response object.
- [Get a digest for an include's rule tree](https://techdocs.akamai.com/property-mgr/reference/head-include-version-rules.md): **Limited availability** Gets the rule tree's ETag without the rule tree object. Ordinarily when you [get a rule tree](/reference/get-include-version-rules), the response includes a large rule tree object. As discussed in [Concurrency control](/reference/concurrency-control), it includes a top-level `etag` data digest to use when [writing back the data](/reference/put-include-version-rules). Use this operation if you simply want to get the `ETag` as a header without the data.
