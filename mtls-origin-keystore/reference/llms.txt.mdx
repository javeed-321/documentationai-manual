## API Reference: Client certificate versions

- [Client certificate versions index](https://techdocs.akamai.com/mtls-origin-keystore/reference/client-certificate-versions/llms.txt): full category index
- [Rotate a client certificate](https://techdocs.akamai.com/mtls-origin-keystore/reference/post-client-cert-version.md): Create a new version in the client certificate specified by `certificateId`.
- [List client certificate versions](https://techdocs.akamai.com/mtls-origin-keystore/reference/get-client-cert-versions.md): Versions of the client certificate specified by `certificateId`.
- [Delete a client certificate version](https://techdocs.akamai.com/mtls-origin-keystore/reference/delete-client-certificate.md): Delete a client certificate version with the provided `certificateId` and `version`. [Learn more](/docs/manage-client-certificates#delete-a-client-certificate-version).
- [Upload a signed client certificate](https://techdocs.akamai.com/mtls-origin-keystore/reference/post-cert-block.md): Upload a signed `THIRD_PARTY` client certificate with the `AWAITING_SIGNED_CERTIFICATE` status. [Learn more](https://techdocs.akamai.com/mtls-origin-keystore/docs/upload-cert).

## API Reference: Client certificates

- [Client certificates index](https://techdocs.akamai.com/mtls-origin-keystore/reference/client-certificates/llms.txt): full category index
- [Create a client certificate](https://techdocs.akamai.com/mtls-origin-keystore/reference/post-client-cert.md): Create a client certificate with the provided name.

- [Get a client certificate](https://techdocs.akamai.com/mtls-origin-keystore/reference/get-client-cert.md): Get details of a client certificate.
- [Patch a client certificate](https://techdocs.akamai.com/mtls-origin-keystore/reference/patch-client-cert.md): Update the client certificate's name or notification emails.
