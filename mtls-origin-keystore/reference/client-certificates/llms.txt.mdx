# Mutual TLS Origin Keystore Documentation

> Use Mutual TLS Origin Keystore to manage client certificates for mTLS authentication between the Akamai edge server and the origin.

## API Reference: Client certificates

- [Create a client certificate](https://techdocs.akamai.com/mtls-origin-keystore/reference/post-client-cert.md): Create a client certificate with the provided name.
- [List client certificates under the account](https://techdocs.akamai.com/mtls-origin-keystore/reference/get-client-certs.md): List client certificates under the account.
- [Get a client certificate](https://techdocs.akamai.com/mtls-origin-keystore/reference/get-client-cert.md): Get details of a client certificate.
- [Patch a client certificate](https://techdocs.akamai.com/mtls-origin-keystore/reference/patch-client-cert.md): Update the client certificate's name or notification emails.
