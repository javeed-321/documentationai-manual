[Travel Monster Pro](https://wptravelengine.com/wordpress-travel-themes/travel-monster-pro/) is a premium plugin that extends the Travel Monster theme. It unlocks premium starter templates and additional customization features not available in the free version of the theme.

## Before you begin

You'll need an active purchase of Travel Monster Pro to download the plugin file. If you haven't purchased it yet, you can do so from the [Travel Monster Pro product page](https://wptravelengine.com/wordpress-travel-themes/travel-monster-pro/?utm_source=travel_monster_pro\&utm_medium=docs\&utm_campaign=upgrade_theme).

## Install and activate the plugin

<Steps title-type="h2">
  <Step title="Download Travel Monster Pro">
    Purchase and download the Travel Monster Pro plugin from the [Travel Monster Pro product page](https://wptravelengine.com/wordpress-travel-themes/travel-monster-pro/).
  </Step>

  <Step title="Log in to WordPress">
    Log in to your WordPress website's admin dashboard.
  </Step>

  <Step title="Open the plugin uploader">
    Navigate to **Plugins > Add New**.
  </Step>

  <Step title="Upload the plugin file">
    Click **Upload Plugin**.
  </Step>

  <Step title="Install the plugin">
    Choose the `.zip` file you downloaded, then click **Install Now**.
  </Step>

  <Step title="Activate the plugin">
    Once installation finishes, click **Activate**.
  </Step>
</Steps>

<Callout kind="success">
  Once activated, Travel Monster Pro is installed but still needs a valid license key before its premium features unlock. Continue to [How to Activate Travel Monster Pro License](/install-and-activate-travel-monster-pro-license) to finish setup.
</Callout>

## Getting help

If you run into any issues during installation or activation, contact the [WP Travel Engine support team](https://wptravelengine.com/support-ticket/).
