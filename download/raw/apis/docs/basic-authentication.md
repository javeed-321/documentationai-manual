# Basic Authentication

Basic Authentication utilizes a *username* and *password* combination for DriveHub access. This section outlines the workflow for new users and credential management.

## Step-by-step: First Login Sequence

* **Access Welcome Email:** Locating the "Welcome to DriveHub" email which contains your Organization Name and Username.
* **Reset Password:** Click the link in the Password Reset email. You must complete this within 5 calendar days before the link expires.
* **Establish MFA:** Following the password reset, you will be prompted to complete the MFA enrollment described in the [MFA setup guide](https://developer.drivewealth.com/apis/v1.82.0/docs/multi-factor-authentication-mfa).
* **Bookmark Access Dashboard:** Save the URL provided in the Welcome Email to bypass entering your Organization Name during future logins.

<Callout icon="❗️" theme="error">
  **Credential Expiration**

  Password reset links expire strictly after 5 calendar days. If the link expires, you must contact your administrator to trigger a new reset email.
</Callout>
