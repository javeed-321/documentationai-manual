# API Release 1.57

## API Release 1.57

## Deployed in Production - September 7th, 2023.

# 🚀New Features - What’s New?

#### Add new API endpoints to allow partners to consume DriveWealth's terms of service and publish these terms via API endpoints.

#### **Expected Behavior Change -** We are introducing 4 new endpoints to allow for a seamless process in the ability to acknowledge disclosures and gather disclosure information via API.

To learn more about this feature, see [here](https://developer.drivewealth.com/apis/docs/improving-disclosures).

# 🎉Feature Enhancements - We are making it better for you!!

#### Existing Feature - Currently, the PDT process includes several steps in regards to unlocking and locking accounts and as well the event notification not being delivered.

#### What is improving? - As part of the PDT enhancements, we will be improving automation for different parts of the current process. These enhancements include automatic unrestricted of accounts by end of day, automatic restriction of accounts in real-time and event notifications for both restriction and unrestricted.

To view the PDT events, see [here](https://developer.drivewealth.com/apis/docs/trading-violations#pattern-day-trades).
