# Security Center Documentation

> Akamai’s security products defend against many different types of attacks. For each attack, you generally want to know who is attacking and which site is being targeted. Different attacks, however, may require the use of different features of Akamai’s security product line. Sorting this out requires presenting specific information related to the situation—which is where Akamai Security Center comes in. It gives you the information you need in a clear and quickly scannable way. Security Center’s dashboard displays high-level information on security events, traffic, and attack activity, all separated into four categories: DoS attack, application layer attack, bot activity, and custom rule activity.
