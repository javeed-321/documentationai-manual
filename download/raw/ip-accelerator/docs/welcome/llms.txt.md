# IP Accelerator Documentation

> Akamai's IP Accelerator (IPA) empowers organizational agility by leveraging the Internet as a standard platform for delivering accelerated TCP/IP based enterprise applications to any user, on any device, anywhere in the world. Use IPA to improve the performance of your IP-based applications while avoiding the high capital expenditure often associated with private-WAN infrastructure. IPA also allows you to leverage key optimization technologies already integrated into Akamai's globally distributed platform such as dynamic mapping, route optimization, packet redundancy, and a high-performance transport protocol.
