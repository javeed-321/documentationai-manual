# UK Payment Purpose & Category Codes

From UK recommended Purpose Code list

These purpose and category codes can be optionally supplied for any payment, and certain codes are mandatory when making CHAPS payments (e.g. for Property related transactions).

The codes are derived from the Bank of England/Pay.UK published [UK Purpose Code list](https://www.bankofengland.co.uk/-/media/boe/files/payments/rtgs-renewal-programme/iso-20022/uk-recommended-purpose-code-list.pdf) which is a subset of the full international[ External Code Set](https://www.iso20022.org/catalogue-messages/additional-content-messages/external-code-sets) of all acceptable Purpose Codes, which is part of the ISO 20022 repository.
