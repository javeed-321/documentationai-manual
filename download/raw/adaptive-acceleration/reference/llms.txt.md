# Adaptive Acceleration Documentation

> Adaptive Acceleration syncs with ​Akamai​ real user monitoring to gather navigation and resource timing data and stores that data in a policy that's associated with your hostname. As requests for your hostname continue, policy data is gathered and reviewed to identify key resources.

Fetch the complete documentation index at: https://techdocs.akamai.com/adaptive-acceleration/llms.txt. Use this file to discover all available pages before exploring further. Append .md to any documentation page URL to get its markdown version.

## API Reference: Adaptive Acceleration report

- [Adaptive Acceleration report index](https://techdocs.akamai.com/adaptive-acceleration/reference/adaptive-acceleration-report/llms.txt): full category index
- [Get a property report](https://techdocs.akamai.com/adaptive-acceleration/reference/get-property.md): Gets the current Adaptive Acceleration report for a specific Ion property.
- [Reset a property report](https://techdocs.akamai.com/adaptive-acceleration/reference/post-property-reset.md): Resets the report Adaptive Acceleration uses to define a server push and preconnect assets. Adaptive Acceleration reviews current real-user monitoring data to reestablish this report.
