# Prolexic Analytics API Documentation

> Akamai's Prolexic managed services help protect your network infrastructure against DDoS attacks. They include managed options available for your entire data center, as well as for individual internet-facing applications. Prolexic services help reduce the risk of DDoS attacks while maintaining the availability of Internet-facing applications.
