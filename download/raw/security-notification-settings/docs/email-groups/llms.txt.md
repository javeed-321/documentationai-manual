# Security Notification Settings Documentation

> Akamai's Security Notification Settings application provides a unified, central location to manage how your organization receives automatic, real-time alerts across the application security portfolio. You can define who receives notifications and where they are delivered by integrating third-party messaging platforms like Slack, Microsoft Teams, PagerDuty, and custom webhooks.
