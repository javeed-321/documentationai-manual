# SIA Configuration API Documentation

> Akamai's Secure Internet Access (SIA) Configuration API offers a programmatic interface to manage policy settings to protect against enterprise security and acceptable user policy related events. A distributed configuration encapsulates all the rules for how to process DNS requests for your enterprise.

Fetch the complete documentation index at: https://techdocs.akamai.com/etp-config/llms.txt. Use this file to discover all available pages before exploring further. Append .md to any documentation page URL to get its markdown version.

## API Reference: Connection Credentials
- [Create a VPN credential](https://techdocs.akamai.com/etp-config/reference/post-vpn-credentials.md): Creates a new VPN credential.
- [List VPN credentials](https://techdocs.akamai.com/etp-config/reference/get-vpn-credentials.md): Provides all VPN credentials.
- [Get a VPN credential](https://techdocs.akamai.com/etp-config/reference/get-vpn-credential-details.md): Provides details for the specified VPN credential.
- [Delete a VPN credential](https://techdocs.akamai.com/etp-config/reference/delete-vpn-credential.md): Deletes the specified VPN credential.
- [Create a proxy credential](https://techdocs.akamai.com/etp-config/reference/post-proxy-credential.md): Creates a new proxy credential.
- [List proxy credentials](https://techdocs.akamai.com/etp-config/reference/get-proxy-credentials.md): Provides list of proxy credentials.
- [Get a proxy credential](https://techdocs.akamai.com/etp-config/reference/get-proxy-credential.md): Provides the proxy credential info for the specified `userName`.
- [Remove a proxy credential](https://techdocs.akamai.com/etp-config/reference/delete-proxy-credential.md): Deletes a specific proxy credential.
