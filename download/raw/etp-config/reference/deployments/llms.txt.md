# SIA Configuration API Documentation

> Akamai's Secure Internet Access (SIA) Configuration API offers a programmatic interface to manage policy settings to protect against enterprise security and acceptable user policy related events. A distributed configuration encapsulates all the rules for how to process DNS requests for your enterprise.

Fetch the complete documentation index at: https://techdocs.akamai.com/etp-config/llms.txt. Use this file to discover all available pages before exploring further. Append .md to any documentation page URL to get its markdown version.

## API Reference: Deployments
- [Create a configuration deployment](https://techdocs.akamai.com/etp-config/reference/post-deployment.md): Creates a new configuration deployment.
- [List configuration deployments](https://techdocs.akamai.com/etp-config/reference/get-deployments.md): Returns a history of deployments for the current configuration.
- [Get a configuration deployment](https://techdocs.akamai.com/etp-config/reference/get-deployment.md): Returns details of a specific  configuration deployment.
- [List deployment changes](https://techdocs.akamai.com/etp-config/reference/get-deployment-diff.md): Provides details of deployment changes.
- [List recent changes](https://techdocs.akamai.com/etp-config/reference/get-config-recent-changes.md): Returns all changes made since the last configuration deployment.
