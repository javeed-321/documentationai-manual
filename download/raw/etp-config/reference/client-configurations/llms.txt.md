# SIA Configuration API Documentation

> Akamai's Secure Internet Access (SIA) Configuration API offers a programmatic interface to manage policy settings to protect against enterprise security and acceptable user policy related events. A distributed configuration encapsulates all the rules for how to process DNS requests for your enterprise.

Fetch the complete documentation index at: https://techdocs.akamai.com/etp-config/llms.txt. Use this file to discover all available pages before exploring further. Append .md to any documentation page URL to get its markdown version.

## API Reference: Client Configurations
- [Get a client configuration](https://techdocs.akamai.com/etp-config/reference/get-client-configuration.md): Provides client configuration details.
- [Update a client configuration](https://techdocs.akamai.com/etp-config/reference/put-client-configuration.md): Updates the client configuration.
- [List client versions](https://techdocs.akamai.com/etp-config/reference/get-client-versions.md): Provides client versions.
- [Rotate the client version entitlement code](https://techdocs.akamai.com/etp-config/reference/post-rotate-entitlement-code.md): Rotates global entitlement code.
- [Update a client version](https://techdocs.akamai.com/etp-config/reference/put-client-version.md): Updates the details of the specific client version.
- [Download a client version](https://techdocs.akamai.com/etp-config/reference/get-client-version-download.md): Provides the link to download client version details.
- [List client devices](https://techdocs.akamai.com/etp-config/reference/get-client-devices.md): Provides client devices and their details.
- [Deactivate a client device](https://techdocs.akamai.com/etp-config/reference/post-device-de-activate.md): Deactivates the specified client device.
- [Re-activate a client device](https://techdocs.akamai.com/etp-config/reference/post-device-re-activate.md): Re-activates the specified device.
- [Get client status](https://techdocs.akamai.com/etp-config/reference/get-client-status.md): Provides details of software installed with device counts. Also specifies errors and device count with errors.
- [Create a network configuration](https://techdocs.akamai.com/etp-config/reference/post-network-configuration.md): Creates the network configuration.
- [Get the network configuration](https://techdocs.akamai.com/etp-config/reference/get-network-configuration.md): Provides network configuration details.
- [Update the network configuration](https://techdocs.akamai.com/etp-config/reference/put-network-configuration.md): Modifies the network configuration.
