# API Definitions Documentation

> Akamai's API Definitions lets you register, manage, and deliver your APIs via Akamai in an efficient and secure manner.  Several products and features utilize API definitions, including: API Acceleration, API Discovery, API Gateway, Bot Manager, Kona Site Defender, and API protector with ASM module.

Fetch the complete documentation index at: https://techdocs.akamai.com/api-definitions/llms.txt. Use this file to discover all available pages before exploring further. Append .md to any documentation page URL to get its markdown version.

## API Reference: API delivery settings
- [Get API privacy settings](https://techdocs.akamai.com/api-definitions/reference/get-api-privacy-settings.md): Returns the API privacy settings configured for an endpoint version and its assigned resources.
- [Edit API privacy settings](https://techdocs.akamai.com/api-definitions/reference/put-api-privacy-settings.md): Updates the API privacy settings configured for an endpoint version and its assigned resources.
- [Get cache settings](https://techdocs.akamai.com/api-definitions/reference/get-cache-settings.md): Returns the caching settings configured for an endpoint version and its assigned resources. You can set all objects independently from the root `customize` field.
- [Edit cache settings](https://techdocs.akamai.com/api-definitions/reference/put-cache-settings.md): Updates the caching settings configured for an endpoint version and its assigned resources.
- [Get CORS settings](https://techdocs.akamai.com/api-definitions/reference/get-cors-settings.md): Returns the cross-origin resource sharing (CORS) settings configured for an endpoint version.
- [Edit CORS settings](https://techdocs.akamai.com/api-definitions/reference/put-cors-settings.md): Updates the cross-origin resource sharing (CORS) settings configured for an endpoint version.
- [Get error response settings](https://techdocs.akamai.com/api-definitions/reference/get-error-response-setting.md): Returns the error response settings configured for an endpoint version.
- [Edit error response settings](https://techdocs.akamai.com/api-definitions/reference/put-error-response-setting.md): Updates the error response settings configured for an endpoint version.
- [Get an error response](https://techdocs.akamai.com/api-definitions/reference/get-error-responses-type.md): Returns a customizable error response of the selected type.
- [Edit an error response](https://techdocs.akamai.com/api-definitions/reference/put-get-error-responses-type.md): Updates a customizable error response of the selected type.
- [Get GraphQL cache settings](https://techdocs.akamai.com/api-definitions/reference/get-graphql-settings.md): Returns the GraphQL caching settings configured for an endpoint version.
- [Edit GraphQL cache settings](https://techdocs.akamai.com/api-definitions/reference/put-graphql-settings.md): Updates the GraphQL caching settings configured for an endpoint version.
- [Get GZIP settings](https://techdocs.akamai.com/api-definitions/reference/get-gzip-settings.md): Returns the GZIP compression settings configured for an endpoint version.
- [Edit GZIP settings](https://techdocs.akamai.com/api-definitions/reference/put-gzip-settings.md): Updates the GZIP compression settings configured for an endpoint version.
- [Get JWT settings](https://techdocs.akamai.com/api-definitions/reference/get-jwt-settings.md): Returns the JWT validation settings configured for an endpoint version and its assigned resources.
- [Edit JWT settings](https://techdocs.akamai.com/api-definitions/reference/put-jwt-settings.md): Updates the JWT validation settings configured for an endpoint version and its assigned resources.
- [Get routing settings](https://techdocs.akamai.com/api-definitions/reference/get-routing-settings.md): Returns the incoming request's routing, forwarding, and SureRoute settings configured for an endpoint version. You can run this operation if you're taking part in the API Gateway beta program.
- [Edit routing settings](https://techdocs.akamai.com/api-definitions/reference/put-routing-settings.md): Updates the incoming request's routing, forwarding, and SureRoute settings configured for an endpoint version. You can run this operation if you're taking part in the API Gateway beta program.
