## API Reference: Domains
- [Create a domain](https://techdocs.akamai.com/linode-api/reference/post-domain.md): Adds a new domain to DNS Manager. You must own the domain before adding it here. Be sure to point your registrar to our nameservers. Akamai Cloud does not act as a registrar.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `account_domain_creator` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `domains:read_write`   **CLI**  ```shell linode-cli domains create \   --type master \   --domain example.org \   --soa_email admin@example.org ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List domains](https://techdocs.akamai.com/linode-api/reference/get-domains.md): This is a collection of Domains that you have registered in Linode's DNS Manager.  Linode is not a registrar, and in order for these to work you must own the domains and point your registrar at Linode's nameservers.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `domain_viewer` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `domains:read_only`   **CLI**  ```shell linode-cli domains list ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Import a domain](https://techdocs.akamai.com/linode-api/reference/post-import-domain.md): Imports a domain zone from a remote nameserver. Your nameserver must allow zone transfers (AXFR) from the following IPs:  - 96.126.114.97 - 96.126.114.98 - 2600:3c00::5e - 2600:3c00::5f   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `domain_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `domains:read_write`   **CLI**  ```shell linode-cli domains import --domain example.com --remote_nameserver examplenameserver.com ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get a domain](https://techdocs.akamai.com/linode-api/reference/get-domain.md): This is a single domain that you have registered in DNS Manager. For this domain record to resolve, you must own the domain and point your registrar at Akamai Cloud's nameservers. Akamai Cloud does not act as a registrar.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `domain_viewer` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `domains:read_only`   **CLI**  ```shell linode-cli domains view 123 ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Update a domain](https://techdocs.akamai.com/linode-api/reference/put-domain.md): Update information about a domain in DNS Manager.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `domain_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `domains:read_write`   **CLI**  ```shell linode-cli domains update 1234 \   --retry_sec 7200 \   --ttl_sec 300 ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Delete a domain](https://techdocs.akamai.com/linode-api/reference/delete-domain.md): Deletes a domain from DNS Manager. The domain will be removed from our nameservers shortly after this operation completes. This also deletes all associated domain records.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `domain_admin` - **OAuth scopes**. - [Clone a domain](https://techdocs.akamai.com/linode-api/reference/post-clone-domain.md): Clones a domain and all associated DNS records from a domain that is registered in DNS manager.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. - [Create a domain record](https://techdocs.akamai.com/linode-api/reference/post-domain-record.md): Adds a new domain record to the zonefile this domain represents.
