## API Reference: Resource locking
- [Create a resource lock](https://techdocs.akamai.com/linode-api/reference/post-resource-lock.md): __Beta__ Create a lock for a resource, to help prevent you from inadvertently deleting it or modifying some aspects of it. You can apply a lock to a single resource, or to a resource and all of its sub-resources. This operation can only be accessed by account [users](ref:get-users) with _unrestricted_ access. Talk to your local account administrator about access management.  Once a resource has a lock, that resource (and its sub-resources, if applicable) can't be deleted, regardless of your user permission. You can unlock a resource by running the [Delete a resource lock](ref:delete-resource-lock) operation for the specific lock.  > 👍 There's a tutorial > > We offer an example API [workflow](ref:create-a-resource-lock-for-a-linode) you can follow to set up a resource lock on a Linode.   **Permissions and scopes**  To call this operation, you need the following:  - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `account:read_write`   **CLI**  ```shell linode-cli resource-locks create \ --entity_id 8642531 \ --entity_type linode \ --lock_type cannot_delete \ ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List resource locks](https://techdocs.akamai.com/linode-api/reference/get-resource-locks.md): __Beta__ Returns all available locks and information on the resources they protect. This operation can only be accessed by account [users](ref:get-users) with _unrestricted_ access. Talk to your local account administrator about access management.   **Permissions and scopes**  To call this operation, you need the following:  - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `account:read_only`   **CLI**  ```shell linode-cli resource-locks list ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get a resource lock](https://techdocs.akamai.com/linode-api/reference/get-resource-lock.md): __Beta__ Returns a specific resource lock. This operation can only be accessed by account [users](ref:get-users) with _unrestricted_ access. Talk to your local account administrator about access management.   **Permissions and scopes**  To call this operation, you need the following:  - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `account:read_only`   **CLI**  ```shell linode-cli resource-locks view 25 ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Delete a resource lock](https://techdocs.akamai.com/linode-api/reference/delete-resource-lock.md): __Beta__ Delete a specific resource lock. Once deleted, the resource it was assigned to is unlocked, and that resource can be deleted. This operation can only be accessed by account [users](ref:get-users) with _unrestricted_ access. Talk to your local account administrator about access management.  > 📘 > > For specific delete instructions and requirements, see the relevant resource's delete operation documentation.   **Permissions and scopes**  To call this operation, you need the following:  - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `account:read_write`   **CLI**  ```shell linode-cli resource-locks delete 25 ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
