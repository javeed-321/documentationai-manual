## API Reference: Object Storage
- [List Object Storage types](https://techdocs.akamai.com/linode-api/reference/get-object-storage-types.md): Returns Object Storage types and prices, including any region-specific rates.   **CLI**  ```shell linode-cli object-storage types ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get Object Storage transfer data](https://techdocs.akamai.com/linode-api/reference/get-object-storage-transfer.md): The amount of outbound data transfer used by your account's Object Storage buckets. Object Storage adds 1 terabyte of outbound data transfer to your data transfer pool. See the [Pricing](https://techdocs.akamai.com/cloud-computing/docs/object-storage-pricing#network-transfer) guide for details on Object Storage transfer quotas.   **Permissions and scopes**  To call this operation, you need the following:  - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `object_storage:read_only`   **CLI**  ```shell linode-cli object-storage transfer-view ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Cancel Object Storage](https://techdocs.akamai.com/linode-api/reference/post-cancel-object-storage.md): Cancel Object Storage on an Account.  > 🚧 > > This removes all buckets and their contents from your Account. This data is irretrievable once removed.   **Permissions and scopes**  To call this operation, you need the following:  - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `object_storage:read_write`   **CLI**  ```shell linode-cli object-storage cancel ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Create an Object Storage access key](https://techdocs.akamai.com/linode-api/reference/post-object-storage-keys.md): Generates a new Object Storage access key and an associated secret key. The secret key is only displayed when the access key is generated and cannot be viewed again. A successful request triggers an `obj_access_key_create` [event](ref:get-events).  > 📘 > > - Accounts with negative balances can't access this operation. > > - This operation has specific [rate limits](ref:rate-limits#specific-operation-rate-limits).  **Unlimited vs. limited access keys**  An unlimited access key grants full access to all of your buckets in each region you name, using the `regions` array. A limited access key lets you name specific buckets where you need to manage content, using the `bucket_access` array.  > 👍 There's a tutorial > > We offer workflows for both an [unlimited access key](ref:create-an-unlimited-access-key) and a [limited access key](ref:create-a-limited-access-key).   **Permissions and scopes**  To call this operation, you need the following:  - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `object_storage:read_write`   **CLI**  ```shell linode-cli object-storage keys-create \   --label "my-object-storage-key" \   --bucket_access '[{"region": "ap-south", "bucket_name": "bucket-example-1", "permissions": "read_write" }]' ```  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List Object Storage access keys](https://techdocs.akamai.com/linode-api/reference/get-object-storage-keys.md): Returns a paginated list of Object Storage access keys for authentication.   **Permissions and scopes**  To call this operation, you need the following:  - **OAuth scopes**. - [Get an Object Storage access key](https://techdocs.akamai.com/linode-api/reference/get-object-storage-key.md): Returns a single Object Storage access key.   **Permissions and scopes**  To call this operation, you need the following:  - **OAuth scopes**. - [Remove an Object Storage bucket](https://techdocs.akamai.com/linode-api/reference/delete-object-storage-bucket.md): Removes a single bucket.  > 📘 > > - You need to remove all objects from a bucket before you can delete it. The best way to empty large buckets is to configure lifecycle policies. Set a policy to remove all objects, wait a day or more for the system to remove all objects, then delete the bucket. For more details, see [Lifecycle policies](https://techdocs.akamai.com/cloud-computing/docs/lifecycle-policies).   **Permissions and scopes**  To call this operation, you need the following:  - **OAuth scopes**.
