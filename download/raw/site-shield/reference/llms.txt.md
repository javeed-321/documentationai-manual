# Site Shield Documentation

> Site Shield provides an additional layer of defense for critical websites and web applications. Site Shield cloaks websites from the public Internet, effectively removing them from Internet-accessible IP address space. This helps prevent attackers from directly targeting the application origin and forces traffic to go through the Akamai Intelligent Platform, where attacks can be detected and mitigated.

## API Reference: Maps

- [Maps index](https://techdocs.akamai.com/site-shield/reference/maps/llms.txt): full category index
- [List maps](https://techdocs.akamai.com/site-shield/reference/get-maps.md): Returns a list of all Site Shield maps that belong to your account.
- [Get a map](https://techdocs.akamai.com/site-shield/reference/get-map.md): Returns information about the specified map, such as the map name, firewall addresses, and when the map was last updated.
- [Acknowledge the map](https://techdocs.akamai.com/site-shield/reference/post-map-acknowledge.md): Acknowledges the proposed firewall update for the specified map. When necessary, the Site Shield Management application issues an update to the IP address list and sends a notification to you to update your firewall. See [Firewall updates and address change acknowledgment](doc:updating-your-firewall-and-acknowledging-address-changes) for more details.
