# Reporting Documentation

> If you’re using Akamai’s Intelligent Platform to deliver your content, you want to see how it’s performing. Reporting lets you create a wide range of reports, with new kinds added periodically. It lets you retrieve data in intervals from minutes to months.

Fetch the complete documentation index at: https://techdocs.akamai.com/reporting/llms.txt. Use this file to discover all available pages before exploring further. Append .md to any documentation page URL to get its markdown version.

## API Reference: Reports
- [List reports](https://techdocs.akamai.com/reporting/reference/get-reports.md): Returns all available reports.
- [List reports per product family](https://techdocs.akamai.com/reporting/reference/get-reports-per-product-family.md): Returns all available reports for a product family.
- [List reports per reporting area](https://techdocs.akamai.com/reporting/reference/get-reports-per-reporting-area.md): Returns all available reports for a product family and reporting area.
- [Get report options](https://techdocs.akamai.com/reporting/reference/get-report-options.md): Returns available options to generate the report.
- [Generate a report](https://techdocs.akamai.com/reporting/reference/post-report-data.md): Produces a report in either JSON or CSV format.
- [Get asynchronous report results](https://techdocs.akamai.com/reporting/reference/get-report-data-async.md): Produces a report for an asynchronous request in either JSON or CSV format.
