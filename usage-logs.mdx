## What Usage & Logs shows

Every time Content Generation writes something for you, Altus AI records it here. This page lets you see exactly what was generated, which provider and model handled it, how many tokens it used, what it cost, and gives you the ability to view full details or delete entries you no longer need.

## Where to find it

From your WP dashboard, go to **Altus AI > Account > Usage & Logs**.

The table lists every generation with these columns:

| Column   | Shows                                                               |
| -------- | ------------------------------------------------------------------- |
| Module   | Which Altus AI module generated this (e.g., Content Generation)     |
| Provider | The AI provider used (e.g., OpenRouter)                             |
| Model    | The specific model that handled the request (e.g., OpenAI: o4 Mini) |
| Status   | Whether the generation succeeded or failed                          |
| Tokens   | How many tokens the request used                                    |
| Date     | When it happened                                                    |
| Actions  | Icons to view full details or delete the entry                      |

## Filter and search logs

Above the table, you can narrow down what you're looking at:

- **All statuses** — filter to only successful or only failed generations
- **All providers** — filter to a specific AI provider
- **Search** — search for a specific entry

## Delete logs

You can remove log entries you no longer need to keep your history clean.

<Tabs tabs="Delete a single entry,Delete multiple entries" default-tab="0">
  <Tab>
    <Steps title-type="h4">
      <Step title="Delete the entry">
        Click the **delete icon** (trash icon) next to that entry in the Actions column.
      </Step>
    </Steps>
  </Tab>

  <Tab>
    <Steps title-type="h4">
      <Step title="Select entries">
        Check the box next to each entry you want to remove.
      </Step>

      <Step title="Choose the bulk action">
        Choose the delete option from the **Bulk actions** dropdown.
      </Step>

      <Step title="Apply the action">
        Click **Apply**.
      </Step>
    </Steps>
  </Tab>
</Tabs>

<Callout kind="info">
  Deleting a log entry only removes the record from this page. It doesn't undo or remove any content that was already generated and applied to a trip.
</Callout>

## Costs

Content generation is billed by whichever AI provider you've connected, based on that provider's own token pricing. Altus doesn't add a charge on top. Use this page to track exactly how much you're spending, and on what, across your site.

## FAQs

<Expandable title="Does deleting a log entry delete the content it generated?" default-open="false">
  No. Deleting a log only removes that record from Usage & Logs. Any content already generated and applied to a trip stays exactly as it is.
</Expandable>

<Expandable title="Can I see the cost for one specific generation instead of my total spend?" default-open="false">
  Yes. Click the view icon on any entry to see its exact cost, along with prompt, completion, and total token counts.
</Expandable>

<Expandable title="Can I filter logs by a specific AI provider?" default-open="false">
  Yes. Use the **All providers** dropdown above the table to narrow the list to one provider.
</Expandable>
