# Prolexic Analytics API Documentation

> Akamai's Prolexic managed services help protect your network infrastructure against DDoS attacks. They include managed options available for your entire data center, as well as for individual internet-facing applications. Prolexic services help reduce the risk of DDoS attacks while maintaining the availability of Internet-facing applications.

## API Reference: Prolexic Analytics

- [Get an attack report](https://techdocs.akamai.com/prolexic/reference/get-attack-report.md): Generates an attack report for the specified customer and `attackId`.
- [List attack reports](https://techdocs.akamai.com/prolexic/reference/get-attack-reports.md): Retrieves a list of attack reports for a customer within the specified time range.
- [List critical events](https://techdocs.akamai.com/prolexic/reference/get-critical-events-contract.md): Retrieves a critical events list for a customer.
- [List events](https://techdocs.akamai.com/prolexic/reference/get-events-contract.md): Retrieves an events list for a customer.
- [Get metrics data](https://techdocs.akamai.com/prolexic/reference/post-metrics.md): Lists metrics specified in the `type` object, between the given `start` and `end` times, sampled at the given rate and attached to given contract. Responses only contain data for valid requests. More meaningful errors result when requesting data for only one type at a time.
- [List metric types](https://techdocs.akamai.com/prolexic/reference/get-metric-types-contract.md): Retrieve a list of metric types for a specific customer.
- [Get active customer names](https://techdocs.akamai.com/prolexic/reference/get-customer-names.md): Retrieves contract and account details for customer names.
- [List Routed tunnel routes](https://techdocs.akamai.com/prolexic/reference/post-routed-routes.md): Lists Routed 3.0 GRE and Routed 3.0 GRE over ADC tunnel routes data for all specified policy domains. Use the `prefix` in the response to match with the `bgp-sessions` response.
- [Get time series data](https://techdocs.akamai.com/prolexic/reference/get-time-series-data.md): Lists usage and attack data for individual destination IP addresses. Optionally specify the `startTime` and `endTime` to get data from a specific period. The maximum date range is the last seven days, and by default you get data from the last two hours. Specify `locations` to include only traffic coming through specific data centers, or `source` for specific router types. Indicate the `samplingSize` to determine the number of timestamps to get data for. Enable `sum` to get aggregated data.
- [Routed tunnel health](https://techdocs.akamai.com/prolexic/reference/post-routed-health.md): Lists total and healthy tunnel counts for Routed 3.0 GRE and Routed 3.0 GRE over ADC tunnels. Counts are per Akamai location and customer router combination for the unique pair of Akamai IP and remote IP.
- [Routed tunnel BGP sessions](https://techdocs.akamai.com/prolexic/reference/post-routed-bgp-sessions.md): Lists BGP session information for Routed 3.0 GRE and Routed 3.0 GRE over ADC tunnels in all specified policy domains. Use the `customerBgpPeerIp4` or `customerBgpPeerIp6` from this response to match with `customerBgpPeerIp` and `prefix` based on the IP version in the routes response. The response includes `lastBgpResponseTimestamp` and `prefixesAdvertised` when available.
- [List active scrubbing centers](https://techdocs.akamai.com/prolexic/reference/get-scrub-centers.md): Provides a list of all active scrub centers.
