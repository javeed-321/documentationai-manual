## Before you start

This documentation covers installing and configuring the [Travel Muni Pro](https://wptravelengine.com/wordpress-travel-themes/travel-muni-pro/?utm_source=travel_muni_pro\&utm_medium=docs\&utm_campaign=upgrade_theme) WordPress theme, from initial setup through every Customizer section it adds.

Work through it in order the first time to build a full picture of the theme. Use the section cards below to jump straight to a specific settings area later, or press <kbd>Ctrl</kbd>+<kbd>F</kbd> to search this page for a keyword.

<Callout kind="tip">
  Prefer video? Travel Muni Pro also has a full [video walkthrough](https://www.youtube.com/embed/t8VUn0jJrSY) covering installation and setup.
</Callout>

<Callout kind="info">
  Have a question that isn't covered here? [Open a support ticket](https://wptravelengine.com/support-ticket/) and the WP Travel Engine team will help.
</Callout>

## Requirements for getting started

Travel Muni Pro works with WordPress 4.5 and above. For the best experience — including added features and the latest security patches — update to the newest version of WordPress before installing the theme. You can download the latest version from the [WordPress repository](https://wordpress.org/download/).

Checklist before you begin:

- Check your WordPress version and update it if needed.
- Install and activate the Travel Muni Pro theme.
- Install the recommended plugins — some theme functionality won't work without them.

### Check and update your WordPress version

Go to **Dashboard > Updates** and install any available WordPress update before continuing.

## Import the demo content

<Steps title-type="h3">
  <Step title="Install the demo import plugin">
    Install and activate the [One Click Demo Import](https://wordpress.org/plugins/one-click-demo-import/) plugin.
  </Step>

  <Step title="Open the demo importer">
    Go to **Appearance > Import Demo Data**.
  </Step>

  <Step title="Run the import">
    Click **Import Demo Data**.
  </Step>
</Steps>

<Callout kind="success">
  You'll see a success message once the import finishes.
</Callout>

## Install and activate the theme

<Callout kind="alert">
  On macOS Safari, downloaded `.zip` files sometimes unzip automatically. Confirm your theme file is still in `.zip` format before uploading — [here's how to stop Safari from auto-unzipping files](https://apple.stackexchange.com/questions/961/how-to-stop-safari-from-unzipping-files-after-download).
</Callout>

<Steps title-type="h3">
  <Step title="Save the theme file">
    Save the downloaded `travel-muni-pro.zip` file somewhere on your computer.
  </Step>

  <Step title="Open the theme uploader">
    Go to **Appearance > Themes**, click **Add New**, then click **Upload Theme**.
  </Step>

  <Step title="Upload the theme">
    Click **Choose File**, select `travel-muni-pro.zip`, and click **Open**.
  </Step>

  <Step title="Activate the theme">
    Once installation finishes, click **Activate**.
  </Step>
</Steps>

## Install recommended plugins

Install and activate these plugins to get the full Travel Muni Pro experience:

| Plugin                                                                        | What it does                                                                                                                               |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| [WP Travel Engine](https://wordpress.org/plugins/wp-travel-engine/)           | Lets you create and manage travel trips, destinations, itineraries, and other trip details. Extends your site's core travel functionality. |
| [Contact Form 7](https://wordpress.org/plugins/contact-form-7/)               | Lets you build and manage multiple contact forms.                                                                                          |
| [Regenerate Thumbnails](https://wordpress.org/plugins/regenerate-thumbnails/) | Regenerates image thumbnail sizes for existing content — run this if you're migrating existing media into the theme.                       |

<Steps title-type="h3">
  <Step title="Open the plugin installer">
    Go to **Appearance > Install Plugins**.
  </Step>

  <Step title="Install each plugin">
    Click **Install** next to each recommended plugin.
  </Step>

  <Step title="Activate each plugin">
    Click **Activate** for each plugin once it's installed.
  </Step>
</Steps>

## Activate your license key

Activating your license keeps Travel Muni Pro updated and gives you access to support. WP Travel Engine releases regular updates that fix compatibility issues, patch bugs, improve security, and add new features.

<Steps title-type="h3">
  <Step title="Open the theme's License tab">
    Go to **Appearance > \[Theme's Name] > License**.
  </Step>

  <Step title="Enter your license key">
    Enter your license key and click **Save Changes**. You'll find this key in your purchase receipt email, or under [your WP Travel Engine account profile](https://wptravelengine.com/my-account/).
  </Step>

  <Step title="Activate the license">
    Click **Activate License**.
  </Step>
</Steps>

<Callout kind="alert">
  A firewall protects the WP Travel Engine license server from bots, and it blocks IPs reported on [abuseipdb.com](https://www.abuseipdb.com/check/). If license activation fails, check your site's IP with a tool like [NSLookup.io](https://www.nslookup.io/website-to-ip-lookup/) — your site may be blocked. If activation still doesn't work, [contact support](https://wptravelengine.com/support-ticket/) with your purchase email and website URL.
</Callout>

## Set up your homepage and blog page

To customize the theme, first set up a front page. If you want your site to match the demo, set the homepage to display a static page.

<Steps title-type="h3">
  <Step title="Open Homepage Settings">
    Go to **Appearance > Customize > Homepage Settings**.
  </Step>

  <Step title="Select a static homepage">
    Choose **A Static Page** under **Your homepage displays**.
  </Step>

  <Step title="Assign your pages (existing sites only)">
    On a fresh WordPress install, skip this step. On an existing site, choose the page you want as **Front Page** and the page you want as the **Posts Page**.
  </Step>

  <Step title="Publish your changes">
    Click **Publish**.
  </Step>
</Steps>
