The User Social Link feature lets you personalize a user account with their social media profiles. Once added, these links appear in the author box on single post pages.

## Add social links to a user profile

<Steps title-type="h2">
  <Step title="Open the Users list">
    Navigate to **Dashboard > Users > All Users**.
  </Step>

  <Step title="Edit the target user profile">
    Click to edit the profile of the user you want to add social links for.

    <Image src="https://rishitheme.com/wp-content/uploads/2022/07/1-24.png" alt="WordPress Users list with edit profile link highlighted" width="600" height="400" />
  </Step>

  <Step title="Find the User Social Link section">
    Scroll down to the **User Social Link** section on the edit profile screen.

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-76.png" alt="User Social Link section with URL fields on the WordPress user profile page" width="600" height="400" />
  </Step>

  <Step title="Enter the social media URL">
    Type the full URL for the social profile into the URL field.
  </Step>

  <Step title="Save your changes">
    Click **Update Profile** to save the added social links.
  </Step>
</Steps>

## Frontend view of user social links

Once saved, the social links appear inside the author box on that user's single post pages.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-77-1024x233.png" alt="User social media links displayed inside the author box on a single post page" width="1024" height="233" />

## Getting help

If social links don't appear on the frontend after saving, confirm the **Social Share Posts** option is configured under [Posts & Pages Settings](/posts-pages-settings) and that your theme's author box is enabled. For further assistance, contact the [WP Travel Engine support team](https://wptravelengine.com/support-ticket/).
