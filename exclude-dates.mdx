---
title: 'Add Excluded Dates '
description: >-
  The Excluded Dates feature lets you block specific dates across all trips.
  This is useful if your business is closed or unavailable on certain days.
---

**How to set Excluded Dates:**

<Image src="https://blob-cdn.documentation.ai/org-fd8ba769-7008-47cf-98f1-e0d78d98350b/doc-08c376b3-8054-4dc6-b874-0c65a04a623e/1786385401342-7ty9qrqm0l-excluded-dates.excluded-dates?fm=auto&auto=compress%2Cformat" width="1505" height="750" alt="" />

1. Open the settings under Fixed Starting Dates.
2. Go to the Exclude Dates tab.
3. In Select Dates, pick one or more dates, or check Select a range of dates using the range calendar to block a date range at once.
4. Click Add Dates.
5. Choose a Block Behavior for the date:
   - **Block Entire Trip Duration:&#x20;**&#x54;rips that include this date anywhere in their duration cannot be booked.
   - **Block Start Date Only:** Trips cannot start on this date, but trips already in progress on this date can still be booked.
   - **Block Specific Time Slots:&#x20;**&#x42;locks only the start times you choose on this date. Customers can still book any remaining time slots. This works best for high-frequency tours where you want to stop overbooking on one slot without shutting down the whole day.
6. If you picked Block Specific Time Slots, add the start times to block under Select Time Slots. Click Add Time to block more than one slot on the same date.

<Image src="https://blob-cdn.documentation.ai/org-fd8ba769-7008-47cf-98f1-e0d78d98350b/doc-08c376b3-8054-4dc6-b874-0c65a04a623e/1786385461675-0mhybdke3rws-time-slots.time-slots?fm=auto&auto=compress%2Cformat" width="2040" height="574" alt="" />

7. Under **Apply Exclusion To**, choose who the exclusion covers:
   - **All Trips**: Blocks the date for every trip on your site.
   - **Specific Trips**: Blocks the date only for the trips you choose.
   - **All Except Selected Trips**: Blocks the date for every trip except the ones you choose.
     <Image src="https://blob-cdn.documentation.ai/org-fd8ba769-7008-47cf-98f1-e0d78d98350b/doc-08c376b3-8054-4dc6-b874-0c65a04a623e/1786385596689-ydeeyou1hga-apply-exclusion.apply-exclusion?fm=auto&auto=compress%2Cformat" width="2040" height="574" alt="" />
8. If you choose Specific Trips or All Except Selected Trips, search for and select the trips in Trips to Exclude. Start typing a trip name to find it in the dropdown.\
   Tip: Use All Except Selected Trips when most of your trips should stay closed on a date but a few need to stay bookable, like a private charter that still runs on a public holiday.
9. Optionally, enable Repeat Yearly to block the same date every year.
10. Click Details on any saved entry to review or change its settings later, and use the delete icon to remove an entry.
11. Click Save Settings.

**Examples of using Excluded Dates:**

- Blocking public holidays when your office is closed (Block Entire Trip Duration)
- Preventing trips from starting on certain peak days while allowing ongoing trips (Block Start Date Only)
- Excluding peak days when guides are unavailable
- Blocking a single overbooked departure time while keeping other time slots open on the same day (Block Specific Time Slots)
- Marking company retreat days where no trips should be booked

<Callout kind="info" collapsed="false">
  **Important Note**: The scope of an excluded date depends on what you choose under Apply Exclusion To. If you set a date to All Trips, no trip can be booked on that day, even if individual trips have seats available. If you scope it to Specific Trips or All Except Selected Trips, only the chosen trips are affected. Check the scope tag on each entry before saving to confirm it matches what you intend.
</Callout>
