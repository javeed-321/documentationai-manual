## Overview

The Trip Search widget lets visitors easily search and filter trips on your travel website. Add it to any page using Elementor and configure each setting to match your site's design.

## Additional settings

These settings let you further customize how the Trip Search widget looks and behaves, making it easier for visitors to find the trips they're searching for.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2025/11/Additional-Settings.png" alt="Additional settings for the Trip Search widget" width="800" height="500" />

### Search button label

Customize the text displayed on the search button to match your site's tone — for example, "Find Trips" or "Search Now."

### Filter fields

Each of the following filters shares the same four settings: whether the filter is shown, its label, its display order among the other filters, and its icon.

| Filter      | What it filters by            |
| ----------- | ----------------------------- |
| Destination | The trip's destination        |
| Trip Types  | The trip's assigned trip type |
| Activity    | The trip's assigned activity  |
| Duration    | How long the trip runs        |
| Price       | The trip's price range        |
| Date        | The trip's available dates    |

For each filter, you can configure:

- **Show \[Filter]** – enables or disables that filter in the widget
- **Filter Label** – changes the label displayed for that filter
- **Display Order** – controls the order in which the filter appears relative to the others
- **Choose Icon** – lets you upload an SVG or select an icon from the icon library for that filter

## Style settings

### General settings

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2025/11/General-Settings.png" alt="General style settings for the Trip Search widget" width="1601" height="563" />

- **Primary Color** – sets the main color for the section
- **Background Color** – chooses the background color for the section
- **Typography** – customizes fonts, sizes, and styles
- **Padding** – adjusts the spacing inside the section
- **Box Shadow** – adds or modifies shadow effects around the section
- **Border Type** – selects the type of border (solid, dashed, etc.)
- **Border Radius** – controls the roundness of the section's corners

### Input

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2025/11/Input.png" alt="Input style settings for the Trip Search widget" width="800" height="500" />

- **Input Color** – sets the color of input text or fields
- **Background Color** – chooses the background color for the item
- **Icon Color** – customizes the color of icons
- **Arrow Color** – sets the color of arrows, such as dropdown arrows
- **Border Type** – selects the type of border (solid, dashed, etc.)
- **Border Radius** – adjusts the roundness of corners
- **Padding** – sets the inner spacing within the item
- **Margin** – defines the outer spacing around the item
- **Item Spacing** – controls the space between multiple items

### Button

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2025/11/Button.png" alt="Button style settings for the Trip Search widget" width="800" height="500" />

- **Typography** – sets the font family, size, weight, and style for the button text
- **Padding** – adjusts the inner spacing inside the button
- **Normal/Hover States** – customizes button appearance separately for normal and hover states
- **Background Color** – chooses the background color for the button
- **Text Color** – sets the color of the button text
- **Border Type** – selects the type of border (solid, dashed, dotted, etc.)
- **Border Width** – defines the thickness of the button border
- **Border Color** – sets the color of the border
- **Border Radius** – adjusts the roundness of the button corners
- **Box Shadow** – applies shadow effects to create depth for the button
