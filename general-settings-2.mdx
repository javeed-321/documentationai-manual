Travel Monster Pro's General Settings panel controls the **Notification Bar** — a message strip that displays on your website header. It's useful for highlighting a discount, promoting a campaign, or surfacing any important message to visitors.

## Notification Bar setting

You can access the Notification Bar settings from **Dashboard > Appearance > Customize > General Settings > General > Notification Bar**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-80.png" alt="Notification Bar settings panel in the WordPress Customizer" width="342" height="801" />

The following settings are available:

| Setting                                                           | What it does                                                             |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Should the notification bar be visible? (Enable Notification Bar) | Turns the Notification Bar on or off across your site header.            |
| What message should the bar show? (Title)                         | The message text displayed inside the Notification Bar.                  |
| What should the button say? (Button Label)                        | The label text for the optional call-to-action button inside the bar.    |
| Where should the button link to? (Button Link)                    | The URL the button navigates to when clicked.                            |
| Should the link open in a new tab? (Open in new tab)              | Opens the button's link in a new browser tab instead of the current one. |
| What color should the bar background be? (Background Color)       | Sets the background color of the Notification Bar.                       |
| What color should the message text be? (Text Color)               | Sets the color of the notification title text.                           |

<Callout kind="tip">
  Keep the Title short and action-oriented — visitors scan the header quickly, so a concise message paired with a clear button label converts better than a long sentence.
</Callout>

## Getting help

If the Notification Bar doesn't appear after enabling it, check that your active theme is Travel Monster and that the Travel Monster Pro license is activated. For further assistance, contact the [WP Travel Engine support team](https://wptravelengine.com/support-ticket/).
