## Send trip-specific emails to each traveler

The Per Trip Emails add-on lets you send a different booking email for each trip. An add-on is an extra plugin that adds a new feature to WP Travel Engine.

That means you do not have to send the same message to every traveler. You can match the email to the trip they actually booked.

For example, say you run a 5-day Everest Base Camp trek. You might want the booking email to include a packing list, an altitude sickness reminder, and your guide's name.

Now imagine you also run a half-day Kathmandu city tour. That email would need very different details, like the meeting point, pickup time, and what to wear. Same plugin. Two completely different emails.

Once you set up one template, the rest will start to feel familiar.

## Create a personalized email template

<Callout kind="info" collapsed="false">
  Before you start, make sure these are active on your WordPress site:

  - **WP Travel Engine Pro**
  - **Per Trip Emails** add-on

  If you are not sure, check **Plugins** on the left sidebar of your WordPress dashboard.
</Callout>

<Steps>
  <Step title="Add a new template" title-type="p">
    This is where you start creating a separate email for one specific trip.

    On your WordPress dashboard, go to **WP Travel Engine → Per Trip Emails → Add New**. The WordPress menu is on the left side of your dashboard.

  </Step>

  <Step title="Name the template" title-type="p">
    This helps you recognize the template later when you have several trips.

    Enter a title for your template. You might name it **Maldives Trip Booking Email** or **Annapurna Trek Confirmation Email**.

    A clear title helps you stay organized when you manage several tours. That makes the next updates easier too.
  </Step>

  <Step title="Write the subject line" title-type="p">
    The subject line is the first thing your customer sees in their inbox.

    Enter an email subject line. You can use tags like `booking_id` and `payment_id`.

    A tag is a short code wrapped in curly braces that pulls in real booking information when the email is sent. For example, you could write `Your booking order has been placed {booking_id}`.

    <Image src="https://blob-cdn.documentation.ai/org-fd8ba769-7008-47cf-98f1-e0d78d98350b/doc-08c376b3-8054-4dc6-b874-0c65a04a623e/1786946498579-bb1lmlybrym-per-trip-email-subject-line.per-trip-email-subject-line?fm=auto&auto=compress%2Cformat" width="1033" height="513" alt="" />
  </Step>

  <Step title="Compose the email body" title-type="p">
    This is where you add the trip details your customer needs.

    Write your email in the text area. You can use tags to personalize the message.

    Tags are short codes that get replaced with real information when the email is sent. For example, a multi-day trek email might include a trip page link, while a day tour email might remind guests what to bring and where to meet.

    <Image src="https://blob-cdn.documentation.ai/org-fd8ba769-7008-47cf-98f1-e0d78d98350b/doc-08c376b3-8054-4dc6-b874-0c65a04a623e/1786946544757-qg09qqqrx3d-per-trip-email-content.per-trip-email-content?fm=auto&auto=compress%2Cformat" width="1024" height="683" alt="" />

    <Callout kind="info" collapsed="false">
      You will find various tags listed below the text area in each email template to personalize your email for each trip.
    </Callout>
  </Step>

  <Step title="Assign the email to a trip" title-type="p">
    This step connects the template to the trip that should use it.

    Select the trip from the **Trip Name** drop-down menu. This tells WP Travel Engine which travelers should receive this email.

    For example, you can assign one email to a winter departure with cold-weather notes, and another to a family day tour with child-friendly instructions.

    <Image src="https://blob-cdn.documentation.ai/org-fd8ba769-7008-47cf-98f1-e0d78d98350b/doc-08c376b3-8054-4dc6-b874-0c65a04a623e/1786946572147-fank0pm118u-Assign-email-to-trip.gif?fm=auto&auto=compress%2Cformat" width="1033" height="654" alt="" />
  </Step>

  <Step title="Preview the email" title-type="p">
    Previewing helps you catch mistakes before travelers see them.

    Click **Preview** to check how the email looks. Read through the subject line and message body.

    Make any changes you need before you save or publish the template. A quick check here can save you from sending the wrong details later.

    <Image src="https://blob-cdn.documentation.ai/org-fd8ba769-7008-47cf-98f1-e0d78d98350b/doc-08c376b3-8054-4dc6-b874-0c65a04a623e/1786946648892-39f5d7ziwl3-per-trip-email-preview-template.per-trip-email-preview-template?fm=auto&auto=compress%2Cformat" width="1024" height="536" alt="" />
  </Step>

  <Step title="Publish or save as draft" title-type="p">
    This decides whether the template starts sending now or stays saved for later.

    Under the **Publish** settings, save the template as a draft or publish it right away. If you are still working on the wording, save it first and come back later.

    <Image src="https://blob-cdn.documentation.ai/org-fd8ba769-7008-47cf-98f1-e0d78d98350b/doc-08c376b3-8054-4dc6-b874-0c65a04a623e/1786946690036-t9ke8cle10a-per-trip-email-template-status.per-trip-email-template-status?fm=auto&auto=compress%2Cformat" width="705" height="433" alt="" />

<Callout kind="alert" collapsed="false">
  If you do not change the template status from Inactive to Active, the default email template is sent to your customers instead.
</Callout>

You can create a personalized email template for each unique trip by repeating the same process. Once your first one is ready, the rest will feel much faster.

## Troubleshooting

### My custom email isn't going out

The template status is probably still set to **Inactive**. Go back to your template, change the status to **Active**, and save it again.

That is the most common reason this happens. Once that is fixed, you can test the email again.

### The tags are showing as plain text in the email

Check that each tag is wrapped in curly braces, like `{name}` or `{booking_id}`. If the braces are missing, or if there is a typo, the tag will not be replaced.

When that happens, your customer sees the raw text instead of the real booking detail. A quick spelling check usually fixes it.

### I can't find the Per Trip Emails menu

The add-on might not be activated. Go to **Plugins** on your WordPress dashboard and check that **Per Trip Emails** is active.

If you do not see it in your plugins list at all, you may need to install it first. Once it is active, the menu should appear in the left sidebar.

### My trip isn't showing up in the Trip Name dropdown

Make sure the trip is published, not saved as a draft. Only published trips appear in the dropdown when you assign an email template.

If you recently created the trip, open it once and confirm its status. Then return to your email template and check the list again.

### I edited my email but travelers are still getting the old version

This can happen if your website is using a caching tool. A cache is a temporary copy of your site that helps pages load faster, but it can also hold onto old content.

Try clearing your cache and test again. The option is usually inside your caching plugin or your hosting settings. If you are not sure how to do that, your hosting provider can help.

### My email looks fine in preview but broken when it arrives

Some email apps display emails differently. The preview shows how the email looks in a browser, but your traveler might be using Gmail, Outlook, or their phone.

If something looks off, make a test booking with your own email address. That shows you what the message actually looks like when it arrives.

## FAQs

<ExpandableGroup>
  <Expandable title="Can I send different emails for different trips?" default-open="false">
    Yes. That is exactly what this add-on is for.

    Create a separate template for each trip and assign it using the **Trip Name** dropdown. Once each trip has its own template, your travelers will get the right message for that booking.
  </Expandable>

  <Expandable title="Do I still need to set up the default booking email?" default-open="false">
    Yes. The default booking email works as a fallback.

    If a trip does not have a custom email assigned, WP Travel Engine sends the default one instead. It is a good idea to keep both set up so no traveler misses a confirmation.
  </Expandable>

  <Expandable title="Can I use the same email template for multiple trips?" default-open="false">
    No. Each template is assigned to one trip at a time.

    If you want similar emails for two trips, create two separate templates and assign each one to its own trip. That gives you more control if the details change later.
  </Expandable>

  <Expandable title="What happens if I don't create a per-trip email?" default-open="false">
    Travelers on that trip will receive the default booking email that comes with WP Travel Engine.

    They will still get a confirmation, but it will not be tailored to that specific trip. If you want to include trip-specific instructions, you need a separate per-trip template.
  </Expandable>

  <Expandable title="Can I include different packing lists or meeting instructions for summer and winter departures of the same trip?" default-open="false">
    Each trip can only have one per-trip email template assigned at a time.

    If you run the same trek in different seasons, consider creating separate trip listings, such as **Annapurna Trek - Winter Departure** and **Annapurna Trek - Summer Departure**. That way each trip can have its own tailored email with the right packing list and meeting details.
  </Expandable>
</ExpandableGroup>
