# Test Center Documentation

> Akamai's Test Center is a testing tool that checks the effect of configuration changes on your web property.  Use this tool as part of your testing protocol to increase your confidence in the safety and accuracy of your configuration changes.

## API Reference: Functions

- [Check how functions work](https://techdocs.akamai.com/test-ctr/reference/post-try-it.md): Runs a created function on sample data to check whether it returns the expected value. A function is valid for use in a test case if the response's `results` value returns only one value. To learn more about functions and variables, see [Variables](/reference/variables-overview).
