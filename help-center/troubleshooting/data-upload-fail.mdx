---
title: Data Upload Failures
description: Fix issues uploading supply chain data.
---

## Symptoms
- You see "Upload failed" messages
- Data files not appearing in dashboard

## Common Causes
- Wrong file format (should be .csv or .xlsx)
- File exceeds 10MB size limit

## Quick Fix
<Steps>
  <Step title="Check file type">
    Ensure file is .csv or .xlsx before uploading.
  </Step>
  <Step title="Reduce file size">
    Split large files into parts if over 10MB.
  </Step>
  <Step title="Try again">
    Re-upload once file is correct format and size.
  </Step>
</Steps>
