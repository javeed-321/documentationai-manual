---
title: Fix Plugin Conflict
description: Resolve conflicts with other WordPress plugins.
---

## Symptoms

- WP Travel Engine features not loading
- JavaScript errors in browser console
- Design/layout issues after activating another plugin

## Quick Fix

<Steps>
  <Step title="Deactivate plugins">
    Temporarily deactivate other plugins one by one and check if WP Travel Engine works after each.
  </Step>
  <Step title="Switch themes">
    Try switching to a default theme (like Twenty Twenty-Three) to rule out theme conflicts.
  </Step>
  <Step title="Contact support">
    If conflict persists, contact our support team with plugin details.
  </Step>
</Steps>
