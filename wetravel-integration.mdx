## Overview

The [WeTravel Integration addon](https://wptravelengine.com/plugins/we-travel/?utm_source=free_plugin\&utm_medium=docs\&utm_campaign=upgrade_to_pro) supports WeTravel or Custom URL booking. [WeTravel](https://wptravelengine.com/plugins/we-travel/?utm_source=free_plugin\&utm_medium=docs\&utm_campaign=upgrade_to_pro) provides payment solutions for travel agencies.

Using the WeTravel Integration addon, you can add a WeTravel trip embed link to trips created in WP Travel Engine.

### Features

- Supports WeTravel or Custom URL booking.
- Lets you add your WeTravel trip embed link to trips created in WP Travel Engine.
- Overrides the default WP Travel Engine booking flow with WeTravel's booking flow.

## How the integration changes the booking flow

When you add an embed link to the WeTravel Embed Link field in the backend, the default Check Availability button layout of WP Travel Engine changes. Clicking the **Book Now** button then opens a popup where travelers continue with the WeTravel payment process.

<Callout kind="info">
  You can change the text displayed on the button from the WP Travel Engine backend settings page.
</Callout>

## How to generate a WeTravel trip embed link

<Steps title-type="h3">
  <Step title="Open your trips in WeTravel">
    Find your trips on the [My Trips](https://www.wetravel.com/user/my_trips) page in WeTravel.
  </Step>

  <Step title="Manage the trip you want to embed">
    Click the manage trip option for the trip whose URL you want to embed.
  </Step>

  <Step title="Open the Promote tab">
    Go to the **Promote** tab and scroll down.
  </Step>

  <Step title="Copy the direct payment link">
    Click the **Direct Link** tab. You'll see two links available to copy — copy the one labeled **Link directly to Payment Page**.
  </Step>

  <Step title="Add the link to WP Travel Engine">
    Paste the copied link into the WeTravel Embed Link field for the corresponding trip in WP Travel Engine.
  </Step>
</Steps>
