## Overview

The Trips Slider widget lets you showcase trips on any page in a carousel layout using Elementor.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/slider-types-1-1024x284.png" alt="Trips Slider widget rendered on a page" width="1024" height="284" />

## Layout settings

- **Layout** – select from a variety of layout options to display trips; several layouts are available so you can customize the appearance of the Trips Slider widget

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/layout-1.png" alt="Layout options for the Trips Slider widget" width="800" height="500" />

## Query settings

- **Show Trips by** – choose how trips are selected: latest trips, trips on sale, featured trips, trips filtered by term, or specific trips picked from a list
- **Number of Trips** – specify the total number of trips to display

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/query-1.png" alt="Query settings for the Trips Slider widget" width="800" height="500" />

## Additional settings

- **Featured Ribbon** – displays a "featured" ribbon on trips
- **Discount** – displays the discount percentage
- **Review** – displays trip reviews
- **Location** – displays the trip's location
- **Title** – displays the trip title
- **Title Meta** – adds the title meta to display for each trip
- **Price** – displays the trip price
- **Show Striked Price on Sale** – displays the struck-through original price for trips on sale
- **Duration Type** – choose whether trip duration displays in days or nights
- **Price Label** – sets the price label text
- **Wishlist** – displays the wishlist icon

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/additional-1.png" alt="Additional settings for the Trips Slider widget" width="800" height="500" />

## Slider settings

- **Slider Number** – sets the number of slides to display at once
- **Space Between Slides** – defines the spacing between each slide, in pixels
- **Autoplay** – enables automatic transitions between slides
- **Autoplay Speed** – sets the time between each slide transition, in milliseconds
- **Loop** – continuously cycles slides after the last one
- **Transition Speed** – adjusts the speed of slide transitions, in milliseconds
- **Slider Arrow** – shows navigation arrows
- **Slider Pagination** – shows dots for navigating between slides

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/slider-1.png" alt="Slider settings for the Trips Slider widget" width="800" height="500" />

## General style settings

- **Background Color** – sets the background color for the widget section
- **Padding** – adjusts the padding around the content within the widget section
- **Border Radius** – controls the roundness of the corners
- **Border Type** – sets the border type for the widget section
- **Box Shadow** – configures the box shadow effect for the trip cards within the widget section

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/General-2.png" alt="General style settings for the Trips Slider widget" width="800" height="500" />
