Travel Monster Pro extends the Header Settings already provided by the free Travel Monster theme with a few additional options for search behavior, contact information, and header layout images.

## General settings

| Setting                                                         | What it does                                                                                                   |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Should the header search only return trips? (Only Search Trips) | Limits the header search form's results to trips only, filtering out other content types like posts and pages. |

## Contact information

| Setting                                                          | What it does                                                           |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------- |
| What label should appear before the phone number? (Phone Label)  | Sets the text label displayed next to the phone number in the header.  |
| What label should appear before the email address? (Email Label) | Sets the text label displayed next to the email address in the header. |

## Getting help

If a header option doesn't appear, confirm you have Travel Monster Pro activated with a valid license and that you've selected a header layout that supports that option. For further assistance, contact the [WP Travel Engine support team](https://wptravelengine.com/support-ticket/).
