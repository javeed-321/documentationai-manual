## What Pattern Engine does

[Pattern Engine](https://wptravelengine.com/pattern-engine/?utm_source=pattern_engine\&utm_medium=docs\&utm_campaign=upgrade_pattern_engine) is a premium plugin that unlocks access to all premium starter sites for the Travelverse theme. It lets you bring professional page and post templates onto your site in a few clicks, and adds customization options such as color settings and custom script injection so you can make the Travelverse theme your own.

<Callout kind="info" collapsed="false">
  To use all the features Pattern Engine offers, the [WP Travel Engine plugin](https://wordpress.org/plugins/wp-travel-engine/) must also be active on your site.
</Callout>

## Install and activate the plugin

<Steps>
  <Step title="Purchase and download the plugin" title-type="p">
    Purchase and download the Pattern Engine plugin `.zip` file from the [Pattern Engine product page](https://wptravelengine.com/pattern-engine/?utm_source=pattern_engine\&utm_medium=docs\&utm_campaign=upgrade_pattern_engine).
  </Step>

  <Step title="Log in to WordPress" title-type="p">
    Log in to your WordPress admin dashboard.
  </Step>

  <Step title="Open the plugin uploader" title-type="p">
    Navigate to **Plugins > Add New**, then click **Upload Plugin**.
  </Step>

  <Step title="Upload and install" title-type="p">
    Choose the `.zip` file you downloaded, then click **Install Now**.
  </Step>

  <Step title="Activate the plugin" title-type="p">
    Once installation finishes, click **Activate**.
  </Step>
</Steps>

## Activate your Pattern Engine license key

Activating your license key keeps Pattern Engine updated and gives you access to support. WP Travel Engine releases regular updates that fix compatibility issues, patch bugs, improve security, and add new features — an inactive license key means you'll miss all of them.

If you're running the **Travelverse** theme, activate the license directly from its dashboard:

<Steps>
  <Step title="Open the Travelverse dashboard" title-type="p">
    Go to **Appearance > Travelverse > Dashboard** in your WordPress admin.
  </Step>

  <Step title="Enter and activate your license key" title-type="p">
    Enter your Pattern Engine license key and activate it from the dashboard screen.
  </Step>
</Steps>

<Callout kind="tip" collapsed="false">
  Using a different theme? Activate the same license key under **Dashboard > Settings > Pattern Engine** instead of the Travelverse dashboard.
</Callout>

## Configure Travelverse dashboard settings

Once Pattern Engine is active on a site running the Travelverse theme, additional settings appear in the Travelverse Dashboard.

### General settings

Configure your site's container width from **Appearance > Travelverse > Dashboard > Settings > General**.

| Setting                | What it does                                                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Container Width        | Sets the site's container width for different devices.                                                                                             |
| Narrow Container Width | Adjusts the narrow container width used across pages and posts for a tighter, more focused layout — useful for smaller screens and limited spaces. |

### Colors

Set the colors used across your site from **Appearance > Travelverse > Settings > Colors**.

| Setting          | What it does                                 |
| ---------------- | -------------------------------------------- |
| Primary Color    | The primary color for your website.          |
| Secondary Color  | The secondary color for your website.        |
| Text Color       | The color applied to all general site text.  |
| Heading          | The color applied to all site headings.      |
| Accent Color One | The background color for all sections.       |
| Accent Color Two | The background color for templates.          |
| Background       | The background color for the entire website. |

### Custom scripts

Add custom code snippets to your site's header, body, or footer without editing theme files or installing a third-party plugin. Access this from **Appearance > Travelverse > Settings > Custom Scripts**.

<Callout kind="alert" collapsed="false">
  Wrap your code in `<script></script>` tags — code entered without these tags won't run.
</Callout>

<Steps>
  <Step title="Add your script" title-type="p">
    Enter your header, body, or footer script in the matching field.
  </Step>

  <Step title="Publish your changes" title-type="p">
    Click **Publish** to apply the script to your live site.
  </Step>
</Steps>

### Custom CSS

Customize your site's design with your own CSS from **Appearance > Travelverse > Settings > Custom CSS**. This gives you direct control over layout and appearance beyond the built-in Colors settings.

<Callout kind="alert" collapsed="false">
  Wrap your CSS in `<style></style>` tags — code entered without these tags won't apply.
</Callout>

## Import starter sites

Once Pattern Engine is installed, you can import ready-made patterns and pages to speed up your site build.

<Callout kind="info" collapsed="false">
  The [WP Travel Engine plugin](https://wordpress.org/plugins/wp-travel-engine/) must be installed on your site to access these templates.
</Callout>

<Steps>
  <Step title="Open the page or post editor" title-type="p">
    Go to **Pages** or **Posts > Add New** in your WordPress admin.
  </Step>

  <Step title="Open the Design Library" title-type="p">
    Click the **Design Library** button to browse the full list of available patterns and pages.
  </Step>

  <Step title="Select a pattern or page" title-type="p">
    Click on any pattern or page you'd like to use to preview it.
  </Step>

  <Step title="Import it" title-type="p">
    Click **Import** to bring the pattern or page onto your site.
  </Step>

  <Step title="Publish your changes" title-type="p">
    Review the imported content, then click **Publish**.
  </Step>
</Steps>
