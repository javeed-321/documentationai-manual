## Overview

Travel Monster's General Settings cover the theme-wide building blocks of your site: layout structure, buttons, colors, typography, and SEO basics. You'll find all of these under **Appearance > Customize > General Settings** in your WordPress dashboard.

## Container settings

A container is the element that holds all of your site's content. Access these settings via **Appearance > Customize > General Settings > General > Container**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-12.png" width="341" height="332" alt="Container settings panel in Travel Monster customizer" />

| Setting                      | What it does                                                    |
| ---------------------------- | --------------------------------------------------------------- |
| Container Width              | Sets the site container's width for different devices.          |
| Fullwidth Centered Max-width | Sets the container width used for a full-width centered layout. |

## Sidebar settings

Access these settings via **Appearance > Customize > General Settings > General > Sidebar**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-13.png" width="341" height="332" alt="Sidebar settings panel in Travel Monster customizer" />

| Setting            | What it does                                                                          |
| ------------------ | ------------------------------------------------------------------------------------- |
| Sidebar Layout     | Chooses whether your site layout includes a sidebar.                                  |
| Sidebar Width      | Sets the sidebar's width.                                                             |
| Widget Spacing     | Sets the spacing between sidebar widgets.                                             |
| Last Widget Sticky | Makes the last widget in the sidebar stick in place as visitors scroll, when enabled. |

## Button settings

Style every button on your site via **Appearance > Customize > General Settings > General > Button**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-14.png" width="341" height="332" alt="Button settings panel in Travel Monster customizer" />

| Setting              | What it does                                                                          |
| -------------------- | ------------------------------------------------------------------------------------- |
| Button Roundness     | Sets the button corner radius.                                                        |
| Button Padding       | Sets the button's internal padding.                                                   |
| Button Initial State | Sets the text, background, and border color for a button before it's interacted with. |
| Button Hover State   | Sets the text, background, and border color for a button when hovered.                |
| Button Typography    | Sets the typography used for button text.                                             |

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-16.png" width="341" height="332" alt="Button initial state color settings in Travel Monster customizer" />

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-17.png" width="341" height="332" alt="Button typography settings in Travel Monster customizer" />

## Scroll to top settings

Access these settings via **Appearance > Customize > General Settings > General > Scroll To Top**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/07/travel-monter-1.png" width="341" height="332" alt="Scroll to top settings panel in Travel Monster customizer" />

| Setting            | What it does                                                                                      |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| Show Scroll to Top | Displays the scroll-to-top button when enabled.                                                   |
| Icon Size          | Sets the icon size for the scroll-to-top button. Only visible when Show Scroll to Top is enabled. |
| Alignment          | Positions the scroll-to-top button on the right or left of the screen.                            |
| Bottom Offset      | Sets the distance between the button and the bottom of the screen.                                |
| Side Offset        | Sets the distance between the button and the side of the screen.                                  |

## Pagination settings

Access these settings via **Appearance > Customize > General Settings > General > Pagination**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-19.png" width="341" height="332" alt="Pagination settings panel in Travel Monster customizer" />

Here you can select the pagination type that displays across your website's pages.

## 404 page settings

Configure your site's 404 page via **Appearance > Customize > General Settings > General > 404 Page**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-15.png" width="341" height="332" alt="404 page settings panel in Travel Monster customizer" />

| Setting           | What it does                                                     |
| ----------------- | ---------------------------------------------------------------- |
| Upload 404 Image  | Sets an image to display on the 404 page.                        |
| Show Latest Posts | Displays your latest posts on the 404 page when enabled.         |
| Number of Posts   | Sets how many posts appear in the Latest Posts section.          |
| Posts per Row     | Sets how many posts display per row in the Latest Posts section. |

## Colors settings

Set colors for your site's key elements via **Appearance > Customize > General Settings > Colors**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-20.png" width="341" height="332" alt="Colors settings panel in Travel Monster customizer" />

| Setting                  | What it does                                             |
| ------------------------ | -------------------------------------------------------- |
| Primary Color            | Sets your website's primary color.                       |
| Secondary Color          | Sets your website's secondary color.                     |
| Body Font Color          | Sets the color for general site text.                    |
| Heading Color            | Sets the color for site headings.                        |
| Section Background Color | Sets a background color used in specific theme sections. |
| Site Background          | Sets the background color for the entire website.        |

## Typography settings

Typography settings let you choose the font family, variant, size, line height, letter spacing, weight, and capitalization for different text types on your site.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-22.png" width="341" height="332" alt="Typography settings panel in Travel Monster customizer" />

| Setting                   | What it does                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| Primary Font              | Sets the primary font and its styling options for your website.                                  |
| Headings                  | Sets the typography applied to site headings.                                                    |
| Load Google Fonts Locally | Loads Google Fonts from your own server rather than Google's, which helps speed up your website. |
| Preload Local Fonts       | Activates preloading for locally hosted Google Fonts.                                            |
| Flush Local Fonts Cache   | Clears the local fonts cache when you click **Successfully Flushed!**.                           |

## SEO settings

SEO settings cover breadcrumbs and post date display. Access these via **Appearance > Customize > General Settings > SEO**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-23.png" width="341" height="332" alt="SEO settings panel in Travel Monster customizer" />

| Setting                     | What it does                                                                                                              |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Show Breadcrumb             | Displays a breadcrumb trail on your website when enabled.                                                                 |
| Breadcrumb Home Text        | Sets the text used to represent the homepage in the breadcrumb trail.                                                     |
| Separator                   | Sets the separator style used between breadcrumb items.                                                                   |
| Show Last Updated Post Date | Displays the date a post was last updated. Enabling this lets Google read the updated date and index your latest content. |

## Social networks settings

Add your social media accounts via **Appearance > Customize > General Settings > Social Networks**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-24.png" width="341" height="332" alt="Social networks settings panel in Travel Monster customizer" />

<Callout kind="info">
  Adding your accounts here doesn't display anything on its own. Enable and add social media icons to the site header through the Social Media setting under Header Settings — once added, those icons automatically link to the accounts you enter here.
</Callout>
