## Overview

WP Travel Engine is fully compatible with WPML, the most popular multilingual plugin for WordPress. This guide walks through translating your travel website step-by-step so you can reach a global audience — from trip packages and custom fields to menus and static strings.

## Prerequisites

Before you begin, make sure you have:

- A WordPress website with WP Travel Engine installed and activated.
- The [WPML Multilingual CMS](https://wpml.org/?aid=351991\&affiliate_key=rRLq5H1LVICh) plugin (paid).
- WPML's required components: **String Translation**, **Translation Management**, and optionally **Media Translation**.

<Callout kind="info">
  For most websites, the WPML Multilingual CMS plan is enough. It includes all WPML features, free automatic translation for around 45,000 words, and costs 99€ per year.
</Callout>

## Install and set up WPML

<Steps title-type="h3">
  <Step title="Upload the plugin">
    Go to **Plugins → Add New → Upload Plugin**, then upload the WPML Multilingual CMS plugin file.
  </Step>

  <Step title="Activate WPML">
    Install and activate the plugin.
  </Step>

  <Step title="Run the setup wizard">
    Choose your site's default language, add the languages you want to translate into, set up a language switcher (menu, widget, or footer), and register your WPML license.
  </Step>
</Steps>

For more detail on any step, refer to [WPML's official installation documentation](https://wpml.org/faq/install-wpml/).

## Configure WPML for WP Travel Engine

<Steps title-type="h3">
  <Step title="Open WPML settings">
    Navigate to **WPML → Settings**.
  </Step>

  <Step title="Make trips translatable">
    Under **Post Types Translation**, set the **Trips** post type from WP Travel Engine to **Translatable**.
  </Step>

  <Step title="Make taxonomies translatable">
    Under **Taxonomies Translation**, set the following to **Translatable**: Destinations, Activities, Trip Types, Difficulty, Trip Tag, and any custom taxonomy added by WP Travel Engine.
  </Step>

  <Step title="Keep trip package categories untranslatable">
    Set the Categories taxonomy (`trip-packages-categories`) to **Not Translatable**.
  </Step>
</Steps>

<Callout kind="alert">
  Leaving trip package categories translatable causes pricing issues between translated versions of the same trip. Keep this taxonomy set to **Not Translatable**.
</Callout>

## Translate trip packages

<Steps title-type="h3">
  <Step title="Open your trips list">
    Go to **Trips → All Trips**.
  </Step>

  <Step title="Start a translation">
    Next to each trip, click the plus (+) icon under the language column you want to translate into.
  </Step>

  <Step title="Choose your editor">
    WPML opens the Advanced Translation Editor by default. You can switch to the Classic Editor if you prefer.
  </Step>

  <Step title="Translate the trip content">
    Translate the trip title, description, itinerary, highlights, FAQs, and price and duration (only if these differ per language).
  </Step>

  <Step title="Complete the translation">
    Click **Complete** once you've finished translating the trip.
  </Step>
</Steps>

<Callout kind="tip">
  You can also enable automatic translation from **WPML → Translation Management → Settings**, which uses DeepL, Google, or Microsoft to pre-translate content.
</Callout>

## Translate trip attributes

Each trip is made up of more than its main content. Here's how to handle the additional fields.

### Custom fields (itinerary, pricing, FAQs, and more)

WP Travel Engine stores these details as custom fields. WPML auto-detects most of them, but if a field isn't showing up for translation:

1. Go to **WPML → Settings**.
2. Scroll to **Custom Fields Translation**.
3. Find the field and set it to **Translate**.

### Image galleries and media

To translate media:

1. Go to **WPML → Media Translation**.
2. Upload alternative images if needed for a specific language.
3. Translate image titles and alt text for SEO.

## Translate widgets, menus, and strings

### Menus

1. Go to **Appearance → Menus**.
2. Select your primary menu.
3. Click the **+** icons to create menu versions in other languages.
4. Add translated links — for example, translated trip pages, blog, and contact page.

### Widgets

Use **WPML Widget Logic** or **Block Widgets** to display language-specific widgets.

### Strings (like "Book Now" and "Read More")

1. Go to **WPML → String Translation**.
2. Search for the string you want to translate.
3. Add translations for each language.

<Callout kind="tip">
  You can also scan WP Travel Engine for additional translatable strings under **WPML → Theme and Plugin Localization**.
</Callout>

## Optional: enable automatic translation

<Steps title-type="h3">
  <Step title="Open Translation Management">
    Go to **WPML → Translation Management**.
  </Step>

  <Step title="Choose content types">
    Select which content types should be included in automatic translation.
  </Step>

  <Step title="Turn on automatic translation">
    Enable **Translate Everything Automatically**.
  </Step>
</Steps>
