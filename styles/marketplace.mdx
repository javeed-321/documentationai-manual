/\*

&#x20;\* Styles for the ReadMe Marketplace components that convert to a classed wrapper

&#x20;\* rather than to a native component — [marketplace-conversion.md](http://marketplace-conversion.md) §5.2.

&#x20;\*

&#x20;\* Register in documentation.json:

&#x20;\*

&#x20;\*   \{ "css": \[\{ "src": "styles/marketplace.css" }] }

&#x20;\*

&#x20;\* Stylesheets load after the default theme, so these rules win without !important

&#x20;\* \[LIVE-DAI /docs/customize/custom-css].

&#x20;\*

&#x20;_&#x20;The&#x20;_`rm-`_&#x20;prefix is deliberate:&#x20;_`dai-` belongs to the platform, and reusing it

&#x20;\* would collide with its own layout hooks.

&#x20;\*/

\


/\* --------------------------------------------------------------------------

&#x20;\* SnapSlider — a scroll-snapping gallery.

&#x20;\*

&#x20;\* The source is pure CSS `snap-x snap-mandatory overflow-x-scroll`), so this is

&#x20;\* a faithful reproduction rather than an approximation.

&#x20;_&#x20;------------------------------------------------------------------------&#x20;_/

\


.rm-slider \{

display: flex;

align-items: center;

gap: 0.75rem;

overflow-x: auto;

scroll-snap-type: x mandatory;

max-width: 100%;

margin: 1rem auto;

padding: 0.5rem;

border: 1px solid var(--dai-border, #d4d4d4);

border-radius: 0.5rem;

}

\


.rm-slider > \* \{

flex: 0 0 auto;

scroll-snap-align: center;

max-width: 100%;

}

\


/\* Respect a reader who has asked for less motion. \*/

@media (prefers-reduced-motion: reduce) \{

.rm-slider \{

scroll-behavior: auto;

&#x20; }

}

/\* --------------------------------------------------------------------------

&#x20;\* Windows — a decorative retro window frame.

&#x20;\*

&#x20;\* These colours are intentionally fixed. The frame is a period reference, not

&#x20;\* themed chrome, so it does not follow light/dark the way real UI should — which

&#x20;_&#x20;is exactly why only decoration belongs in this file. The&#x20;_&#x74;ext\* inside inherits

&#x20;\* normally, so the readable part still themes.

&#x20;_&#x20;------------------------------------------------------------------------&#x20;_/

\
