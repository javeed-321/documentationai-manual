## Overview

WP Travel Engine provides settings to edit trip slugs. You can change the permalink slug for the WP Travel Engine Trip default archive and all trip custom taxonomy archives from the settings.

To customize the trip slugs, navigate to **WordPress Dashboard > Settings > WP Travel Engine: Trip Slugs**. There you can edit the following base slugs:

- Trips base
- Trip Type base
- Trip Destination base
- Trip Activity base
- Trip Tag base
- Trip Difficulty base

## Benefits and use cases

- Makes URLs shorter, cleaner, and easier for your customers to remember
- Improves SEO by using meaningful, keyword-rich slugs
- Aligns your site's structure with your branding and content style
- Helps users quickly understand the purpose of each link (e.g., destinations vs. activities)

## Changing the default Trips base slug

Go to the **Trips base** field and replace the default **"trip"** with your preferred term (e.g., `tour`, `holiday`). Once updated, your site automatically uses the new slug.

## Changing the default Trip Type base slug

In the **Trip Type base** field, enter a custom slug, such as `style` or `category`, to better describe the types of trips you offer.

## Changing the default Trip Destination base slug

In the **Trip Destination base** field, enter a custom term that makes location-based URLs clearer, such as `destination` or `places`.

## Changing the default Trip Activity base slug

In the **Trip Activity base** field, enter a custom term that better represents the activities included in your trips, such as `activity` or `experiences`.

## Changing the default Trip Tag base slug

In the **Trip Tag base** field, enter a custom term to make tagged trips easier to categorize and search, such as `tags` or `highlights`.

## Changing the default Trip Difficulty base slug

In the **Trip Difficulty base** field, enter a custom term to organize trips by difficulty, such as `level` or `difficulty`.

<Callout kind="alert">
  Changing a base slug updates the permalink structure for that archive immediately. If you change slugs on a live site, consider setting up redirects from the old URLs to avoid broken links in search results or bookmarks.
</Callout>
