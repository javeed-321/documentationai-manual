## Overview

The Labels feature lets you customize static HTML strings used throughout WP Travel Engine. Whether you want default labels to match your site's branding or you need a quick translation, Labels gives you a simple, code-free way to replace any static string with your own text.

## What the Labels feature does

Labels provides an interface for changing default static strings in WP Travel Engine. For example, you can replace "Check Availability" with "Book Now," or change "Travellers" to "Travelers" to match your site's language and tone. This is useful for:

- Personalizing static strings to match your brand.
- Making quick translations for simple, static text.
- Modifying strings without editing code.

<Callout kind="info">
  Labels uses WordPress's `__()` translation function and is built for simple, static strings. It may not reliably replace longer or complex text. For advanced translations, use a dedicated tool like Loco Translate — see [how to translate themes and plugins using Loco Translate](/article/how-to-translate-themes-and-plugins-using-loco-translate).
</Callout>

## How to access the Labels feature

1. Log in to your WordPress admin dashboard.
2. Navigate to **WP Travel Engine → Settings → Display → Labels**.

You'll find an interface here for modifying existing static strings.

## How to use the Labels feature

<Steps title-type="h3">
  <Step title="Add a new label">
    Click **Add Text** at the bottom of the table. A new row appears with two fields: **Initial Text** and **Modified Text**.
  </Step>

  <Step title="Define the strings">
    In **Initial Text**, enter the default string you want to replace — for example, `Check Availability`. In **Modified Text**, enter the new text you want to display — for example, `Vérifier la disponibilité`.
  </Step>

  <Step title="Save changes">
    Click **Save Settings** to apply the changes across your website. The customized label now appears on the front end wherever the original string was used.
  </Step>

  <Step title="Delete a customization (if needed)">
    Click the delete (trash can) icon in the **Action** column next to the label you want to remove. The label reverts to its default value once deleted.
  </Step>
</Steps>

## Example use cases

### Personalization

If your website uses American English, update the default label "Travellers" to "Travelers":

- **Initial Text**: `Travellers`
- **Modified Text**: `Travelers`

### Quick translation

For a quick translation, change "Check Availability" to its French equivalent:

- **Initial Text**: `Check Availability`
- **Modified Text**: `Vérifier la disponibilité`

## Limitations of the Labels feature

Labels is powerful for quick changes, but it isn't designed for:

1. **Complex or dynamic strings** — long strings, or strings generated programmatically, may not be replaced effectively.
2. **Advanced translations** — for a comprehensive multilingual website, use a dedicated translation plugin like Loco Translate instead.

## Recommended tool for advanced translations

For advanced translation needs — including hardcoded strings, themes, and add-ons — use Loco Translate. It provides a more complete solution for translating your travel website. See [how to translate themes and plugins using Loco Translate](/article/how-to-translate-themes-and-plugins-using-loco-translate) for the full walkthrough.

## Summary

The Labels feature gives you a fast, no-code way to personalize static strings on your WP Travel Engine site — ideal for minor wording changes or simple one-off translations. For deeper multilingual support or hardcoded strings, pair it with Loco Translate.
