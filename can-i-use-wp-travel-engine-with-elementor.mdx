---
title: Can I Use WP Travel Engine with Elementor?
description: >-
  Yes — WP Travel Engine works with Elementor through the free WP Travel Engine
  Elementor Widgets add-on, which lets you visually design the Single Trip page.
type: guide
---
Yes, [WP Travel Engine](https://wptravelengine.com/) is compatible with Elementor. Currently, WP Travel Engine only supports editing the **Single Trip page** through Elementor. To build with WP Travel Engine inside Elementor, you'll need the free **WP Travel Engine – Elementor Widgets** add-on.

<Callout kind="info">
  Download the add-on for free from the [WordPress.org plugin repository](https://wordpress.org/plugins/wte-elementor-widgets/).
</Callout>

## WP Travel Engine Elementor Widgets

The WP Travel Engine – Elementor Widgets add-on ships over 20 Elementor widgets built specifically for travel and tour booking sites. With it, you can:

- Create and customize Single Trip pages visually, using Elementor's drag-and-drop editor.
- Use pre-designed templates to speed up page building instead of starting from a blank canvas.

## Set up WP Travel Engine with Elementor

<Steps title-type="h3">
  <Step title="Install WP Travel Engine">
    Install and activate the core WP Travel Engine plugin if you haven't already.
  </Step>

  <Step title="Install Elementor">
    Install and activate the Elementor plugin.
  </Step>

  <Step title="Install WP Travel Engine – Elementor Widgets">
    Download and activate the [WP Travel Engine – Elementor Widgets](https://wordpress.org/plugins/wte-elementor-widgets/) add-on.
  </Step>
</Steps>

Once all three plugins are installed and activated, you can start building and customizing your Single Trip pages with the WP Travel Engine widgets inside Elementor.
