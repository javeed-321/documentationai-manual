## Overview

Travel Monster provides dedicated settings for each type of content on your site: your blog listing, standalone pages, single posts, and taxonomy archives. Access them via **Appearance > Customize > Posts & Pages** in your WordPress dashboard.

<Tabs tabs="Blog Page,Page,Single Post,Archive" default-tab="1">
  <Tab>
    ### Page title

    Access via **Appearance > Customize > Posts & Pages > Blog Page**.

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-35.png" width="338" height="253" alt="Blog page title settings panel in Travel Monster customizer" />

    | Setting              | What it does                                                                                            |
    | -------------------- | ------------------------------------------------------------------------------------------------------- |
    | Show Title           | Displays the page title on the Blog page, when enabled.                                                 |
    | Page Description     | Displays the Blog page's description, when enabled. Add the description text itself in the page editor. |
    | Horizontal Alignment | Sets the alignment for the page title content.                                                          |

    ### Image setting

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-36.png" width="338" height="253" alt="Blog page image settings panel in Travel Monster customizer" />

    **Crop Featured Image:** Crops the featured image to fit the theme's recommended size, when enabled. When disabled, the image displays exactly as uploaded.

    ### Post settings

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-37.png" width="338" height="253" alt="Blog page post settings panel in Travel Monster customizer" />

    | Setting        | What it does                                                                                                                                                         |
    | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | Post Content   | Displays either the full post content or just an excerpt for posts listed on the Blog page.                                                                          |
    | Excerpt Length | Sets how many words appear in the excerpt. Only visible when Post Content is set to Excerpt.                                                                         |
    | Meta Order     | Sets the order of post meta elements (author name, published date, comment count, and so on) by dragging them, and shows or hides each one by clicking its eye icon. |
    | Read More Text | Sets the label text for the Read More link on the blog list.                                                                                                         |

    ### Sidebar layouts

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-38.png" width="338" height="253" alt="Blog page sidebar layout settings in Travel Monster customizer" />

    **Blog Sidebar Layout:** Sets the sidebar layout used on the Blog page.

    ### Header background image

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-39.png" width="338" height="253" alt="Blog page header background image setting in Travel Monster customizer" />

    Uploads a background image for the Blog page header.
  </Tab>

  <Tab>
    ### Page title

    Access via **Appearance > Customize > Posts & Pages > Page**. Adjusts the look and feel of general pages on your website.

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-40.png" width="338" height="253" alt="Page title settings panel in Travel Monster customizer" />

    | Setting              | What it does                                              |
    | -------------------- | --------------------------------------------------------- |
    | Show Title           | Displays the page title in the page header, when enabled. |
    | Horizontal Alignment | Sets the alignment for the page title.                    |

    ### Sidebar layouts

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-41.png" width="338" height="253" alt="Page sidebar layout settings in Travel Monster customizer" />

    **Page Sidebar Layout:** Sets the sidebar layout used on website pages.

    ### Show featured image

    Displays the featured image as page content, when enabled.

    ### Show comments

    Displays comments and the comment form on site pages, when enabled.
  </Tab>

  <Tab>
    ### Sidebar layouts

    Access via **Appearance > Customize > Posts & Pages > Single Post**. Configures the layout and components of blog posts on your website.

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-42.png" width="338" height="253" alt="Single post sidebar layout settings in Travel Monster customizer" />

    Sets the preferred sidebar layout for the single post page.

    ### Crop featured image

    Crops the featured image to fit the theme's recommended size, when enabled. When disabled, the image displays exactly as uploaded.

    ### Post meta settings

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-43.png" width="338" height="253" alt="Single post meta settings panel in Travel Monster customizer" />

    **Meta Order:** Sets the order of post meta elements (author name, published date, comment count, and so on) by dragging them, and shows or hides each one by clicking its eye icon.

    ### Show author box

    Displays an author box with the author's bio on the single post page, when enabled.

    ### Display post tags

    Displays the post's tags, if any, when enabled.

    ### Show pagination

    Displays navigation links to the previous and next post, when enabled.

    ### Related posts

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-45.png" width="338" height="253" alt="Related posts settings panel in Travel Monster customizer" />

    | Setting                     | What it does                                                            |
    | --------------------------- | ----------------------------------------------------------------------- |
    | Show Related Posts          | Displays a Related Posts section on the single post page, when enabled. |
    | Related Posts Section Title | Sets the title for the Related Posts section.                           |
    | Related Post Taxonomy       | Sets the taxonomy used to determine which posts are related.            |
    | Number of Posts             | Sets how many posts appear in the Related Posts section.                |
    | Posts per row               | Sets how many posts display per row in the Related Posts section.       |
    | Location                    | Sets where the Related Posts section appears on the page.               |

    ### Comment settings

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-46.png" width="338" height="253" alt="Comment settings panel in Travel Monster customizer" />

    | Setting       | What it does                                                                  |
    | ------------- | ----------------------------------------------------------------------------- |
    | Show Comments | Displays comments and the comment form on the single post page, when enabled. |
    | Comment Form  | Displays the comment form above or below the listed comments.                 |
    | Location      | Sets where the comment section appears on the page.                           |
  </Tab>

  <Tab>
    ### Page title

    Access via **Appearance > Customize > Posts & Pages > Archive**. Controls the archive page elements on your website.

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-47.png" width="338" height="253" alt="Archive page title settings panel in Travel Monster customizer" />

    | Setting              | What it does                                                           |
    | -------------------- | ---------------------------------------------------------------------- |
    | Show Prefix          | Displays the category prefix in the archive page header, when enabled. |
    | Show Title           | Displays the archive title in the archive page header, when enabled.   |
    | Show Description     | Displays the archive's description text, when enabled.                 |
    | Show Post Counts     | Displays the number of posts inside an archive, when enabled.          |
    | Horizontal Alignment | Sets the alignment for the archive page header content.                |

    ### Sidebar layouts

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-48.png" width="338" height="253" alt="Archive sidebar layout settings in Travel Monster customizer" />

    **Archive Sidebar Layout:** Sets the sidebar layout used for archive pages on your website.

    ### Header background image

    <Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-49.png" width="338" height="253" alt="Archive page header background image setting in Travel Monster customizer" />

    Uploads a general background image for the archive page header.
  </Tab>
</Tabs>
