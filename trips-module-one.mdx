## Overview

The Trips Module One widget lets you showcase trips on any page using Elementor, with a hero-style featured trip layout.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/Trip-Module-1-1024x358.png" alt="Trips Module One widget rendered on a page" width="1024" height="358" />

## Layout settings

- **Gap** – defines the spacing between the rows and columns of trips displayed in this section
- **Layout** – select from a variety of layout options to display trips; several layouts are available so you can customize the appearance of the Trips Module One widget

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/Layout-8-1.png" alt="Layout options for the Trips Module One widget" width="800" height="500" />

## Query settings

- **Show Featured Trip** – select the featured trip you want to display as the hero post

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/query-5.png" alt="Query settings for the Trips Module One widget" width="800" height="500" />

## Hero post settings

- **Featured Ribbon** – displays a "featured" ribbon on trips
- **Discount** – displays the discount percentage
- **Review** – displays trip reviews
- **Trip Meta** – adds the title meta to display for each trip
- **Price** – displays the trip price
- **Show Striked Price on Sale** – displays the struck-through original price for trips on sale
- **Duration Type** – choose whether trip duration displays in days or nights
- **Price Label** – sets the price label text
- **Wishlist** – displays the wishlist icon

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/hero-post.png" alt="Hero post settings for the Trips Module One widget" width="800" height="500" />

## Additional settings

- **Location** – displays the trip's location
- **Title** – displays the trip title

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/additional-8.png" alt="Additional settings for the Trips Module One widget" width="800" height="500" />

## General style settings

- **Background Color** – sets the background color for the widget section
- **Padding** – adjusts the padding around the content within the widget section
- **Border Radius** – controls the roundness of the corners
- **Border Type** – sets the border type for the widget section
- **Box Shadow** – configures the box shadow effect for the trip cards within the widget section

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/General-2.png" alt="General style settings for the Trips Module One widget" width="800" height="500" />
