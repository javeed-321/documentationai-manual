## Overview

The Logo widget lets you display your site or affiliate logo on any page built with Elementor. You can choose between your default WordPress site logo or a custom uploaded logo, and control its resolution and size.

## Layout settings

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2025/12/Screenshot_122425_032057_PM.jpg" width="291" height="485" alt="Logo widget layout settings in Elementor" />

### Logo type

Choose the source of the logo:

- **Default** – displays the site logo set in WordPress
- **Custom** – lets you upload a custom logo, such as an affiliate logo

### Image resolution

Select the resolution of the logo image to ensure optimal display quality across devices.

### Image width

Set the width of the logo image to control its size within the layout.
