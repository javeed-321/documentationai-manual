## Overview

WP Travel Engine is a powerful WordPress plugin that lets you create professional travel booking websites. You can build detailed trip pages with itineraries, pricing, galleries, and booking forms. It handles everything from trip management to customer portals, making it easy to run a travel business online.

Key benefits include customizable designs, seamless booking integration, and pro addons for advanced features like seat allocation and social login. Whether you manage tours, adventures, or packages, WP Travel Engine streamlines your workflow while delivering great user experiences.

## Quick Start

<Callout kind="info">
  Ensure you have WordPress `>=5.0` and PHP `>=7.4`. Basic hosting with MySQL support works best.
</Callout>

Follow these steps to get WP Travel Engine running in minutes.

<Steps>
  <Step title="Install the Plugin" icon="download">
    Choose your preferred method.

    <Tabs>
      <Tab title="WordPress Admin" icon="monitor">
        1. Go to **Plugins > Add New**.
        2. Upload the `wp-travel-engine.zip` file.
        3. Click **Install Now** then **Activate**.
      </Tab>
      <Tab title="WP-CLI" icon="terminal">
````bash
wp plugin install wp-travel-engine.zip --activate
````
      </Tab>
    </Tabs>
  </Step>
  <Step title="Create Your First Trip" icon="plus">
    Navigate to **Trips > Add New** in your admin dashboard.

    Fill in:
    - General info (title, description)
    - Date and price
    - Itinerary tabs

    Publish the trip.
  </Step>
  <Step title="Display Trips" icon="eye">
    Add this shortcode to any page or post:

````php
[wpte_trip_search]
````

    Or use Gutenberg blocks: Search for "WP Travel Engine" blocks.
  </Step>
</Steps>
