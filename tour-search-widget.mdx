## Overview

The Tour Search widget lets visitors quickly search and filter trips on your travel website.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2025/11/Tour-Search-1024x180.png" alt="Tour Search widget rendered on a page" width="1024" height="180" />

## Prerequisites

Before adding this widget, install and activate the [WP Travel Engine – Elementor Widgets](https://wordpress.org/plugins/wte-elementor-widgets/) plugin. Once it's activated, you can add and customize the Tour Search widget using the Elementor page builder.

## Configuring taxonomy filters

These options control which taxonomies (filters) appear in the Tour Search widget. Taxonomies help visitors filter trips based on different criteria.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2025/11/Step-2.png" alt="Taxonomy filter settings for the Tour Search widget" width="800" height="500" />

### Select taxonomy

Choose which filters (taxonomies) to display in the search widget:

- **Destination**
- **Activities**
- **Trip Types**

### Show terms by

Controls how the terms inside each taxonomy are displayed:

- **Default** – automatically shows all terms from the selected taxonomy
- **Choose From the List** – lets you manually select specific terms that should appear in the filter

## Additional settings

These settings give you extra customization options for the search widget.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2025/11/Additional.png" alt="Additional settings for the Tour Search widget" width="800" height="500" />

- **Show Category** – enables or disables the category filter in the search widget
- **Button Text** – sets the label shown on the search button
- **Button Link** – adds a custom URL if you want the search button to redirect visitors to a specific page
- **Button Icon** – adds an icon to the button; you can upload an SVG file or choose an icon from the icon library to match your design
