# Linode API Documentation

> Programmatically create Linode instances, deploy Kubernetes clusters, and use the full range of Akamai cloud computing products and services.

## API Reference: Longview

- [Create a Longview client](https://techdocs.akamai.com/linode-api/reference/post-longview-client.md): Creates a Longview Client.  This Client will not begin monitoring the status of your server until you configure the Longview Client application on your Linode using the returning `install_code` and `api_key`.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `account_longview_creator` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `longview:read_write`   **CLI**  `shell linode-cli longview create \   --label client789 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List Longview clients](https://techdocs.akamai.com/linode-api/reference/get-longview-clients.md): Returns a paginated list of Longview Clients you have access to. Longview Client is used to monitor stats on your Linode with the help of the Longview Client application.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `longview_viewer` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `longview:read_only`   **CLI**  `shell linode-cli longview list `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get a Longview client](https://techdocs.akamai.com/linode-api/reference/get-longview-client.md): Returns a single Longview Client you can access.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `longview_viewer` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `longview:read_only`   **CLI**  `shell linode-cli longview view 789 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Update a Longview client](https://techdocs.akamai.com/linode-api/reference/put-longview-client.md): Updates a Longview Client.  This cannot update how it monitors your server; use the Longview Client application on your Linode for monitoring configuration.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `longview_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `longview:read_write`   **CLI**  `shell linode-cli longview update 789 \   --label client789 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Delete a Longview client](https://techdocs.akamai.com/linode-api/reference/delete-longview-client.md): Deletes a Longview Client from your Account.  **All information stored for this client will be lost.**  This _does not_ uninstall the Longview Client application for your Linode - you must do that manually.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `longview_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `longview:read_write`   **CLI**  `shell linode-cli longview delete 789 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get a Longview plan](https://techdocs.akamai.com/linode-api/reference/get-longview-plan.md): Get the details of your current Longview plan. If your current plan is Longview Free, this operation returns an empty set `{}`.  To update your subscription plan, send a request to [Update a Longview plan](/reference/put-longview-plan).   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `longview_viewer` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `longview:read_only`   **CLI**  `shell linode-cli longview plan-view `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Update a Longview plan](https://techdocs.akamai.com/linode-api/reference/put-longview-plan.md): Update your Longview plan to that of the given subscription ID. If the updated plan is Longview Free, this operation returns an empty set `{}`.  You can send a request to the [List Longview subscriptions](/reference/get-longview-subscriptions) operation to receive the details, including `id`'s, of each plan.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `account_longview_subscription_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `longview:read_write`   **CLI**  `shell linode-cli longview plan-update --longview_subscription longview-10 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List Longview subscriptions](https://techdocs.akamai.com/linode-api/reference/get-longview-subscriptions.md): Returns a paginated list of available Longview subscriptions.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `longview_viewer`   **CLI**  `shell linode-cli longview subscriptions-list `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get a Longview subscription](https://techdocs.akamai.com/linode-api/reference/get-longview-subscription.md): Get a specific Longview subscription plan.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `longview_admin`   **CLI**  `shell linode-cli longview subscription-view `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List Longview types](https://techdocs.akamai.com/linode-api/reference/get-longview-types.md): Returns Longview types and prices, including any region-specific rates.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `longview_viewer`   **CLI**  `shell linode-cli longview types `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
