# Linode API Documentation

> Programmatically create Linode instances, deploy Kubernetes clusters, and use the full range of Akamai cloud computing products and services.

## API Reference: Linode StackScripts

- [Create a StackScript](https://techdocs.akamai.com/linode-api/reference/post-add-stack-script.md): Creates a StackScript in your Account.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `account_stackscript_creator` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `stackscripts:read_write`   **CLI**  `shell linode-cli stackscripts create \   --label a-stackscript \   --description "This StackScript install and configures MySQL" \   --images "linode/debian13" \   --images "linode/debian13" \   --is_public true \   --rev_note "Set up MySQL" \   --script '#!/bin/bash' `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List StackScripts](https://techdocs.akamai.com/linode-api/reference/get-stack-scripts.md): If the request is not authenticated, only public StackScripts are returned.  For more information on StackScripts, please read our [StackScripts documentation](https://techdocs.akamai.com/cloud-computing/docs/stackscripts).   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `Public StackScripts are Internet facing, and Private StackScripts require the stackscript_viewer role` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `stackscripts:read_only`   **CLI**  `shell linode-cli stackscripts list `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get a StackScript](https://techdocs.akamai.com/linode-api/reference/get-stack-script.md): Returns all of the information about a specified StackScript, including the contents of the script.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `stackscript_viewer` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `stackscripts:read_only`   **CLI**  `shell linode-cli stackscripts view 10079 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Update a StackScript](https://techdocs.akamai.com/linode-api/reference/put-stack-script.md): Updates a StackScript.  **Once a StackScript is made public, it cannot be made private.**   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `stackscript_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `stackscripts:read_write`   **CLI**  `shell linode-cli stackscripts update 10079 \   --label a-stackscript \   --description "This StackScript installs \     and configures MySQL" \   --images "linode/debian13" \   --images "linode/debian13" \   --is_public true \   --rev_note "Set up MySQL" \   --script '#!/bin/bash' `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Delete a StackScript](https://techdocs.akamai.com/linode-api/reference/delete-stack-script.md): Deletes a private StackScript. You can't delete a public StackScript.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs these roles assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Roles: `stackscript_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `stackscripts:read_write`   **CLI**  `shell linode-cli stackscripts delete 10079 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
