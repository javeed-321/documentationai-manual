# Linode API Documentation

> Programmatically create Linode instances, deploy Kubernetes clusters, and use the full range of Akamai cloud computing products and services.

## API Reference: VPCs

- [Create a VPC](https://techdocs.akamai.com/linode-api/reference/post-vpc.md): Create a new VPC and optionally define new subnets within it. A successful request triggers a `vpc_create` event, and `subnet_create` events for any created VPC subnets.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `create_vpc` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `vpc:read_write`   **CLI**  `shell linode-cli vpcs create \   --description "A description of my VPC." \   --label cool-vpc \   --region us-east \   --subnets.label cool-vpc-subnet \   --subnets.ipv4 10.0.1.0/24 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List VPCs](https://techdocs.akamai.com/linode-api/reference/get-vpcs.md): Display all VPCs on your account.  The system automatically sorts the IPv4 ranges using standard Python network sorting logic, the primary sort is by network address, and then by prefix length.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `view_vpc`   **CLI**  `shell linode-cli vpcs list `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get a VPC](https://techdocs.akamai.com/linode-api/reference/get-vpc.md): Get information about a single VPC.  The system automatically sorts the IPv4 ranges using standard Python network sorting logic, the primary sort is by network address, and then by prefix length.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `view_vpc`   **CLI**  `shell linode-cli vpcs view $vpcId `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Update a VPC](https://techdocs.akamai.com/linode-api/reference/put-vpc.md): Update an existing VPC. A successful request triggers a `vpc_update` event.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `update_vpc` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `vpc:read_write`   **CLI**  `shell linode-cli vpcs update $vpcId \   --description "A description of my VPC." \   --label myvpc `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Delete a VPC](https://techdocs.akamai.com/linode-api/reference/delete-vpc.md): Delete a single VPC and all of its Subnets.  - A successful request triggers a `vpc_delete` event and `subnet_delete` events for each deleted VPC subnet. - All of the VPC's subnets need to be eligible for deletion. You need to delete all network interfaces each subnet is assigned to. If those interfaces are active, you need to shut down the associated Linodes first. If any subnet can't be deleted, it prevents the VPC and its subnets from being deleted. - You can't delete a VPC if a NodeBalancer or a managed database is attached to one of its subnets.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `delete_vpc` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `vpc:read_write`   **CLI**  `shell linode-cli vpcs delete $vpcId `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List VPC IP addresses](https://techdocs.akamai.com/linode-api/reference/get-vpcs-ips.md): Returns a paginated list of all VPC IP addresses and address ranges on your account.  > 📘 > > If a Linode has several configuration profiles that include a VPC interface, address information for all of them is listed in the response. Since VPCs can use the same address space, you may see duplicate IP addresses.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `list_vpcs_ip_addresses` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `ips:read_only`   **CLI**  `shell linode-cli vpcs ips-all-list `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List a VPC's IP addresses](https://techdocs.akamai.com/linode-api/reference/get-vpc-ips.md): Returns a paginated list of IP addresses for a single VPC.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `list_vpc_ip_addresses` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `ips:read_only`   **CLI**  `shell linode-cli vpcs ip-list 123 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Create a VPC subnet](https://techdocs.akamai.com/linode-api/reference/post-vpc-subnet.md): Create a VPC subnet within an existing VPC. A successful request triggers a `subnet_create` event.  After you create a VPC subnet, you can attach it to a Linode by assigning the subnet to one of the Linode's network interfaces.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `create_vpc_subnet` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `vpc:read_write`   **CLI**  `shell linode-cli vpcs subnet-create $vpcId \   --label cool-vpc-subnet \   --ipv4 10.0.1.0/24 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List VPC subnets](https://techdocs.akamai.com/linode-api/reference/get-vpc-subnets.md): Get information about all VPC Subnets associated with a VPC.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `view_vpc_subnet`   **CLI**  `shell linode-cli vpcs subnets-list $vpcId `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get a VPC subnet](https://techdocs.akamai.com/linode-api/reference/get-vpc-subnet.md): Get information about a single VPC Subnet.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `view_vpc_subnet`   **CLI**  `shell linode-cli vpcs subnet-view $vpcId $vpcSubnetId `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Update a VPC subnet](https://techdocs.akamai.com/linode-api/reference/put-vpc-subnet.md): Update a VPC Subnet. A successful request triggers a `subnet_update` event.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `update_vpc_subnet` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `vpc:read_write`   **CLI**  `shell linode-cli vpcs subnet-update $vpcId \   --label cool-vpc-subnet `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Delete a VPC subnet](https://techdocs.akamai.com/linode-api/reference/delete-vpc-subnet.md): Delete a single VPC subnet. A successful request triggers a `subnet_delete` event.  > 📘 > > You need to delete all network interfaces, managed databases and NodeBalancers that this subnet is assigned to before you can delete it. If interfaces are active, the associated Linode needs to be shut down before they can be removed. For more information see: > > - [Delete a Linode interface](/reference/delete-linode-interface) and [Delete a configuration profile interface](/reference/delete-linode-config-interface) > - [Delete a MySQL Managed Database](/reference/delete-databases-mysql-instance) and [Delete a PostgreSQL Managed Database](/reference/delete-databases-postgre-sql-instance) > - [Delete a NodeBalancer](/reference/delete-node-balancer)   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `delete_vpc_subnet` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `vpc:read_write`   **CLI**  `shell linode-cli vpcs subnet-delete $vpcId $vpcSubnetId `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
