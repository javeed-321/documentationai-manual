# Linode API Documentation

> Programmatically create Linode instances, deploy Kubernetes clusters, and use the full range of Akamai cloud computing products and services.

## API Reference: Beta programs

- [List Beta programs](https://techdocs.akamai.com/linode-api/reference/get-beta-programs.md): Display all active Beta programs. This operation can only be accessed by account [users](/reference/get-users) with _unrestricted_ access. Talk to your local account administrator about access management.   **CLI**  `shell linode-cli betas list `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get a Beta program](https://techdocs.akamai.com/linode-api/reference/get-beta-program.md): Display information about a Beta program. You can use it to access inactive and active Beta programs. This operation can only be accessed by account [users](/reference/get-users) with _unrestricted_ access. Talk to your local account administrator about access management.   **CLI**  `shell linode-cli betas view $betaId `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
