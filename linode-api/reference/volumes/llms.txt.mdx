# Linode API Documentation

> Programmatically create Linode instances, deploy Kubernetes clusters, and use the full range of Akamai cloud computing products and services.

## API Reference: Volumes

- [Create a volume](https://techdocs.akamai.com/linode-api/reference/post-volume.md): Creates a [Block Storage](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-block-storage) volume on your account. Creating a new volume accrues additional charges on your account.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `create_volume` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `volumes:read_write`   **CLI**  `shell linode-cli volumes create \   --label my-volume \   --size 20 \   --linode_id 12346 \   --no-defaults `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List volumes](https://techdocs.akamai.com/linode-api/reference/get-volumes.md): Returns a paginated list of the Block Storage volumes that you have permission to view.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `view_volume` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `volumes:read_only`   **CLI**  `shell linode-cli volumes list `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Get a volume](https://techdocs.akamai.com/linode-api/reference/get-volume.md): Get information about a specific Block Storage volume.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `view_volume` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `volumes:read_only`   **CLI**  `shell linode-cli volumes view 12345 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Update a volume](https://techdocs.akamai.com/linode-api/reference/put-volume.md): Update a specific Block Storage volume.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `update_volume` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `volumes:read_write`   **CLI**  `shell linode-cli volumes update 12345 \   --label my_volume `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Delete a volume](https://techdocs.akamai.com/linode-api/reference/delete-volume.md): Delete a Block Storage volume. Some conditions apply when deleting a volume:  - Deleting a volume can't be undone.  - Deleting stops billing for the volume. You'll be billed for the time the volume was active during the current billing period.  - You can't delete a volume that's attached to a Linode currently being [migrated](/reference/post-migrate-linode-instance). You need to wait for the migration to complete.  - You can't delete a volume that has a `cannot_delete` or `cannot_delete_with_subresources` [resource lock](/reference/post-resource-lock) set for it.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `delete_volume` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `volumes:read_write`   **CLI**  `shell linode-cli volumes delete 12345 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Attach a volume](https://techdocs.akamai.com/linode-api/reference/post-attach-volume.md): Attach a Block Storage volume to an existing Linode.  > 📘 > > - The volume and its target Linode need to exist in the same `region`. You can run the [List volumes](/reference/get-volumes) and [List Linodes](/reference/get-linode-instances) operations and review the `region` for each. > > - There's a maximum number of volumes that can be attached to a single Linode configuration. This number varies, based on the Linode's plan, with higher plan types supporting more volumes. The maximum follows a formula of the Linode plan's `total_ram / 1024`, with a minimum of 8 and a total maximum of 64 volumes. Rescue configurations support a maximum of 8.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `attach_volume` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `volumes:read_write, linodes:read_write`   **CLI**  `shell linode-cli volumes attach 12345 \   --linode_id 12346 \   --config_id 23456 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Clone a volume](https://techdocs.akamai.com/linode-api/reference/post-clone-volume.md): Target an existing Block Storage volume to create a new one. The resulting volume will be the same size and include the same data. A new volume will incur a charge on your account.  > 📘 > > Only a volume with a `status` of `active` can be cloned. Run the [List volumes](/reference/get-volumes) operation to view the `status` of each of your volumes.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `clone_volume` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `volumes:read_write`   **CLI**  `shell linode-cli volumes clone 12345 \   --label my-volume `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Detach a volume](https://techdocs.akamai.com/linode-api/reference/post-detach-volume.md): Detach a Block Storage volume from a Linode. When you [delete](/reference/delete-linode-instance) a Linode, any volumes attached to it are automatically detached.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `detach_volume` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `volumes:read_write, linodes:read_write`   **CLI**  `shell linode-cli volumes detach 12345 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [Resize a volume](https://techdocs.akamai.com/linode-api/reference/post-resize-volume.md): Increase the size of an existing Block Storage volume on your account.  > 📘 > > - You can't decrease the size of an existing volume. > > - Only a volume with a `status` of `active` can be resized. Run the [List volumes](/reference/get-volumes) operation to view the `status` of each of your volumes.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. Your user needs a role with these permissions assigned. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles).   - Permissions: `resize_volume` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth).    - Scopes: `volumes:read_write`   **CLI**  `shell linode-cli volumes resize 12345 \   --size 30 `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
- [List volume types](https://techdocs.akamai.com/linode-api/reference/get-volume-types.md): Returns Block Storage volume types and prices, including any region-specific rates.   **Permissions and scopes**  To call this operation, you need the following:  - **Identity and access permissions**. This operation is internet-facing. No permissions are required.   **CLI**  `shell linode-cli volumes types `  [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
