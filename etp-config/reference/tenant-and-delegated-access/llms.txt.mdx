# SIA Configuration API Documentation

> Akamai's Secure Internet Access (SIA) Configuration API offers a programmatic interface to manage policy settings to protect against enterprise security and acceptable user policy related events. A distributed configuration encapsulates all the rules for how to process DNS requests for your enterprise.

## API Reference: Tenant and Delegated Access

- [Onboard a tenant](https://techdocs.akamai.com/etp-config/reference/post-onboard-tenant.md): Onboards a new Tenant.
- [List all tenants](https://techdocs.akamai.com/etp-config/reference/get-tenants.md): Returns all tenants.
- [Get a tenant](https://techdocs.akamai.com/etp-config/reference/get-tenant.md): Returns a tenant details.
- [Update a tenant](https://techdocs.akamai.com/etp-config/reference/put-tenant.md): Updates the specified tenant.
- [Remove a tenant](https://techdocs.akamai.com/etp-config/reference/delete-tenant.md): Deletes a specific tenant.
- [List tenant users](https://techdocs.akamai.com/etp-config/reference/get-tenant-users.md): Lists details of users assigned to a tenant.
