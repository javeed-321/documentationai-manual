# SIA Configuration API Documentation

> Akamai's Secure Internet Access (SIA) Configuration API offers a programmatic interface to manage policy settings to protect against enterprise security and acceptable user policy related events. A distributed configuration encapsulates all the rules for how to process DNS requests for your enterprise.

## API Reference: Policies

- [Create a policy](https://techdocs.akamai.com/etp-config/reference/post-policy.md): Creates a new policy.
- [List policies](https://techdocs.akamai.com/etp-config/reference/get-policies.md): Returns all policies.
- [Get a policy](https://techdocs.akamai.com/etp-config/reference/get-policy.md): Returns the details of a policy.
- [Update a policy](https://techdocs.akamai.com/etp-config/reference/put-policy.md): Modifies the specified policy.
- [Remove a policy](https://techdocs.akamai.com/etp-config/reference/delete-policy.md): Deletes the specified policy.
- [Get policy metadata](https://techdocs.akamai.com/etp-config/reference/get-policy-metadata.md): Returns the policy metadata details.
- [List built-in responses](https://techdocs.akamai.com/etp-config/reference/get-responses.md): Returns all available Akamai built-in responses.
- [List security category predefined configurations](https://techdocs.akamai.com/etp-config/reference/get-security-categories.md): Returns all available predefined security categories.
