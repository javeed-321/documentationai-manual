# SIA Configuration API Documentation

> Akamai's Secure Internet Access (SIA) Configuration API offers a programmatic interface to manage policy settings to protect against enterprise security and acceptable user policy related events. A distributed configuration encapsulates all the rules for how to process DNS requests for your enterprise.

## API Reference: Data Loss Prevention Dictionary

- [Create a DLP dictionary](https://techdocs.akamai.com/etp-config/reference/post-dictionary.md): Creates a DLP dictionary.
- [List DLP dictionaries](https://techdocs.akamai.com/etp-config/reference/get-dictionaries.md): Lists all DLP dictionaries for the configuration.
- [Get a DLP dictionary](https://techdocs.akamai.com/etp-config/reference/get-dictionary.md): Returns details of a DLP dictionary.
- [Update a DLP dictionary](https://techdocs.akamai.com/etp-config/reference/put-dictionary.md): Updates a DLP dictionary.
- [Remove a DLP dictionary](https://techdocs.akamai.com/etp-config/reference/delete-dictionary.md): Deletes a specific DLP dictionary.
- [Create a DLP pattern](https://techdocs.akamai.com/etp-config/reference/post-patterns.md): Creates a DLP custom dictionary pattern.
- [List DLP dictionary patterns](https://techdocs.akamai.com/etp-config/reference/get-patterns.md): Returns the DLP dictionary patterns.
- [Get a DLP dictionary pattern](https://techdocs.akamai.com/etp-config/reference/get-pattern.md): Returns the specified DLP dictionary pattern.
- [Delete a DLP dictionary pattern](https://techdocs.akamai.com/etp-config/reference/delete-pattern.md): Removes the specified DLP dictionary pattern.
- [Create DLP regular expressions](https://techdocs.akamai.com/etp-config/reference/post-dlp-regexes.md): Creates DLP regular expressions.
- [List DLP regular expressions](https://techdocs.akamai.com/etp-config/reference/get-dlp-regexes.md): Returns all DLP regular expressions.
- [Get a DLP regular expression](https://techdocs.akamai.com/etp-config/reference/get-dlp-regex.md): Returns the specified DLP regular expression details.
