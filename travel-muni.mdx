## Before you start

This documentation walks through installing and configuring the [Travel Muni](https://wptravelengine.com/wordpress-travel-themes/travel-muni/?utm_source=travel_muni\&utm_medium=docs\&utm_campaign=upgrade_theme) WordPress theme, from initial setup through every Customizer section the theme adds.

Work through it in order the first time to get a full picture of the theme. If you're looking for a specific setting later, use the section cards below to jump straight there, or press <kbd>Ctrl</kbd>+<kbd>F</kbd> to search this page for a keyword.

<Callout kind="tip">
  Prefer video? Travel Muni also has a full [video walkthrough](https://www.youtube.com/embed/t8VUn0jJrSY) covering installation and setup.
</Callout>

<Callout kind="info">
  Have a question that isn't covered here? [Open a support ticket](https://wptravelengine.com/support-ticket/) and the WP Travel Engine team will help.
</Callout>

## Requirements for getting started

Travel Muni works with WordPress 4.5 and above. For the best experience — including added features and the latest security patches — update to the newest version of WordPress before installing the theme. You can download the latest version from the [WordPress repository](https://wordpress.org/download/).

Checklist before you begin:

- Check your WordPress version and update it if needed.
- Install and activate the Travel Muni theme.
- Install the recommended plugins — some theme functionality won't work without them.

### Check and update your WordPress version

Go to **Dashboard > Updates** and install any available WordPress update before continuing.

## Recommended image sizes

Use these dimensions so your images display correctly across the theme:

| Element                 | Recommended size |
| ----------------------- | ---------------- |
| Header Image            | 960 × 650 px     |
| Header Background Image | 1920 × 350 px    |
| Site Logo               | 150 × 150 px     |
| Trip Taxonomy Image     | 600 × 600 px     |
| Post Thumbnail Image    | 610 × 343 px     |
| Single Trip Page Banner | 1920 × 500 px    |

## Import the demo content

Importing the Travel Muni demo content is the fastest way to make your site look like the theme's live preview.

<Steps title-type="h3">
  <Step title="Download the demo content">
    [Download the Travel Muni demo content](https://docs.wptravelengine.com/wp-content/uploads/2022/04/travel-muni-demo-content.zip) and extract the `.zip` file.
  </Step>

  <Step title="Install the demo import plugin">
    Install and activate the [One Click Demo Import](https://wordpress.org/plugins/one-click-demo-import/) plugin.
  </Step>

  <Step title="Open the demo importer">
    Go to **Appearance > Import Demo Data**.
  </Step>

  <Step title="Upload the demo files">
    Select and upload the XML file, WIE file, and DAT file from the extracted demo content folder.
  </Step>

  <Step title="Run the import">
    Click **Continue & Import**. The process can take a few minutes — don't close or refresh the page while it runs.
  </Step>
</Steps>

<Callout kind="success">
  You'll see a success message once the import finishes.
</Callout>

## Install and activate the theme

<Callout kind="alert">
  On macOS Safari, downloaded `.zip` files sometimes unzip automatically. Confirm your theme file is still in `.zip` format before uploading — [here's how to stop Safari from auto-unzipping files](https://apple.stackexchange.com/questions/961/how-to-stop-safari-from-unzipping-files-after-download).
</Callout>

<Steps title-type="h3">
  <Step title="Save the theme file">
    Save the downloaded `travel-muni.zip` file somewhere on your computer.
  </Step>

  <Step title="Open the theme uploader">
    Go to **Appearance > Themes**, click **Add New**, then click **Upload Theme**.
  </Step>

  <Step title="Upload the theme">
    Click **Choose File**, select `travel-muni.zip`, and click **Open**.
  </Step>

  <Step title="Activate the theme">
    Once installation finishes, click **Activate**.
  </Step>
</Steps>

## Install recommended plugins

Install and activate these plugins to get the full Travel Muni experience:

| Plugin                                                                          | What it does                                                                                                                               |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| [WP Travel Engine](https://wordpress.org/plugins/wp-travel-engine/)             | Lets you create and manage travel trips, destinations, itineraries, and other trip details. Extends your site's core travel functionality. |
| [Travel Booking Toolkit](https://wordpress.org/plugins/travel-booking-toolkit/) | Adds extra Customizer and widget functionality so your site can support more features.                                                     |
| [Contact Form 7](https://wordpress.org/plugins/contact-form-7/)                 | Lets you build and manage multiple contact forms.                                                                                          |
| [Regenerate Thumbnails](https://wordpress.org/plugins/regenerate-thumbnails/)   | Regenerates image thumbnail sizes for existing content — run this if you're migrating existing media into the theme.                       |

<Steps title-type="h3">
  <Step title="Open the plugin installer">
    Go to **Appearance > Install Plugins**.
  </Step>

  <Step title="Install each plugin">
    Click **Install** next to each recommended plugin.
  </Step>

  <Step title="Activate each plugin">
    Click **Activate** for each plugin once it's installed.
  </Step>
</Steps>

## Set up your homepage and blog page

To customize the theme, first set up a static front page. If you want your site to match the demo, set the homepage to display a static page.

<Steps title-type="h3">
  <Step title="Open Homepage Settings">
    Go to **Appearance > Customize > Homepage Settings**.
  </Step>

  <Step title="Select a static homepage">
    Choose **A Static Page** under **Your homepage displays**.
  </Step>

  <Step title="Assign your pages">
    Choose the page you want as your homepage under **Homepage**, and the page you want as your blog listing under **Posts Page**.
  </Step>

  <Step title="Publish your changes">
    Click **Publish**.
  </Step>
</Steps>
