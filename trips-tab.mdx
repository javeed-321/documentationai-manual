## Overview

The Trips Tab widget lets you showcase trips on any page in a tabbed layout using Elementor.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/trip-tab-1024x345.png" width="1024" height="345" alt="Trips Tab widget rendered on a page" />

## Layout settings

- **Layout** – select from a variety of layout options to display trips; several layouts are available so you can customize the appearance of the Trips Tab widget

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/layout-2.png" width="800" height="500" alt="Layout options for the Trips Tab widget" />

## Query settings

- **Number of Trips** – specify the total number of trips to display
- **Offset** – set the number of trips to skip before displaying the rest
- **Taxonomy** – select the taxonomy used for filtering the displayed trips

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/query-4.png" width="800" height="500" alt="Query settings for the Trips Tab widget" />

## Additional settings

- **Enable Slider** – toggles displaying the tabs in a slider format
- **Featured Ribbon** – displays a "featured" ribbon on trips
- **Discount** – displays the discount percentage
- **Review** – displays trip reviews
- **Location** – displays the trip's location
- **Title** – displays the trip title
- **Title Meta** – adds the title meta to display for each trip
- **Price** – displays the trip price
- **Show Striked Price on Sale** – displays the struck-through original price for trips on sale
- **Duration Type** – choose whether trip duration displays in days or nights
- **Price Label** – sets the price label text
- **Wishlist** – displays the wishlist icon
- **Show View More Button** – displays a "view more" button

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/additional-2.png" width="800" height="500" alt="Additional settings for the Trips Tab widget" />

## Slider settings

These settings apply when **Enable Slider** is turned on.

- **Slider Number** – sets the number of slides to display at once
- **Space Between Slides** – defines the spacing between each slide, in pixels
- **Autoplay** – enables automatic transitions between slides
- **Autoplay Speed** – sets the time between each slide transition, in milliseconds
- **Loop** – continuously cycles slides after the last one
- **Transition Speed** – adjusts the speed of slide transitions, in milliseconds
- **Slider Arrow** – shows navigation arrows
- **Slider Pagination** – shows dots for navigating between slides

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/slider-1.png" width="800" height="500" alt="Slider settings for the Trips Tab widget" />

## General style settings

- **Background Color** – sets the background color for the widget section
- **Padding** – adjusts the padding around the content within the widget section
- **Border Radius** – controls the roundness of the corners
- **Border Type** – sets the border type for the widget section
- **Box Shadow** – configures the box shadow effect for the trip cards within the widget section

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/General-2.png" width="800" height="500" alt="General style settings for the Trips Tab widget" />

## Tab styling

- **Layout** – choose from various layout options to display the tabs
- **Gap** – adjusts the column and row gaps between the tabs
- **Orientation** – selects horizontal or vertical tab orientation
- **Typography** – customizes font size, style, and weight for the tabs
- **Color** – sets the tab color in both active and inactive states

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/tabs.png" width="1248" height="420" alt="Tab styling settings for the Trips Tab widget" />
