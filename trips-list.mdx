## Overview

The Trips List widget lets you showcase trips on any page in a compact list layout using Elementor.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/Trips-List-1024x202.png" alt="Trips List widget rendered on a page" width="1024" height="202" />

## Layout settings

- **Column** – chooses the number of trips to display per row
- **Gap** – sets the spacing between the rows and columns of trips
- **Layout** – select from three layout options to display trips, each customizing the appearance of the Trips List widget

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/layout-9.png" alt="Layout options for the Trips List widget" width="800" height="500" />

## Query settings

- **Show Trips by** – choose how trips are selected: latest trips, trips on sale, featured trips, trips filtered by term, or specific trips picked from a list
- **Number of Trips** – specify the total number of trips to display

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/query-2.png" alt="Query settings for the Trips List widget" width="800" height="500" />

## Additional settings

- **Location** – displays the trip's location
- **Title** – displays the trip title
- **Wishlist** – displays the wishlist icon

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/Additional-10.png" alt="Additional settings for the Trips List widget" width="800" height="500" />

## General style settings

- **Typography** – configures the typography for the widget section
- **Padding** – adjusts the padding around the content within the widget section
- **Margin** – sets the margin for the widget section
- **Alignment** – aligns the widget section
- **Background Color** – sets the background color for the widget section
- **Box Shadow** – configures the box shadow effect for the trip cards within the widget section
- **Border Type** – selects the border type for the widget section, for both normal and hover states
- **Border Radius** – controls the roundness of the corners, for both normal and hover states

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/08/General-6-1.png" alt="General style settings for the Trips List widget" width="800" height="500" />
