## Overview

Travel Monster provides several settings under Main Header Settings for configuring your site header's elements. Access these via **Appearance > Customize > General Settings > Main Header** in your WordPress dashboard.

## General settings

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-26.png" width="326" height="450" alt="General header settings panel in Travel Monster customizer" />

| Setting          | What it does                                                      |
| ---------------- | ----------------------------------------------------------------- |
| Header Width     | Sets the width of the header container.                           |
| Sticky Header    | Makes the header stick in place as visitors scroll, when enabled. |
| Header Search    | Displays a search icon in the site header when enabled.           |
| Top Header Color | Sets the background color for the top header.                     |
| Text Color       | Sets the text color for the top header.                           |

## Navigation menu

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-27.png" width="326" height="450" alt="Navigation menu settings panel in Travel Monster customizer" />

| Setting        | What it does                                                                    |
| -------------- | ------------------------------------------------------------------------------- |
| Items Spacing  | Sets the spacing between menu items.                                            |
| Stretch Menu   | Stretches menu items across the full width of the menu container, when enabled. |
| Dropdown Width | Sets the width of the dropdown menu container.                                  |

## Contact information

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-28.png" width="326" height="450" alt="Contact information settings panel in Travel Monster customizer" />

| Setting | What it does                                            |
| ------- | ------------------------------------------------------- |
| Phone   | Sets the contact number displayed in the header.        |
| Email   | Sets the contact email address displayed in the header. |

## Header button

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-29.png" width="326" height="450" alt="Header button settings panel in Travel Monster customizer" />

| Setting                | What it does                                                       |
| ---------------------- | ------------------------------------------------------------------ |
| Button Label           | Sets the label text for the header button.                         |
| Button URL             | Sets the URL the header button links to.                           |
| Open link in new Tab   | Opens the header button's link in a new tab, when enabled.         |
| Show in Sticky Header  | Displays the header button inside the sticky header, when enabled. |
| Background Color       | Sets the header button's background color.                         |
| Background Hover Color | Sets the header button's background color on hover.                |
| Text Color             | Sets the header button's text color.                               |
| Text Hover Color       | Sets the header button's text color on hover.                      |

## Social media settings

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-30.png" width="326" height="450" alt="Social media settings panel in Travel Monster customizer" />

| Setting            | What it does                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| Social Media       | Displays social media icons in the site header, when the toggle is enabled.                    |
| Open in new tab    | Opens linked social network accounts in a new tab, when enabled.                               |
| Social Media Icons | Shows or hides an individual social media icon in the site header when you click its eye icon. |

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-31.png" width="326" height="450" alt="Social media icons visibility toggle in Travel Monster customizer" />

<Callout kind="info">
  Social media icons link automatically to the accounts you've entered under the Social Networks setting in General Settings — there's no need to re-enter URLs here.
</Callout>

## Mobile header settings

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-32.png" width="326" height="450" alt="Mobile header settings panel in Travel Monster customizer" />

| Setting            | What it does                                                                |
| ------------------ | --------------------------------------------------------------------------- |
| Menu Label         | Sets the text used to represent the navigation menu in mobile view.         |
| Show Search        | Displays the search form in mobile view, when enabled.                      |
| Show Phone Number  | Displays your phone number inside the mobile menu container, when enabled.  |
| Show Email Address | Displays your email address inside the mobile menu container, when enabled. |
| Show Social Media  | Displays social media icons inside the mobile menu container, when enabled. |
