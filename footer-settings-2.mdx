Travel Monster Pro adds the option to hide the Author Link and WordPress Link that appear in the default footer copyright information.

<Callout kind="alert">
  Using illegitimate methods to hide these links elsewhere can hurt your SEO. This built-in Travel Monster Pro setting is the safe way to remove them from your footer's copyright text.
</Callout>

## Bottom footer settings

You can access these settings from **Dashboard > Appearance > Customize > General Settings > Footer Settings > Bottom Footer**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-73.png" alt="Bottom Footer settings panel in the WordPress Customizer" width="342" height="559" />

| Setting                                                    | What it does                                               |
| ---------------------------------------------------------- | ---------------------------------------------------------- |
| Should the author link be hidden? (Hide Author Link)       | Removes the Author link from the footer copyright text.    |
| Should the WordPress link be hidden? (Hide WordPress Link) | Removes the WordPress link from the footer copyright text. |

## Getting help

If these options don't appear in your Customizer, confirm that Travel Monster Pro is installed, activated, and licensed. For further assistance, contact the [WP Travel Engine support team](https://wptravelengine.com/support-ticket/).
