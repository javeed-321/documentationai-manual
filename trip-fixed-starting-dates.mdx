## Run trips on fixed dates instead of open-date booking

Trip Fixed Starting Dates helps you control exactly when a trip can start. Instead of letting travelers pick any date, you choose the departure dates for each trip.

This works well for trips that only run on certain days. Think monthly group treks, festival departures, seasonal wildlife tours, or day tours that only run on weekends.

You can also control how many seats are available, add repeating schedules, show booking status, and display all upcoming departures in one place. Once this is set up, travelers can see what is available without needing to ask you first.

## Key features

These are the main things the add-on helps you manage:

- **Trip Expiry:** Automatically expire trips after a certain date.
- **Fixed Departure Dates:** Set specific start dates for each trip.
- **Seat Management:** Define total seats for a trip per day, package, or time slot.
- **Recurring Dates:** Create daily, weekly, or monthly schedules.
- **Time Slots:** Run multiple sessions of a trip, such as morning, evening, and night, with the same seat pool.
- **Date Availability Labels:** Mark trips as Available, Limited, and Guaranteed.
- **Departure Dates:** Assign the Departure Dates Status as well.

## Prerequisites

Before you start, make sure these basics are in place.

- You have WP Travel Engine installed and activated on your WordPress site. You need Version 6.5.0 or higher.
- You have installed and activated the Trip Fixed Starting Dates add-on.
- You have added at least one trip.

Once these are ready, you can start setting up your dates.

## Configuring the global settings for Trip Fixed Starting Dates

Global settings apply across your whole site. That means the choices you make here affect all trips unless you change them inside a specific trip later.

You can find these settings in **WP Travel Engine → Settings → Extensions → Fixed Starting Dates → General**. This menu is inside your WordPress dashboard, on the left sidebar.

### Enable Trip Fixed Starting Dates for trips

This setting controls whether the Fixed Starting Dates area appears on your trip pages. If you want travelers to see a list of upcoming departures, start here.

**Fixed Starting Dates Section Title:** Enter a custom title for the section, such as "Available Departures" or "Trip Dates." This shows above the date list. Leaving the title blank shows the default heading.

A clear title helps travelers understand what they are looking at. For example, a trek operator might use "Upcoming Trek Dates," while a day-tour business might use "Next Available Departures."

Once the section is visible, you can decide how booking behaves when someone picks a date.

### Booking Modal options

This option removes one extra step for the traveler during booking.

**Skip Date Selection in Booking Modal:** When enabled, travelers won't see the date selection field in the booking pop-up, since they've already chosen a date from the list on the trip's date table. When a traveler clicks **Book Now** next to a specific date, the system knows which date they selected, so the booking pop-up skips the extra date selection step.

This is helpful if you want booking to feel more direct. It is especially useful on busy pages with many departures.

### Enable FSD below the Banner

This setting controls where the dates section appears on trip pages. That matters because it changes what travelers see first.

**Show FSD below Banner:** A global setting that determines where the FSD section appears on trip pages. When enabled, the FSD section displays just below the banner area across all trip pages by default. If you've specifically hidden the FSD section below the banner for an individual trip, that preference overrides the global setting, and the section appears below the main content area instead.

If you want your departure dates to be visible right away, placing them below the banner can help. That works well for fixed-date group tours where the departure list is the main thing travelers need.

#### Configuring Departure Date status

This section helps you show booking urgency in a clear way. Travelers can tell at a glance whether a date is wide open, nearly full, or sold out.

Define labels and colors for seat availability.

- **Display Booked Seats:** Shows how many seats are already booked.
- **Display Status:** Shows availability labels.
  - **Available:** Predefined label and color for when seats are available, for example green at 0% booked. The percent value can't be changed.
  - **Sold Out:** Predefined label and color for when all seats are filled, 100% booked. The percent value can't be changed.
  - **Add Status:** Add another status like "Limited" for when 80% of seats are filled, with its own color, label, and percent.

<Callout kind="tip" collapsed="false">

Example: 0% booked → Available; 80% booked → Limited (yellow); 100% booked → Sold Out (red).

</Callout>

This is especially useful for popular departures. A safari operator, for example, might use "Limited" when only a few jeep seats remain.

### Adding excluded dates

Excluded dates let you block bookings on certain days. This is useful when you are closed, your guides are unavailable, or you want to stop bookings for one part of your schedule.

A common example is a public holiday, a staff training day, or a date when a permit area is closed.

<Video src="https://www.youtube.com/embed/uYhS-p9RYoI" render-type="video" width="100%" height="600" controls="true" allow-full-screen="true" />

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/image-47.png" width="1024" height="600" alt="Exclude Dates settings" />

<Callout kind="info" collapsed="false">

What you'll need before you start: the Trip Fixed Starting Dates add-on must be active, and you should already know which dates or time slots you want to block.

</Callout>

<Steps>
  <Step title="Open Exclude Dates" title-type="p">

Before you add blocked dates, go to the right place in the settings.

Open the settings under Fixed Starting Dates and go to the **Exclude Dates** tab.

  </Step>

  <Step title="Select the dates to block" title-type="p">

This tells the plugin which dates should not be bookable.

In Select Dates, pick one or more dates, or check "Select a range of dates using the range calendar" to block a date range at once, then click **Add Dates**.

  </Step>

  <Step title="Choose a block behavior" title-type="p">

This controls how strictly that excluded date should affect bookings.

<Tabs>
  <Tab title="Block Entire Trip Duration">

Trips that include this date anywhere in their duration cannot be booked.

  </Tab>

  <Tab title="Block Start Date Only">

Trips cannot start on this date, but trips already in progress on this date can still be booked.

  </Tab>

  <Tab title="Block Specific Time Slots">

Blocks only the start times you choose on this date. Customers can still book any remaining time slots - best for high-frequency tours where you want to stop overbooking on one slot without shutting down the whole day.

  </Tab>
</Tabs>

  </Step>

  <Step title="Select time slots (if applicable)" title-type="p">

Only use this step if you chose **Block Specific Time Slots**.

If you picked "Block Specific Time Slots," add the start times to block under Select Time Slots. Click **Add Time** to block more than one slot on the same date.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/image-57-1024x288.png" width="1024" height="288" alt="Selecting time slots to block" />

  </Step>

  <Step title="Choose which trips the exclusion applies to" title-type="p">

This decides whether the blocked date affects every trip or only some of them.

Under Apply Exclusion To, choose:

- **All Trips** - blocks the date for every trip on your site.
- **Specific Trips** - blocks the date only for the trips you choose.
- **All Except Selected Trips** - blocks the date for every trip except the ones you choose.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/image-56-1024x288.png" width="1024" height="288" alt="Apply Exclusion To options" />

  </Step>

  <Step title="Select specific trips (if applicable)" title-type="p">

Use this only if you chose **Specific Trips** or **All Except Selected Trips**.

If you chose Specific Trips or All Except Selected Trips, search for and select the trips in Trips to Exclude.

<Callout kind="tip" collapsed="false">

Use "All Except Selected Trips" when most of your trips should stay closed on a date but a few need to stay bookable, like a private charter that still runs on a public holiday.

</Callout>

  </Step>

  <Step title="Save the exclusion" title-type="p">

This makes the blocked dates live on your site.

Optionally enable **Repeat Yearly** to block the same date every year, then click **Save Settings**. Click Details on any saved entry to review or change it later, or use the delete icon to remove it.

  </Step>
</Steps>

**Examples of using excluded dates:**

- Blocking public holidays when your office is closed (Block Entire Trip Duration).
- Preventing trips from starting on certain peak days while allowing ongoing trips (Block Start Date Only).
- Excluding peak days when guides are unavailable.
- Blocking a single overbooked departure time while keeping other time slots open on the same day (Block Specific Time Slots).
- Marking company retreat days where no trips should be booked.

<Callout kind="alert" collapsed="false">

The scope of an excluded date depends on what you choose under Apply Exclusion To. If you set a date to All Trips, no trip can be booked on that day, even if individual trips have seats available. If scoped to Specific Trips or All Except Selected Trips, only the chosen trips are affected.

</Callout>

##### Using shortcodes - copy-and-paste ready

After saving your settings, you can place the departure calendar on any page of your site. A shortcode is the small code you paste into a page, post, or widget to show something on the front end.

This is how you create a page like "Upcoming Departures" without building it by hand.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/shortcode-section.png" width="1024" height="600" alt="Departure Calendar shortcode section" />

**Simple shortcode**

The `[WPTravelEngine_Trip_Departure_Calendar]` shortcode displays the calendar exactly as configured in the global settings. Copy and paste it into any page or post.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/shortcode-paste-in-a-page.png" width="1024" height="600" alt="Shortcode pasted into a page" />
<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/departure-calendar-1.png" width="1024" height="600" alt="Departure calendar rendered on the frontend" />

**Advanced shortcode (optional)**

Override specific settings on a single page, for example:

```typescript
[WPTravelEngine_Trip_Departure_Calendar layout="list-one" display_contact_us="yes" display_available_seats="yes" display_only_booked_trips="yes" display_available_trips_only="yes" no_of_trips="24" exclude="trip_id1,trip_id2" include="trip_id1,trip_id2" default_year="20xx" default_month="all"]
```

| Attribute | Accepts | Description |
| --- | --- | --- |
| `layout` | `grid`, `list-one`, `list-two` | Force that layout for this page. |
| `display_contact_us` | `yes` / `no` | Show or hide the Contact Us button. |
| `display_available_seats` | `yes` / `no` | Show or hide Spots Left / Sold Out badges. |
| `display_only_booked_trips` | `yes` / `no` | Show only trips with at least one confirmed booking. |
| `display_available_trips_only` | `yes` / `no` | Hide fully booked (sold-out) trips. |
| `no_of_trips` | 3-48 | How many trips load initially. |
| `exclude` | comma-separated trip IDs | Trips to leave out, e.g., `6380,6783`. |
| `include` | comma-separated trip IDs | Trips to display exclusively. |
| `default_year` | `20xx` or a specific year | `20xx` shows the current year; a specific year (e.g., `2027`) shows trips for that year by default. |
| `default_month` | `all` or 1-12 | `all` shows trips from all months; a number shows a specific month (e.g., `6` for June). |

**How to find the trip ID**

<Callout kind="info" collapsed="false">

What you'll need before you start: at least one trip already created in WP Travel Engine. You will find this under **Trips** in the left sidebar of your WordPress dashboard.

</Callout>

<Steps>
  <Step title="Open Trips" title-type="p">

You need the trip list first so you can identify the right trip.

Go to Trips in your WordPress Dashboard.

  </Step>

  <Step title="Hover over a trip" title-type="p">

This shows the hidden link preview for that trip.

Hover your mouse over the trip you want to target.

  </Step>

  <Step title="Read the URL preview" title-type="p">

The trip ID is part of the link.

## FSD settings in a single trip

Single-trip settings let you override the global setup for one specific trip. This is useful when one departure needs special dates, different seat handling, or its own blocked dates.

You can find these settings inside the trip editor.

### Assigning dates to packages in FSD

This is where you tell each package exactly when it can be booked. That helps when different packages follow different schedules or limits.

Assign specific dates to packages so customers know exactly when a trip is available. Each package, such as Standard or Premium, can have its own dates, seat capacity, and availability labels - whether the trip runs on a single day, across a date range, or on repeating schedules.

For example, you might run a 1-day city tour with both Standard and Premium packages, but only offer the Premium package on weekends.

### How to assign dates to a package

</Callout>

### Selecting a range of dates

Use this when the same package should be available on several dates in a row.

To assign multiple consecutive dates, check the box "Select a range of dates using the range calendar." For example, selecting August 1 to August 7 makes the package available on each of those dates.

This is handy for a week-long holiday package or a festival tour that runs every day during an event period.

This helps when not every departure should cost the same.

You can set different prices for specific dates - for example, a higher price during peak season and a lower price off-season. If you don't set date-specific prices, the system uses your global pricing. See the full [Conditional Price documentation](/article/conditional-price/) for details.

A good example is a mountain trek that costs more in peak spring months, or a winter wildlife trip that includes extra gear rental.

### Adding time slots for booking

Use time slots when the same trip runs more than once in a day. That is common for walking tours, food tours, rafting sessions, and short day trips.

### Recurring time

Recurring dates save time when the same trip repeats on a pattern. Instead of entering each date by hand, you set the rule once.

Instead of adding each date one by one, set a trip to repeat automatically. You can choose only one option for a particular date.

- **Daily:** The trip repeats every day starting from the chosen date.
- **Weekly:** The trip repeats every week on the same weekday - you can also select specific weekdays.
- **Monthly:** The trip repeats once a month, and you can choose which months, for example only January and February.
- **Yearly:** The trip repeats once a year on the same date.

This is useful for weekend hikes, weekly food tours, or an annual festival package that always starts on the same date.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/chrome-capture-2025-10-08.gif" width="1024" height="600" alt="Configuring a recurring departure schedule" />

<Callout kind="tip" collapsed="false">

Example: If you set a trip to repeat weekly starting on August 5 (Monday), it automatically creates departures for every Monday that follows.

</Callout>

#### Stopping repeats

You stay in control of when the pattern ends.

Stop the repeat schedule in two ways:

- **Repeat Until:** Select a specific end date, e.g., repeat until December 31, 2025.
- **Repeat Limit:** Enter the number of times the trip should repeat, e.g., 10 times only.

If you only want a summer season schedule, **Repeat Until** is usually the clearest option.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/image-18-1024x541.png" width="1024" height="541" alt="Repeat Until and Repeat Limit options" />

### Setting total seats

This setting controls how many people can book that package date or time. It helps stop overbooking before it happens.

For each package date or time slot, assign a Total Seat. For example, setting 3 seats means only 3 travelers can book that package for that date and time - once the limit is reached, no more bookings are allowed.

A small-group canyoning trip, for example, might cap seats at 6 because of guide and gear limits.

<Callout kind="info" collapsed="false">

See the [Seat Allocation and Booking Capacity documentation](/article/seat-allocation-and-booking-capacity/) for how seat allocation works across general settings, packages, and time slots.

</Callout>

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/image-20-1024x305.png" width="1024" height="305" alt="Setting the total seats for a date or time slot" />

### Availability Label

Availability labels help you explain the booking status in a way travelers can understand quickly.

Set an Availability Label to show the booking status of the package:

- **Guaranteed:** The trip will definitely run.
- **Available:** Seats are still open.
- **Limited:** Only a few seats are left.

<Callout kind="info" collapsed="false">

## Date settings in a single trip

These settings control how the Fixed Starting Dates section behaves for one trip only. Use them when one trip needs different rules from the rest of your site.

Configure these via **Trips → Edit a Trip → Date and Price → Date Settings**.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/image-52-1024x433.png" width="1024" height="433" alt="Date Settings section in a single trip" />

### Section Title

This lets you change the heading shown on that trip page.

Enter a custom heading for the availability section on the trip page. For example, entering "Upcoming Departures" shows that heading above the list of dates. If left blank, the default title is used.

This is useful if you want one trip to use a more specific label than the rest of the site.

This option hides the dates section on one trip page.

Enable this to hide the fixed departure dates section on a single trip page - normally shown between the featured image/slider and the main trip content.

You might use this if the trip is inquiry-only or if you want to handle dates another way for that one trip.

### Trip Expiry Date

Use this when a trip should stay visible on your site but stop accepting bookings after a certain date.

Choose a date after which the trip can't be booked. The trip page remains visible, but bookings are automatically disabled once the expiry date is reached.

<Callout kind="info" collapsed="false">

Example: if you set the expiry date to December 31, 2025, travelers can view the trip details but won't be able to book after that date.

</Callout>

This works well for seasonal trips that you want to keep visible for future marketing.

### Excluded Dates

Use trip-specific excluded dates when only one trip needs special blocking rules. This is useful when the rest of your trips should stay open.

For example, you might block one rafting trip on a river closure date while keeping your walking tours available.

Block specific dates for this trip only. Exclude individual dates or select a range from the calendar, choose how the date blocks bookings, and optionally repeat it every year.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/image-60.png" width="1024" height="600" alt="Excluded Dates settings for a single trip" />

**How excluded dates work for this trip:**

<Tabs>
  <Tab title="Block Entire Trip Duration">

The trip cannot be booked if its duration includes the excluded date, even if the trip starts before or ends after that date.

  </Tab>

  <Tab title="Block Start Date Only">

The trip cannot start on the excluded date, but bookings are still allowed if the trip includes the date during its duration.

  </Tab>

  <Tab title="Block Specific Time Slots">

Blocks only the departure times you pick on that date, while the trip's other time slots stay bookable. Under Select Time Slots, tap the times you want to block.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2019/12/image-61.png" width="1024" height="600" alt="Selecting time slots to block for a trip" />

<Callout kind="info" collapsed="false">

Only the departure times already configured for that date appear here. If the trip has no time slots set up for that date, there's nothing to select.

</Callout>

  </Tab>
</Tabs>

**Examples:**

- If a trip runs daily in August but can't operate on August 15, exclude that date using Block Entire Trip Duration.
- If a trip shouldn't start on August 15 but can continue through that day, exclude the date using Block Start Date Only.
- If a trip runs three departures a day and one on August 15 is fully staffed elsewhere, exclude just that time using Block Specific Time Slots, keeping the other departures open.

<Callout kind="alert" collapsed="false">

There are two types of exclusions: **Global Exclusions** (set in the global settings, applied to all trips) and **Trip-Specific Exclusions** (set here, applied only to this trip). If the same date is excluded in both, the trip-specific setting takes priority - including its block behavior. For example, if January 2, 2027 is excluded globally with Block Entire Trip Duration, but this trip has that date excluded with Block Specific Time Slots, this trip only blocks the selected time slots - the global rule doesn't apply to it. The final unavailable dates for a trip combine both global and trip-specific exclusions.

</Callout>

## Shortcode

Shortcodes let you place trip date information on other parts of your site. A shortcode is a small line of text you paste into a WordPress page, post, or widget so WordPress can display the feature there.

A widget is a small content block you can place in certain areas of your site, depending on your theme.

The FSD plugin provides shortcodes to display departure dates anywhere on your site - in posts, pages, or widgets.

**How shortcodes work:**

- Copy and paste the shortcode into a post, page, or widget.
- The shortcode automatically pulls in the trip dates configured for each trip.
- On the frontend, travelers see the list of available departure dates, the price for each date, and the number of seats left.

As bookings come in, available seats update in real time until the trip is sold out.

**All Fixed Starting Dates**

To display all fixed starting dates from all trips across your site:

```typescript
[WTE_TRIPS_FIXED_STARTING_DATES]
```

This shows a complete calendar of all available trips, organized by months and years.

<Callout kind="tip" collapsed="false">

Example use case: create a dedicated page called "Upcoming Departures" that lists every trip date.

</Callout>

## Troubleshooting

### My trip shows seats available, but travelers still cannot book

Check whether the package seats or date seats are lower than the total seats in your General Settings. The system uses the smaller number.

Also check whether the trip date is excluded or the trip has already passed its expiry date.

### My trip dates are not showing up on the website

Make sure you turned on the "Show Fixed Trip Starts Dates" section in global settings. Then check that the trip has active dates added.

If you are using a shortcode on a page, confirm that the shortcode is pasted correctly and the page is published.

### I am getting overbookings

Check **Total Traveller Seats** in your General Settings. This setting works as the top limit.

Your package seats and time slot seats should not go above that daily cap.

### My expired trip is still visible

Set the **Trip Expiry Date** in the trip editor under **Date Settings**. The trip page can still stay visible even after booking is disabled.

If you want the trip completely hidden, you will need to remove it from public display separately.

### My departure calendar is not showing on the page

Check that you pasted the shortcode into the page or post correctly. Then make sure the page is published.

If you are expecting the full departure calendar, use `[WPTravelEngine_Trip_Departure_Calendar]`. If you are expecting the all-dates list, use `[WTE_TRIPS_FIXED_STARTING_DATES]`.

### The sticky filter bar is covering my site menu

Increase the sticky filter offset for the device size you are testing. Use **Sticky Filter Offset – Desktop**, **Sticky Filter Offset – Tablet**, or **Sticky Filter Offset – Mobile** until the filter sits below your header.

Also remember that the Sticky Filter does not work while you are logged in as an admin. Test it in an incognito window or while logged out.

### My recurring dates will not stop

Check whether you set **Repeat Until** or **Repeat Limit**. If neither is set the dates may keep repeating based on your chosen pattern.

Open the package date settings and confirm the end date or repeat count is saved.

### My excluded dates are not blocking bookings

First check whether the exclusion was saved. Then check the block type you chose.

For example, **Block Start Date Only** will not block trips that are already in progress on that date. Also check whether the exclusion applies to **All Trips**, **Specific Trips**, or **All Except Selected Trips**.

If you set both a global exclusion and a trip-specific exclusion for the same date, the trip-specific one takes priority for that trip.

### My trip says Sold Out, but I still have seats left

Check how your seats are set at all levels. The system looks at General Settings, package seats, date seats, and time slots.

Also check whether your display is showing **Primary Package** seats instead of **Total Seats**. If one package is full but another still has space, the display may look different depending on that setting.

## Frequently asked questions

### Can I run a trip at multiple times in one day?

Yes. Add multiple time slots for the same date.

### What happens when all seats are sold out?

The system automatically marks the trip as Sold Out.

### How do repeating schedules stop?

You can stop them with an end date using **Repeat Until** or with a repeat count using **Repeat Limit**.

### Can I list all trips with fixed dates on one page?

Yes. Use `[WTE_TRIPS_FIXED_STARTING_DATES]`.

### What happens if I leave an attribute out of the Departure Calendar shortcode?

If you leave an attribute out, or leave its value empty, the calendar falls back to the global settings for that value.

### How do I find a trip's ID for the include/exclude shortcode attributes?

Go to your WordPress Dashboard → Trips. Hover over the trip title and look at the URL preview in the bottom-left of your browser. The link contains something like `post=1234`, where 1234 is the trip ID.

### Can I charge different prices for different dates?

Yes. Use conditional pricing for date-specific prices.

This is useful for peak-season departures, festival tours, or trips that include seasonal extras like gear rental.

### Can I let travelers request a private trip on their preferred dates?

Yes. Turn on **Enable Private Trip** and add a form shortcode in **Private Trip Form**.

That form appears next to the departure dates so travelers can ask for a custom date or quote.

### Can I block bookings on public holidays?

Yes. Use **Excluded Dates**.

If the holiday should block every trip, use the global exclusion settings. If it should block only one trip, use the trip-specific exclusion settings.

### What is the difference between global excluded dates and trip-specific excluded dates?

Global excluded dates apply across your site. Trip-specific excluded dates apply only to one trip.

If the same date is set in both places, the trip-specific exclusion takes priority for that trip.
