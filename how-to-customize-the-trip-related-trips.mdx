## Overview

The Show Related Trips feature lets you showcase similar or complementary trips on a single trip page. This helps travelers explore more of your offerings and increases the chances of bookings. You can customize how related trips appear using the WP Travel Engine settings.

## Benefits

- **Boosts engagement** by encouraging visitors to explore more trips
- **Improves user experience** by making it easier for travelers to find similar trips
- **Adds professionalism** with a well-structured, visually appealing trip detail page

## Enabling Show Related Trips

<Steps title-type="h3">
  <Step title="Open the Single Trips display settings">
    Log in to your WordPress dashboard and go to **WP Travel Engine > Settings > Display > Single Trips**.
  </Step>

  <Step title="Turn on Related Trips">
    Toggle **Show Related Trips** to display related trips on single trip pages.
  </Step>
</Steps>

## Configuring the Show Related Trips feature

Once you enable Show Related Trips, several options let you control how related trips appear on the single trip page.

### Related section title

Set the heading text that appears above the related trips. The default is **Related Trips**, but you can change it to something more engaging, such as "You May Also Like" or "Similar Adventures."

### Number of related trips to display

Decide how many related trips should be shown. By default, **3 trips** are displayed, but you can increase or decrease this number depending on your design and user experience goals.

### Enable Related Trips By

This setting controls how related trips are matched to the current trip, rather than using the default behavior. You can filter related trips by:

| Filter      | Matches trips by                                           |
| ----------- | ---------------------------------------------------------- |
| Destination | Same location                                              |
| Activities  | Similar activities (e.g., Boating, City Tour)              |
| Trip Type   | Same type, such as Adventure, Child-friendly, or Home Stay |
| Difficulty  | Same difficulty level                                      |
| Tag         | Shared tags                                                |
| Package     | Same package                                               |

### New layout for Related Trips

The New Layout for Related Trips provides an enhanced, modern design for displaying related trips on the single trip page. Once enabled, you can configure additional display options to make the section more informative and engaging.

**Available options:**

| Option                      | What it does                                                                     |
| --------------------------- | -------------------------------------------------------------------------------- |
| Enable Slider               | Displays trip images in a slider format instead of a static grid                 |
| Enable Featured Tag on Card | Adds a badge (e.g., Featured or Popular) to highlight selected trips             |
| Enable Wishlist             | Lets travelers save trips to their wishlist using a heart icon on each trip card |
| Enable Map                  | Displays a map or map link showing the trip location                             |
| Show Excerpt                | Shows a brief description beneath the trip title                                 |
| Enable Difficulty           | Displays the trip's difficulty level (e.g., Easy, Moderate, Challenging)         |
| Enable Tag                  | Shows trip tags for better categorization                                        |
| Enable Next Departure Dates | Highlights the next available departure date for each trip                       |
| Enable Available Months     | Displays the months when the trip is available (e.g., Jan–Mar)                   |
| Enable Available Dates      | Shows the specific dates when the trip is available                              |

<Callout kind="tip">
  To use Enable Difficulty or Enable Tag, make sure the related trips already have a difficulty level or tag assigned — otherwise those badges won't have anything to display.
</Callout>
