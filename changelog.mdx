## Recent Updates

Keep your integration current with the Wholechain API. Review changes below to ensure compliance, transparency, and efficiency in your supply chain tracking.

<Update label="2024-10-15" description="v2.3.0" tags={["feature","improvement"]}>
  ## New Features

  - Added `/events/v2` endpoint for enhanced event creation with trade partner support.
  - Introduced bulk location uploads via `POST /locations/bulk` for faster onboarding.

  ## Improvements

  - Reduced latency on product queries by `>30%` with optimized caching.
  - Enhanced error responses with detailed `error_code` fields for better debugging.

  ## Bug Fixes

  - Fixed pagination issues in `/products` listings.
  - Resolved intermittent failures in authentication token refresh.
</Update>

<Update label="2024-09-20" description="v2.2.0" tags={["feature","bugfix"]}>
  ## New Features

  - New webhook support for real-time event notifications at `POST /webhooks`.
  - Sandbox environment now mirrors production with sample data generation.

  ## Bug Fixes

  - Corrected invalid schema validation on location creation.
  - Fixed `400` errors during trade partner association.
</Update>

<Update label="2024-08-10" description="v2.1.0" tags={["breaking","feature"]}>
  ## Breaking Changes

  - Deprecated `/events/v1` endpoint; migrate to `/events/v2`.
  - `Authorization` header now requires `Bearer` prefix strictly.

  ## New Features

  - Added `GET /trade-partners` for querying verified partners.
  - Support for custom metadata in product events.

  ## Migration Notes

  Update your requests to use the new endpoints. See migration guide below.
</Update>

## Migration Guide

Follow these steps to upgrade your integration painlessly.

<Steps>
  <Step title="Review Breaking Changes" icon="alert-triangle" title-type="p">
    Check the `v2.1.0` release notes above for deprecated endpoints.
  </Step>

  <Step title="Update Authentication" icon="lock" title-type="p">
    <CodeGroup show-lines="true">
      ```javascript
      const response = await fetch('https://api.example.com/events/v2', {
        headers: {
          'Authorization': `Bearer ${YOUR_TOKEN}`,
          'Content-Type': 'application/json'
        }
      });
      ```

      ```bash
      curl -X POST https://api.example.com/events/v2 \
        -H "Authorization: Bearer YOUR_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"event_type": "shipment"}'
      ```
    </CodeGroup>
  </Step>

  <Step title="Test in Sandbox" icon="terminal" title-type="p">
    Use the sandbox at `https://sandbox.example.com` to validate changes.
  </Step>

  <Step title="Deploy to Production" icon="rocket" title-type="p">
    Monitor webhooks for any issues post-deployment.
  </Step>
</Steps>

<Callout kind="alert" collapsed="false">
  Breaking changes in `v2.1.0` require immediate action. Update before `2024-11-01` to avoid disruptions.
</Callout>
