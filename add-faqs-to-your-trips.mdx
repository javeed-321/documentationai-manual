## Overview

The FAQ feature lets you add frequently asked questions to your trip pages so travelers can find answers without contacting you directly. You can add FAQs manually on a single trip, import them in bulk from a centralized Global FAQs list, and organize them using categories for a clean, structured layout.

<Video src="https://www.youtube.com/watch?v=oVVxLS9MWaY" width="100%" height="600" />

## Key features

- Add FAQs manually to individual trips
- Import FAQs in bulk from Global Settings
- Organize FAQs using categories
- Reorder FAQs and categories with drag and drop
- Automatic conversion of a global FAQ to a local FAQ when you edit it on a trip

## Benefits at a glance

| Feature                    | Benefit                                               |
| -------------------------- | ----------------------------------------------------- |
| Manual & bulk FAQ addition | Quickly add FAQs without repetitive work              |
| Global FAQs                | Reuse the same FAQs across multiple trips             |
| Categories                 | Keep FAQs structured and easy to navigate             |
| Drag & drop reordering     | Easily organize FAQs and categories                   |
| Flexible editing           | Customize FAQs per trip without affecting global data |

## Setting up Global FAQs

Global FAQs let you create a centralized list of questions and answers that can be reused across multiple trips.

<Steps title-type="h3">
  <Step title="Open the FAQs display settings">
    Navigate to **WP Travel Engine > Settings > Display > Single Trip > FAQs**.
  </Step>

  <Step title="Enable the FAQs section">
    Turn on the **Show FAQs Section** toggle to display the FAQs section on the frontend of your trip pages.
  </Step>

  <Step title="Add a global FAQ">
    Click **+ Add FAQ**, then enter the **Question** and **Answer**.
  </Step>

  <Step title="Save your changes">
    Save the settings page to store the new global FAQ.
  </Step>
</Steps>

<Callout kind="info">
  You can edit any existing global FAQ by updating its question or answer fields, or remove it using the red delete icon next to the entry.
</Callout>

## Managing FAQs on a single trip

You can manage FAQs individually for each trip — importing global FAQs, adding local FAQs, and organizing them into categories.

To get started, edit the trip where you want to add FAQs, then navigate to **WP Travel Engine > Trip Settings > FAQs**.

### Adding new FAQs manually

Manually added FAQs are treated as local FAQs and apply only to the trip you're editing.

<Steps title-type="h3">
  <Step title="Start a new FAQ">
    Click **+ Add New FAQs**.
  </Step>

  <Step title="Enter the question">
    Type the question travelers commonly ask about this trip.
  </Step>

  <Step title="Enter the answer">
    Type the answer to the question.
  </Step>
</Steps>

### Adding FAQs in bulk

Use this option to import questions you've already created in Global FAQs, instead of retyping them for every trip.

<Steps title-type="h3">
  <Step title="Open the bulk import dialog">
    Click **Add FAQs in Bulk**. A pop-up titled "FAQs in Bulk" opens.
  </Step>

  <Step title="Find the FAQs you need">
    Use the search bar to find globally created FAQs in the list.
  </Step>

  <Step title="Select the FAQs">
    Select the FAQs you want using the checkboxes.
  </Step>

  <Step title="Add the FAQs to the trip">
    Click **Add FAQs** to import the selected questions into the trip.
  </Step>
</Steps>

<Callout kind="alert">
  If you edit an FAQ that was added from Global FAQs, it converts into a local FAQ. The changes apply only to this trip and do not affect the original global FAQ.
</Callout>

### Organizing FAQs with categories

Categories help you group related FAQs so travelers can navigate them more easily.

<Steps title-type="h3">
  <Step title="Create a category">
    Click **+ Add New Category** and enter a category name.
  </Step>

  <Step title="Arrange FAQs within the category">
    Use the order (drag) icon to move and arrange FAQs under the category you created.
  </Step>
</Steps>
