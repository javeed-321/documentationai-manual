## Date settings for a single trip

These settings control how the fixed starting dates section appears and behaves for a specific trip, independent of global settings; go to Trips → Edit a Trip → Date and Price → Date Settings.

## Section Title

Set a custom heading for the fixed starting dates section on the trip page.

<Callout kind="info" collapsed="false">
  Enter a label such as `Upcoming Departures` to show that heading above the date list. If you leave this field blank, the trip uses the default title.
</Callout>

## Hide FSD Section

Hide the fixed departure dates section for this trip without changing other trip content.

<Callout kind="info" collapsed="false">
  By default, the dates section appears between the featured image or slider and the main trip content. Turn this option on to remove that section from view on this trip page.
</Callout>

## Trip Expiry Date

Choose a date after which this trip can no longer be booked.

If you set an expiry date of `31 December 2025`, visitors can still open the trip page and review the trip details, but they cannot complete a booking after that date.

<Callout kind="alert" collapsed="false" color="#f97316">
  The trip page stays visible after the expiry date. Only booking is disabled.
</Callout>

## Excluded Dates

Exclude specific dates for this trip only when you need to block individual departures or a date range.

<Steps>
  <Step title="Open Excluded Dates" icon="calendar" title-type="p">
    Go to the **Excluded Dates** section inside **Date Settings**.
  </Step>

  <Step title="Select the dates to block" icon="edit" title-type="p">
    Select one or more dates, or use the range calendar to choose consecutive dates.
  </Step>

  <Step title="Choose a block behavior" icon="settings" title-type="p">
    Pick the block behavior that matches how the trip should be restricted.
  </Step>

  <Step title="Select time slots when needed" icon="clock" title-type="p">
    If you choose **Block Specific Time Slots**, select the departure times to block from the available time slots.
  </Step>

  <Step title="Enable yearly repeat if needed" icon="refresh-cw" title-type="p">
    Turn on **Repeat Yearly** if the same excluded dates should apply every year.
  </Step>

  <Step title="Save the trip" icon="check-circle" title-type="p">
    Save the trip to apply the exclusion settings.
  </Step>
</Steps>

## Block Behaviors

Choose the block behavior based on whether you need to stop the whole trip, only stop new starts, or block selected departure times.

<ExpandableGroup>
  <Expandable title="Block Entire Trip Duration" default-open="false">
    The trip cannot be booked if its duration includes the excluded date, even if the trip starts before or ends after that date.

    Example: if a trip runs daily in August but cannot operate on `15 August`, use this option to block any booking that overlaps that date.
  </Expandable>

  <Expandable title="Block Start Date Only" default-open="false">
    The trip cannot start on the excluded date, but bookings are still allowed if the trip includes that date during its duration.

    Example: if a trip should not start on `15 August` but can continue through that day, use this option.
  </Expandable>

  <Expandable title="Block Specific Time Slots" default-open="false">
    Block only the departure times you pick on that date, while other time slots remain available for booking.

    Under **Select Time Slots**, choose the times to block. Only departure times already configured for that date appear in this list.
  </Expandable>
</ExpandableGroup>

## Global vs. Trip-Specific Priority

Date exclusions can come from both global settings and the settings on an individual trip.

- **Global exclusions** are set in global settings and apply to all trips.
- **Trip-specific exclusions** are set here and apply only to this trip.
- If the same date is excluded in both places, the trip-specific setting takes priority.
- If the block behavior differs for the same date, the trip-specific block behavior overrides the global one for this trip.

<Callout kind="tip" collapsed="false">
  If `2 January 2027` is excluded globally with **Block Entire Trip Duration**, but this trip excludes the same date with **Block Specific Time Slots**, this trip blocks only the selected time slots. The global full-duration rule does not apply to this trip for that date.
</Callout>

<Callout kind="info" collapsed="false">
  The final unavailable dates for a trip are a combination of both global and trip-specific exclusions.
</Callout>
