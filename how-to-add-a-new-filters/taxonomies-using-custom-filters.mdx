## Overview

The Custom Filters feature lets you create your own filters, which act as custom taxonomies, to help organize and categorize trips beyond the default options like Destination, Activities, or Trip Type. This allows travelers to filter trips more precisely on the frontend.

## Creating a custom filter

Navigate to **Admin Dashboard > Trips > Custom Filters** to add a new custom filter.

Fill out the following fields to create your filter:

| Field                 | Description                                                                                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Filter/Category Label | The readable name of the filter shown to users when browsing or refining trips (e.g., "Trip Duration" or "Difficulty Level")                                       |
| Filter/Category Slug  | The URL-friendly version of the filter name. Must be lowercase, without spaces, using hyphens to separate words (e.g., `trip-duration` or `difficulty-level`)      |
| Hierarchical          | Checked: acts like categories with parent/child relationships (e.g., Continent > Country > City). Unchecked: acts like tags, flat with no hierarchy                |
| Show in Filters       | Checked: the filter appears on the trip archive page for users to refine their search. Unchecked: the filter is available only in the backend for organizing trips |

## Adding categories or tags to a custom filter

<Steps title-type="h3">
  <Step title="Open the custom filter">
    Click on the custom filter you created.
  </Step>

  <Step title="Add categories or tags">
    Add the categories or tags you want to display under the filter.
  </Step>
</Steps>

<Callout kind="alert">
  Categories or tags must be added to a trip for the filter to appear on the Trip Archive page. The custom filter won't display unless at least one trip is assigned to a category or tag.
</Callout>

## Assigning custom filters to trips

<Steps title-type="h3">
  <Step title="Open the trip list">
    Go to **Trips > All Trips**.
  </Step>

  <Step title="Edit the trip">
    Edit the trip you want to assign a filter to.
  </Step>

  <Step title="Find the custom filter panel">
    On the right-hand side, you'll see the custom filter alongside other taxonomies like Destination, Trip Type, and Pricing Categories.
  </Step>

  <Step title="Select the category or tag">
    Select the appropriate category or tag for the trip.
  </Step>

  <Step title="Save the trip">
    Save or update the trip.
  </Step>
</Steps>

Once assigned, your custom filter appears on the Trip Archive page, letting travelers refine their search using your custom categories.

## Editing or removing a filter later

You can update or delete filters at any time through the dashboard.

- **Edit:** Modify the filter's name, slug, or settings if you need to make changes.
- **Remove:** Delete the filter completely if it's no longer needed.

## Benefits of using Custom Filters

- Organize trips more effectively by adding your own categories (e.g., Difficulty, Season, Travel Style)
- Enhance user experience by making it easier for travelers to filter and find the right trips
- Boost conversions since customers can quickly locate trips that match their preferences
- Get the flexibility to customize filters to suit your business needs
