In this article, we walk you through the steps to download and install the Scrut Endpoint Agent on an RPM-based Linux distribution like Fedora, CentOS, or RHEL.

## Prerequisites

- Root (sudo) access to the terminal
- An active internet connection

## Step 1: Install AppImage Launcher

AppImageLauncher allows you to easily integrate AppImages with your system (creating menu entries and icons).

1. **Download the RPM package**. Click the link below to download the specific version of AppImageLauncher: [Download AppImageLauncher v2.2.0](https://github.com/TheAssassin/AppImageLauncher/releases/download/v2.2.0/appimagelauncher-2.2.0-travis995.0f91801.x86_64.rpm)

2. **Open your Terminal**. Navigate to the directory where you downloaded the file (usually the Downloads folder): cd ~/Downloads

3. **Install the package**. Run the following command to install the downloaded RPM.

   ```text
   sudo dnf install ./appimagelauncher-2.2.0-travis995.0f91801.x86_64.rpm
   ```

**Note**: If prompted, enter your system password to authorize the installation.

## Step 2: Install System Dependencies

The Scrut Agent requires specific system tray indicators to function correctly on the Gnome desktop environment.

1. **Install AppIndicator Extension**. Run the following command in your terminal:

   ```text
   sudo dnf install gnome-shell-extension-appindicator
   ```

2. **Restart Shell (Optional but Recommended)**. If you do not see the indicator immediately after installation, you may need to log out and log back in or restart your computer.

## Step 3: Install Scrut Agent

1. **Download the Agent**. Click the link below to download the Scrut Endpoint Agent AppImage: [https://scrut-agent-artifact.s3.ap-south-1.amazonaws.com/scrut-endpoint-agent-linux-setup-1.5.7.AppImage](https://scrut-agent-artifact.s3.ap-south-1.amazonaws.com/scrut-endpoint-agent-linux-setup-1.5.7.AppImage)

2. **Launch and Integrate**.

   - Open your File Manager and locate the downloaded file (scrut-endpoint-agent-linux-setup-1.5.4.AppImage).

   - Right-click on the file.

   - Select “Open With” → “AppImageLauncher”.

     <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162082016-4q47zuxzq5-base64-converted-image-1782883716996.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. Finalize Installation.

   - A prompt will appear asking how you want to run the file.

   - Click the button labeled “Integrate and Run.”

     <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162083292-xavl82cc6vk-base64-converted-image-1782883716999.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. The Scrut Agent will now move to your applications directory and launch automatically.

## Step 4: Launch the App

You can now find the Scrut Endpoint Agent in your Applications menu. It will run like a regular app.

1. Launch the app and log in using your registered email address (the email address you use to log in to Scrut, typically your work email).

2. Scrut will send a One-Time Password (OTP) to your email. Check your inbox for the OTP. If you haven't received it, click **Resend**.
