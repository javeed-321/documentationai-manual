<Callout kind="custom">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

Editing and deleting an audit request in the audit center allows you to modify or remove a previously recorded observation or issue identified during an audit. This feature allows auditors and authorized users to make necessary updates to the information associated with a specific request.

## How to Edit an Audit Request

1. Sign in to Scrut, and click **Audit → Audit Center** on the left navigation menu.

2. Select the audit corresponding to the request.

3. Once you’re on the audit page, scroll to the **requests** tab, and open the request that you want to edit.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166055770-i2hbd6ylfr8-Selecting-an-Audit-Request.png?fm=auto&auto=compress%2Cformat" alt="Selecting an Audit Request" caption=" " />

4. Alternatively, you can directly navigate to **Audit → Audit Center → Requests** tab and open the request you want to edit.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163293041-dr2x8cnpo27-Requests-Tab-in-the-Audit-Center.png?fm=auto&auto=compress%2Cformat" alt="Requests Tab in the Audit Center" caption=" " />

5. Click the edit icon next to the field you want to edit. You can modify the following details:

   - Request Name
   - Description
   - Assignees

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163283779-4o5mg2wwn9c-Request-Details.png?fm=auto&auto=compress%2Cformat" alt="Request Details" caption=" " />

6. Make the necessary changes and click **Save**.

## How to Delete an Audit Request

<Callout kind="danger">
  **Heads Up!**

  Deleting a request involves permanently removing it from the audit record. So, proceed with caution.
</Callout>

1. Sign in to Scrut, and click **Audit → Audit Center** on the left navigation menu.

2. Select the audit corresponding to the request.

3. Once you’re on the audit page, scroll to the **Requests** tab, and click the delete icon next to the request you want to delete.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166055770-i2hbd6ylfr8-Selecting-an-Audit-Request.png?fm=auto&auto=compress%2Cformat" alt="Selecting an Audit Request" caption=" " />

4. Click **Delete** to confirm.

<Callout kind="alert">
  **Note:**

  When you delete an audit request, Scrut will unlink the controls linked to it and the status of the controls will revert accordingly.
</Callout>
