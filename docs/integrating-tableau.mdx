The **Scrut - Tableau** integration fetches user access data, permissions, and role assignments from your Tableau account and syncs them with the [Access Review](/docs/access-review-walkthrough) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  **Heads Up!**

  The data synced from Tableau flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- Permission to create a [Personal Access Token (PAT)](https://help.tableau.com/current/server/en-us/security_personal_access_tokens.htm) in Tableau
- Personal Access Tokens enabled for your organization’s Tableau account ([See here for how](https://help.salesforce.com/s/articleView?id=001470600&type=1))

### Permissions

Scrut requires **read-only access** to the following data in Tableau

- User Accounts: View name, email, and user role

<Callout kind="tip">
  **Pro Tip!**

  We recommend logging into your Tableau account before starting the integration to avoid doing so later.
</Callout>

## How To Connect Tableau With Scrut

### Step 1: Fetch Access Token from Tableau

1. Log in to your Tableau account, click on your profile in the top right corner, and then click **My Account Settings**.

2. Scroll to the **Personal Access Token** section, enter a name for the token (such as Scrut) and click **Create Token**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171147965-jl76m9dldqb-Screenshot-2025-09-10-at-18-53-15.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. **Copy the Token Secret** and **Name**, as you’ll need to enter them in Scrut in the [next step](/docs/integrating-tableau#step-2-go-to-integrations-in-scrut).

   **Important**: The secret will not be displayed after closing this screen. So, make sure to copy and save it before closing this window.

<Callout kind="tip">
  **Pro Tip!**

  Refer to Tableau’s help documentation for [more information on Personal Access Tokens](https://help.tableau.com/current/server/en-us/security_personal_access_tokens.htm).

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.

2. Navigate to the **Integrations Library** tab, and choose **Capacity & Usage Monitoring** in the **Categories** section.

3. Scroll to the **Tableau** tile and click **Integrate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171150735-680y2udf6uu-Screenshot-2025-09-10-at-19-41-32.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. On the integration page, paste the Token Secret and Name obtained in [Step 1](/docs/integrating-tableau#step-1-fetch-access-token-from-tableau).

5. Enter the base URL of your Tableau account.

6. Click **Submit**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171152158-9vbvrnkximc-Screenshot-2025-09-10-at-19-43-23.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

7. Once authorization is done, you’ll see the “**Connected Successfully**” message and the **Connected** status indicator.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171153532-xqwfrck0jnk-Screenshot-2025-09-10-at-19-44-21.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Tableau. This process typically takes a few hours to complete. Check the Audit Log on the Tableau integration page in Scrut to review the status.

- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.

- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Tableau

To view the data fetched from your Tableau account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Tableau account. Click on it for more information.

You can also create an Access Review (or edit an existing one) and include the Tableau application in scope. Refer to this guide for step-by-step instructions on [creating an access review](/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Tableau:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Tableau in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click Tableau to view user details in Scrut.
