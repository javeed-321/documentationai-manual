Learn how to add and manage updates on your Trust Portal.

The **Updates section** in your Trust Portal helps to keep stakeholders informed about your latest security improvements, policy changes, compliance achievements, and other important changes. Regular updates build confidence in your security posture and demonstrate your commitment to security.

With **Trust Portal Subscriptions**, you can notify subscribed stakeholders automatically whenever you publish or re-publish an update.

## Before You Begin

- Ensure [Trust Portal Subscriptions are turned on](/docs/trust-management/trust-vault/settings-1/turn-on-subscriptions-to-trust-portal-updates#how-to-enable-subscriptions-to-updates) in Trust Vault → Settings

## How to Add an Update to the Trust Portal

1. Log in to Scrut and navigate to **Trust → Trust Vault** using the left side panel.

2. Click the **Overview** tab.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162579428-cr5cyplr266-Overview-Tab---Trust-Vault.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Scroll to the **Updates** section and click the **Add Update** button.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161858197-fdf8pxqbooq-Add-Update.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Enter a clear and descriptive **Title** for the update.

5. Select a **Category** from the dropdown. (e.g., Legal, Corporate Security, Endpoint Security, Compliance, General, etc.).

6. **Entity (if applicable)** – If you use multi-entity Trust Vault, select the entities to which you want to post this update. Choose organization-wide to post it across all your entities.

7. Add a description of the update. You can **format the description using Markdown**. Click **Preview** to view how the update will appear with the formatting applied.

8. If subscriptions are enabled, you will see a **Notify subscribers** toggle.

   - If you select this checkbox, all verified subscribers receive an email notification.
   - If left unselected, the update is published without sending notifications.

9. Click **Save**.

## Edit an Existing Update

To make any changes to existing updates:

1. Go to **Trust → Trust Vault → Overview**.

2. Scroll to the **Updates** section.

3. Click the three-dot menu next to the update.

4. Select **Edit**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162014290-k8y4dclp9qq-Edit-or-Delete-an-Update.png?fm=auto&auto=compress%2Cformat" alt="" />

5. When saving your edit, you can:

   - **Notify Subscribers**: Select the checkbox Send notification to subscribers again. A new email notification is sent to verified subscribers.
   - **Skip resending the notification**: Leave the checkbox unselected. The update is saved without sending another notification.

6. Click **Save**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165280049-ydw4sjxaun-Screenshot-2026-03-03-at-12-25-29.png?fm=auto&auto=compress%2Cformat" alt="" />

## Best Practices

- Maintain a consistent format across updates.
- Use clear and direct language that readers can follow easily.
- Post timely updates to keep stakeholders informed of important changes.
- Categorize updates appropriately to help users find relevant information.
- Use Markdown to enhance the readability of descriptions.
- Enable notifications only for meaningful updates to avoid email fatigue.

## FAQs

<ExpandableGroup>
  <Expandable title="What’s included in the email notification sent to subscribers?" default-open="true">
    When notifications are enabled, subscribers receive an email containing:

    - Update title
    - Category
    - Published date
    - Description

    Only **Verified** subscribers receive notifications.
  </Expandable>

  <Expandable title="How to delete an update?" default-open="true">
    From the Trust Vault **Overview** page, scroll to the **Updates** section. Click the three-dots icon next to the update you want to remove, then click **Delete**.
