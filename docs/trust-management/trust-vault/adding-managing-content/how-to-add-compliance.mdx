In this guide, we'll explain how to add compliance frameworks (implemented, in progress, and yet to be implemented) to your Trust Portal.

You can use your Trust Portal to showcase the compliance frameworks and certifications your organization has achieved or is pursuing. This demonstrates your adherence to industry standards such as SOC 2, ISO 27001, HIPAA, GDPR, and more, thereby building trust with prospects and customers who require you to have specific compliance credentials.

## How to Showcase a Framework on your Trust Portal

1. [Log in to Scrut](https://app.scrut.io/) using your credentials.

2. From the left navigation panel, expand the **Trust** menu and click **Trust Vault**.

3. Navigate to the **Overview** tab.

4. Click the **Add Framework** button in the **Compliance** section.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161830763-har94y72cd-Add-Framework---Trust-Vault.png?fm=auto&auto=compress%2Cformat" alt="" />

5. The **Framework** dropdown includes all default and custom frameworks you've added to Scrut. Search and select your required framework.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165321111-o2aophx1d0m-Screenshot-2026-03-13-at-16-05-14.png?fm=auto&auto=compress%2Cformat" alt="" width="532" height="803" />

6. Scrut automatically fetches the framework's logo and description. You can replace the logo or edit the description as required.

7. _\[Optional\]_ Enter the name of the **audit firm** that performed the compliance audit for this framework.

8. If you have a multi-entity Trust Portal, select the entities for which you want to add this framework.

9. Select the **Implementation Level**:

   - **N/A**: Choose this option if you have not yet implemented this compliance.
   - **In Progress**: Choose this option if the compliance is in progress.
   - **Fully implemented**: Choose this option if you have completed the compliance.

10. _\[Optional\]_ Click **Add Documents** to upload compliance certification, reports or other relevant documents.

11. Select the **Make All Documents Private** checkbox if you want visitors to require authorization to view attached documents.

    <Callout kind="alert">
      **Note:**

      If this checkbox is left unselected, visitors will be able to view the framework documents publicly without any request for access authorization.
    </Callout>

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165322471-naxb8gms6g-Screenshot-2026-03-13-at-16-09-41.png?fm=auto&auto=compress%2Cformat" alt="" />

12. Click the **Add** button to add the chosen framework to the trust vault.

Once you click **Add**, the framework appears in the **Compliance** section of your trust vault.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165156591-it7t79pxrpj-Screenshot-2026-02-16-at-11-41-49.png?fm=auto&auto=compress%2Cformat" alt="" />

## FAQs

<ExpandableGroup>
  <Expandable title="How many frameworks can I showcase on the Trust Vault?" default-open="false">
    As many as you require. There are no restrictions on the number of frameworks displayed in the Trust Vault.
  </Expandable>

  <Expandable title="Can I add frameworks that I have not yet implemented to the Trust Vault?" default-open="false">
    Yes, you can also include frameworks you plan to comply with soon. Ensure that you set the Implementation Level to **N/A**. Once you start implementing it, change the status to In Progress, and when you become compliant, change the implementation level to **Fully Implemented**.
  </Expandable>

  <Expandable title="Can I create a custom framework and add it to the Trust Vault?" default-open="false">
    In the **Framework** dropdown, enter the name of the new framework, and click the **+Create \[Framework Name\]** button.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161814712-0i0xdrk8xz7j-Add-Compliance-Framework-to-Trust-Vault-8.jpg?fm=auto&auto=compress%2Cformat" alt="" />

    Fill in the framework details and click **Add**. You can now see the newly created custom framework listed in the Compliance section of the Trust Vault.
  </Expandable>

  <Expandable title="How do I edit or delete a framework in the Trust Vault?" default-open="false">
    To make any changes to the framework you have included in the Trust Vault, click on the framework's name. This opens the Edit panel, where you can make changes or delete it if you no longer want to include it in your Trust Portal.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161816036-9fuvejckff-Add-Compliance-Framework-to-Trust-Vault-9.jpg?fm=auto&auto=compress%2Cformat" alt="" />
  </Expandable>
</ExpandableGroup>
