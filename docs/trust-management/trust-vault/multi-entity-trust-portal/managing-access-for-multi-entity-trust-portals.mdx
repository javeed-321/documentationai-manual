<Callout kind="info">
  **Who can use this feature**

  - Supported on **Scale** plan
</Callout>

## Requesting Access

When a visitor lands on your Trust Portal, by default, they’ll be directed to the default entity. They can then switch to the desired entity by using the dropdown at the top right. The user can click the “**Login/Get Access**” button to request access to the Trust Portal of a specific entity.

<Image src="/images/Request-access-for-a-specific-entity-in-trust-portal.png" alt="" />

## Approving Access Requests

To approve access requests:

1. Navigate to **Trust → Trust Vault → Access → Pending**.

2. On this page, you can view all pending access requests. Use the column selector to display entities in the table. This shows the entity for which the user has requested access.

   <Image src="/images/Column-Selector---Pending-Tab---Multi-Entity-Trust-Vault.png" alt="" />

3. Click **Accept** to grant the user access to the Trust Portal of a specific entity.

   <Image src="/images/Pending-Tab---Multi-Entity-Trust-Vault.png" alt="" />

   <Callout kind="alert">
     **Heads Up!**

     While approving the user’s access, you can also grant them access to other entities (or organization-wide), if required.
   </Callout>

   <Image src="/images/Screenshot-2025-10-29-at-19.25.49.png" alt="" />

## Manually Adding Users

1. Navigate to **Trust → Trust Vault → Access → Pending**.

2. Click **Add User**.

   <Image src="/images/Add-User-Manually-in-Trust-Vault.png" alt="" />

3. Enter the user details and select the entities for which you want to grant the user access.

4. Select organization-wide to grant the user access to all entities.

5. Click **Add**.

   <Image src="/images/Screenshot-2025-10-29-at-19.10.34.png" alt="" />

## Viewing Approved Users

1. Navigate to **Trust → Trust Vault → Access → Approved**.

2. This tab shows all users with access to your Trust Portal.

3. Use the column selector to view the entities for which a user has access.

   <Image src="/images/Screenshot-2025-10-29-at-19.26.55.png" alt="" />

**Note:** If a user has access to multiple entities, it will be indicated in the Entities column with a prefix showing the number of additional entities they have access to.

## Logging In and Viewing Entity-Specific Content

Once you approve a user’s request:

- When they log in, they can see an entity dropdown showing all entities they have access to.
