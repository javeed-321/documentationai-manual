This guide explains how to configure partial or full access for Trust Portal documents.

## Understanding Access Types

When approving user access to your Trust Portal, you can either grant them:

- **Full Access**: Grants access to all documents in your Trust Portal
- **Partial Access**: Grants access to specific documents only

## How Users Request Access

Users follow these steps to request Trust Portal access:

1. Navigate to the Trust Portal webpage ( `trust.example.com)`

2. Click **Login/Get Access.**

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165136996-k9tl8byzhac-Screenshot-2026-02-12-at-18-09-29.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Enter their work email and click **Continue.**

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165138367-1cslem8lw26-Screenshot-2026-02-12-at-18-10-23.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Complete the access request form with the required details:

   - First Name\*, Last Name\*
   - Email\*
   - Organization Name\*, Organization Type
   - Street Address, Country\*, State

5. Select preferred document access level:

   - Choose **Full Access** for all documents, or
   - Choose **Partial Access** and select specific documents

6. Accept the Terms of Service.

7. Click **Get Access.**

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162582001-7q0yo160dl9-Partial-or-Full-Access.png?fm=auto&auto=compress%2Cformat" alt="" />

Once submitted, users receive an on-screen confirmation message, and the request appears in the **Trust Vault → Access → Pending** tab in Scrut.

## Review Access Requests

#### Step 1: Access Pending Requests

1. Navigate to **Trust → Trust Vault → Access → Pending** tab in Scrut.
2. Click the green check mark to approve the user's access.
3. Review the access request details, including user information and access levels.

#### Step 2: Modify Access (Optional)

Before approving, you can adjust the access configuration:

1. In the Document Access section, you can switch between full or partial access as needed.
2. If granting partial access, select the list of documents that the user will have access to.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165139685-szmpruj6g3o-Screenshot-2026-02-12-at-18-17-13.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Step 3: Configure Access Settings

Set the following parameters:

- **Access Expiry Duration**: Define how long the user will have access.
- **NDA Settings**: Review and configure NDA requirements.

#### Step 4: Approve the Request

Once you've reviewed and configured the settings, click Save to approve the request.

## Modifying Access After Approval

You can update user permissions even after granting access:

1. Navigate to the user's profile in **Trust → Trust Vault → Access → Approved** tab.

2. Click the edit icon to modify the user’s access type.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165144150-5mvs5z37u8o-Screenshot-2026-02-12-at-18-22-03.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Edit the access type:

   - Switch between full and partial access
   - If using partial access, adjust the document list

4. **Save** the changes.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165141090-41cjfilleo3-Screenshot-2026-02-12-at-18-21-17.png?fm=auto&auto=compress%2Cformat" alt="" />
