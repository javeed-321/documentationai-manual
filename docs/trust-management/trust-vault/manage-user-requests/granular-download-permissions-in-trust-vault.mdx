You can now control who can download documents from your Trust Portal. This feature lets you customize the document download access at the user level, ensuring that **only authorized users can download sensitive information**. Learn how to configure user-specific download permissions in the Trust Vault.

## Customizing Download Permissions for Individual Users

<Callout kind="alert">
  **Note:**

  The default setting for the **Document Download** toggle is the same as the **Enable Downloading of Reports** settings of the Trust Vault.
</Callout>

### For New Requests

New access requests arrive in the **Pending** tab on the Trust Vault dashboard. When approving a user request, you can set the user's download permissions. To do this:

1. Navigate to **Access → Pending** tab in Trust Vault.

2. Click the **Approve** icon in the **Actions** column for a specific user.

   <Image src="/images/image-1770900995094.png" alt="" />

3. In the **Approve Access** window, turn the **Document Download** toggle on or off as required.

   <Image src="/images/image-1770901022782.png" alt="" />

If enabled, users can download all documents they’ve been granted access to via the **Document Access** settings.

### For Approved Users

For users you’ve granted access to the Trust Vault, you can change their download permissions by editing their details. To do this:

1. Navigate to the **Approved** tab in Trust Vault and click the **pencil icon** next to the user you want to edit.

   <Image src="/images/Pencil-icon.png" alt="" />

   <Image src="/images/Screenshot-2026-02-12-at-18.22.03-1.png" alt="" />

2. This opens the **Edit User** sidebar.

3. Toggle the **Document Download** setting on or off, as needed.

   <Image src="/images/image-1770901474301.png" alt="" />

4. Click **Save**.

### Further Insights

<ExpandableGroup>
  <Expandable title="Can I enable document downloads for a specific user when the global download setting is OFF?" default-open="false">
    Yes, even if the global download setting is turned OFF, you can turn ON the downloads for individual users as required.
  </Expandable>

  <Expandable title="Are user-level download document settings captured in the audit log?" default-open="false">
    Yes. Any changes you make to a user’s document download access settings are included in the audit log.
  </Expandable>

  <Expandable title="How do I determine if a user has document download access?" default-open="true">
    The user list in the **Approved** tab includes a **Document Download column** that shows the user's document download status (Enabled/Disabled).

    <Image src="/images/Screenshot-2025-03-22-at-11.37.59.png" alt="" />
  </Expandable>

  <Expandable title="Can I provide document download access to declined users?" default-open="true">
    Yes. Go to the **Declined** tab and click the **Approve** icon for the user you want to approve. Turn on the **Document Download** toggle and click **Approve**.

    <Image src="/images/image-1770901543925.png" alt="" />
  </Expandable>
</ExpandableGroup>
