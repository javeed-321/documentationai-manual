In Scrut, there are two ways to create a mitigation task:

- [From the Risk Register](/docs/risk-management/mitigation-task/add-a-mitigation-task#how-to-create-a-mitigation-task)
- [While assessing a risk](/docs/risk-management/risk-treatment/risk-assessment-workflow#step-4-mitigation-task-optional)

In this article, we walk you through how to **create a mitigation task for a specific risk from the Risk Register**.

## How to Create a Mitigation Task

1. [Sign in to Scrut](https://app.scrut.io/), and navigate to **Risk → Risk Management** using the left side panel.

2. Go to the **Risk Register** tab and click on the risk for which you want to create a mitigation task.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163892983-cx6j85dwh15-Screenshot-2025-07-23-at-11-42-31.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Once you’re on the risk detail page, scroll below to the **Mitigation Tasks** tab and click **Add Mitigation Task**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161847056-vpilh9w9ij-Add-Risk-Mitigation-Task.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Enter the following details in the Mitigation Task window:

   - **Task Name:** Enter a name for the mitigation task.

   - **Due Date:** Select the date by which the assignee has to complete the task.

   - **Assignee:** Use the dropdown to select a user who will be responsible for handling the task.

   - **Approver:** If you have enabled the mitigation task approval workflow, you can select an approver for reviewing the completed task.

   - **Department:** Select the department to which you want to assign this task.

     **Note:** The assignee must belong to the selected department to access this task.

   - **Description:** Optionally, add a description to provide more context about the task.

5. Click **Save**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165201575-1bj17cxj7cw-Screenshot-2026-02-24-at-09-38-38.png?fm=auto&auto=compress%2Cformat" alt="" />

6. The newly created mitigation task will be added to the Mitigation Tasks tab. Click on it to view its details.
