The **Policy Editor** is an in-platform tool that helps you create, edit, and format policies and enhance team collaboration. It helps you:

- **Save Time:** Quickly draft policies using built-in templates and pre-defined sections.
- **Collaborate Effectively:** Use comments to request feedback and clarification from team members.
- **Ensure Consistency:** Leverage formatting tools to maintain a unified structure and style across all policies.

## Step 1: Open the Policy Editor

1. [Log in to Scrut](https://app.scrut.io/) and click **Compliance → Policies** in the left panel.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162166586-b61zawko0e-image-1760630823010.png?fm=auto&auto=compress%2Cformat" alt="Policies tab" />

2. Navigate to the **All Policies** tab and create a new policy or open an existing one.

3. On the Policy Details page, scroll to the **Attachments** section and click **Create Policy**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164495828-j3ur8hwt9tl-Screenshot-2025-10-16-at-21-38-24.png?fm=auto&auto=compress%2Cformat" alt="" />

<Callout kind="success">
  **Heads Up!**

  Scrut pre-populates the editor with a sample policy template, that you can edit and modify, as per your requirements. However, note that the sample template is not available for custom policies.
</Callout>

<Expandable title="Working with Tables" default-open="false">
  **How to Insert and Work with Tables**

  The policy editor includes a built-in table tool that lets you insert and customize tables directly in your policy content.

  **To Insert a Table**

  1. Place your cursor where you want the table to appear.
  2. Click the **Table** icon in the editor toolbar.
  3. Drag across the grid to select the number of rows and columns you need, then click to insert.

  <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165648229-8trt4y3aoai-Screenshot-2026-05-08-at-15-02-13.png?fm=auto&auto=compress%2Cformat" alt="" />

  **Manage Columns**

  Click inside any column, then click the **Column** dropdown in the table toolbar. You can:

  <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162457097-2h02h2aq8k4-image-1778233497595.png?fm=auto&auto=compress%2Cformat" alt="" />

  - Turn on Header column to style the first column as a header.
  - Click Insert column left or Insert column right to add a column.
  - Click Delete column to remove the selected column.
  - Click Select column to highlight the entire column for bulk formatting.

  **Manage Rows**

  <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162458407-frjcnijzfi-image-1778233525150.png?fm=auto&auto=compress%2Cformat" alt="" />

  Click inside any row, then use the Row dropdown in the table toolbar to insert rows above or below, delete a row, or toggle a header row.

  **Merge Cells**

  <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162459694-8c0a78g5ihe-image-1778233582288.png?fm=auto&auto=compress%2Cformat" alt="" />

  1. Select the cells you want to merge by clicking and dragging across them.
  2. Click Merge cells in the table toolbar.
  3. To split a previously merged cell, select it and click Split cell.

  **Set Table Properties**

  1. Click anywhere inside the table.

  2. Click the **Table properties** icon in the table toolbar.

     <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165650991-ntoqfnupej-Screenshot-2026-05-08-at-15-12-57.png?fm=auto&auto=compress%2Cformat" alt="" />

  3. In the Table properties dialog, configure the following:

     - Border: Set the style (for example, Double), color, and width.
     - Background: Set a background color for the entire table.
     - Dimensions: Enter a fixed width and height.
     - Alignment: Align the table to the left, center, or right of the content area.

  4. Click Save to apply, or Cancel to discard changes.

     <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165649658-730xrxooagx-Screenshot-2026-05-08-at-15-12-48.png?fm=auto&auto=compress%2Cformat" alt="" />

  **Set Cell Properties**

  Cell-level properties such as background color, padding, and border can be set separately by right-clicking a cell and selecting **Cell properties**.

## Resolving Formatting Issues

When you copy-paste content from external documents such as Word files or Google Docs, formatting inconsistencies can appear in the Policy Editor. To ensure consistent formatting throughout the policy, clean up the content before editing further.

**To resolve formatting issues:**

1. Launch the Policy Editor.

2. Use the shortcuts Ctrl + A (For Windows) or Cmd + A (For Mac) to **Select All**.

   - Change the text style to **Paragraph**
   - Change the font family to **Default**
   - Change the font size to **Default**

3. Remove extra line breaks or spacing.

4. Reset the indentation and reapply bullets or numbering, as required.

  <Expandable title="What happens if multiple users try to edit the same policy simultaneously?" default-open="false">
    When a user edits a policy, it gets locked for others. If someone else tries to access the editor, they'll see a message saying, "Another user is editing." If the current editor goes offline or is idle, the lock will release automatically after a timeout, allowing others to edit.

  <Expandable title="How to manually save the policy?" default-open="false">
    Scrut automatically saves your changes while you edit. If autosave fails for any reason, you can use the "**Save Now**" button in the top right to save any unsaved changes.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162170684-wdsnq8ovhfr-image-1760631437590.png?fm=auto&auto=compress%2Cformat" alt="" />
  </Expandable>

  <Expandable title="Can I edit the policy while offline?" default-open="false">
    Yes, any edits made offline are saved locally. When your internet connection returns, Scrut will automatically save them or prompt you to click the "Save Now" button.
  </Expandable>

  <Expandable title="Why isn’t the policy editor pre-populating with a sample template?" default-open="false">
    The sample template is not available for custom policies. If you’re working on a custom policy, initially, the policy editor will be blank, and you have to build the policy from scratch.
