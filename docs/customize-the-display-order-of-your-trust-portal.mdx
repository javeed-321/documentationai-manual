This guide covers how to customize the display order of Trust Portal sections and items within each section.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161984231-u0p6xxts8vp-Customize-Trust-Portal-Layout.gif?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

Display order customization works at two levels:

- **Page layout:** Drag and reorder entire sections (Compliance, Controls, Sub-Processors, FAQs, Updates).
- **Section sort:** Set a sort strategy for items within each section, such as sorting compliance frameworks alphabetically or placing your most recently added sub-processors at the top.

<Callout kind="alert">
  **Note:**

  Any changes you make in Trust Vault → Settings → Portal Layout affect presentation only. They do not modify your compliance data, control configurations, or any other content.
</Callout>

## Reorder Trust Vault Sections

1. Sign in to Scrut and navigate to **Trust → Trust Vault → Settings**.
2. Click the **Portal Layout** tab.
3. Drag each section to your preferred position.
4. Click **Save** to apply the new layout.

The updated section order is reflected on your Trust Portal immediately.

## Set the Sort Order for Items Within a Section

You can also customize the sorting order for items within each section.

1. Navigate to **Trust → Trust Vault → Settings**.
2. Click the section you want to configure on the left panel: Compliance, Controls, Sub-Processors, or FAQs.
3. Select your preferred order from the sorting dropdown.
4. If you select Custom Order, drag handles appear next to each item. Drag them to rearrange the order.
5. Click **Save**.

The selected order is automatically applied to the Trust Portal.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166089033-l33nw98x3gj-Sorting-order-for-items-in-a-section.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

<Callout kind="alert">
  **Heads Up!**

  - Updates are always sorted by Newest First. This ordering is fixed and cannot be changed.
  - The Documents section follows the same sort order as you have set for Compliance and Controls.
</Callout>

## FAQs

<ExpandableGroup>
  <Expandable title="Does reordering sections or items affect my compliance data?" default-open="false">
    No. Display order changes are presentation only. Your compliance data, control configurations, and all other content remain unaffected.
  </Expandable>

  <Expandable title="Does the ordering apply to the Documents section too?" default-open="false">
    Yes. Compliance documents follow the sorting applied in the Compliance section. Control documents follow a two-level sort: category order is applied first, then the sort order of controls within each category is applied.
  </Expandable>

  <Expandable title="How do I reset to the default order?" default-open="false">
    Select **Newest First** from the sorting dropdown to return to the default ordering for a section.
  </Expandable>

  <Expandable title="What are the available sorting options for items within a category?" default-open="false">
    - **Newest First (default):** Items appear in reverse chronological order based on when they were added.
    - **Oldest First:** Items appear in chronological order.
    - **Alphabetical (A to Z)**
    - **Alphabetical (Z to A)**
    - **Custom Order:** Drag items into your preferred order. Drag handles appear when Custom is selected.
  </Expandable>

  <Expandable title="How to sort items in the Controls section?" default-open="false">
    Controls have two levels of ordering:

    - Categories displayed as cards
    - Controls listed inside each category

    You can apply different sorting options for each, as needed.

    **Note:** Only controls with an implementation level of In Progress or Fully Implemented are visible on the Trust Portal. Controls set to N/A are not displayed to visitors, regardless of their position in the list.
  </Expandable>
</ExpandableGroup>
