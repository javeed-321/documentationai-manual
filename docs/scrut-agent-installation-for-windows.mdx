## Enabling Default Security Parameters on Your Device

### **HD Encryption**

You can enable BitLocker encryption using one of the following methods:

#### **Method 1: Using the Start Menu**

- Click on the Start Menu.
- Type **BitLocker** into the search box.
- Select **BitLocker Drive Encryption** from the results.
- Click **Turn on BitLocker**.

#### **Method 2: Using the Control Panel**

- Open Windows Control Panel.
- In the upper-right search box, type **BitLocker** and press **Enter**.
- Click on **Manage BitLocker** from the search results.
- On the next screen, click **Turn on BitLocker**.
- Once enabled, BitLocker will check your PC’s configuration to ensure your device supports encryption. Follow the on-screen instructions to complete the setup.

### **AV Installed**

- **Open Windows Security**: Click the Start button, then search for **Windows Security** and open the app.
- **Access Virus** and **Threat Protection**: On the left-hand menu, click on **Virus** and **Threat Protection**.
- **Check Real-time protection**: Under **Virus & threat protection settings**, ensure the toggle switch for **Real-time protection** is turned on.

### **ScreenLock Enabled**

To ensure that Screen Lock is enabled on your Windows device, follow these steps:

#### **Method 1: Using System Settings**

- Click on the Start Menu and select **Settings**.
- Navigate to **Accounts → Sign-in** options.
- Under **Require sign-in**, select **When PC wakes up from sleep** to prompt for a password.

#### **Method 2: Configuring Lock Screen Timeout**

- Open Settings and go to **System → Power & sleep**.
- Under **Screen**, set a preferred time for **Turn off the display after inactivity.**
- Under **Sleep,** ensure the device is set to sleep after a defined period of inactivity.
