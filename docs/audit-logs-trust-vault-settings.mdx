---
title: "View Audit Logs in Trust Vault Settings"
metaDescription: "Track changes made to Trust Vault Settings via the Audit Logs tab."
---

The **Audit Logs** in **Trust Vault Settings** track all configuration changes, including updates to branding, custom domain, NDA, additional settings, and auto-approve. This makes it easy for you to track who made which changes and when.
