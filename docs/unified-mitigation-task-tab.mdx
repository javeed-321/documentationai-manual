The Mitigation Task Tab provides a centralized hub to manage all tasks related to your risks. It gives risk managers a single place to view, track, and act on mitigation activities across risks.

## How To Access the Mitigation Task Tab

1. Sign in to Scrut, and go to **Risk → Risk Management** using the left navigation panel.

2. Click the **Mitigation Task** tab. On this page, you can see all Mitigation Tasks and their current statuses.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162538667-mdd77xbn6cj-Mitigation-Task-Tab.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. Click on any mitigation task to go to the task detail page. This page provides in-depth details about the task, including name, description, assignee, approver, due date, and department. It also links directly to the risk to which this task is attached.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162537360-drs8zzghyo-Mitigation-Task-Details-Page.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

## Overview of Mitigation Task Tab

### Metrics Card

The metrics card shows the number of mitigation tasks under each status. See here to learn more about these statuses.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165216948-05tq8g4hyw9-Screenshot-2026-02-24-at-13-58-36.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

### Mitigation Tasks Table

The table lists all mitigation tasks for various risks. It offers a convenient overview of each task, including the associated risk name, current status, assignee, due date, department and more. It also includes a flexible column selector to choose which columns are visible in the table.

### Search and Filters

#### Search

The search bar at the top of the table makes it easy to find specific tasks. You can search by task title and other relevant keywords.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164074951-6ffubu9659w-Screenshot-2025-08-19-at-19-55-46.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

#### Filters

You can filter the tasks on the table by using these filters:

- Due Date
- Assignee
- Department
- Approver
- Entity
- Risk Treatment Strategy
