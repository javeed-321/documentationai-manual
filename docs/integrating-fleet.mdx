---
title: "Integrating Fleet"
---

Fleet integration fetches employees' endpoint/device data to Scrut. This data is displayed in the People Dashboard and the People -> Employee module. The following data is fetched from Fleet:

- Device name
- OS version
- Serial number
- Antivirus Installed(Yes/No)
- HD Encrypted(Yes/No)
- Screenlock Enabled(Yes/No)

## Integrating Fleet

1. From the left navigation panel, select Integrations.
2. Click on **Available**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162735854-jq0i4zso6ld-image-9CXHGH6K.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. Scroll to _Mobile Device Management Tools_ section and find _Fleet_.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162918322-rpywq82g9v-image-I9BAHU6G.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. Click **Integrate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162975469-7b6nfiir59l-image-L1GANCUO.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

Fleet integration page opens.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163038196-86qxqsu844j-image-OTTVRBSW.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

5. In _URL_ field, enter the full url of your fleet instance (e.g. https://fleet.acme.com)
6. In API Token field, enter the api token.

<Callout kind="info">
  **How to generate API Token?**

  Read the following [Fleet Guide](https://fleetdm.com/docs/using-fleet/fleetctl-cli#create-an-api-only-user) to generate API token.
</Callout>

7. Click on **Submit**.

Integration is successful.
