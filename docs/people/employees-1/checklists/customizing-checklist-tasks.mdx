Scrut gives you complete control over which employee tasks to include in a checklist. If you want to keep things simple initially, we suggest customizing the default checklist and assigning it to the default employee group, which includes all employees. This means all employees will be assigned similar tasks.

However, there are plenty of scenarios where this approach wouldn’t work. For example, permanent employees might need to complete a different set of compliance tasks, whereas contractors will have a different set of security requirements. In this case, we recommend creating role-specific checklists to meet varying compliance requirements.

<Callout kind="info">
  **Best Practices: Create Role-Specific Checklists**

  We recommend creating multiple checklists with varying compliance requirements and assigning them to different groups of personnel. As job responsibilities and access to information vary, having distinct checklists for roles like interns, contractors, full-time employees, etc. will help you address the specific needs of each team/role.

  See here for step-by-step instructions on [creating a new checklist](/docs/people/employees-1/checklists/create-a-new-checklist).
</Callout>

## How To Customize the Default Scrut Checklist

Once you import employees, Scrut automatically creates the **Scrut Default** checklist. You cannot delete this checklist. However, you can customize it to suit your specific compliance requirements.

1. Navigate to **People → Employee** module, click the **Settings** icon on the top-right.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162224893-gzia4m28l4q-image-1763443684763.png?fm=auto&auto=compress%2Cformat" alt="" />

2. Navigate to the **Checklists** tab.

3. Locate the **Scrut Default** checklist and click **Edit**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162006336-g48dfagbaxs-Edit-Default-Checklist.png?fm=auto&auto=compress%2Cformat" alt="" />

4. \[Optional\] Rename the default checklist. (Compliance Essentials, IT Security Onboarding, etc.)

5. Configure ongoing and offboarding tasks as required.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164692145-hkj08m0sura-Screenshot-2025-11-18-at-10-59-41.png?fm=auto&auto=compress%2Cformat" alt="" />

6. Review the selections you made in the previous steps and save your changes.
