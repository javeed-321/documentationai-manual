This guide explains how to access and navigate the Employee Detail page in Scrut.

## How To Access an Employee’s Detail Page

Follow these steps to open an employee’s profile page:

1. Click **People → Employees** on the left navigation panel.

2. Navigate to the **All Employees** tab.

3. Search and find the employee whose details you want to view.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166062880-7tj9eq9d56e-Selecting-an-individual-employee.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Click the employee’s name to open their profile page.

## Understanding the Employee Detail Page

The page is organized into multiple sections. Below is a detailed breakdown of each section.

#### Employee Details

The topmost section displays employee details, including Name, Email, Joining Date, Groups assigned in Scrut, Reporting Manager, and Department. Depending on the source from which you’re fetching the employee details, some of this information may not be present.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164897278-agkv2k9p4a6-Screenshot-2025-12-31-at-13-11-40.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Ongoing Tasks

This section displays active tasks and requirements currently assigned to the employee. It includes:

- **Policy Acceptance:** Policies the employee has to accept and their current status
- **Install Monitoring Agents**: Status of required monitoring software installation
- **Install Password Manager**: Password management tool deployment status
- **Device Security**: Current device security configuration requirements
- **Security Awareness Campaigns**: Active training campaigns that the employee needs to complete
- **Background Checks**: Status of background verification processes

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164898568-ryvoncecsys-Screenshot-2025-12-31-at-13-13-09.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Offboarding Tasks

Status of the offboarding tasks the employee must complete upon leaving the organization. These tasks will become active only [when offboarding is initiated](/docs/people/employees-1/terminating-and-offboarding-an-employee).

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164899875-233zoyt82zn-Screenshot-2025-12-31-at-13-13-35.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Documents

This tab lists all the [onboarding and offboarding documents that you have uploaded for an employee in Scrut](/docs/people/employees-1/uploading-onboarding-documents-of-an-employee).

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164901167-94vnu7t2qp-Screenshot-2025-12-31-at-13-14-27.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Trainings

This section provides a complete record of all security awareness activities:

- **Trainings**: List of all assigned security awareness campaigns that the employee has participated in
- **Attempted Date**: When the employee accessed or completed each campaign
- **Score**: Performance results for assessments
- **Status**: Completion status (e.g., Completed, In Progress, Not Started)

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164903749-72uh61qs9vn-Screenshot-2025-12-31-at-13-42-53.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Technicals

This section displays the security posture of all devices associated with the employee, including:

- Device compliance status
- Security configurations
- Operating system details
- Installed security controls

**Note:** You can mark specific devices as **Out of Scope** to exclude them from compliance calculations. This is useful for personal devices or equipment not subject to company security policies.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162307041-0mszcwakojqj-image-1767180234857.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Access

This section shows application access information, including:

- Which applications does the employee have access to
- Access permissions and roles

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164906367-va0heaspd0c-Screenshot-2025-12-31-at-13-48-37.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Audit Log

This section provides a detailed activity history, showing:

- All actions performed on this employee's record
- Who made changes and when
- What information was modified
- A complete audit trail for compliance purposes
