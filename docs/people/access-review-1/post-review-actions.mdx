---
title: "What to Do After Completing an Access Review"
description: "Check the various actions you can perform on completed access reviews in Scrut."
---

Once the review is concluded, you can perform the following actions:

- [Export Review Report](/docs/people/access-review-1/post-review-actions#export-review-report)
- [Clone Review](/docs/people/access-review-1/post-review-actions#clone-review)
- [Archive Review](/docs/people/access-review-1/post-review-actions#archive-review)

### Export Review Report

Click **Export** to generate a comprehensive report. The report includes key details of the review, such as critical dates, access changes, applications included in the scope, and user details for each application.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163812485-4v5rycvwem-Screenshot-2025-07-07-at-20-13-31.png?fm=auto&auto=compress%2Cformat" alt="" caption="Sample Access Review Report" />

### Clone Review

To streamline future access review, you can clone the current review configuration. This allows you to duplicate the current review settings, saving significant setup time. When cloning, you can modify the review name, description, in-scope applications, and other details, as needed.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162416395-fs2804ud46u-image-1773154957924.png?fm=auto&auto=compress%2Cformat" alt="" />

### Archive Review

Scrut allows you to archive the completed review for future reference. This helps you track access trends over time and support compliance audits.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165305258-4su8chg07g3-Screenshot-2026-03-10-at-20-33-52.png?fm=auto&auto=compress%2Cformat" alt="" />

You can only archive **active, overdue**, or **completed reviews**. You cannot archive a review that is in the **Draft** state.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163584838-xgifd4we7vd-Screenshot-2025-05-27-at-19-10-20.png?fm=auto&auto=compress%2Cformat" alt="" />

When marking a review as “archived,” you must provide a reason for active and overdue reviews. For completed reviews, the reason field is optional. The archive action is recorded in the **Audit Log**, which includes the user's name, timestamp, review name, and reason (if provided).

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163586713-00j7u6jd0avej-Screenshot-2025-05-27-at-19-11-52.png?fm=auto&auto=compress%2Cformat" alt="" />

Users can access archived reviews in read-only mode by navigating to the Archived tab.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165306683-oidobednjt-Screenshot-2026-03-10-at-20-35-00.png?fm=auto&auto=compress%2Cformat" alt="" />
