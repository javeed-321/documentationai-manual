---
title: "Create a New Access Review"
description: "Learn how to create a new access review in Scrut."
---

Here’s a step-by-step guide for creating a new access review:

1. Sign in to Scrut and go to **People → Access Reviews** using the left navigation panel.

2. On the **Reviews** tab, click the **Add Review** button.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161786059-u8ay0lsxj7-1773291522003-15ffc998.png?fm=auto&auto=compress%2Cformat" alt="" />

3. The first step of the setup process is to **enter the review details**.

   - Enter the **Review Name** and, optionally, include a **Description**.

   - Select an **Owner** who will oversee the entire process.

   - Set the review duration in days, i.e., the time it takes to complete the review (e.g., 10 days).

   - Select the **Schedule Review** checkbox to have the review recur periodically. If you select this checkbox, you’ll have to choose a **Start Date** and define the **Recurrence** frequency:

     - Monthly
     - Quarterly
     - Semi-Annually
     - Annually

     <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162408393-gwfgild6hb-image-1773152060930.png?fm=auto&auto=compress%2Cformat" alt="" />

4. The second step is to **select the applications that are in scope** for this access review.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162407060-5vu5yrpmfow-image-1773151933172.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Use the **Type** filter to filter applications to include in the review from:

   - **Integration**: Applications you’ve integrated with Scrut.

   - **Vendor**: Vendors added to your Scrut organization.

   - **Manual:** Custom applications that you’ve manually added to Access Reviews.

     - Click the **Add Application** button to add a custom app.

     - Enter the Application Name, select its Category, and choose the associated entity.

     - You can also add the application to your vendor list if required.

     - Once you add it, it will begin showing in the applications list.

       <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162412362-k0b934pdfk-image-1773152530475.png?fm=auto&auto=compress%2Cformat" alt="" />

   - **SSO**: Third-party applications that your employees access via single sign-on.

   - **Native**: The Scrut application itself.

6. Use the **Inherent Risk** filter to select applications by risk level: High, Medium, or Low.

7. Click the **Reset** icon to remove the applied filters.

8. The third step is to add reviewers and approvers. Select a **Reviewer** and **Approver** using the dropdown for each application you selected in the previous step.

   **Note:** Scrut recommends not selecting the same user as both the Reviewer and the Approver.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162409786-zenoxqbzq4m-image-1773152095734.png?fm=auto&auto=compress%2Cformat" alt="" />

9. The final step is to review the information and create the access review.

10. Review all settings and click **Save Review**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162411079-le1rf9ulkz-image-1773152144769.png?fm=auto&auto=compress%2Cformat" alt="" />

The newly created review will appear in the table on the Reviews page. You can search for it by typing its name in the search bar. The table displays the following details of each access review: Name, Owner, Status, Review Period, Apps in Review, and Recurrence.
