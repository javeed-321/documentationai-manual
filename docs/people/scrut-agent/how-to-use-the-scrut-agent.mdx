## Manual Sync

The Scrut Agent performs automatic, periodic background syncs between your device and Scrut. However, you can also initiate an immediate manual sync by clicking the **Sync Now** button. This allows for real-time updates, giving you complete control, especially when you need it most, such as before audits or compliance reviews.

## Run Diagnostics

Scrut Agent automatically runs the following diagnostic checks on your device during installation and once every 3 days thereafter.

- **VPN Configuration:** Checks for existing VPN setups that might interfere with connectivity.
- **Firewall Settings:** Verifies firewall rules to ensure unblocked communication.
- **Internet Connectivity:** Validates the system's connection to the internet

Additionally, you can manually trigger the diagnostics check by clicking the Run Diagnostics button at the bottom right.

## Check for Updates

Scrut automatically updates Scrut Agents installed on employee devices to the latest version. We do this as a security best practice. However, you can also manually update it by clicking the **Check for Updates**icon. This ensures you always run the latest version with the most current security patches and updates.

## Report an Issue

The **Report an Issue** button on the bottom left provides a direct communication channel to the Scrut Support team when you encounter any problems with the Scrut Agent.

- Click the Report an Issue button.
- Select the type of issue you’re facing: Login issue, Sync issue, or Incorrect data captured.
- Add any additional comments and click Submit.

This captures diagnostic information automatically and provides the Scrut support team with contextual data about your device, reducing resolution times and eliminating the need for multiple back-and-forth communications.
