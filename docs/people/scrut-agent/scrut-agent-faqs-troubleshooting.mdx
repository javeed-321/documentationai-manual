Find answers to common Scrut Agent questions and issues.

### FAQs & Troubleshooting

<ExpandableGroup>
  <Expandable title="What is the Scrut Agent, and is it a replacement for MDM tools?" default-open="true">
    Scrut Agent is a lightweight watchdog program that monitors security-related settings on your devices. It is not intended to replace MDM tools but instead works alongside them.
  </Expandable>

  <Expandable title="How does the Scrut Agent work?" default-open="true">
    Scrut Agent is built on osquery, an open-source platform that monitors critical security settings, including hard drive encryption, screen lock status, and antivirus installation. The app never modifies your computer settings and does not transmit sensitive information, such as passwords, messages, or browsing history, to Scrut.
  </Expandable>

  <Expandable title="How do I download the Scrut Agent?" default-open="true">
    Employees can download the Agent from the Scrut employee training portal. To learn more, [see here](/docs/people/scrut-agent/how-to-install-scrut-agent/how-to-install-scrut-agent-1).
  </Expandable>

  <Expandable title="Is the Scrut Agent compatible with all operating systems?" default-open="true">
    Scrut Agent is compatible with Windows, macOS, and Linux operating systems. Refer to this help guide for more detailed information on the [supported OS versions](/docs/people/scrut-agent/scrut-agent-supported-operating-systems).
  </Expandable>

  <Expandable title="Does the Scrut Agent restrict USB blocking, OS patch updates, AV, etc?" default-open="true">
    No, Scrut Agent only monitors and reports on security settings. It doesn't enforce restrictions like USB blocking, OS updates, or antivirus installations, and makes no changes to your system.
  </Expandable>

  <Expandable title="Will the Scrut Agent hamper my employee system performance or privacy?" default-open="true">
    No, Scrut Agent runs in the background with minimal system impact. It doesn't access or transmit sensitive data, such as passwords, messages, or browsing history, thereby preserving employee privacy.
  </Expandable>

  <Expandable title="Why is the Scrut Agent not showing the correct data?" default-open="true">
    Make sure that you (and your employees) have the latest version of the Scrut Agent. If you’re still experiencing issues, you can [report them directly from Scrut Agent](/docs/people/scrut-agent/how-to-use-the-scrut-agent#report-an-issue) or reach out to the customer support team (support@scrut.io).
  </Expandable>

  <Expandable title="If the Scrut Agent shows HD not encrypted, what are the steps to get it encrypted for different OS?" default-open="true">
    Follow the instructions to enable HD encryption for different operating systems:

    - **Windows:** [https://support.microsoft.com/en-us/windows/device-encryption-in-windows-cf7e2b6f-3e70-4882-9532-18633605b7df](https://support.microsoft.com/en-us/windows/device-encryption-in-windows-cf7e2b6f-3e70-4882-9532-18633605b7df)
    - **Mac OS:** [https://support.apple.com/en-in/guide/disk-utility/dskutl35612/mac#:~:text=In%20the%20Disk%20Utility%20app,device%20you%20want%20to%20encrypt](https://support.apple.com/en-in/guide/disk-utility/dskutl35612/mac#:~:text=In%20the%20Disk%20Utility%20app,device%20you%20want%20to%20encrypt).
    - **Linux Environment:** [https://docs.oracle.com/en/database/other-databases/nosql-database/19.5/security/disk-encryption-linux-environment.html](https://docs.oracle.com/en/database/other-databases/nosql-database/19.5/security/disk-encryption-linux-environment.html)
  </Expandable>

  <Expandable title="Can I customize the security requirements for different device types using the Scrut Agent?" default-open="true">
    Currently, Scrut Agent applies a standard set of security checks across all devices and does not support customization based on device types.
  </Expandable>

  <Expandable title="Is it mandatory to install Scrut Agent when we already have MDM solutions?" default-open="true">
    No, it's not mandatory.
  </Expandable>

  <Expandable title="What security settings does Scrut Agent monitor?" default-open="true">
    Scrut Agent monitors hard drive encryption, screen lock status, and antivirus installation on your devices and other system diagnostics. Refer to this section for [all device checks](/docs/people/scrut-agent/scrut-agent-walkthrough#device-checks) performed by the Scrut Agent.
  </Expandable>

  <Expandable title="Does the Scrut Agent sync daily?" default-open="true">
    The Scrut Agent syncs once every 3 hours.
  </Expandable>

  <Expandable title="Does the Scrut Agent auto-activate on every system restart?" default-open="true">
    Yes, the Scrut Agent automatically runs in the background on every system restart.
  </Expandable>
</ExpandableGroup>
