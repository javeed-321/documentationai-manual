---
title: "How can Employees Install Scrut Agent"
description: "Learn how to install Scrut Agent for different operating systems."
---

Your employees can download the Scrut Agent directly from the [Scrut Employee Training Portal](https://app.scrut.io/employee-campaign), as part of their security tasks. Once they log in to the portal, they’ll be instructed to download the Scrut Agent. Scrut will automatically detect the employee's device's operating system and download the correct file.
