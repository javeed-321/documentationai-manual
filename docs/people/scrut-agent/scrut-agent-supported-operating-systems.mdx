---
title: "Scrut Agent: Supported Operating Systems"
description: "Discover the operating systems that are compatible with the Scrut Agent."
---

The Scrut Agent is currently supported in the following operating systems:

| Operating System | Versions |
| :---: | :---: |
| **Windows** | Windows 11 Home • Windows 11 Pro • Windows 10 Home • Windows 10 Pro |
| **macOS** | macOS Tahoe (26) • macOS Sequoia (15) • macOS Sonoma (14) • macOS Ventura (13) |
| **Linux** | Ubuntu (18.04.6 to 24.04.2) • Pop!_OS (22.04 LTS) • Fedora (36, 40, 41) • Garuda Linux |

For further questions regarding compatibility, please get in touch with the Scrut support team at support@scrut.io.
