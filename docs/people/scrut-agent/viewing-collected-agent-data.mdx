Once the Scrut Agent is installed and running on employee devices, it continuously collects security and system information. You can view this data in Scrut to monitor device compliance and identify potential security risks.

## How to View Agent Data

To view the data collected from an employee's Scrut Agent:

1. Sign in to Scrut and click **People → Employees** on the left navigation panel.

2. Click the **All Employees** tab and select an employee from the list.

3. Go to the **Technicals** tab. This tab displays all data collected from that employee's Scrut Agent, including:

   - **Device security checks**: Hard drive encryption status, antivirus installation status, screen lock configuration, password manager, and installed application details
   - **System details**: Device name, serial number, OS version
   - **Last check:** The last time the agent performed these checks
