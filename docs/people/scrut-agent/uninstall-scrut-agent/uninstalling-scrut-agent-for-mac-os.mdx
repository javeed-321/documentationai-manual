## How To Uninstall Scrut Agent for Windows

Below are detailed instructions on how to do so through various methods for a Windows Operating system

1. Open the Scrut Agent on your device.

   <Image src="/images/Screenshot-2025-04-17-at-12.07.37-AM.png" alt="" />

2. Press **Control + Shift + 9** this will quit the agent.

3. **Uninstall in Settings**: Select Start > Settings > Apps > Apps & features. Find the Scrut application to remove. Select "More" > "Uninstall". Please note that some apps might not be uninstallable directly from the Settings app. In such cases, you can follow step 4.

4. **Uninstall from Control Panel**: In the search box on the taskbar, enter "Control Panel," then select it from the results. Select "Programs" > "Programs and Features".

   <Image src="/images/image-4-1.png" alt="" />

Press and hold (or right-click) the Scrut application to remove it. Select "Uninstall" or "Uninstall/Change", then follow the on-screen instructions.

<Image src="/images/image-2-4.png" alt="" />

<Callout kind="alert">
  **Note:**

  Once the Scrut Agent is uninstalled the data sync will stop, but the system details collected before the uninstallation will still show in the "Technical Details" section under the Employees Profile.
</Callout>
