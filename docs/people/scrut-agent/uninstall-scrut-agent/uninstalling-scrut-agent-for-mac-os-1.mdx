### How to Uninstall Scrut Agent for MAC OS

Below are detailed instructions on how to uninstall Scrut Agent for a MAC operating system:

1. Open the Scrut Agent on your device.

<Image src="/images/Screenshot-2025-04-17-at-12.07.37-AM.png" alt="" />

2. Press **Command + Shift + 9** to quit the agent.
3. Go to Finder, then go to Applications.

<Image src="/images/Screenshot-2025-04-17-at-12.14.30-AM.png" alt="" />

4. Search for Scrut Endpoint Agent, right-click the app, and click Move to Bin to complete the uninstallation process.

<Image src="/images/Screenshot-2025-04-17-at-12.14.01-AM.png" alt="" />

<Callout kind="alert">
  **Note:**

  Once the Scrut Agent is uninstalled the data sync will stop, but the system details collected before the uninstallation will still show in the "Technical Details" section under the Employees Profile.
</Callout>
