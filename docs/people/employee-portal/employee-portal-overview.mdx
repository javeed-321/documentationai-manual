The **Scrut Employee Portal** provides an interface to help your employees review and accept your organizational policies and complete the security training campaigns assigned to them. In this guide, we walk you through the portal’s navigation and functionalities.

## Getting Started with the Scrut Agent

Some organizations may not utilize an MDM tool for compliance tracking. In such cases, if the Scrut Agent installation is enabled, employees will see an option to install the Scrut Agent on their devices. For a deeper dive, [learn more about the Scrut agent](/docs/people/scrut-agent/scrut-agent-walkthrough).

<Callout kind="alert">
  **Note:**

  This section will not be visible if your organization has disabled the Scrut Agent MDM.
</Callout>

## Policies Overview

This section encompasses a list of policies assigned to the employee. It is a clickable section that, upon selection, displays a list of accepted and pending policies.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162801715-7oy71c48ug8-image-DN2VFGVK.png?fm=auto&auto=compress%2Cformat" alt="" />

## List of Policies

As the name suggests, this section displays the policies assigned to the employee. Click on a policy to review and accept it. For a deeper dive, learn more about [Accepting Policies in the Employee Portal](/docs/people/employee-portal/accepting-policies-in-the-employee-portal).

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162720049-oev9ca48vxh-image-83RQTSHX.png?fm=auto&auto=compress%2Cformat" alt="" />

## My Campaigns

Any training campaigns assigned by the organization are listed here. For a deeper dive, learn more about [Completing Security Training Campaigns in the Employee Portal](/docs/people/employee-portal/completing-assigned-security-campaigns).
