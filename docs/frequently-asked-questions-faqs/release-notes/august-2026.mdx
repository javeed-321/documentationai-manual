## Key Features & Enhancements

### View compliance status for each framework a control is mapped to

Continuous compliance means controls are rarely mapped to just one framework, but many. Multi-framework programs break when a control is complete for one framework and incomplete for another, but you have to open separate views to notice. For example, a control meeting SOC 2's requirement but not ISO 27001's would still show only one combined status, masking exactly where the gaps are and making it harder to know which framework actually needs attention.

Scrut solves this by showing control compliance status per framework, so you clearly see which frameworks a control satisfies and which still need work.
