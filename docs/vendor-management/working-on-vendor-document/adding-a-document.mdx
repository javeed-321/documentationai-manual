<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

The **Documents tab** on a vendor’s profile is where you collect and store security evidence such as compliance reports, security questionnaires, and trust portal links.

Scrut will automatically populate Trust Portal links for recognized vendors, and Scrut Teammates can [automatically collect documents and public security links](/docs/vendor-management/working-on-vendor-document/auto-fetch-documents-via-scrut-teammates). Additionally, you can also add documents manually.

<Callout kind="alert">
  **Note:**

  When you add a vendor from Scrut’s predefined list of known vendors, the system automatically populates the compliance URL (Trust Center/Trust Portal/Security Page) in the **Documents** tab. This link helps your team to quickly collect and review the vendor's security documentation, instead of spending time on manually searching for this URL.
</Callout>

## Add a Vendor Document Manually

1. Click **Risk → Vendors** on the left navigation panel and go to the **Vendors** tab.

2. Select a vendor from the list and click the **Documents** tab on the vendor page.

3. Click **Add Document**.

   <Image src="/images/Add-Document---Vendor.png" alt="" />

4. Click **Add Manually**.

   <Image src="/images/Screenshot-2026-07-22-at-11.42.31.png" alt="" />

5. From the drop-down menu, select one of the following options:

   - **File:** Upload a file by dragging and dropping it, or selecting it from your system.
   - **Link:** Copy-paste the document link.
   - **Add from Trust Portal:** Available only for vendors whose trust portal is hosted on Scrut. [See the section below for details](/docs/vendor-management/working-on-vendor-document/adding-a-document#fetching-documents-from-a-vendors-trust-portal).

6. Optionally, enter any notes about the document in the **Notes** field.

7. Click **Submit**.

   <Image src="/images/Screenshot-2026-03-02-at-14.14.10.png" alt="" />

8. The document will be uploaded to the vendor profile, with Source Type set to **Direct Upload** (when you upload a file or link).

   <Image src="/images/Screenshot-2026-03-02-at-14.19.30.png" alt="" />

## Fetching Documents from a Vendor’s Trust Portal

<Callout kind="info">
  **Pro Tip!**

  You can also let Scrut Teammates collect documents and links for you instead of adding them one by one. See [Auto Fetch Documents via Scrut Teammates](/docs/vendor-management/working-on-vendor-document/auto-fetch-documents-via-scrut-teammates) for the full walkthrough.
</Callout>

For vendors whose trust portal is hosted on Scrut, you can pull publicly available documents directly into the vendor's **Documents** tab, without leaving Scrut.

1. Go to the vendor's profile and click the **Documents** tab.

2. Click **Add Document**.

3. Select **From Live Trust Portal**.

4. A list of all publicly available documents from the vendor's trust portal appears. Select the documents you want to add.

5. Click **Submit**. The selected documents are added to the Documents tab.

   <Image src="/images/Screenshot-2026-03-02-at-14.16.41.png" alt="" />

6. The document will be uploaded to the vendor profile, with Source Type set to **Trust Portal**.

   <Image src="/images/Screenshot-2026-03-02-at-14.17.04.png" alt="" />

#### Points to note:

- Documents fetched from a trust portal are static. If you need an updated version, add the document again using the same workflow.
- Private documents are not shown in this list. To request access, use the trust portal link available in the same window to visit the vendor's portal directly.
