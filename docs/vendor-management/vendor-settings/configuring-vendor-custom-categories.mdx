<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

The Vendor Custom Category is a feature that allows users to create and manage their own vendor categories. It addresses the need for a more flexible and tailored approach to vendor risk management.

## Configuring Vendor Custom categories

1. From the left navigation panel, expand _Risk_ menu.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162710673-nf4t6q5a7nc-image-7VUAOC2E.png?fm=auto&auto=compress%2Cformat" alt="" />

2. Click **Vendors** and go to **Settings**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162796388-yv5ep263ft-image-DADG5Z9D.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Select **Category**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162677192-wlcga3mjphh-image-5K8NW0BZ.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Click **New category** to create a new vendor category.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162818837-k81w5y7x0vr-image-FLJSPNBE.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Add category name and click **Save**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162762383-pe12n3djgm-image-BG2OIFP4.png?fm=auto&auto=compress%2Cformat" alt="" />

The Vendor category gets added successfully.

<Callout kind="info">
  **Note:**

  You can also remove vendor categories from the list by clicking on the delete icon. Associated vendors will be linked to "Others" category automatically.
</Callout>
