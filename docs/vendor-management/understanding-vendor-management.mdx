Scrut's vendor management solution empowers organizations to track, assess, and mitigate vendor risks efficiently. In this article, learn how to navigate the vendor module and understand its core functionalities.

## How To Access the Vendor Management Module

1. [Log in to your Scrut account](https://app.scrut.io/) and click **Risk → Vendors** using the left navigation panel.
2. This opens the **Vendor** **Dashboard**.

## Tabs

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163491472-ut4arx5msqh-Screenshot-2025-05-02-at-12-19-30.png?fm=auto&auto=compress%2Cformat" alt="" />

The Vendor Management module includes the following key sections:

1. **Dashboard**: The dashboard displays key vendor metrics, including their assessment status and other relevant details, helping you make informed decisions. For an in-depth understanding, [explore the dashboard here](/docs/vendor-management/understanding-vendor-dashboard).
2. **Vendors**: The Vendors tab streamlines the process of importing vendors into Scrut and presents a clear view of your current vendors. To learn more, refer to [Adding a Vendor](/docs/vendor-management/managing-your-vendors/adding-a-single-vendor).
3. **Questionnaires**: This tab allows you to monitor all questionnaires sent to vendors and their current statuses. Check out this step-by-step guide to conduct an [AI-Powered Vendor Assessment](/docs/vendor-management/vendor-risk-assessment-workflow/ai-enhanced-vendor-assessment).
4. **Mitigation Tasks**: This tab shows all assigned mitigation tasks and their statuses, making it easy to manage vendor mitigation tasks from a single location. Check out this guide to understand the [Vendor Mitigation Task Workflow](/docs/vendor-management/working-on-mitigation-task-1/understanding-vendor-mitigation-task-approval-workflow).
5. **Onboarding**: The Vendor Onboarding tab serves as a central hub for effectively onboarding vendors. It allows employees to fill out customized forms with vendor information, accelerating the vendor assessment process. For a deeper dive, refer to [Vendor Onboarding](/docs/vendor-management/managing-your-vendors/vendor-onboarding-intake-form/how-to-onboard-vendors-using-an-intake-form).

## Key Components

In this section, we explain the key components of this module that help you understand your vendor information better.

### Filters

The vendor management module offers three primary filters to customize the data displayed.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163493116-03oy46j0wa47-Screenshot-2025-05-02-at-14-41-23.png?fm=auto&auto=compress%2Cformat" alt="" />

- **Assignee**: Use this filter to narrow down vendor data by specific assignees or display data without any assignee. You can also use it to quickly view the data of vendors assigned to you.
- **Category**: Use this filter to narrow the data by specific vendor categories, making it easier to focus on relevant information.
- **Entities**: Use this filter to narrow the data by specific entities or view organization-wide data.

<Callout kind="info">
  **Pro Tip!**

  Click on the circular **undo** icon to reset the applied filters.
</Callout>

### Metrics

The metrics cards at the top of the page display vendor counts based on their assessment status.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163494377-13gf1nw8akij-Screenshot-2025-05-02-at-14-41-40.png?fm=auto&auto=compress%2Cformat" alt="" />

- **Not Assessed:** Number of vendors pending assessment. No questionnaires have been sent to these vendors.
- **In Progress:** Number of vendors currently undergoing assessment. At least one questionnaire has been sent to these vendors, but either the vendor has not yet submitted the questionnaire or the questionnaire is yet to be evaluated by the vendor risk assessment team.
- **Assessed:** Number of vendors with completed assessment (either in Scrut or off Scrut). All relevant questionnaires have been sent, submitted by the vendor, and evaluated by the vendor risk assessment team.
- **Needs reassessment:** Number of vendors overdue for assessment, based on the recurrence schedule.

### Vendor Table

The core component of the Vendors tab is the Vendor Table. It displays a comprehensive list of all your vendors, providing a quick snapshot of the vendor name, assessment status, category, assignee, and other details.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163495621-419vdfkjlow-Screenshot-2025-05-02-at-14-51-27.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Sort By

Use the **Sort By** icons at the top of each column to apply ascending/descending sorting.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166216742-m82qmkpcoch-Vendor-Table-Sort.gif?fm=auto&auto=compress%2Cformat" alt="" />

#### Filters

Click the **Filters** button to narrow the table data by vendor categories like Tier, Risk Score, Inherent Risk, Residual Risk, Recurrence, or Next Assessment Date.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162052497-5m3mlz3pbmk-Filters-on-Vendor-Table.gif?fm=auto&auto=compress%2Cformat" alt="" />

<Callout kind="info">
  **Pro Tip!**

  Click the reset filter icon to remove all applied filters.
</Callout>

#### Search

Use the search bar at the top of the table to locate a specific vendor quickly.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163496946-f1iju4rrvp-Screenshot-2025-05-02-at-14-57-43.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Column Selector

You can customize the data displayed on the vendor table by choosing columns according to your requirements. Click the **Columns** button to select the columns you want to view here.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161960352-ncxdvsphcsi-Column-Selector-Vendor-Table.gif?fm=auto&auto=compress%2Cformat" alt="" />

### Export

Click the **Export** button to download the vendor table as a CSV file.

**Note:** Ensure you select the desired columns using the column selector before downloading if you want more information.
