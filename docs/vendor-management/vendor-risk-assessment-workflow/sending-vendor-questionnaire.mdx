Sending a questionnaire is a key step in actively assessing a vendor in Scrut. You can create the questionnaire manually using a template or let Scrut Teammates generate one based on the vendor's profile and your compliance requirements.

## Before You Begin

Scrut sends the questionnaire to the vendor's Point of Contact (POC) via email. Make sure you've [added a POC to the vendor's profile](/docs/vendor-management/editing-vendor-details/editing-poc-details) before sending. If you haven't, you can add one directly from the Send Questionnaire window.

## How to Create and Send a Questionnaire

1. Navigate to **Risk → Vendors** on the left navigation panel.

2. Go to the **Vendors** tab and click the vendor you want to assess.

   <Image src="/images/Selecting-a-Single-Vendor.png" alt="" />

3. Go to the **Questionnaires** tab.

4. Click **+ Start Creating a New Questionnaire** or **Add Questionnaire** (if you already have existing questionnaires for this vendor).

   <Image src="/images/Screenshot-2026-07-16-at-12.39.44.png" alt="" />

5. Choose how you want to create it.

   <Image src="/images/Create-questionnaire-options.png" alt="" />

6. **Create Manually**: Select Create Manually to build the questionnaire using a template from your organization's library or the default VSA template.

   - Enter a name for the questionnaire.
   - Set the Submission Deadline, the date by which the vendor POC must be submitted.
   - Set the Review Date, the date by which the reviewer must complete the evaluation.
   - Select a Reviewer from the dropdown. Scrut automatically notifies the reviewer about the assignment.
   - From the Select a Questionnaire Type dropdown, choose a template from your organization's library, select VSA to use the default template, or select Custom to build a new template.
   - Click Create Questionnaire & Continue.

7. **Let AI Create**: Select Let AI Create to have Scrut Teammates generate a tailored questionnaire based on the vendor's profile, data access, vendor type, and your compliance requirements. See [Vendor Risk Assessment with Scrut Teammates](/docs/vendor-management/vendor-risk-assessment-workflow/ai-enhanced-vendor-assessment) for the full AI assessment workflow.

8. Once the questionnaire is ready, click **Send to Vendor** on the questionnaire page.

   <Image src="/images/Screenshot-2026-07-16-at-12.44.46.png" alt="" />

9. Alternatively, you can also send the questionnaire by clicking the email icon on the questionnaire table in the Vendors page.

   <Image src="/images/Screenshot-2026-07-16-at-12.46.02.png" alt="" />

10. In the Send Questionnaire window, select the recipient from the Recipient Emails dropdown. If you haven't added a POC yet, click **+ Add POC** to add one.

11. Review the prefilled Email Subject and Body. Edit the content if needed to match your requirements.

    **Note:** The Email Body field supports Markdown formatting. Click **Preview** to see how the email will appear to the recipient before sending.

12. Click **Send**.

The questionnaire status changes to Sent. The vendor POC receives an email with a link to the Scrut Vendor Portal, where they can log in and complete the questionnaire.

## Sending a Questionnaire to Multiple Vendors

1. Navigate to **Risk → Vendors** and go to the **Vendors** tab.

2. Select the vendors you want to assess.

3. Click **Send Questionnaires**.

   **Note:** Scrut sends the questionnaire only to vendors with an assigned POC. Vendors without a POC will be skipped.

   <Image src="/images/Screenshot-2026-07-16-at-12.48.40.png" alt="" />

4. Select the Questionnaire Template and set the Submission Deadline and Review Date.

5. Select the Reviewer(s) who will evaluate the responses once the vendor submits.

6. Click Send Questionnaire.

Scrut emails the questionnaire to the POCs of all selected vendors.

<Image src="/images/Screenshot-2026-07-16-at-12.49.15.png" alt="" />

## What Happens Next?

The Vendor Point of Contact (POC) will receive an email notifying them of the questionnaire.

<Image src="/images/Screenshot-2025-07-24-at-20.17.31.png" alt="" />

When they click the **View Questionnaire** button, they will be directed to the [Scrut Vendor Portal](/docs/vendor-management/overview-2/centralised-vendor-portal). They can log in to the portal using their email address and complete the questionnaire.

<Image src="/images/Screenshot-2025-07-24-at-20.22.16.png" alt="" />

## FAQs

<ExpandableGroup>
  <Expandable title="What happens if I create a questionnaire but don’t send it?" default-open="true">
    The questionnaire stays in the **Created** status on the vendor's Questionnaires tab. Click the Send icon next to it to send it when you're ready.

    <Image src="/images/Screenshot-2025-07-24-at-20.26.40.png" alt="" />
  </Expandable>

  <Expandable title="How do I remind the vendor POC to complete the questionnaire?" default-open="true">
    Open the questionnaire page and click Send Reminder. Scrut sends a reminder email to the vendor POC.

    <Image src="/images/Screenshot-2025-07-24-at-20.24.46.png" alt="" />
  </Expandable>
</ExpandableGroup>
