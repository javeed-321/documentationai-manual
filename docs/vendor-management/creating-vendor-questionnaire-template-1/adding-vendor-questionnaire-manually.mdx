<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

If the default [VSA template](/docs/vendor-management/creating-vendor-questionnaire-template-1/using-the-vsa-template-for-vendor-questionnaire) doesn't fit your requirements, you can build a custom template from scratch. This article walks you through creating a template and adding questions to it.

## Step 1: Name Your Template

1. Sign in to Scrut and navigate to **Risk → Vendors** using the left navigation panel.

2. Click the **Settings** icon on the top right of the page.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166214141-bf22exlx0pf-Vendor-Settings-Icon.png?fm=auto&auto=compress%2Cformat" alt="" />

3. In the **Templates** tab, click the **Add Template** button and select **Manually**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161866284-7mkwg3gr2u3-Add-Vendor-Template.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Enter the name of the template and click **Save & Continue**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165226835-ebsimazro48-Screenshot-2026-02-27-at-12-57-51.png?fm=auto&auto=compress%2Cformat" alt="" />

## Step 2: Add Questions to the Template

1. Click **Add Question**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165228175-zhb57o1yb4r-Screenshot-2026-02-27-at-12-59-42.png?fm=auto&auto=compress%2Cformat" alt="" />

2. Enter your question in the textbox.

3. For **Question Type**, you can choose one of the following options:

   - **Subjective:** An open-ended text response.

   - **Objective (Single Select)**: The vendor selects one answer from the options you define.

     Note: You can include [conditional follow-up questions](/docs/vendor-management/creating-vendor-questionnaire-template-1/adding-vendor-questionnaire-manually#add-conditional-followup-questions) nested within the parent question.

   - **Objective (Multi Select)**: The vendor selects one or more answers from the options you define.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165229535-2r9csrga5gs-Screenshot-2026-02-27-at-13-01-52.png?fm=auto&auto=compress%2Cformat" alt="" />

4. If you select **Objective (Single Select)** or **Objective (Multi Select)**, you must set risk scores for each option.

   <Callout kind="alert">
     **Note:**

     Scrut scores risk on a scale of 0 to 5.

     0 to 1: Low Risk 2 to 3: Medium Risk 4 to 5: High Risk
   </Callout>

5. Click **+ Add Option** to add more choices for objective questions.

6. Select the **Question Domain** from the options available.

7. Choose the **Question Weightage**. Scrut uses this value to calculate the weighted average vendor risk score.

8. Select the “**Make attachment mandatory for this question**” if you want the responder to include a supporting file.

9. Click **Save**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165230875-jjlb50li03n-Screenshot-2026-02-27-at-13-04-15.png?fm=auto&auto=compress%2Cformat" alt="" />

The question is added to the template. Repeat these steps to add more questions.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165232309-qjcgopd63w-Screenshot-2026-02-27-at-13-06-24.png?fm=auto&auto=compress%2Cformat" alt="" />

### Add Conditional Follow-up Questions

If you add an **Objective (Single Select)** question to your questionnaire, you have the option to include a conditional follow-up question that is linked to the answer selected by the vendor. **This follow-up question will only appear if the vendor selects a specific option from the parent question.**

For example, if the vendor answers “Yes” to the question, “Have you ever had a data breach?”, you can then ask for additional details about the breach. This could include inquiries about the impact of the breach, when it occurred, and any other relevant information you deem necessary. By including conditional follow-up questions, you can develop more focused, adaptive questionnaires tailored to the answers vendors provide.

To add a conditional follow-up question:

1. Click the **+Add Follow-up Question** button. This is available only for **objective (single-select questions)**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162375691-8p8mvym5v0d-image-1772177862613.png?fm=auto&auto=compress%2Cformat" alt="" />

2. Select the answer option that triggers the follow-up question.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162377238-0b8u3j0bv1ip-image-1772177878058.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Type your follow-up question.

4. Choose the Question Type: Subjective, Objective (Single Select), or Objective (Multi Select).

5. Choose the Question Domain from the available options.

6. Select the Question Weightage and click Add.

The follow-up question appears below the parent question.

## FAQs and Troubleshooting

<ExpandableGroup>
  <Expandable title="Are there any restrictions on the number of questions included on a template?" default-open="false">
    No limitations. You can add as many questions as required.
  </Expandable>

  <Expandable title="Can I mark a question as optional?" default-open="false">
    No. Currently, all questions are mandatory.
  </Expandable>

  <Expandable title="What is the maximum character limit for a question?" default-open="false">
    Questions can be up to 1000 characters.
  </Expandable>

  <Expandable title="Can I include bullet points in a question?" default-open="false">
    Yes. Scrut supports bullets and line breaks in questions.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162510189-0dob3krsv35v-Line-Breaks-and-Bullets-in-Vendor-Questions-1.png?fm=auto&auto=compress%2Cformat" alt="" />
  </Expandable>

  <Expandable title="What is the maximum number of options for an objective question?" default-open="false">
    The maximum number of options for objective questions is currently restricted to four.
  </Expandable>

  <Expandable title="How many levels of follow-up questions are supported?" default-open="false">
    You can add up to two levels of follow-up questions, such as Parent → Child 1 → Child 2.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162378566-1jpy38jrx6u-image-1772177912874.png?fm=auto&auto=compress%2Cformat" alt="" />
  </Expandable>

  <Expandable title="Can I add multiple follow-up questions for the same parent question?" default-open="false">
    Yes, you can add multiple follow-up questions for a parent question. This is useful when you want to:

    - Add follow-ups for each option
    - Add multiple options for a single option

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163798873-bya7bwvtl9-Screenshot-2025-06-25-at-19-50-40.png?fm=auto&auto=compress%2Cformat" alt="" />
  </Expandable>

  <Expandable title="Can I reorder the questions?" default-open="false">
    Sorry, this option is currently unavailable.
  </Expandable>

  <Expandable title="Can I reorder the answer options in a question?" default-open="false">
    Yes. Just drag the options using the six-dot icon to rearrange their order.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162379931-gb3m9ziqahk-image-1772177932468.png?fm=auto&auto=compress%2Cformat" alt="" />
  </Expandable>

  <Expandable title="What happens if I delete a question with follow-up questions nested within it?" default-open="false">
    Scrut will delete all child questions nested within the parent.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162381317-s6rzllfotvq-image-1772177954160.png?fm=auto&auto=compress%2Cformat" alt="" />
  </Expandable>

  <Expandable title="Can vendors add attachments to follow-up questions?" default-open="false">
    Yes. Attachments are allowed for follow-up questions, just as they are for other questions.
  </Expandable>
</ExpandableGroup>
