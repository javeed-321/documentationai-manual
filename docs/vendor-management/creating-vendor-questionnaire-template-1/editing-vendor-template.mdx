<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

You can update a template at any time: rename it or modify the questions within it. Changes apply only to future questionnaires and do not affect those already sent.

## Edit the Template Name

1. Navigate to **Risk → Vendors** using the left navigation panel.

2. Click the **Settings** icon at the top right of the page.

3. Select the **Templates** tab.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166073934-ywpn22lg53d-Settings---Template-tab.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Click the **Edit** icon next to the template you want to rename.

5. Enter the new name and click **Save**. The template name is updated immediately.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165435437-nizmde22qal-Screenshot-2026-03-27-at-13-23-10.png?fm=auto&auto=compress%2Cformat" alt="" />

## Edit Questions in a Template

1. Navigate to **Risk → Vendors** using the left navigation panel.

2. Click the **Settings** icon at the top right of the page.

3. Select the **Templates** tab and click the template you want to edit.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166073934-ywpn22lg53d-Settings---Template-tab.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Click the **Edit** to make changes to the question.

5. Click **Delete** to remove a question. The template is updated and reflected in all future questionnaires that use it.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165438370-w4r7sp9tyad-Screenshot-2026-03-27-at-13-24-16.png?fm=auto&auto=compress%2Cformat" alt="" />
