<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

You can delete a template or remove individual questions from a template when they're no longer needed.

<Callout kind="alert">
  **Important:**

  The default VSA template cannot be deleted. This ensures you always have access to a baseline template for vendor assessments.
</Callout>

## Delete a Template

1. Navigate to **Risk → Vendors** using the left navigation panel.

2. Click the **Settings** icon at the top right of the page.

3. Select the **Templates** tab.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166073934-ywpn22lg53d-Settings---Template-tab.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Click the **Delete** icon next to the template you want to remove.

5. Click Delete in the confirmation window.

The template is permanently deleted.

## Delete a Question from a Template

1. Navigate to **Risk → Vendors** using the left navigation panel.
2. Click the **Settings** icon at the top right of the page.
3. Select the **Templates** tab and click the template containing the question you want to delete.
4. Click Delete next to the question and confirm your action.

The question is removed from the template. If the question includes conditional follow-up questions, those are deleted as well.
