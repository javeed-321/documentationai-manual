The VSA template gives you a ready-to-use foundation for vendor security assessments while offering the flexibility to adapt it to your organization's requirements. This article explains how to customize and use the default VSA template in Scrut.

## What Is the VSA Template?

The [Vendor Security Alliance](https://www.vendorsecurityalliance.org/) (VSA) is a coalition of companies committed to improving internet security. The VSA has designed the [Vendor Security Alliance Questionnaire (VSAQ)](https://www.vendorsecurityalliance.org/downloadQuestionaire), a standardized and comprehensive method for assessing and streamlining vendor security compliance.

Scrut offers a version of the VSA questionnaire as a default, out-of-the-box template that you can customize and send to your vendors as part of the vendor assessment process.

## Customizing the Default VSA Template

The default VSA template is fully customizable to meet your organization’s specific vendor assessment needs.

1. [Sign in to Scrut](https://app.scrut.io/), and go to **Risk → Vendors** using the left navigation panel.

2. Click the **Settings** icon at the top right of the Vendor Management page.

3. In the Templates tab, you’ll find the **VSA template** with the default tag. You can perform the following actions.

### Modify the Template Name

You can rename the template to match your organization’s terminology. For example, you can change it to Standard Vendor Security Assessment, Third-party Risk Evaluation Questionnaire, etc. Click the **Edit** icon in the **Actions** column to change the template’s name.

### Add New Questions

Click to open the VSA template. Click the **Add Question** button at the top right to include additional security, compliance, or business-specific questions, as needed. Enter the question text, type, domain, and weightage and click **Add**. Refer to this section for [step-by-step instructions on adding questions to the template](/docs/vendor-management/creating-vendor-questionnaire-template-1/adding-vendor-questionnaire-manually#step-2-add-questions-to-the-template).

<Callout kind="alert">
  **Heads Up!**

  Any changes made to the VSA template will permanently overwrite the default one.
</Callout>

### Edit Existing Questions

Click the **Edit icon** next to a question to modify question text, type, domain, and weightage.

### Delete Questions

Click the **Delete icon** next to a question to remove questions that aren’t relevant to your assessment process.

<Callout kind="danger">
  **Restrictions**

  You cannot delete the default VSA template. This is to ensure that you always have access to a default vendor assessment template.
</Callout>

## How To Use the VSA Template

Follow these steps to use the VSA (default) template when creating a vendor questionnaire:

1. [Sign in to Scrut](https://app.scrut.io/) and click **Risk → Vendors** using the left navigation panel.

2. Go to the **Vendors** tab, and click on a vendor to whom you want to send the questionnaire.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163670404-nkuawfgedgm-Screenshot-2025-06-17-at-17-52-47.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Click the **Create Questionnaire** button at the top right.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163671669-tttn1yi9eo-Screenshot-2025-06-17-at-17-53-53.png?fm=auto&auto=compress%2Cformat" alt="" />

4. In the **Questionnaire Type** dropdown, select the **VSA (Default)** template.

5. Enter the remaining details, then click **Create Questionnaire & Continue**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163672905-sj5055d85n-Screenshot-2025-06-17-at-17-56-50.png?fm=auto&auto=compress%2Cformat" alt="" />

Scrut will populate the questionnaire with your customized questions from the VSA template. Refer to this guide for step-by-step instructions on [sending the questionnaire you created to the vendor](/docs/vendor-management/vendor-risk-assessment-workflow/sending-vendor-questionnaire).

## FAQs & Troubleshooting

<ExpandableGroup>
  <Expandable title="Does editing the default VSA template impact questionnaires already created from it?" default-open="true">
    - No. Any modifications to the VSA template will be reflected only in future questionnaires created using it.
    - Existing questionnaires are not affected by template changes.
  </Expandable>

  <Expandable title="I am unable to locate the default VSA template. What should I do?" default-open="true">
    - Ensure you're looking in the **Vendor Settings → Templates** section.
    - Look for the VSA template labeled **"Default"**.
    - Even if you have changed the template’s name, the Default label will always be present.
    - Contact support if the template is missing.
  </Expandable>

  <Expandable title="Which version of the VSA template does Scrut use? [VSA Core or VSA Full?](https://www.vendorsecurityalliance.org/downloadQuestionaire)" default-open="true">
    Scrut uses an enhanced version of the VSA questionnaire, which doesn't strictly adhere to the "core" or "full" designations of the original VSAQ framework. Instead, the questionnaire provides a comprehensive overview of a vendor's security posture, combining industry best practices and various assessment experiences.

    The template is designed for efficiency, allowing you to evaluate vendors' security controls in a manageable way. Based on the responses, you can identify areas for further inquiry and request additional documentation as needed.

    It is fully customizable, enabling you to add or remove questions to fit your organization’s specific risk management needs.
  </Expandable>
</ExpandableGroup>
