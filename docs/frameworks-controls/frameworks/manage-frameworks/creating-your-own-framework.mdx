<Callout kind="info">
  **Who can use this feature**

  - Supported on **Growth** and **Scale** plans
</Callout>

Scrut provides a growing library of [ready-to-use frameworks](/docs/frameworks-controls/frameworks/framework-overview) for various regulatory and industry standards. If, however, you have a set of requirements not covered in the library (such as an internal compliance program, a program you run for your customers or vendors, or just a differently structured compliance standard), you can create a custom framework for your organization.

## How To Create a Custom Framework

1. Sign in to Scrut, and click Compliance → Framework on the left navigation panel.
2. Click +**Create Framework**.

<Image src="/images/Screenshot-2025-08-29-at-20.24.04.png" alt="" />

3. In the Framework Name field, enter a name for the framework.

4. From the Entity section, select an entity to which you would like to link your framework.

   <Image src="/images/Screenshot-2025-08-29-at-20.25.57.png" alt="" />

5. On clicking **Create**, Scrut will create the custom framework and add it to the My Frameworks tab.

   <Image src="/images/Screenshot-2025-08-29-at-20.27.20.png" alt="" />
