---
title: "Edit or Delete a Framework Requirement"
description: "Learn how to edit or delete framework requirements in Scrut."
---

<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

Scrut makes it easy to modify and remove requirements.

## Editing a Requirement

1. [Sign in to Scrut](https://app.scrut.io/) and go to **Compliance → Framework** using the left side panel.

2. Click the **My Frameworks** tab, and select the framework for which you want to modify a requirement.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163738696-4zv77nux3rt-Screenshot-2025-06-23-at-12-29-26.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Click on the requirement page and then click the **three-dot icon** next to the requirement name.

4. Optionally, use the search bar at the top to find a specific requirement. You can search by requirement name, code, or category.

5. Click the three-dot icon next to the requirement and choose **Edit Requirement**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166128372-gwpnszpuppv-Three-dots-icon-4.png?fm=auto&auto=compress%2Cformat" alt="Three-dots menu icon" width="25" height="25" />

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163740211-gkzkdagrccl-Screenshot-2025-06-23-at-12-35-13.png?fm=auto&auto=compress%2Cformat" alt="" />

6. You can modify the following requirement details:

   - Category
   - Code
   - Name
   - Description

7. Click **Update Requirement**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163741833-ojpqjn5uidl-Screenshot-2025-06-23-at-12-35-53.png?fm=auto&auto=compress%2Cformat" alt="" />

8. Watch out for the “Requirement updated successfully!” notification message.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163743391-09j03it08m8i-Screenshot-2025-06-23-at-12-36-47.png?fm=auto&auto=compress%2Cformat" alt="" />

## Deleting a Requirement

1. [Sign in to Scrut](https://app.scrut.io/) and go to **Compliance → Framework** using the left side panel.

2. Click the **My Frameworks** tab, and select the framework for which you want to delete a requirement.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163738696-4zv77nux3rt-Screenshot-2025-06-23-at-12-29-26.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Click on the requirement category and click the **three-dot icon** next to the requirement name you want to delete.

   <Callout kind="danger">
     **Heads Up!**

     You cannot delete a mandatory requirement.
   </Callout>

4. Click the three-dot icon next to the requirement and choose **Delete Requirement**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166128372-gwpnszpuppv-Three-dots-icon-4.png?fm=auto&auto=compress%2Cformat" alt="Three-dots menu icon" width="25" height="25" />

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163744647-0ftuvf8daujg-Screenshot-2025-06-23-at-12-42-27.png?fm=auto&auto=compress%2Cformat" alt="" />

5. A confirmation window appears. Click **Delete**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163745907-7lvze3q6xev-Screenshot-2025-06-23-at-12-44-36.png?fm=auto&auto=compress%2Cformat" alt="" />

<Callout kind="danger">
  **Warning**

  Deleting a requirement is permanent. So, proceed with caution.
</Callout>
