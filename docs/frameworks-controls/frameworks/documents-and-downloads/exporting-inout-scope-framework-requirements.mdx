  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

With the **Export Frameworks** feature, you can download all in-scope and out-of-scope requirements for your compliance frameworks as a CSV file and share it with auditors and other stakeholders. This article explains how to download your framework requirements.

## How To Export Framework Requirements

1. [Sign in to Scrut](https://app.scrut.io/) and go to **Compliance → Framework** using the left navigation panel.

2. Click on the framework for which you want to download the requirements.

   <Image src="/images/Screenshot-2025-06-23-at-12.29.26.png" alt="" />

3. Click on the requirement page, click the **three-dot icon** at the top-right and select **Export Requirement (CSV)**.

   <Image src="/images/Screenshot-2025-06-23-at-18.25.38.png" alt="" />

4. Select the location where you want to save the file, and then click **Save**.

The downloaded file includes all the requirement details such as code, name, description, scope, and justification.
