A System Description is a required component of your SOC 2 attested report. In Scrut, you can:

- Use Scrut Teammates to **generate a System Description with AI assistance**, drawing on your organization’s information already available in Scrut.
- **Upload an existing System Description document**, if you have one, and then review and approve it before it's included in your audit package.

## What Is a System Description?

A System Description outlines the scope of your SOC 2 report, covering your infrastructure, people, and processes. It’s a formal document that explains how your organization's systems work, what services they provide, and how you secure them. It covers your infrastructure, system boundaries, security controls, and customer commitments.

It provides auditors with a clear picture of your organization's boundaries, infrastructure, and controls for your SOC 2 attestation. Auditors use it as the foundation for your SOC 2 report, and it's shared externally as part of your attested report.

## Create a System Description

<Callout kind="alert">
  **Heads Up!**

  Each audit supports only one System Description. If the audit you want already has one, even an In Progress draft, you cannot generate a new one.
</Callout>

1. Sign in to Scrut and navigate to **Frameworks → SOC2 Framework → System Description**.
2. Choose one of the two methods below to continue.

### Generate with AI

1. Select **Generate with AI**.

2. In the **Setup** section, fill in the required fields covering your audit context, organization type, trust services criteria, and company details.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166000122-2ekpej64bc6-Screenshot-2026-08-20-at-18-46-05.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Click **Generate with AI**.

4. It takes a few minutes for Scrut Teammates to process your information and generate the draft.

5. You can safely leave this page and return later.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166001448-oms4e16ta0o-Screenshot-2026-08-20-at-18-49-58.png?fm=auto&auto=compress%2Cformat" alt="" />

6. Once the draft is ready, review each section.

7. Scrut automatically populates them using your Setup inputs along with other organization data already available in Scrut.

8. Review the auto-populated content in each section and edit it as needed.

   **Note:** Every field is fully editable. Use the edit control on any section to overwrite the AI-generated content with your own.

9. Complete each section and move to the next. If you exit the wizard before finishing, the system automatically saves your progress.

10. On the final step, it takes a few moments for Scrut Teammates to generate the review summary. You can leave this page and return later.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166002805-gpfdvp4v56b-Screenshot-2026-08-20-at-19-01-43.png?fm=auto&auto=compress%2Cformat" alt="" />

11. In the Review & Publish section, use the toolbar to make any needed formatting changes, such as headings, bold or italic text, lists, tables, images, etc.

12. Once done, click **Publish** to finalize the document.

13. Once published, the System Description is included in the audit package for that audit. If you publish a document more than once, only the most recent published version is included.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166004161-gvy4dpx8rkl-Screenshot-2026-08-20-at-19-11-40-1.png?fm=auto&auto=compress%2Cformat" alt="" />

## FAQs

<ExpandableGroup>
  <Expandable title="Which audits can I create a System Description for?" default-open="true">
    Available only for external SOC 2 audits.
  </Expandable>

  <Expandable title="Why can’t I select an audit while generating a system description?" default-open="true">
    Each audit supports only one System Description. If the audit you want already has one, even an In Progress draft, you cannot generate a new one.
  </Expandable>

  <Expandable title="How does Scrut source content for each section of the system description?" default-open="true">
    Scrut Teammates uses multiple data collection methods to populate the sections of your System Description. Every field stays fully editable no matter how it was sourced.

    | Data Source | What is it? | Example |
    | --- | --- | --- |
    | User Input | Data you provide yourself, either during initial setup or within an individual section. | Manual entry for specific company background details or architecture context. |
    | Internal Database Retrieval | Structured data already stored in Scrut. | Pulling the exact number of employees, recurrence periods for an evidence, or existing policy variables. |
    | Policy and Evidence | Reads and parses your uploaded policies and evidence to extract relevant details. | Parsing a list of security incidents or extracting specific clauses from an InfoSec policy. |
    | Publicly-available Information | Scans your company's public website to gather public-facing information. | Scanning your company's website to extract marketing context or product descriptions. |
    | Rewriter | Refines your rough notes into formal, audit-ready language. | Upgrading a note like "We use AWS for hosting" into a formal compliance statement. |
  </Expandable>

  <Expandable title="What happens if Scrut Teammates can’t find enough information for a section?" default-open="true">
    If a website is unreachable, a policy is missing, or multiple architecture diagrams are available, Scrut flags the section with a placeholder or a selection prompt instead of guessing. Fill these in manually to complete the section.
  </Expandable>

  <Expandable title="Can I include multiple network diagrams?" default-open="true">
    Yes. You can upload multiple images as required.
  </Expandable>

  <Expandable title="Can I edit a System Description?" default-open="true">
    It depends on how the document was created. If you generated it with Scrut AI, click the edit icon next to the System Description in the list view, revise any section, then regenerate and publish it again. If you uploaded the document manually, you cannot edit it directly. Delete the existing System Description, upload a new file, and publish it again.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166009643-q5xqi1k4lad-Screenshot-2026-08-20-at-21-44-14.png?fm=auto&auto=compress%2Cformat" alt="" />
  </Expandable>

  <Expandable title="How do I delete a System Description?" default-open="true">
    Click the delete icon next to the System Description in the list view.
  </Expandable>

  <Expandable title="How do I download a System Description?" default-open="true">
    Click the download icon next to the System Description in the list view.
  </Expandable>
</ExpandableGroup>
