The **Scrut - Sumo Logic** integration fetches user access data, permissions, and role assignments from your Sumo Logic account and syncs them with the [Access Review](/docs/access-review-walkthrough) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  **Heads Up!**

  The data synced from Sumo Logic flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You need the [Create Access Keys role capability](https://help.sumologic.com/docs/manage/users-roles/roles/role-capabilities/#security) in Sumo Logic to create an access key

### Permissions

Scrut requires **read-only access** to the following data in Sumo Logic

- User Accounts: View name, email, and user role

<Callout kind="tip">
  **Pro Tip!**

  We recommend logging into your Sumo Logic account before starting the integration to avoid doing so later.
</Callout>

## How To Connect Sumo Logic With Scrut

### Step 1: Fetch Access Key and ID from Sumo Logic

1. In the main menu in Sumo Logic, select your **Username**, and then **Preferences → Personal Access Keys**.

2. Click **+Add Access Key**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171134225-glk14khf2zd-Screenshot-2025-09-10-at-16-44-08.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. In the Add Access Key window, enter a name for the key, such as Scrut.

4. In the **Scopes**, select **Custom**, expand **User Management**, and set **View** for **Users and Roles**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171135557-bo1vc9ca6pb-Screenshot-2025-09-10-at-16-46-08.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

5. Click **Save** to generate the key.

6. **Copy** both the generated **Access ID** and **Access Key**, as you’ll need to enter them in Scrut in the next step.

   **Important**: These values will not be displayed after closing this screen. So, make sure to copy the ID and key and save them in a safe location.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171136898-3o8gqod8tda-Screenshot-2025-09-10-at-16-46-34.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

<Callout kind="tip">
  **Pro Tip!**

  Refer to these guides from Sumo Logic for [more information on generating Access Keys](https://help.sumologic.com/docs/manage/security/access-keys/) and the [required role capabilities](https://help.sumologic.com/docs/manage/users-roles/roles/role-capabilities/#security).
</Callout>

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.

2. Navigate to the **Integrations Library** tab, and choose **Capacity & Usage Monitoring** in the **Categories** section.

3. Scroll to the **Sumo Logic** tile and click **Integrate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171143650-5239b8valuy-Screenshot-2025-09-10-at-18-16-57.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. On the integration page, paste the Access Key and ID obtained in Step 1.

5. Enter the URL based on the location of your Sumo Logic deployment.

   - AU: https://api.au.sumologic.com/

   - CA: https://api.ca.sumologic.com/

   - DE: https://api.de.sumologic.com/

   - EU: https://api.eu.sumologic.com/

   - FED: https://api.fed.sumologic.com/

   - JP: https://api.jp.sumologic.com/

   - KR: https://api.kr.sumologic.com/

   - US1: https://api.sumologic.com/

   - US2: https://api.us2.sumologic.com/

     Note: Refer to the [Sumo Logic API help guide for more information](https://help.sumologic.com/docs/api/access-keys/).

6. Click **Submit**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171138275-fovsjbcem3a-Screenshot-2025-09-10-at-16-51-56.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

7. Once authorization is done, you’ll see the “**Connected Successfully**” message and the **Connected** status indicator.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171139582-ll4vy1rlrod-Screenshot-2025-09-10-at-16-52-32.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Sumo Logic. This process typically takes a few hours to complete. Check the Audit Log on the Sumo Logic integration page in Scrut to review the status.

- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.

- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Sumo Logic

To view the data fetched from your Sumo Logic account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Sumo Logic account. Click on it for more information.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171140910-57vyt0nd4e6-Screenshot-2025-09-10-at-16-53-24.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

You can also create an Access Review (or edit an existing one) and include the Sumo Logic application in scope. Refer to this guide for step-by-step instructions on [creating an access review](/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Sumo Logic:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Sumo Logic in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171142264-e1j4vt7ycp-Screenshot-2025-09-10-at-16-53-55.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

From the Access Review page, click Sumo Logic to view user details in Scrut.
