<Callout kind="custom">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

When an application is marked as Restricted, you can send removal or uninstallation instructions directly to the employees using it. Scrut generates the notification email automatically based on the application's source.

<Callout kind="danger">
  **Important:**

  Scrut does not automatically block employee access to restricted applications. Notifications are informational and instruct employees to take action themselves.
</Callout>

## Notify Users from the Restricted Tab

1. Navigate to **Access Review → Applications → Restricted**.

2. Locate the restricted application.

3. Click the **Notify Users** icon in the Actions column.

4. Alternatively, open the app and click **Notify Users**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165847020-9q9qub99avk-Screenshot-2026-07-02-at-21-11-58.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

<Callout kind="alert">
  **Heads Up!**

  Sending a notification does not confirm that employees have completed the removal or uninstallation. Follow up directly with employees or check the application's user list for updates.
</Callout>
