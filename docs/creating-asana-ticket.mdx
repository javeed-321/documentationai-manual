After completing the [Scrut - Asana integration](/docs/integrating-asana), you’ll be able to create or link Asana tasks directly from various compliance task modules within Scrut, including:

- [Policies](/docs/policy-module-walkthrough)
- [Evidence Tasks](/docs/evidence-tasks-walkthrough)
- [Tests](/docs/getting-started-with-tests-in-scrut)
- [Cloud](/docs/accessing-the-cloud-module)
- [Risk Management](/docs/how-to-use-the-risk-dashboard)
- [Audit → Audit Center → Requests](/docs/creating-a-request-in-audit-centre)
- [Audit → Audit Center → Findings](/docs/reporting-an-audit-finding)
- [Audit → Audit Center → Corrective Actions](/docs/creating-corrective-action-from-audit-finding)
- [Vulnerabilities → Findings](/docs/take-actions-on-scan-findings#2-create-a-project-management-ticket)

**Note:**

- Any updates to linked Asana tasks will automatically reflect in Scrut. This maintains consistency across both platforms, closing the loop between evidence collection, remediation, and reporting.

In this article, we explain how to create a ticket from Scrut to Asana and link an existing ticket from Asana to Scrut.

## Data Synced With Asana

### Standard Data Fields

By default, Scrut sends the following ticket data to Asana:

- Workspace: The Asana workspace where tasks will be created
- Project: The specific project within the workspace
- Task Name: The title of the created task
- Description \[Optional\]: Detailed information about the task
- Assignee: The team member responsible for the task

### Optional Data Fields

You can also configure these additional fields to be sent to Asana:

- Collaborators: Team members who can view and comment on the task
- Tags: Labels to categorize and filter tasks
- Attach Files: Documents and other files related to the task
- Due Date: Deadline for task completion

## How To Create an Asana Task in Scrut

1. [Log in to Scrut](https://app.scrut.io/) and navigate to the artifact you want to connect. This could be a Policy, Evidence Task, Risk, or Test.

2. Click the three-dots icon on the top-right and select **Create Asana Task**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162448657-n66l8hize5-image-1776685243578.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. Enter the task details:

   - Workspace

   - Project

   - Task Name

   - Description (Optional)

   - Assignee

   - Collaborators

   - Tags

     <Callout kind="alert">
       **Note:**

       Besides the tags in your Asana dashboard, you'll notice an additional tag labeled "**Scrut**." This tag is selected by default when you create an Asana task from Scrut. It helps you and your teammates easily identify tasks from Scrut in your Asana dashboard. If you don’t need this tag, you can unselect it.
     </Callout>

4. Click **Create**.

## Linking Existing Asana Tasks in Scrut

Scrut allows you to link existing tickets in your Asana dashboard to specific artifacts. To do this:

1. [Log in to Scrut](https://app.scrut.io/) and navigate to the artifact you want to connect. This could be a Policy, Evidence Task, Risk, or Test.

2. Scroll to the **Tickets (Asana)** tab.

3. Click the **Create** button and select **Link Existing Tickets**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162450230-m8mvvjj6gc-image-1776685319775.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. Copy the URL of the Asana ticket you want to link to the artifact.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163444588-gs975yq8ds-Screenshot-2025-04-12-at-12-55-09.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

5. Paste the copied URL and click **Link**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163445883-xdw6fn609t-Screenshot-2025-04-12-at-12-55-32.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

The ticket will be linked to the artifact.

## Updating Tasks in Asana

The integration between Scrut and Asana is bidirectional and works in real time. **When you change any synced fields in your Asana tasks, those changes will automatically update in Scrut.** For example, if you mark a task as completed in Asana, that completion status will immediately appear in Scrut.
