For Partners, to be notified of a Customer's initial Verfication Status updating, as they progress through the KYC/KYB process.

## Customer Verification Status

The `CUSTVSTAT` event is triggered when a Partner's customer verification status is updated as the customer progresses through the initial stage of the KYC/KYB Process.

This notification type is only available to Modulr's Partners and is not available to Direct Customers. It notifies you when a Customer has passed initial Verification checks.

You may have to wait for the [Customer Status](/update/docs/customer-status) webhook to notify you that the Customer is fully approved and ready for account creation.

| Parameter         | Description                                                                                                                                      |
| :---------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| EventId           | Unique id for the webhook event. This can change if webhook needs to be resent.                                                                  |
| EventName         | Type of event: CUSTVSTAT - Customer Verification Status Update.                                                                                  |
| EventTime         | Date and Timestamp for the Event - All Dates and times are UTC based.                                                                            |
| NewStatus         | Updated verification status of the customer.                                                                                                     |
| OldStatus         | Previous verification status of the customer.                                                                                                    |
| CustomerId        | Modulr Unique Customer Reference for the impacted customer.                                                                                      |
| ExternalReference | This can be a unique reference that links to your own platform to allow linking of Customer record on Modulr with the record on your own system. |
