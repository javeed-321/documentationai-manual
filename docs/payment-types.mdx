---
title: "Payment Types"
---

The following describes the various types of payments possible:

## Inbound Payments

| Category      | Type           | Payment Scheme                | Example Usage                               |
| ------------- | -------------- | ----------------------------- | ------------------------------------------- |
| UK Payments   | PI\_FAST       | Faster Payments               | Inbound GBP Payments from External Accounts |
|               | PI\_BACS       | Bacs                          | Inbound GBP Payments from External Accounts |
|               | PI\_CHAPS      | CHAPS                         | Inbound GBP Payments from External Accounts |
|               | PI\_DD         | Direct Debit                  | Inbound GBP Direct Debit Collections        |
| EU Payments   | PI\_SECT       | SEPA Credit Transfers         | Inbound EUR Payments from External Accounts |
|               | PI\_SEPA\_INST | SEPA Instant Credit Transfers | Inbound EUR Payments from External Accounts |
| Card Payments | PI\_MASTER     | Mastercard                    | Card Refunds                                |
|               | PI\_VISA       | VISA                          | Card Refunds                                |

## Outbound Payments

| Category      | Type           | Payment Scheme                | Example Usage                              |
| ------------- | -------------- | ----------------------------- | ------------------------------------------ |
| UK Payments   | PO\_FAST       | Faster Payments               | Outbound GBP Payments to External Accounts |
|               | PO\_CHAPS      | CHAPS                         | Outbound GBP Payments to External Accounts |
|               | PO\_DD         | Direct Debit                  | Outbound GBP Payments via Direct Debit     |
| EU Payments   | PO\_SECT       | SEPA Credit Transfers         | Outbound EUR Payments to External Accounts |
|               | PO\_SEPA\_INST | SEPA Instant Credit Transfers | Outbound EUR Payments to External Accounts |
| Card Payments | PO\_MASTER     | Mastercard                    | Card Settlements                           |
|               | PO\_VISA       | VISA                          | Card Settlements                           |
