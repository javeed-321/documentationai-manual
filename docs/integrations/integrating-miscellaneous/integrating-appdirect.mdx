The **Scrut - AppDirect** integration fetches user access data, permissions, and role assignments from your AppDirect account and syncs them with the [Access Review](/docs/people/access-review-1/access-review-walkthrough) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  **Heads Up!**

  The data synced from AppDirect flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to fetch the Domain URL, Client ID and Secret from your AppDirect account

### Permissions

Scrut requires **read-only access** to the following data in AppDirect

- User Accounts: View name, email, and user role

<Callout kind="info">
  **Pro Tip!**

  We recommend logging into your AppDirect account before starting the integration to avoid doing so later.
</Callout>

## How To Connect AppDirect With Scrut

### Step 1: Fetch Domain URL, Client ID & Secret from AppDirect

1. Log in to your AppDirect account.

2. Copy the base URL for your account, which will be in the format **https://marketplace.example.com**. This is your Domain URL.

3. Click the **Gear icon** in the top menu and navigate to **All Settings**.

   <Image src="https://mintcdn.com/cobalt-55/USIhqTKu3QZXm8QM/images/Appdirect/appdirect_navigation.png?fit=max&auto=format&n=USIhqTKu3QZXm8QM&q=85&s=3aacc5bba421e39f7a18b02bb7e0b7ee" alt="Navigation in AppDirect" />

4. Click **API Clients** in the side menu, and click **+Create API Client**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164677244-x95qc3xg0v-Screenshot-2025-11-17-at-10-42-20.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Enter a name, choose **Client Type** as **Non-interactive application**, select **System-level scopes** as **Read Only** and click **Save Settings**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164680001-ep7spb1uoa-Screenshot-2025-11-17-at-10-50-35.png?fm=auto&auto=compress%2Cformat" alt="" />

6. Copy the **Client ID (Consumer Key)** and **Secret**. Save it in a safe location, as you’ll need to enter it in Scrut in the next step.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164681428-gbihto4977w-Screenshot-2025-11-17-at-10-50-52.png?fm=auto&auto=compress%2Cformat" alt="" />

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.

2. Navigate to the **Integrations Library** tab, and choose **Miscellaneous** in the **Categories** section.

3. Scroll to the **AppDirect** tile and click **Integrate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164678626-6goggpfz0jb-Screenshot-2025-11-17-at-10-42-42.png?fm=auto&auto=compress%2Cformat" alt="" />

4. On the integration page, paste the details obtained in Step 1.

5. Click **Submit**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164682759-5jyo4zkm047-Screenshot-2025-11-17-at-10-58-36.png?fm=auto&auto=compress%2Cformat" alt="" />

6. Once authorization is done, you’ll see the success toast message and the **Connected** status indicator.

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from AppDirect. This process typically takes a few hours to complete. Check the Audit Log on the AppDirect integration page in Scrut to review the status.
- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.
- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from AppDirect

Scrut fetches the following access-related data points from AppDirect:

- User Name
- User Email
- User Role

## Viewing AppDirect Data in Scrut

To view the data fetched from your AppDirect account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your AppDirect account.

You can also create an Access Review (or edit an existing one) and include the AppDirect application in scope. Refer to this guide for step-by-step instructions on [creating an access review](/docs/people/access-review-1/creating-a-new-access-review).

Follow these steps to create a new access review for AppDirect:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select AppDirect in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click AppDirect to view user details in Scrut.
