Learn how to connect your Gainsight PX account with Scrut to fetch compliance data.

## What This Integration Does in Scrut

- **User Access Data:** Fetches user details and roles from Gainsight PX for Access Reviews.
- **Automated Tests:** Runs automated checks that continuously evaluate Gainsight PX for security misconfigurations and compliance checks against your applicable compliance frameworks.

## Prerequisites

- An active Gainsight PX account with administrator access
- An API key generated from the Gainsight PX Administration panel (see Step 1 below)

## Permissions and Access Requirements

#### For Gainsight PX

- Admin access to your Gainsight PX account to generate an API key
- Read permission scope on the API key

#### For Scrut

- Admin access to Scrut, or Contributor access with permissions to the Integrations module

## Data Collected

- User name: Full name of the user record
- Email address: Primary email on the user record
- User role: User’s role as defined in Gainsight PX

## Sync Frequency

Data is synced automatically once every 24 hours. You can also manually trigger a sync from the integration settings page.

### Step 2: Connect Gainsight PX in Scrut

1. Log in to Scrut and navigate to **Integrations** in the left sidebar.

2. Select the **Integrations Library** tab.

3. Search for **Gainsight PX** or browse to the **Miscellaneous** category.

4. Click **Integrate** on the Gainsight PX card.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165761561-1ylu8nc8ao1i-Screenshot-2026-06-04-at-10-52-33.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Under Credentials, paste your API key into the Api Key field.

6. Click **Submit**.

## What Happens Next?

#### Initial data sync

Once the integration is connected, Scrut begins the initial data sync automatically. You can monitor sync activity and review logs by navigating to Integrations, selecting Gainsight PX, and opening the Audit Log tab.

#### Review synced data

- Navigate to **People → Access Reviews → Applications** to view the user records fetched from Gainsight PX, including names, email addresses, and roles.
- Navigate to **Tests → Automated Tests** to view the results of the compliance checks that Scrut runs on your Gainsight PX account.

## Common Errors and Troubleshooting

#### Invalid API key

Cause: The API key entered in Scrut is incorrect, has been revoked, or was not copied in full.

Possible solutions:

- Confirm you copied the entire API key at the time of creation.
- If the key was lost or revoked, generate a new one in Gainsight PX under Administration → REST API and re-enter it in Scrut.
- Check that the API key has the Read permission scope assigned.

#### User data not appearing in Access Reviews

Possible solutions:

- Allow up to 24 hours for the initial sync to complete.
- Trigger a manual sync from the integration settings page and check the Audit Log for errors.
- Confirm the users in Gainsight PX have complete records, including name and email address.
