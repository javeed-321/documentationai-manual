Learn how to connect your Amplitude account with Scrut to fetch compliance data.

## What This Integration Does in Scrut

- User Access Data: Fetches user details, roles, and permissions from Amplitude for Access Reviews.
- Automated Tests: Runs automated checks that continuously evaluate Amplitude for security misconfigurations and compliance checks against your applicable compliance frameworks.

## Prerequisites

- An active Amplitude account with Admin or Owner access.
- An Amplitude project with users you want to sync to Scrut.

## Permissions and Access Requirements

#### For Amplitude

- Admin or Owner role on your Amplitude account.
- Read access to users in the relevant Amplitude project.

#### For Scrut

- Admin access to Scrut, or Contributor access with permission to the Integration module.

## Data Collected

- User display name: First and last name as configured in Amplitude
- Email Address: Primary email associated with the Amplitude account
- User role: Role associated with the user in Amplitude

## Sync Frequency

Data is synced automatically once every 24 hours. You can also manually trigger a sync from the integration settings page.

## Integration Setup

### Step 1: Retrieve Your Credentials From Amplitude

1. Log in to your Amplitude account.

2. Click the **Settings** icon in the top-right corner, scroll to the Connections section on the left sidebar, and click **API Keys**.

3. Click **Generate API Key**.

   <Image src="/images/Screenshot-2026-06-03-at-21.32.26.png" alt="" />

4. Enter a name such as Scrut Integration and click **Create API Key**.

   <Image src="/images/Screenshot-2026-06-03-at-21.32.57.png" alt="" />

5. Copy the API Key value and store it safely.

   <Image src="/images/Screenshot-2026-06-03-at-21.33.16.png" alt="" />

6. Next, copy the Secret Key and store it safely.

   <Image src="/images/Screenshot-2026-06-03-at-21.33.59.png" alt="" />

7. You’ll need to enter these values in Scrut in the next step.

<Callout kind="alert">
  **Note:**

  Each Amplitude project has its own API Key and Secret Key. Make sure you are copying credentials from the correct project before proceeding.
</Callout>

### Step 2: Connect Amplitude in Scrut

1. In Scrut, navigate to **Integrations** in the left sidebar.

2. Click the **Integrations Library**, scroll to the **Miscellaneous** section.

3. Locate **Amplitude** and click **Integrate**.

   <Image src="/images/Screenshot-2026-06-03-at-21.19.17.png" alt="" />

4. On the Amplitude integration page, under **Credentials**, enter the **API Key** and **Secret Key** you copied from Amplitude.

5. Click **Submit**.

   <Image src="/images/Screenshot-2026-06-03-at-21.34.41.png" alt="" />

Scrut validates the credentials and establishes the connection. The status indicator changes from **Not Connected** to **Connected** when the setup is complete.

<Image src="/images/Screenshot-2026-06-03-at-21.34.55.png" alt="" />

## What Happens Next?

#### Initial data sync

After you connect the integration, Scrut begins the initial data sync automatically. You can monitor sync activity and check for any errors under the **Audit Log** tab on the Amplitude integration page.

#### Review synced data

Once the sync completes, verify the data in Scrut by navigating to the following:

- Navigate to **People → Access Reviews → Applications** and verify if Scrut has synced the user records from Amplitude.
- Navigate to **Tests →** **Automated Tests** to view automated test results for Amplitude.

## Common Errors and Troubleshooting

#### Invalid credentials

Cause: The API Key or Secret Key entered does not match the credentials in your Amplitude project. Possible solutions:

- Return to your Amplitude project settings and re-copy both the API Key and Secret Key.
- Confirm you are copying credentials from the correct Amplitude project.
- Re-enter both values in Scrut and click Submit again.

#### Data not appearing after sync

Possible solutions:

- Check the Audit Log tab on the Amplitude integration page for any sync errors.
- Confirm the integration status shows Connected.
- Wait for the next scheduled sync (every 24 hours) or trigger a manual sync from the integration settings.
- Verify that the Amplitude project you connected has active users.

#### Connection fails after credential rotation

Cause: Amplitude API Keys and Secret Keys are project-specific. If credentials are rotated or regenerated, the existing connection breaks. Possible solutions:

- Retrieve the new API Key and Secret Key from your Amplitude project settings.
- Update the credentials in Scrut by navigating to Integrations, selecting Amplitude, and re-entering the new values under the Details tab.

## FAQs

<ExpandableGroup>
  <Expandable title="Can I connect multiple Amplitude projects to Scrut?" default-open="true">
    Each Amplitude integration in Scrut corresponds to one project. If you need to pull data from multiple Amplitude projects, contact your CSM to discuss your setup.
  </Expandable>

  <Expandable title="What happens if I rotate my Amplitude API Key?" default-open="true">
    The integration stops syncing until you update the credentials in Scrut. Go to Integrations, open Amplitude, and re-enter the new values under the Details tab.
  </Expandable>

  <Expandable title="What happens if a user is deleted in Amplitude?" default-open="true">
    Deleted users may no longer appear in subsequent syncs. Scrut reflects the state of user data as of the most recent sync. Review your Access Reviews data periodically to account for deprovisioned users.
  </Expandable>
</ExpandableGroup>
