The **Scrut - Calendly** integration fetches user access data, permissions, and role assignments from your Calendly account and sends them to the [Access Review](/docs/people/access-review-1/access-review-walkthrough) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  **Heads Up!**

  The data synced from Calendly flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- Login credentials and access to your organization’s Calendly account

### Permissions

Scrut requires **read-only access** to the following data in Calendly

- User Accounts: View name, email, and user role

<Callout kind="info">
  **Pro Tip!**

  We recommend logging into your Calendly account before starting the integration to avoid doing so later.
</Callout>

## How To Connect Calendly With Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.

2. Navigate to the **Integrations Library** tab, and choose **Communication Tools** in the **Categories** section.

3. Scroll to the **Calendly** tile and click **Integrate**.

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Calendly. This process typically takes a few hours to complete. Check the Audit Log on the Calendly integration page in Scrut to review the status.

- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.

- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Calendly

Scrut fetches the following access-related data points from Calendly:

- User Name
- User Email
- User Role

## Viewing Calendly Data in Scrut

To view the data fetched from your Calendly account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Calendly account.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164283434-1ihbgsj3tef-Screenshot-2025-09-08-at-19-35-34.png?fm=auto&auto=compress%2Cformat" alt="" />

You can also create an Access Review (or edit an existing one) and include the Calendly application in scope. Refer to this guide for step-by-step instructions on [creating an access review](/docs/people/access-review-1/creating-a-new-access-review).

Follow these steps to create a new access review for Calendly:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Calendly in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164284749-ezirvg41hiu-Screenshot-2025-09-08-at-19-36-20.png?fm=auto&auto=compress%2Cformat" alt="" />

From the Access Review page, click Calendly to view user details in Scrut.
