The **Scrut - Okta (SSO)** integration allows your organization’s users to log into Scrut using their Okta credentials. In this guide, we walk you through connecting your organization’s Okta account to **Scrut for SSO.**

<Callout kind="alert">
  **Heads Up!**

  If you’re looking to connect **Okta as an IDP**, [see here](/docs/integrations/integrating-identity-providers/integrating-okta-idp).
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You need Admin access to your organization’s Okta account

## How To Integrate Okta (SSO) With Scrut

### Step 1: Install Scrut Automation Application in your Okta Account

1. Log in to your Okta Admin Console.

2. Navigate to **Applications → Applications → Browse App Catalog**.

3. Search for **Scrut Automation (OIDC)**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164710130-4bbghlnxh8o-Screenshot-2025-11-19-at-11-28-31.png?fm=auto&auto=compress%2Cformat" alt="" />

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164839905-z7m4bs91pfi-Screenshot-2025-12-10-at-20-33-00-1.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Click **Add Integration**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164834523-hmmc26h5r3k-Screenshot-2025-12-10-at-19-27-21.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Search for and choose **Scrut Automation.** Click **Next**.

6. Enter an application label (e.g., Scrut Automation) and **Base URL** based on the region you signed up for Scrut.

   - US: **app.us.scrut.io**
   - EU: **app.eu.scrut.io**
   - IN: **app.scrut.io**

   <Callout kind="danger">
     **Important Note:**

     Make sure the base url doesn’t include **https://**. Enter only the core domain, such as **app.us.scrut.io**.
   </Callout>

7. Click **Done**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164841272-oi8b2b3zigl-Screenshot-2025-12-10-at-20-35-20.png?fm=auto&auto=compress%2Cformat" alt="" />

### Step 2: Assign Users

1. Navigate to the **Assignments** tab in Okta.
2. Assign the users and groups that require access to your Scrut organization.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164842627-qaeqzar5agi-Screenshot-2025-12-10-at-20-35-34.png?fm=auto&auto=compress%2Cformat" alt="" />

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162290915-iy8mo4g1zw-image-1765379276598.png?fm=auto&auto=compress%2Cformat" alt="" />

### Step 3: Retrieve Client ID and Secret

1. Navigate to the **Sign On** tab and copy the **Client ID** and **Client Secret**.
2. Save these details in a safe location. You’ll need to enter them in Scrut.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164835842-6bnkakm81le-Screenshot-2025-12-10-at-19-46-41.png?fm=auto&auto=compress%2Cformat" alt="" />

### Step 4: Copy your Okta Domain

1. Click your username in the top-right corner of the Admin Console to find and copy the Okta domain.
2. Save it in a safe location. You’ll need to enter it in Scrut.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164837187-vfs8n4lys4-Screenshot-2025-12-10-at-19-47-44.png?fm=auto&auto=compress%2Cformat" alt="" />

### Step 5: Add Configuration Details in Scrut

1. Sign in to Scrut and click **Integrations** on the left navigation panel.

2. Navigate to the **Integrations Library** tab, choose **Identity Providers** in the **Categories** section.

3. Scroll to the **Okta (SSO)** tile and click **Integrate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164707406-exj0405zpx8-Screenshot-2025-11-19-at-10-37-39.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Enter the details you fetched in the previous step:

   - Client ID
   - Client Secret
   - Okta Domain

5. Click **Submit**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164708798-7ax2w2ja9k9-Screenshot-2025-11-19-at-10-55-06.png?fm=auto&auto=compress%2Cformat" alt="" />

Watch for the success toast message and the Connected status flag indicator.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164843957-5yuchohb8rm-Screenshot-2025-12-10-at-20-39-21.png?fm=auto&auto=compress%2Cformat" alt="" />

## What Next?

[Enable Okta SSO in Settings](/docs/settings/administration/configuring-sso-login-methods). This allows users and groups you selected in Okta to log in to Scrut via Okta (SSO).

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162292223-uv3y7z94y6n-image-1765379460604.png?fm=auto&auto=compress%2Cformat" alt="" />

Optionally, users can use the AppEmbedLink found in the **General** tab of the Scrut Automation app in Okta to sign in to the platform.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164838510-8mf3xxhujg7-Screenshot-2025-12-10-at-19-58-14.png?fm=auto&auto=compress%2Cformat" alt="" />

Additionally, users can add the Scrut Automation app to their End User Dashboard so everybody can launch from there.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166188925-sxd3nao9jv-Untitled-9.png?fm=auto&auto=compress%2Cformat" alt="" />

<Callout kind="alert">
  **Note:**

  The option to add the app to the End User dashboard is available only for premium Okta customers.
</Callout>
