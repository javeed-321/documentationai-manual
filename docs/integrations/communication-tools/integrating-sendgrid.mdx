The **Scrut - SendGrid** integration fetches user access data, permissions, and role assignments from your SendGrid account and syncs them with the [Access Review](/docs/people/access-review-1/access-review-walkthrough) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  **Heads Up!**

  The data synced from SendGrid flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to generate an API key in SendGrid

### Permissions

Scrut requires **read-only access** to the following data in SendGrid

- User Accounts: View name, email, and user role

<Callout kind="info">
  **Pro Tip!**

  We recommend logging into your SendGrid account before starting the integration to avoid doing so later.
</Callout>

## How To Connect SendGrid With Scrut

### Step 1: Fetch API Key from SendGrid

1. Log in to your SendGrid account, click **Settings** on the left navigation bar, and then select **API Keys**.

2. Click **Create API Key**.

   <Image src="/images/Screenshot-2025-09-10-at-20.25.49.png" alt="" />

3. Give the API key a name, such as Scrut.

4. Select Full Access.

5. Click **Create & View**.

   <Image src="/images/Screenshot-2025-09-10-at-20.35.54.png" alt="" />

6. Copy the API key in a safe location, as you’ll need to enter it in Scrut in the [next step](/docs/integrations/communication-tools/integrating-sendgrid#step-2-go-to-integrations-in-scrut).

   **Note:** The API key will not be shown again. So, make sure to save it somewhere safe.

   <Image src="/images/Screenshot-2025-09-10-at-20.30.02.png" alt="" />

<Callout kind="info">
  **Note:**

  Refer to this guide from SendGrid for [more information on the API key and what it does](https://www.twilio.com/docs/sendgrid/ui/account-and-settings/api-keys).
</Callout>

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.

2. Navigate to the **Integrations Library** tab, and choose **Communication Tools** in the **Categories** section.

3. Scroll to the **SendGrid** tile and click **Integrate**.

   <Image src="/images/Screenshot-2025-09-10-at-19.58.42.png" alt="" />

4. On the integration page, paste the API key obtained in [Step 1](/docs/integrations/communication-tools/integrating-sendgrid#step-1-fetch-api-key-from-sendgrid).

5. Click **Submit**.

   <Image src="/images/Screenshot-2025-09-10-at-20.31.10.png" alt="" />

6. Once authorization is done, you’ll see the “**Connected Successfully**” message and the **Connected** status indicator.

   <Image src="/images/Screenshot-2025-09-10-at-20.34.16.png" alt="" />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from SendGrid. This process typically takes a few hours to complete. Check the Audit Log on the SendGrid integration page in Scrut to review the status.

- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.

- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

  <Image src="/images/Screenshot-2025-09-10-at-20.38.57.png" alt="" />

## Data Fetched from SendGrid

Scrut fetches the following access-related data points from SendGrid:

- User Name
- User Email
- User Role

## Viewing SendGrid Data in Scrut

To view the data fetched from your SendGrid account, you’ll need to create an Access Review (or edit an existing one) and include the SendGrid application in scope. Refer to this guide for step-by-step instructions on [creating an access review](/docs/people/access-review-1/creating-a-new-access-review).

Follow these steps to create a new access review for SendGrid:

1. Go to **People → Access Review** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select SendGrid in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click SendGrid to view user details in Scrut.
