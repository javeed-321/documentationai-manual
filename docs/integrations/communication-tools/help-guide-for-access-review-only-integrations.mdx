title: "Integrate Zoom"

The **Scrut-Zoom** integration fetches user access data, permissions, and role assignments from your Zoom account and sends them to Scrut’s **Access Review** module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

## How To Connect Zoom With Scrut

### Prerequisites

Before starting the integration, ensure you have the following permissions for your Zoom account:

- **Account Information**: Login credentials

- **Access Level**: Admin access

- **Permissions**: Scrut requires the following permissions to fetch access review details:

  - View users
  - View a user’s permissions
  - View a user’s tokens

<Callout kind="info">
  **Pro Tip!**

  We recommend logging into your Zoom account before starting the integration to avoid doing so later.
</Callout>

### Step 2: Connect Your Zoom Account in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.

2. Navigate to the **Integrations Library** tab, and choose **\[Category Name\]** in the **Categories** section.

3. Scroll to the **Zoom** tile and click **Integrate**.

4. On the integration setup page:

   - Enter the Tenant ID, instance URL, domain, etc.
   - Copy and paste the API key or credentials obtained in Step 1

5. Click **Submit**.

## Synchronization Details

- **Initial Sync**: Complete synchronization of all users, roles, permissions, and access assignments. This process typically takes 2-6 hours, depending on organization size.
- **Recurring Sync**: Automatic synchronization every 24 hours to capture new users, role changes, and permission updates.
- **Manual Sync**: Available on-demand through the integration settings page. Click the **Sync Now** button to trigger an immediate data refresh.
- **Real-time Updates**: Critical access changes (privileged role assignments, administrative access grants) are synchronized within 15 minutes.

## Limitations

When using Zoom with Scrut for access review, please be aware of the following limitations:

- **Historical Data**: Only the last 12 months of access change history are imported during initial sync.
- **Custom Attributes**: Organization-specific custom user attributes may require additional configuration.
- **Nested Groups**: Complex nested group structures may require up to 24 hours for complete mapping.
- **API Rate Limits**: Synchronization speed is subject to Zoom API rate limiting policies.
- **Deleted Users**: Access data for permanently deleted users is retained for 90 days only.
- **Third-party Applications**: Access to external applications integrated with Zoom may have limited visibility.

## Data Fetched from Zoom

Scrut fetches the following access-related data points from Zoom:

- **User Accounts**: Active and inactive user profiles, including personal information and employment status
- **Role Assignments**: All roles assigned to users, including inherited and direct assignments
- **Permission Grants**: Detailed permissions associated with each role and direct user grants
- **Group Memberships**: Security groups, distribution lists, and organizational units
- **Administrative Privileges**: Elevated access rights and administrative role assignments
- **Application Access**: Access to integrated applications and services
- **Resource Permissions**: Access rights to files, folders, databases, and other resources
- **Last Login Data**: User activity timestamps and login patterns
- **Access Request History**: Records of access requests, approvals, and denials
- **Audit Trail**: Changes to user access rights and permission modifications

## Viewing Zoom Data in Scrut

To view the data fetched from your Zoom account, you’ll need to create an Access Review and include the Zoom application in scope.

Refer to this guide for step-by-step instructions on [creating an access review](/docs/people/access-review-1/creating-a-new-access-review).

## FAQs & Troubleshooting

<ExpandableGroup>
  <Expandable title="Issue #1: Integration fails with “Insufficient Permissions” error" default-open="false">
    Verify that your API key or service account has all required permissions listed in the Prerequisites section. Contact your Zoom administrator to ensure proper access levels are granted.
  </Expandable>

  <Expandable title="Issue #2: User data appears incomplete or outdated" default-open="false">
    Check the last synchronization timestamp in the integration settings. If sync is failing, verify your API credentials are still valid and that there are no network connectivity issues between Scrut and Zoom.
  </Expandable>

  <Expandable title="Issue #3: Access review notifications are not being sent" default-open="false">
    Ensure that notification settings are configured correctly in both Scrut and Zoom. Verify that email addresses for access review owners are current and that emails are not being filtered as spam.
  </Expandable>

  <Expandable title="Issue #4: Permission mapping appears incorrect" default-open="false">
    Review the role and permission mapping configuration in the integration settings. Custom mappings may need to be adjusted to accurately reflect your organization's access structure.
  </Expandable>
</ExpandableGroup>
