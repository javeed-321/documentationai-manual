title: "Integrate CyberArk"
---

CyberArk is a top privileged access management solution that secures sensitive accounts. Our integration with CyberArk enhances Scrut by automating user list syncing, secure API authentication, and evidence collection for user access controls. This provides better visibility, saves time, improves accuracy, and streamlines audits within Scrut's GRC platform.

## Integrating CyberArk

1. From the left navigation panel, select Integrations.
2. Click on **Available**.

<Image src="/images/image-9CXHGH6K.png" alt="" />

3. Scroll to the *Human Resource Information Systems* section and find *CyberArk*.

<Image src="/images/image-UCC879R6.png" alt="" />

4. Click **Integrate**.

<Image src="/images/image-B263H0IL.png" alt="" />

5. Click **Connect**.

<Image src="/images/image-QIW9GMTD.png" alt="" />

6. Fill in the following details :

- **Enter your CyberArk Tenant URL**: The URL used to log in to the CyberArk portal. For example, if you sign in at https://abj4090.id.cyberark.cloud, then enter "*abj4090.id.cyberark.cloud*".

- **Enter your CyberArk Application Id**: Enter the application ID that you specified while creating the OAuth web client. For more information, refer to [this link](https://docs.cyberark.com/identity-administration/latest/en/Content/CoreServices/Authenticate/OAuth2-Client.htm).

- **Enter your CyberArk Service User Name**: Enter the username of the service user that you specified while creating the service user. For more information, refer to [this link](https://docs.cyberark.com/identity-administration/latest/en/Content/ISPSS/ISPSS-Add-Service-User.htm).

- **Enter your CyberArk Service User Password**: Enter the password of the service user that you specified while creating the service user. For more information, refer to [this link](https://docs.cyberark.com/identity-administration/latest/en/Content/ISPSS/ISPSS-Add-Service-User.htm).

  <Image src="/images/image-JR3WVILG.png" alt="" />

7. Once the credentials are entered, click **Submit**.

Congrats! Your CyberArk account is successfully integrated with Scrut.
