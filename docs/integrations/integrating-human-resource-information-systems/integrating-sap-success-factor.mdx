title: "Integrate SAP Success Factors"
description: "Learn how to connect your SAP SuccessFactors account with Scrut."
---

SAP SuccessFactors is a human resources management system (HRMS) that covers a wide range of HR functions. Through integrating SAP with scrut platform, we can fetch the employee details in the scrut platform, like Employee Name, email, department, reporting manager, joining date, and exit date.

## Integrating SAP SuccessFactors

### Step 1: Integration in Scrut

1. From the left navigation panel, select Integrations.
2. Click on **Available**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162735854-jq0i4zso6ld-image-9CXHGH6K.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Scroll to the _Human Resource Information Systems_ section and find _SAP SuccessFactors_.

4. Click **Integrate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162987991-6j42ywij5us-image-LTS0BAA6.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Click **Connect**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162758233-d0c4nw1m66-image-B2KCZF9Y.png?fm=auto&auto=compress%2Cformat" alt="" />

SAP SuccessFactors window opens.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162678667-m94cc94p3pd-image-5N2QL0B6.png?fm=auto&auto=compress%2Cformat" alt="" />

### Step 2: Find your SAP SuccessFactors API Server URL

1. To find your API Server URL, go to this [link](https://help.sap.com/docs/SAP_SUCCESSFACTORS_PLATFORM/28bc3c8e3f214ab487ec51b1b8709adc/af2b8d5437494b12be88fe374eba75b6.html).

2. In the listed API Server URLs, search for the environment that matches your subdomain. For example, if your domain is https://salesdemo4.successfactors.com, search for salesdemo4.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166170610-fe13xvfco0h-Untitled-14.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Copy the entire URL.

In this example, it would be: apisalesdemo4.successfactors.com

4. Enter your SAP SuccessFactors API Server URL into scrut's UI Auth component.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162673338-9wk72zsstu-image-5BN9ZY84.png?fm=auto&auto=compress%2Cformat" alt="" />

### Step 3: Find your SAP SuccessFactors Username and Company ID

1. To find your SAP SuccessFactors username, go to the upper right-hand side and click on your profile image to view your username.

<Callout kind="alert">
  **Note**: The username is not your email address.
</Callout>

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166171998-zwmyo942coa-Untitled-16.png?fm=auto&auto=compress%2Cformat" alt="" />

2. To find your SAP SuccessFactors Company ID, in the same dropdown menu, click "Show version information." Locate Company ID in the modal that pops up:

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166173398-gmo2o3onf8-Untitled-17.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Once you obtain your username (not email) and company ID from the previous step, enter them in Scrut's UI component.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163012411-algcsncnul8-image-N6983XGP.png?fm=auto&auto=compress%2Cformat" alt="" />

### Step 4: Find your SAP SuccessFactors API Key and Certificate details\*\*

1. In your Admin Center, go to Tools, and search for _Manage OAuth2 Client Applications_ (If your page looks different, search for Manage OAuth2 Client Applications in the search tool on your homepage).

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166174664-darkldx9wgs-Untitled-19.png?fm=auto&auto=compress%2Cformat" alt="" />

2. Click **Register Client Application**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166176038-kdzu8uvmc6-Untitled-20.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Fill out Application Name & Application URL (what actually goes in these fields is not important).

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166177357-9ifig9gwi8l-Untitled-21.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Click _Generate X.509 Certificate_. Fill out Common Name (name doesn't matter) and click **Generate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166178626-8mhnmzr5kzi-Untitled-22.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Once the certificate populates, _download and save it_. You will have downloaded a file called _Certificate.pem_.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166179925-91k6j346zq9-Untitled-23.png?fm=auto&auto=compress%2Cformat" alt="" />

6. Click Register (it will have replaced the Generate button).

7. Back on your Manage OAuth2 Client Applications, go to the application you just created and click **Edit**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166181187-5ugwbcdsj0x-Untitled-24.png?fm=auto&auto=compress%2Cformat" alt="" />

8. You will now see an API key listed - this is your Client ID. _Copy and Save this Key_.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166182438-pc7xe3grc6s-Untitled-25.png?fm=auto&auto=compress%2Cformat" alt="" />

9. Open up the "Certificate.pem" file that you downloaded previously in a text editor.

10. Copy only the string between —BEGIN ENCRYPTED PRIVATE KEY——- and —-END ENCRYPTED PRIVATE KEY——-.

<Callout kind="alert">
  **Note**: Do not copy ——BEGIN ENCRYPTED PRIVATE KEY——and —-END ENCRYPTED PRIVATE KEY——.
</Callout>

This is your SuccessFactors Private Key.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166183731-d44ko775xhe-Untitled-26.png?fm=auto&auto=compress%2Cformat" alt="" />

11. Enter your API Key and certificate’s private key into scrut's UI Auth component and hit **Submit**.

    <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162113086-luf94vwksyf-image-0DUBC2IJ.png?fm=auto&auto=compress%2Cformat" alt="" />

<Callout kind="info">
  **Info**:

  - Employee data will start syncing immediately. Incremental data will be synced every 24 hours.
  - Data can also be manually synced by clicking the three dots and choosing the **Sync Now** option.
</Callout>
