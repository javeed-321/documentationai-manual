Once you’ve [integrated Linear with Scrut](/docs/integrations/integrating-project-management-platforms/integrating-linear), you can create a Linear issue from any of the following compliance modules in Scrut:

- Policies
- Evidence Tasks
- Tests
- Cloud
- Risk Management
- Audit → Audit Center → Requests
- Audit → Audit Center → Findings
- Audit → Audit Center → Corrective Actions
- Vulnerabilities → Findings

## Steps to create a Linear Issue

1. Navigate to the relevant artifact in any of the modules listed above.

2. Click the three-dots icon at the top-right of the page and select **Create Linear Issue**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165568348-7ej9q1ve9h-Screenshot-2026-04-15-at-14-50-05.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Fill in the issue details.

4. Scrut autofills the task name and description based on the compliance item. Edit them as needed.

5. Select the Team, Priority, Status, Assignee, and Labels.

6. Click **Create**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165569842-jm3cjub5cpn-Screenshot-2026-04-15-at-14-51-20.png?fm=auto&auto=compress%2Cformat" alt="" />

The issue is created in Linear. You can open it in Linear to take further action.
