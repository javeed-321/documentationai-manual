Shortcut integration enables users to create compliance tasks/issues in Shortcut directly from the Scrut platform.

## Integrating Shortcut

1. From the left navigation panel, select Integrations.

2. Click on **Available**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162735854-jq0i4zso6ld-image-9CXHGH6K.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Scroll to _Project Management Platforms_ section and find _Shortcut_.

4. Click **Integrate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163005313-er0eaks9k78-image-MV2K5XBD.png?fm=auto&auto=compress%2Cformat" alt="" />

5. In _API Token_ field, enter your shortcut account API Token.

<Callout kind="info">
  **How to obtain API Token?**

  Refer to this [Shortcut Guide](https://help.shortcut.com/hc/en-us/articles/205701199-Shortcut-API-Tokens) for obtaining API Token.
</Callout>

6. Click **Submit**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162930363-9doagjxnbtc-image-IOQIYR2E.png?fm=auto&auto=compress%2Cformat" alt="" />

7. Upon successful integration you will see a connected flag in the integration page.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162724204-jkoy7vndswe-image-8AFN2H90.png?fm=auto&auto=compress%2Cformat" alt="" />

<Callout kind="info">
  **Info**: Refer to this guide to learn "[How to create a Shortcut story from Scrut?](/docs/integrations/integrating-project-management-platforms/creating-a-shortcut-story)"
</Callout>
