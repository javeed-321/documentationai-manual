The **Scrut - Cal.com** integration fetches user access data, permissions, and role assignments from your Cal.com account and syncs them with the [Access Review](/docs/access-review-walkthrough) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  **Heads Up!**

  The data synced from Cal.com flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to generate an API key in Cal.com

### Permissions

Scrut requires **read-only access** to the following data in Cal.com

- User Accounts: View name, email, and user role

<Callout kind="tip">
  **Pro Tip!**

  We recommend logging into your Cal.com account before starting the integration to avoid doing so later.
</Callout>

## How To Connect Cal.com With Scrut

### Step 1: Fetch API Key from Cal.com

1. Log in to your Cal.com account and click on the dropdown menu beside your name.

2. Click on **My Settings**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164265665-ocflrz2jxn-Screenshot-2025-09-08-at-16-55-20.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. Scroll to the **Developer** section and click on **API keys**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164267058-jfomqy4nxrb-Screenshot-2025-09-08-at-16-55-39.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. Click **+Add** to create an API key.

5. Name the key as "Scrut" and set its expiry date.

6. Click the **Save** button.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164268379-3b73gzgvk8q-Screenshot-2025-09-08-at-17-00-59.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

7. Copy the API key code, as you won’t be able to see this later. Save the code in a safe location, as you’ll need to enter it in Scrut in the [next step](/docs/integrating-cal-com#step-2-go-to-integrations-in-scrut).

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164269716-wv4tiebh1e-Screenshot-2025-09-08-at-17-01-21.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

**Note:** Refer to this guide from Cal.com for [more information on the API key and what it does](https://cal.com/blog/where-is-my-api-key-and-what-can-it-do).

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.

2. Navigate to the **Integrations Library** tab, and choose **Miscellaneous** in the **Categories** section.

3. Scroll to the **Cal.com** tile and click **Integrate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164264201-5jw8z8f5uwv-Screenshot-2025-09-08-at-16-40-09.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. On the integration page, paste the API key obtained in [Step 1](/docs/integrating-cal-com#step-1-fetch-api-key-from-calcom).

5. Click **Submit**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164271058-odhd3te9mw-Screenshot-2025-09-08-at-17-06-59.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

6. Once authorization is done, you’ll see the “**Connected Successfully**” message and the **Connected** status indicator.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164272444-c6zgw3fnye4-Screenshot-2025-09-08-at-17-07-35.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Cal.com. This process typically takes a few hours to complete. Check the Audit Log on the Cal.com integration page in Scrut to review the status.

  <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164275340-a9clb513ji6-Screenshot-2025-09-08-at-17-12-13.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.

- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

  <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164274019-0lxr9lpcst4-Screenshot-2025-09-08-at-17-12-13-1.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

## Data Fetched from Cal.com

Scrut fetches the following access-related data points from Cal.com:

- User Name
- User Email
- User Role

## Viewing Cal.com Data in Scrut

To view the data fetched from your Cal.com account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Cal.com account.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164283434-1ihbgsj3tef-Screenshot-2025-09-08-at-19-35-34.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

You can also create an Access Review (or edit an existing one) and include the Cal.com application in scope. Refer to this guide for step-by-step instructions on [creating an access review](/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Cal.com:

1. Go to **People → Access** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Cal.com in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164284749-ezirvg41hiu-Screenshot-2025-09-08-at-19-36-20.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

From the Access Review page, click Cal.com to view user details in Scrut.
