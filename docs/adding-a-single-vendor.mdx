In Scrut, you can add a vendor manually in two ways:

1. [Add a Single Vendor](/docs/adding-a-single-vendor#add-a-single-vendor)
2. [Bulk Import Multiple Vendors](/docs/adding-a-single-vendor#bulk-import-multiple-vendors)

This article guides you through both methods.

## Add a Single Vendor

1. [Sign in to Scrut](https://app.scrut.io/) and go to **Risk → Vendors** using the left navigation panel.

2. Go to the **Vendors** tab, click the **Add Vendor** button and choose **Manually**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161864901-7khvqhy7x2q-Add-Vendor-Button.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. The Add Vendor modal opens.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164717391-tkjnxv8vr6j-Screenshot-2025-11-19-at-22-22-13.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

### Step 1: Enter Vendor Details

Enter key details about your vendor to create the vendor profile in Scrut.

#### Vendor Name

Enter the official (or legal) name of the vendor organization.

<Callout kind="tip">
  **Pro Tip!**

  When adding a vendor, start typing the vendor name in the **Name** field. If the vendor is in Scrut's pre-defined list of known vendors, a dropdown will appear with matching suggestions. Selecting a vendor from the dropdown automatically fills in details if available, so you don't have to look them up manually.
</Callout>

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163277912-zrrxieulwmp-Prefilled-Vendor-Details.gif?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

#### Vendor Status

Choose the vendor’s current status:

- **Prospective:** If you’re currently reviewing the vendor for potential engagement
- **Active:** If the vendor is currently engaged and providing services

<Callout kind="alert">
  **Heads Up!**

  If you choose the vendor status as “Prospective”, the step to add the vendor to your Trust Vault will not be shown here. However, you can add the [vendor as a sub-processor in your Trust Portal](/docs/how-to-add-subprocessors) later once you move them to the active status.
</Callout>

#### Vendor URL

Enter the vendor's official website link.

#### Vendor Category

Select the most appropriate category that accurately represents the vendor's services or products. If the vendor already exists in Scrut’s database, this field will be prefilled.

#### Service Description

Briefly describe the primary purpose for engaging the vendor’s services.

#### Assigned To

Select one or more team members responsible for managing this vendor relationship.

#### Entities

Select the specific entity or business unit within your organization that should be linked to this vendor. Click **Next**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165909226-t49fii1j1hr-Screenshot-2026-07-22-at-12-35-47.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

### Step 2: Add to Trust Vault (Optional)

This step is optional. If you'd like to [showcase the vendor as a sub-processor in the Trust Vault](/docs/how-to-add-subprocessors), fill in the relevant details here. However, if you prefer not to include the vendor in the Trust Vault, you can skip this step.

<Callout kind="tip">
  **Pro Tip!**

  Scrut recommends adding vendors to the Trust Vault if they handle sensitive customer data or provide critical services.
</Callout>

- **Sub-Processor Name:** This name is displayed only in the Trust Vault and doesn’t affect the Vendor Name.
- **Sub-Processor Website:** Enter the official URL of the sub-processor.
- **Location:** Specify the sub-processor's location. This is important for compliance with regional data protection regulations.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164031908-7rvdtvdcl8w-Screenshot-2025-08-08-at-10-47-32.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

<Callout kind="success">
  **Note:**

  Adding the sub-processor details here will automatically make the sub-processor visible on your Trust Vault. Head to the Trust Vault page to [modify the sub-processor description and logo](/docs/how-to-add-subprocessors).
</Callout>

### Step 3: Enter POC Details

In this step, provide the vendor's contact details. Ideally, the Vendor POC is the person on the vendor’s team to whom you send the vendor questionnaire. This part is optional. If you don’t have the contact information, you can skip it and add it later.

- **POC Name:** Enter the first and last name of the contact.
- **POC Email:** Enter the work email of the contact.

Click **Next**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163778918-7m4tl4kxpdp-Screenshot-2025-06-24-at-14-22-52.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

### Step 4: Review Information

The final step is to review the information you entered in the previous steps. If you want to make any changes, click **Back** to return to the relevant step. Click **Save** to finish creating the vendor.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164718738-ezjkec9mjhi-Screenshot-2025-11-19-at-22-26-21.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

## Bulk Import Multiple Vendors

Scrut also allows you to bulk import multiple vendors via a CSV or XLSX file.

1. [Sign in to Scrut](https://app.scrut.io/), and go to **Risk → Vendors** using the left navigation panel.

2. Go to the **Vendors** tab, click the **Add Vendor** button, and select **Import (CSV/XLSX)**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161864901-7khvqhy7x2q-Add-Vendor-Button.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. Download the template from the Import Vendor window.

4. Replace the contents of the template file with details of your vendors.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163780426-9owj3d38yma-Screenshot-2025-06-24-at-20-48-55.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

   <Callout kind="tip">
     **Pro Tip!**

     Refer to this section for detailed [instructions on how to use the Import Vendor template](/docs/adding-a-single-vendor#tips-for-using-the-import-vendor-template).
   </Callout>

5. Drag and drop the template file into the File field, or click to upload it manually.

6. Click **Import**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162231923-r43tn4gl8uc-image-1763571493540.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

Scrut processes the file and imports your vendors.

#### Note:

- The import succeeds only when all entries are valid. If any error exists, the import will fail with an error message.
- Rectify the template and retry.
- If errors persist, reach out to support@scrut.io for assistance.

### Tips for Using the Import Vendor Template

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164029113-gxeutxm3t1-Screenshot-2025-08-08-at-10-33-18.png?fm=auto&auto=compress%2Cformat" alt="" caption="Columns A to J" />

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164030544-wahlkclmjn-Screenshot-2025-08-08-at-10-33-35.png?fm=auto&auto=compress%2Cformat" alt="" caption="Columns K to P" />

- Do NOT remove the first row, as it contains column headers. Scrut requires this information to import vendors accurately.
- Refer to the descriptive content in the second row to know the data format and accepted values for each column.
- Include each vendor in a separate row.
- **Vendor Name (Column A)**, **Vendor’s Category (Column C)** and **Assessment Status (Column I)** are mandatory; all other fields are optional.
- Avoid using extra formatting, such as background colors, when entering vendor details in the template.
- Once you’ve finished entering all vendor details, delete the second row.
