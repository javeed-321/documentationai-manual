Find answers to common questions on checklists.

### FAQ

<ExpandableGroup>
  <Expandable title="Can I add new tasks to existing checklists?" default-open="false">
    Yes, you can edit a checklist to add or remove tasks. Go to **People → Employees → Checklists**, and click the edit icon next to the checklist. Update the tasks as needed and click **Yes** to enable notifications. This will notify employees via [email](/docs/email-notifications), [Slack, or Teams](/docs/configuring-slack-reminders) about new task assignments.
  </Expandable>

  <Expandable title="Can I assign multiple checklists to a single group?" default-open="false">
    No. A group can have only one checklist assigned at a time. However, you can assign the same checklist to multiple groups.
  </Expandable>

  <Expandable title="Is it possible to not assign any tasks to a specific group of employees?" default-open="false">
    Yes. You can achieve this with [empty checklists](/docs/empty-checklists).
  </Expandable>

  <Expandable title="Can I exclude certain tasks for specific employees?" default-open="false">
    Yes. See here for step-by-step instructions on [turning off certain tasks for specific employees](/docs/disabling-specific-tasks-for-employees#how-to-turn-off-specific-tasks-for-employees).
  </Expandable>

  <Expandable title="Can I send reminders to employees to help them complete their tasks?" default-open="false">
    You can send manual reminders to employees to complete their tasks. To do this, go to **People → Employees → All Employees**, select an employee, and click the **Send Reminder** button.
