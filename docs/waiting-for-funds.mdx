---
title: "Waiting for funds"
---

Normally, if you request us to create a payment and there are no funds in the account the payment will come out from, the payment request will fail.

There is an option that can be turned on that allows you to request a payment successfully even if there are not enough funds in the account; Wait for funds. We will check for any pending payments out whenever you pay in to the account and if there are any and the funding is enough, the payment out will be initiated. Until that point, unless it is awaiting approval, the payment will be in a status of awaiting funds.

Without this feature turned on you will not be able to use the funding rule.
