<Callout kind="plan">
  **Who can use this feature**

  - Supported on **Scale** plan
</Callout>

Scrut gives you the flexibility to customize the details captured in a corrective action by adding custom fields that match your specific requirements. To add a custom field:

1. Go to **Audits → Corrective Actions** and click the **Settings** icon on the top right.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166231230-pxny24gc5c-settings.png?fm=auto&auto=compress%2Cformat" alt="Settings icon" width="25" height="25" caption=" " />

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171245847-qd8dht29tgf-Screenshot-2025-09-17-at-18-23-55.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

2. This opens the Corrective Actions Settings page with the Custom Fields tab selected by default.

3. Click the **+Add Custom Field** button.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171247289-eugmofi7wti-Screenshot-2025-09-17-at-18-24-22.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. Enter the field name and choose an appropriate field type. You can select from: Textbox, Textarea, Single Select, Multi Select, Currency, and Date.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171248694-9sm7qymc9q-Screenshot-2025-09-17-at-18-25-51.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

   <Callout kind="alert">
     **Heads Up!**

     Make sure to select the correct field type, as once you create the custom field you cannot edit its type.
   </Callout>

5. Click **Save**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171250027-alsmd0ddt9-Screenshot-2025-09-17-at-18-26-07.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

### What Happens Next?

Once you add a custom field, it will be available while creating a Corrective Action.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162142914-qhccw325pe-image-1758115358369.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

You can find the custom field data on the Corrective Action details page under the Custom Fields section.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162144310-57lxmtke2tl-image-1758115400816.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />
