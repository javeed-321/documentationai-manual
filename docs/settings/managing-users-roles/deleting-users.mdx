<Callout kind="danger">
  **Important Warning**

  Deleting a user is permanent and cannot be undone.
</Callout>

## How To Delete a User in Scrut

### Step 1: Deactivate the User

To delete a user, first deactivate them. Follow this guide to deactivate a user in Scrut.

### Step 2: \[Recommended\] Reassign their Tasks

We strongly recommend reassigning the user’s pending tasks to another active user before deleting them from Scrut. Follow this guide to [reassign all their tasks in a single click](/docs/settings/managing-users-roles/deactivating-users#reassigning-tasks).

### Step 3: Delete the User

1. Navigate to **Settings → Manage Users**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166078739-lgetvt8pe9-Settings-Page.png?fm=auto&auto=compress%2Cformat" alt="" />

2. Find the user you want to deactivate, and click the **Delete User** icon in the Actions column.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162404418-5gorzrxlc7x-image-1773122727398.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Type **Delete** in the confirmation modal.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164047350-we28eer4ifl-Screenshot-2025-08-16-at-19-41-37.png?fm=auto&auto=compress%2Cformat" alt="" />

On deletion, the user is removed from the Users table.
