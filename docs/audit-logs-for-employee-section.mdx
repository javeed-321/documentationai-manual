The Audit Log in the Employee module provides a complete history of all activities within the module.

## Audit Log for the Employee Module

1. Click **People → Employees** on the left navigation menu, and click the **Settings** icon on the top-right.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162022497-kglt3v1besa-Employee-Settings.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

2. Navigate to the **Audit Log** tab.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164910355-yr301enpa9-Screenshot-2026-01-08-at-20-56-24.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. Here you can find detailed information about actions performed, including:

   - **Group Actions:** Group created, edited, deleted
   - **Checklist Actions:** Checklist created, edited, and configuration changes

4. Expand any log entry for more information about the action.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164911708-cvp3zhpge-Screenshot-2026-01-08-at-20-56-42.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

5. Use the search bar and filters to quickly find specific actions.

   - **Search Bar:** Use it to quickly find specific actions, keywords, or details within the audit logs.
   - **Sort By:** Use this filter to sort the logs by newest or oldest.
   - **Performed By:** Use this filter to find actions performed by a specific user quickly.
   - **Date Filter:** Use this filter to find logs based on specific criteria, such as the current month, the previous month, or a custom range

## Audit Log for Individual Employee Records

These audit logs track all changes and activities performed on a specific employee record, providing a complete history of who did what and when.

1. Navigate to **People → Employees → All Employees** and select a specific employee from the table.
2. Click the **Audit Log** tab to view log entries specific to this employee’s record.
