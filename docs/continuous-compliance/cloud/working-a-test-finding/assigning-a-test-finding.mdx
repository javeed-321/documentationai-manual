title: "Assign a Test Finding"
description: "Learn how to assign a test finding to an assignee in Scrut."
---

You can assign test findings to specific team members to efficiently remediate the compliance and security issues identified by cloud tests. There are two ways of assigning test findings:

- [Assign a Single Test Finding](/docs/continuous-compliance/cloud/working-a-test-finding/assigning-a-test-finding#how-to-assign-a-single-test-finding)
- [Bulk Assign Multiple Test Findings](/docs/continuous-compliance/cloud/working-a-test-finding/assigning-a-test-finding#how-to-bulk-assign-multiple-test-findings)

## How To Assign a Single Test Finding

1. Click **Compliance → Cloud** on the left navigation menu, and go to the **Tests** tab.

2. Click on the test for which you want to add an assignee.

   <Image src="/images/Select-an-individual-test-1.png" alt="" />

3. Click the **+** icon under the **Assigned To** section.

   <Image src="/images/image-1763734312809.png" alt="" />

4. In the **Assignees dropdown**, select the team members who will be working on remediating the test finding. You can add multiple assignees, if required.

5. Click **Add**.

6. Click the **Make Primary** action button to set a specific assignee as the main person responsible for fixing this test.

7. Click **Save**.

   <Image src="/images/Screenshot-2025-11-21-at-19.42.57.png" alt="" />

Assignees will be notified via email about the task assigned to them. Scrut will display the assignee’s initials in the **Assigned To** section on the Test Details page.

<Image src="/images/image-1763734473429.png" alt="" />

## How To Bulk Assign Multiple Test Findings

1. Click **Compliance → Cloud** on the left navigation menu, and go to the **Tests** tab.

2. Select the checkboxes corresponding to the tests for which you want to add assignees.

3. Click **Assign to Users**.

   <Callout kind="info">
     **Pro Tip!**

     Use the search bar and filters at the top to quickly locate specific tests.
   </Callout>

   <Image src="/images/image-1763734573950.png" alt="" />

4. In the **Assignees dropdown**, select the team member who will be working on remediating the test finding.

5. Click **Add**.

6. Repeat steps 4 & 5 to add multiple assignees.

7. Click the **Make Primary** action button to set a specific assignee as the main person responsible for fixing this test.

8. Click **Save**.

<Image src="/images/Screenshot-2025-11-21-at-19.46.52.png" alt="" />

<Callout kind="alert">
  **Heads Up!**

  Any existing assignees will be replaced by the assignees you’ve selected now.
</Callout>
