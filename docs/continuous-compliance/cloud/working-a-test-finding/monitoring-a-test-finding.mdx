---
title: "Monitor an Ignored Test"
description: "Learn how to revert an ignored test by monitoring it."
---

There may be scenarios where you need to revert an ignored test. For example, you might have wrongly marked a test as ignored, or a previously ignored test might be relevant as your tech stack changes, and so on. In such cases, you can revert it by monitoring it. In this article, we explain how to monitor an ignored test:

- [Monitor a Single Test](/docs/continuous-compliance/cloud/working-a-test-finding/monitoring-a-test-finding#monitor-a-single-test)
- [Bulk Monitor Multiple Tests](/docs/continuous-compliance/cloud/working-a-test-finding/monitoring-a-test-finding#bulk-monitor-multiple-tests)

## Monitor a Single Test

1. Click **Compliance → Cloud** on the left navigation menu, and click the **Tests** tab.

2. Click the test that you want to monitor.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164759607-wghev2ma90p-Screenshot-2025-11-24-at-21-35-30.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Once you’re on the test details page, click the **Monitor** button.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164760943-qqjqnho2qr8-Screenshot-2025-11-24-at-21-35-55.png?fm=auto&auto=compress%2Cformat" alt="" />

4. The test status changes to **Needs Attention**. [Remediate the test](/docs/continuous-compliance/cloud/working-a-test-finding/remediating-a-test-finding) and click **Test Now** to validate the remediation.

## Bulk Monitor Multiple Tests

1. Click **Compliance → Cloud** on the left navigation menu, and click the **Tests** tab.

2. Click Ignored on the status card to view only ignored tests.

3. Select the tests that you want to monitor.

4. Click the **Monitor** button at the top of the table.
