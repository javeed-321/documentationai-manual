---
title: "Supported Services for Each Cloud Provider"
description: "Services supported for popular cloud providers"
---

Scrut supports the following services for each cloud provider:

- **Supported AWS Services:** acm, cloudtrail, ec2, elb, elbv2, iam, kms, rds, redshift, s3, ses, sns, sqs, vpc
- **Supported AWS Regions:** us-east-1, us-east-2, us-west-1, us-west-2, ap-south-1, ap-south-2, ap-southeast-1, ap-southeast-2, ap-southeast-3, ap-southeast-4, ap-northeast-1, ap-northeast-2, ap-northeast-3, ap-east-1, eu-central-1, eu-central-2, eu-west-1, eu-west-2, eu-west-3, eu-north-1, eu-south-1, eu-south-2, ca-central-1, ca-west-1, sa-east-1, af-south-1, me-south-1, me-central-1, il-central-1
- **Supported Azure Services:** aad, appservice, mysqldatabase, network, securitycenter, sqldatabase, storageaccounts, virtualmachines
- **Supported GCP Services:** cloudsql, cloudstorage, computeengine, iam, kms, kubernetesengine, stackdriverlogging
