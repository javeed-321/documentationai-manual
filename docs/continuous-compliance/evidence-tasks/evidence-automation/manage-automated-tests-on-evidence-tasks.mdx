## Link an Automated Test to an Evidence Task

Add any automated test that provides valid proof for a task, even if Scrut has not mapped it automatically.

1. Navigate to **Compliance → Evidence Tasks**.

2. Open the evidence task you want to link a test to.

3. Scroll to the **Automation Sources** section.

4. Click **Add Automation Sources**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166013613-4hn5uwv5vf7-Screenshot-2026-08-27-at-21-15-05.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Select **Automated Tests** as the source type.

6. Search for and select the test or tests you want to link.

7. Click **Save**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166015312-7ootx32ibf9-Screenshot-2026-08-27-at-21-15-36.png?fm=auto&auto=compress%2Cformat" alt="" />

8. The linked test now appears in the Automation Sources section, along with its current status (Passing, Fix Required, or Ignored).

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166021967-h3jniva1ij6-Screenshot-2026-08-28-at-17-51-11.png?fm=auto&auto=compress%2Cformat" alt="" />

## Attach a Test Export to an Evidence Task

<Callout kind="alert">
  **Heads Up!**

  Linking a test to an evidence task does not automatically attach its export as evidence. You need to export the test results to attach it to the current evidence period.
</Callout>

1. Navigate to **Compliance → Evidence Tasks**.

2. Open the evidence task with the linked automated test.

3. Scroll to the **Automation Sources** section.

4. Click the **Export** icon next to the test you want to attach.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166019315-bv57w2lc4la-Screenshot-2026-08-28-at-17-47-00.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Scrut exports the test result in the background and attaches it to the evidence task.

6. The attachment appears in the current evidence period evidence task, and the task's status updates depending on whether you have the approval workflow enabled or not.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166020649-zl8itlyfqj8-Screenshot-2026-08-28-at-17-47-34.png?fm=auto&auto=compress%2Cformat" alt="" />

<Callout kind="info">
  **Pro Tip!**

  Click the Export icon whenever you want a current test result attached as evidence.
</Callout>

## Unlink an Automated Test

Remove a test once it no longer applies to the evidence task.

1. Navigate to **Compliance → Evidence Tasks**.

2. Open the evidence task and scroll to the **Automation Sources** section.

3. Locate the test you want to remove.

4. Click the **unlink** icon next to the test.

5. Confirm the removal in the dialog that appears.

6. The test is removed from the Automation Sources section.

## FAQs

<ExpandableGroup>
  <Expandable title="Does linking a test automatically mark the evidence task as complete?" default-open="false">
    No. Linking a test only makes it available as an automation source. The evidence status changes only when you attach an export, and you still need to review it and mark the task as uploaded.
  </Expandable>
</ExpandableGroup>
