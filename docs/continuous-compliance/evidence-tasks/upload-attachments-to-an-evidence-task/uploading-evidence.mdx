In this article, we’ll walk you through the process of manually uploading evidence files for an evidence task.

## How To Upload Evidence Manually

1. Sign in to Scrut, and click **Compliance → Evidence Tasks** on the left navigation panel.

2. Go to the **All Evidences** tab and click on the task for which you want to upload a manual evidence.

   <Image src="/images/Screenshot-2025-10-08-at-11.22.01.png" alt="" />

3. Click the **Add Attachment** button on the evidence detail page.

   <Image src="/images/Screenshot-2025-10-15-at-12.12.32.png" alt="" />

   <Callout kind="info">
     **Pro Tip: Download or Edit the Sample Template**

     Not sure what to include in your evidence file ? Use the sample template on the Evidence Details page to get started:

     - **Download the template** to use as a reference when preparing your evidence file. It gives you a clear idea of what information to include in it to meet audit requirements.
     - **Edit the template** to tailor it to your organization's process — adjust the tone, steps, links, or formatting to match your requirements.

     Learn more about [downloading and editing the sample template](/docs/continuous-compliance/evidence-tasks/upload-attachments-to-an-evidence-task/using-evidence-templates).
   </Callout>

4. Select the Source you want to use to add the attachment. You can either:

   - **Upload a File:** Use this to upload an evidence file from your device. Drag and drop or select a file.

   - **Use a Link:** To upload an evidence file available in an external link.

     <Callout kind="alert">
       **Note**

       - You can upload multiple files at once.
       - There are no file format restrictions, but **each file must not exceed 100 MB**.
     </Callout>

5. **Heads Up!** Click **Download Template** for a sample template that you can use as a reference.

6. In the **Date** field, select the date on which you’re uploading the evidence. By default, it is set to today's date. Click on the calendar widget to change the date, as required.

   <Image src="/images/Screenshot-2025-10-08-at-11.34.11.png" alt="" />

7. Optionally, use the **Add a Note** field to enter additional information about the evidence you uploaded.

8. Click **Save**.

   <Image src="/images/Screenshot-2025-10-08-at-11.38.06.png" alt="" />

## Key Points to Know

#### Automatic Date-Based Organization

Scrut automatically organizes evidence into date-specific folders as shown in the screenshot below. The date format is configured according to the fiscal year format you set in Settings.

<Image src="/images/Screenshot-2025-10-08-at-11.53.36.png" alt="" />

#### Backdated Evidence Handling

Evidence created with a backdate will be automatically added to a new bucket for the appropriate timeframe, depending on the recurrence frequency.

<Image src="/images/image-1760510609524.png" alt="" />

#### Distinguish between Manual and Automated Evidence

To distinguish between manually uploaded evidence and automated evidence, Scrut adds the “Automated Evidence” tag for evidence fetched from integrations via Scrut Monitor. Manually uploaded evidence documentation does not have any tags.
