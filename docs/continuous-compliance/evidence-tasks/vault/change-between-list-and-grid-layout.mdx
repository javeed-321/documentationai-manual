There are two ways to view files and folders in Vault: **grid and list layouts**.

<Image src="/images/Screenshot-2025-08-18-at-11.28.22.png" alt="" caption="List Layout" />

## Switch Between Grid and List Layout

By default, the Vault shows the grid layout.

- To change to the list layout, click the list layout icon.
- To change back to the grid layout, click the grid layout icon.
