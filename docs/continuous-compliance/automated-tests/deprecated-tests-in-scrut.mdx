Scrut regularly evaluates our automated tests against industry standards and best practices to ensure that we are aligned with current compliance requirements. To enhance the overall compliance experience, we deprecate tests that are no longer relevant or have been superseded by more effective alternatives.

This guide provides a comprehensive list of tests that have been deprecated in Scrut. These tests are no longer active and have been removed from your dashboard.

## Deprecated Tests

When tests are deprecated, they no longer appear in the Automated Tests and Cloud Tests modules.

| Test Name | Application |
| --- | --- |
| No Security Contact Phone Set | **Azure** |
| Web App Running an Outdated .NET Framework Version | **Azure** |
| Web App Running an Outdated Python Version | **Azure** |
| Web App Running an Outdated PHP Version | **Azure** |
| Web App Running an Outdated Java Version | **Azure** |
| Pod Security Policy Disabled | **GCP** |
| VPC allows all egress(Default Network) | **AWS** |
| VPC allows all ingress(Default Network) | **AWS** |
| VPC allows all egress(Custom Network) | **AWS** |
| VPC allows all ingress(Custom Network) | **AWS** |

*This guide is regularly updated as additional tests are deprecated.*
