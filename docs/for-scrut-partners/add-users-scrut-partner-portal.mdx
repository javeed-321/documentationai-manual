In this article, we walk you through adding users to workspaces and managing user permissions.

## Add a New User

The **Users** tab in the **Partner Console (**[**console.scrut.io**](https://console.scrut.io/login)**)** allows you to create users and control their access to the workspaces console.

1. Go to the **Users** tab.

2. Click **Add User.**

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161863627-fngngmrist-Add-User.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Enter the user's name and email address.

4. Choose the user's access level. You have two options:

### Option 1: Grant Console Access

- Select **Workspace Console Access** if you want the user to:

  - Manage and create workspaces
  - Add or remove users
  - Access the Partner Portal administration features

- Click **Save** to create the user.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165083945-0dg4gklij38r-Screenshot-2026-02-02-at-20-06-00.png?fm=auto&auto=compress%2Cformat" alt="" />

### Option 2: Grant Workspace-Only Access

In this option, the user will not be able to access the Partner console portal. Instead, they can only access the specific workspaces to which they’ve been added.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165085283-o2ows7rf8p8-Screenshot-2026-02-02-at-20-06-43.png?fm=auto&auto=compress%2Cformat" alt="" />

- Click **Assign Workspace** to give them access to specific customer workspaces.
- Select which workspace(s) they should access.
- Choose their role for each workspace (e.g., Contributor, Admin)
- Customize module permissions if needed. Click **Edit** to modify module access.
- You can assign different roles for different workspaces (e.g., Contributor in Customer 1, Admin in Customer 2)
- Click **Save** to create the user.

<Callout kind="info">
  **Pro Tip!**

  Filter users by Workspaces or Workspace Console Access (Yes/No) using the filters at the top of the Users table.
</Callout>
