Templates allow you to standardize the questions you send to vendors during the assessment process. Instead of building a questionnaire from scratch each time, you create a template once and reuse it across assessments.

## How Vendor Questionnaire Templates Work

Templates live in Vendor Settings and serve as the foundation for every vendor questionnaire you create manually. The typical lifecycle looks like this:

1. Create a template using one of three methods:

   - Use the built-in VSA template
   - Build one manually from scratch
   - Import an existing questionnaire to use as a template

2. Customize the template by adding, editing, or removing questions to match your assessment requirements.

3. Select your preferred template when creating a vendor questionnaire. Scrut populates the questionnaire with all questions from the template. You can then add, edit, or delete questions for that specific questionnaire without affecting the original template.

4. Edit the template name or questions at any time. Changes apply only to future questionnaires and do not affect those already sent.

5. Delete a template when it's no longer needed.

<Callout kind="tip">
  **Pro Tip!**

  Scrut includes a built-in VSA template based on the Vendor Security Alliance Questionnaire (VSAQ), a widely used standard for assessing vendor security posture. It's fully customizable and available to all plans out of the box.
</Callout>
