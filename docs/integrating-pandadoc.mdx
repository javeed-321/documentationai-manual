The **Scrut - PandaDoc** integration fetches user access data, permissions, and role assignments from your PandaDoc account and sends them to Scrut’s Access Review module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  **Heads Up!**

  The data synced from PandaDoc flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to generate an API key in PandaDoc

### Permissions

Scrut requires **read-only access** to the following data in PandaDoc

- User Accounts: View name, email, and user role

<Callout kind="tip">
  **Pro Tip!**

  We recommend logging into your PandaDoc account before starting the integration to avoid doing so later.
</Callout>

## How To Connect PandaDoc With Scrut

### Step 1: Fetch API Key from PandaDoc

1. Log in to your PandaDoc account, navigate to API and Integrations and click API.

2. Click Enable to enable API keys for your account.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164309589-eq5uyrr2xpo-Screenshot-2025-09-09-at-11-31-46.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. Generate the API key. To generate the API key for the Production environment, contact the PandaDoc sales team.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164311089-375ee6kg6hl-Screenshot-2025-09-09-at-11-33-52.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. Once you have generated the API key, copy and save it in a safe location. You’ll need to enter it in Scrut in the [next step](/docs/integrating-pandadoc#step-2-go-to-integrations-in-scrut).

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164312459-rx66mrh4v5k-Screenshot-2025-09-09-at-11-36-17.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

**Note:** Refer to this guide from PandaDoc for [more information on the API key and what it does](https://developers.pandadoc.com/reference/api-key-authentication-process).

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.

2. Navigate to the **Integrations Library** tab, and choose **Policy Management** in the **Categories** section.

3. Scroll to the **PandaDoc** tile and click **Integrate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164313877-rq4gloxcg99-Screenshot-2025-09-09-at-11-37-40.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. On the integration page, paste the API key obtained in [Step 1](/docs/integrating-pandadoc#step-1-fetch-api-key-from-pandadoc).

5. Click **Submit**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164315338-ct9lwzgufcu-Screenshot-2025-09-09-at-11-38-04.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

6. Once authorization is done, you’ll see the “**Connected Successfully**” message and the **Connected** status indicator.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164316669-p2z2xru8o9g-Screenshot-2025-09-09-at-11-38-32.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from PandaDoc. This process typically takes a few hours to complete. Check the Audit Log on the PandaDoc integration page in Scrut to review the status.

- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.

- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from PandaDoc

Scrut fetches the following access-related data points from PandaDoc:

- User Name
- User Email
- User Role

## Viewing PandaDoc Data in Scrut

To view the data fetched from your PandaDoc account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your PandaDoc account. You can also create an Access Review (or edit an existing one) and include the PandaDoc application in scope. Refer to this guide for step-by-step instructions on [creating an access review](/docs/creating-a-new-access-review).
