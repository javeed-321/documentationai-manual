You can respond to auditor requests by creating targeted corrective actions to meet their requirements. Scrut streamlines the process of addressing audit requests by making it easy to create and manage corrective actions directly from within the Audit Center. This cohesive connection between audit requests and corrective actions enhances efficiency and transparency in your audit management process.

In this article, we walk you through the process of creating a corrective action from an audit request.

## How To Create a Corrective Action from an Audit Request

1. Sign in to Scrut, click **Audit → Audit Center** on the left navigation panel, and select the audit for which you want to create a corrective action.

   <Image src="/images/Screenshot-2025-09-17-at-15.04.05.png" alt="" />

2. Go to the **Requests** tab and click the request for which you want to create a corrective action.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166055770-i2hbd6ylfr8-Selecting-an-Audit-Request.png?fm=auto&auto=compress%2Cformat" alt="Selecting an Audit Request" />

3. Scroll to the **Corrective Actions** section and click **Add Corrective Action**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164983222-c3zzu479ssp-Screenshot-2026-01-20-at-19-38-16.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Fill in the required details such as:

   - **Corrective Action Name**: Enter a relevant name for the corrective action.

   - **Corrective Action Description**: Briefly describe the short-term fix to address the non-conformity. This should outline the immediate steps taken to rectify the issue and ensure compliance.

   - **Non-Conformity Description**: Scrut auto-fills this field with the request name and description when you create a corrective action from an audit request. This provides context to the issue being addressed. You can edit it if needed.

   - **Root Cause**: Explain the underlying cause of the non-conformity. Explain the factors that led to the issue, which can help in determining effective preventive measures.

   - **Preventive Action**: Describe the long-term preventive measures to address the root cause and prevent recurrence. This should include strategies or changes that will be implemented to ensure that the non-conformity does not happen again.

   - **Detection Date**: Select the date the non-conformity was detected.

   - **Assignees**: Choose the users responsible for taking the action.

   - **Approver:** By default, the user who created this Request is pre-selected as the **Approver** for this corrective action. However, you can change the approver if needed.

     **Note:** Scrut recommends that the assignee and approver be different to ensure an independent review.

   - **Due Date**: Set the deadline for completing the corrective action.

   - **Criticality Rating**: Assign a rating based on the severity of the non-conformity. You can choose from: Low, Medium, or High.

   - **Add Attachments**: Attach relevant documents or evidence related to the corrective action.

5. Click **Save**.
