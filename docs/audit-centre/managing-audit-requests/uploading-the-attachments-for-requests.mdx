title: "Add Artifacts to an Audit Request"

---

<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

When an auditor requests any data via an audit request, the assignee has three ways to resolve it:

1. [**Upload an Artifact**](/docs/audit-centre/managing-audit-requests/uploading-the-attachments-for-requests#1-upload-an-artifact): The assignee can upload relevant documentation or evidence directly to the audit request.
2. [**Link Existing Artifacts**](/docs/audit-centre/managing-audit-requests/uploading-the-attachments-for-requests#2-link-existing-artifacts): If relevant documentation is already available in Scrut, the assignee can link it to the request.
3. [**Create a New Artifact and Link It**](/docs/audit-centre/managing-audit-requests/uploading-the-attachments-for-requests#3-create-a-new-artifact-and-link-it): If no suitable artifacts are available, the assignee can create a new artifact addressing the issue and link it to the request.

## 1: Upload an Artifact

Upload an artifact to associate it with the audit request.

1. [Log in to Scrut](https://app.scrut.io/login) and click **Audit → Audit Center** on the left menu.

2. Click on the audit you want to add the artifact for.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161944221-0nzl3zfnfg4-Click-on-an-audit-in-Audit-Center.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Scroll to the **Requests** tab and click on the request you want to add artifacts to.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788163290455-zsbirv9xcwk-Request-Tab-in-Audit-Page.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Click the **Upload** button in the **Uploaded Artifacts** section.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788166198413-u6d4hnzliw-Upload-button-in-Artifacts.png?fm=auto&auto=compress%2Cformat" alt="Upload button in Artifacts" />

5. Upload the relevant artifact file from your system.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164656371-oart8jo3fv-Screenshot-2025-11-12-at-12-34-07.png?fm=auto&auto=compress%2Cformat" alt="" />

## 2: Link Existing Artifacts

You can also link an existing artifact to the audit request.

1. In the **Requests** page, scroll to the **Linked Items** section and click the **Link Existing** button.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162512779-9zdjdbzp6s-Link-Existing-Items-in-Audit-Requests.png?fm=auto&auto=compress%2Cformat" alt="Link Existing Items in Audit Requests" />

2. You can link an existing artifact by selecting a relevant **Policy, Evidence,** **Automated Test** or **Risk**.

3. Select the checkboxes corresponding to the existing policies, evidence, automated tests, or risks you want to link.

4. Click **Link**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164657800-xcaisuvfc7a-Screenshot-2025-11-12-at-12-39-19.png?fm=auto&auto=compress%2Cformat" alt="" />

<Callout kind="info">
  **Pro Tip:**

  To unlink artifacts, just click the Unlink button next to the artifact you want to remove.
</Callout>

## 3: Create a New Artifact and Link It

1. In the **Requests** page, scroll to the **Linked Items** section and click the **Add** button.

2. Choose whether you want to create a new **Policy, Evidence**, or **Risk** and link it to the request.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164659255-ieqfwi5krlk-Screenshot-2025-11-12-at-12-42-55.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Enter Policy, Evidence, or Risk details and click **Next**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164660697-pbrrkyoq5to-Screenshot-2025-11-12-at-12-43-44.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Select the controls you want to link to the artifact and click **Next**. The selected controls will also be linked to the request.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164662096-ng4v7j0ismk-Screenshot-2025-11-12-at-12-43-56.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Verify the details and click **Save**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164663560-n84zjtwhovd-Screenshot-2025-11-12-at-12-44-06.png?fm=auto&auto=compress%2Cformat" alt="" />
