title: "Add Artifacts to an Audit Request"
description: "Learn how to upload artifacts to audit requests."
---

<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

When an auditor requests any data via an audit request, the assignee has three ways to resolve it:

1. [**Upload an Artifact**](/docs/audit-centre/managing-audit-requests/uploading-the-attachments-for-requests#1-upload-an-artifact): The assignee can upload relevant documentation or evidence directly to the audit request.
2. [**Link Existing Artifacts**](/docs/audit-centre/managing-audit-requests/uploading-the-attachments-for-requests#2-link-existing-artifacts): If relevant documentation is already available in Scrut, the assignee can link it to the request.
3. [**Create a New Artifact and Link It**](/docs/audit-centre/managing-audit-requests/uploading-the-attachments-for-requests#3-create-a-new-artifact-and-link-it): If no suitable artifacts are available, the assignee can create a new artifact addressing the issue and link it to the request.

## #1: Upload an Artifact

Upload an artifact to associate it with the audit request.

1. [Log in to Scrut](https://app.scrut.io/login) and click **Audit → Audit Center** on the left menu.

2. Click on the audit you want to add the artifact for.

   <Image src="/images/Click-on-an-audit-in-Audit-Center.png" alt="" />

3. Scroll to the **Requests** tab and click on the request you want to add artifacts to.

   <Image src="/images/Request-Tab-in-Audit-Page.png" alt="" />

4. Click the **Upload** button in the **Uploaded Artifacts** section.

   <Image src="/images/Upload-button-in-Artifacts.png" alt="Upload button in Artifacts" />

5. Upload the relevant artifact file from your system.

   <Image src="/images/Screenshot-2025-11-12-at-12.34.07.png" alt="" />

## #2: Link Existing Artifacts

You can also link an existing artifact to the audit request.

1. In the **Requests** page, scroll to the **Linked Items** section and click the **Link Existing** button.

   <Image src="/images/Link-Existing-Items-in-Audit-Requests.png" alt="Link Existing Items in Audit Requests" />

2. You can link an existing artifact by selecting a relevant **Policy, Evidence,** **Automated Test** or **Risk**.

3. Select the checkboxes corresponding to the existing policies, evidence, automated tests, or risks you want to link.

4. Click **Link**.

   <Image src="/images/Screenshot-2025-11-12-at-12.39.19.png" alt="" />

<Callout kind="info">
  **Pro Tip:**

  To unlink artifacts, just click the Unlink button next to the artifact you want to remove.
</Callout>

<Image src="/images/Unlink-Existing-Items-in-Requests.png" alt="Unlink Existing Items in Requests" />

## #3: Create a New Artifact and Link It

1. In the **Requests** page, scroll to the **Linked Items** section and click the **Add** button.

2. Choose whether you want to create a new **Policy, Evidence**, or **Risk** and link it to the request.

   <Image src="/images/Screenshot-2025-11-12-at-12.42.55.png" alt="" />

3. Enter Policy, Evidence, or Risk details and click **Next**.

   <Image src="/images/Screenshot-2025-11-12-at-12.43.44.png" alt="" />

4. Select the controls you want to link to the artifact and click **Next**. The selected controls will also be linked to the request.

   <Image src="/images/Screenshot-2025-11-12-at-12.43.56.png" alt="" />

5. Verify the details and click **Save**.

   <Image src="/images/Screenshot-2025-11-12-at-12.44.06.png" alt="" />
