<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

By exporting audit requests, you can quickly share them with external auditors and other stakeholders who do not have access to Scrut. In this article, we explain how to export audit requests in two ways:

- \#1: [Export Requests Specific to an Audit](/docs/audit-centre/managing-audit-requests/export-audit-center-requests#1-export-requests-specific-to-an-audit)
- \#2: [Export Requests for all Audits](/docs/audit-centre/managing-audit-requests/export-audit-center-requests#2-export-requests-for-all-audits)

## How to Export Audit Requests

### #1: Export Requests Specific to an Audit

1. Navigate to **Audit → Audit Center** via the left navigation menu.

2. Click the **Audit** tab and open the audit for which you want to export the requests.

   <Image src="/images/Click-on-an-audit-in-Audit-Center.png" alt="" />

3. Scroll to the **Requests** tab and click the **Export** button.

   <Image src="/images/image-1762953246283.png" alt="" />

The file will be downloaded to your system in CSV format.

### #2: Export Requests for all Audits

If you’re looking to export requests across all audits, follow these steps:

1. Navigate to **Audit → Audit Center** via the left navigation menu.

2. Go to the **Requests** tab and click the **Export** button.

   <Image src="/images/image-1762953383699.png" alt="Requests Tab in the Audit Center" />

The file will be downloaded to your system in CSV format.
