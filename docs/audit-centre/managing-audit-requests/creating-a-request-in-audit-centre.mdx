<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

There are two primary ways to create an audit request:

- [Create a Single Audit Request](/docs/audit-centre/managing-audit-requests/creating-a-request-in-audit-centre#create-a-single-audit-request)
- [Bulk Import Multiple Requests](/docs/audit-centre/managing-audit-requests/creating-a-request-in-audit-centre#bulk-import-multiple-requests)

## Create a Single Audit Request

1. Sign in to Scrut, and click **Audit → Audit Center**.

2. Click on the audit for which you want to create a request.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161944221-0nzl3zfnfg4-Click-on-an-audit-in-Audit-Center.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Scroll and click the **Requests** tab.

4. Click the **Add Requests** button and select **Manually**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161841686-3sl2rvky8n-Add-Request-button.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Enter the required details, such as:

   - **Entities**: Select the entities to which the Audit Request applies. Choose Organization Wide if you want to apply this to all entities.

   - **Request Name**: Provide a clear and descriptive name that accurately reflects the request.

   - **Assignees**: Select the user responsible for handling the request. Choose No Assignee if you’re unsure who to assign it to.

     **Note:** Scrut will notify assignees via email regarding the task.

   - **Description**: Optionally, add details that will help the assignee better understand the request.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164955405-489ompcdbfj-Screenshot-2026-01-13-at-20-28-56.png?fm=auto&auto=compress%2Cformat" alt="" />

6. In the next step, you can create a corrective action for the request. Feel free to skip this if it's not applicable.

   **Note:** You can also [create a corrective action for the request](/docs/audit-centre/managing-audit-requests/creating-corrective-action-from-audit-request) later, if required.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164647336-j2ox0or3r6-Screenshot-2025-11-12-at-10-51-35.png?fm=auto&auto=compress%2Cformat" alt="" />

7. Next, [link or unlink any relevant controls](/docs/audit-centre/managing-audit-requests/linking-controls-to-audit-request) to the finding. Feel free to skip this step if it is not applicable.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164648671-7h5xn8h98wv-Screenshot-2025-11-12-at-10-51-52.png?fm=auto&auto=compress%2Cformat" alt="" />

8. Finally, review all the information you've entered to ensure accuracy, and then click **Save**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164650024-dsfmm4p4lxo-Screenshot-2025-11-12-at-10-52-03.png?fm=auto&auto=compress%2Cformat" alt="" />

## Bulk Import Multiple Requests

You can add multiple requests simultaneously by bulk importing them. Follow these steps:

1. Sign in to Scrut, and click **Audit → Audit Center**.

2. Click on the audit for which you want to create a finding.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161944221-0nzl3zfnfg4-Click-on-an-audit-in-Audit-Center.png?fm=auto&auto=compress%2Cformat" alt="" />

3. On the audit page, scroll and click the **Requests** tab.

4. Click the **Add Requests** button and select **Import (CSV/XLSX)**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788161841686-3sl2rvky8n-Add-Request-button.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Click **Download Sample Template**. Replace the contents of the file with your list of requests.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162218086-jwmii9g96d-image-1762925572259.png?fm=auto&auto=compress%2Cformat" alt="" />

6. Upload the filled template by dragging and dropping it or selecting it from your device.

   <Callout kind="info">
     **Pro Tip!**

     See here for [instructions on filling the template](/docs/audit-centre/managing-audit-requests/creating-a-request-in-audit-centre#tips-for-using-the-template).
   </Callout>

7. Click **Save**.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164652818-n6k5a4zs3ma-Screenshot-2025-11-12-at-11-06-44.png?fm=auto&auto=compress%2Cformat" alt="" />

Scrut checks the template file's format to ensure there are no errors. If any errors are detected, download the spreadsheet from the **Upload Status** message to view them. Fix the spreadsheet and reupload it.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164654799-r7verkf0cn9-Screenshot-2025-11-12-at-11-07-54.png?fm=auto&auto=compress%2Cformat" alt="" />

#### Tips for Using the Template

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164956802-u48lqct7clp-Screenshot-2026-01-13-at-20-34-22.png?fm=auto&auto=compress%2Cformat" alt="" />

- Do NOT remove the first row as it contains column headers.
- You can enter the request details from the second row.
- Create a row for each request.
- Mandatory fields: Request Name. All other fields are optional.
- For the Assignees field, enter the assignees' email addresses, separated by commas. Email should match the assignees’ emails in Scrut.
