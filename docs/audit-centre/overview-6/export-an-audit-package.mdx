---
title: "Export an Audit Package"
---

**Who can use this feature**

- Supported on Foundation, Growth, and Scale plans

The **Audit Package** export gives you a complete, self-contained copy of an audit that auditors can browse and verify offline, without needing access to Scrut. It includes an offline viewer, consistent file and folder names, and structured data for independent analysis.

## How To Export an Audit Package

1. Sign in to Scrut, click

   **Audit → Audit Center**

   on the left navigation panel.

2. Click the audit you want to export.

3. Click the

   **Export**

   dropdown and select

   **Audit Package**

   .

4. Click

   **Export**

   to generate the package.

5. Once the export is ready, download it from the

   **Notification Center**

   .

Your Audit Package downloads as a browsable folder that auditors can open on any computer, no Scrut login required.

## What's Included in the Package

- **Structured, browsable export:**

  Evidence, policies, and tests are organized with breadcrumbs and section grouping, so auditors can navigate the audit the way they would inside Scrut.

- **Reliable file names:**

  File and folder names stay short and unique, so the package opens correctly regardless of the auditor's operating system.

- **Structured data for further analysis:**

  Alongside the offline viewer, the package includes structured data files auditors can use to verify evidence independently or run their own tooling.

**How is this different from the Audit Readiness Report?**

The Audit Readiness Report is a single summary report of your audit completion. The Audit Package is a full, browsable export of the underlying evidence, policies, and tests, built for auditors working offline.

**Do auditors need a Scrut account to open the package?**

No. The package is self-contained and opens in the built-in offline viewer without requiring Scrut access.
