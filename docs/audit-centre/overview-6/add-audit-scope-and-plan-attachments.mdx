You can attach documents to an audit to keep all audit-related information in one place. This includes audit scope, audit plans, and other supporting documents that your team or auditors may need throughout the audit.

Storing these documents within the audit eliminates the need to manage them across emails or shared drives. It also keeps them alongside the audit's Findings, Requests, and Corrective Actions, making them easy for everyone involved to find and reference at any stage of the audit.

## Example Documents

You can upload documents such as:

- **Audit scope:** Defines the boundaries of the audit, including the systems, controls, entities, and time period being reviewed.
- **Audit plan:** Outlines the audit approach, including the methodology, timeline, and activities for the engagement.
- **Audit schedules:** List key audit milestones, timelines, meetings, and planned activities.
- **Supporting reference documents:** Such as policies, procedures, standards, or other documents that provide additional context for the audit.
- **Other audit-related files:** Upload any additional documents relevant to the audit, such as checklists, meeting notes, evidence summaries, etc.

## Add an Audit Attachment

1. Sign in to Scrut and click **Audit → Audit Center** on the left navigation panel.
2. Click the audit to which you want to add scope or plan documents.
3. Navigate to the **Attachments** section.
4. Click **Upload**, or drag and drop your file into the section.
5. Repeat to add more files.

<Image src="/images/Upload-Audit-Attachments.png" alt="" />

Points to Note:

- There is no limit on the number of attachments you can add. Supported file types are PDF, DOCX, XLSX, PNG, and JPG.
- You can add attachments only after the audit is created. It is not available during audit creation.
- Each uploaded file appears in the Attachments section along with its file name, upload date, and the name of the person who uploaded it.

## View or Download an Attachment

1. Open the audit and navigate to the **Attachments** section.

2. Click the attachment you want to access.

   <Image src="/images/Screenshot-2026-07-14-at-11.50.03.png" alt="" />

3. If the file format is supported, it opens in the preview window.

4. To save a copy to your device, click **Download**.

   <Image src="/images/Screenshot-2026-07-14-at-11.50.23.png" alt="" />

## Delete an Attachment

Only users with edit permissions on the audit can delete attachments.

1. Navigate to the **Attachments** section of the audit.

2. Click the delete icon next to the file you want to remove.

3. Click Delete to confirm.

   **Important:** Deleting an attachment is permanent and cannot be undone.

4. The file is removed from the Attachments section immediately.

## FAQs

<ExpandableGroup>
  <Expandable title="Will the attachments be duplicated when cloning an audit?" default-open="true">
    No. When you clone an audit, the attachments are not carried over to the cloned audit. Upload them again to the cloned audit if needed.
  </Expandable>

  <Expandable title="Can I add scope and plan attachments while creating a new audit?" default-open="true">
    No. You can add attachments only after the audit is created. Add your scope and plan documents from the audit detail page once it is set up.
  </Expandable>
</ExpandableGroup>
