---
title: "Create an Audit By Framework"
description: "Learn how to create an audit for a specific framework."
---

<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

## Method 1: Via the Audit Center

1. [Sign in to Scrut](https://app.scrut.io/) and click **Audit → Audit Center** on the left navigation panel.

2. Click the **+New Audit** button and select **By Framework** in the dropdown.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171318499-lfhl0gf5ey-Screenshot-2025-09-19-at-12-28-29.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Select the framework that you want to audit.

4. Enter a name for the audit.

5. Choose the **Audit Type**:

   - **Internal:** Conducted within your organization
   - **External:** Conducted by a third-party audit firm **Note**: Only one active external audit is allowed per framework at a time. However, multiple internal audits can be created as needed.

6. From the Entities dropdown, select the organizational entity or entities that the audit belongs to.

7. In the **Audit Date** field, select the specific date when the audit will take place.

8. In the **Observation Period** field, select the **Start Date** and **End Date** and set an observation period for the audit project to the period for which you are being audited. The evidence you’ve collected will be scoped based on these dates.

9. Click **Create**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171319834-mblpaanr79p-Screenshot-2025-09-19-at-12-29-33.png?fm=auto&auto=compress%2Cformat" alt="" />

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171321193-yaao745deal-Screenshot-2025-09-19-at-12-30-19.png?fm=auto&auto=compress%2Cformat" alt="" />

<Callout kind="success">
  **Heads Up!**

  When an audit is created, its status will be initially set to **Upcoming**. The status will change to **In Progress** when findings or requests are added or when the audit date arrives.
</Callout>

## Method 2: Via the Framework Details Page

You can also create an audit for a framework directly from the Framework details page.

1. Click **Compliance → Frameworks** on the left navigation panel.

2. Click the Framework for which you want to create an audit. This takes you to the Framework details page.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171256896-1blj3fk74pyj-Screenshot-2025-09-18-at-12-16-45.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Click the **Create Audit** button at the top.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171251346-wc1opcep8n-Screenshot-2025-09-18-at-12-08-31.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Enter the audit details and click **Create**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171252673-xnknn5o1f0r-Screenshot-2025-09-18-at-12-09-05.png?fm=auto&auto=compress%2Cformat" alt="" />

The created audit details are available both on the Framework details page and in the Audit Center.
