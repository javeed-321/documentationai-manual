The **Audit Center** in Scrut is a central hub for managing both internal and external audits. You can create audits and add auditors using the audit module. Auditors can raise requests and report their findings directly in the audits to which they are added. This ensures clear communication and transparency throughout the audit process.

In this article, we provide an overview of the audit center.

## How To Access the Audit Center

Click **Audit → Audit Center** on the left navigation panel. This takes you to the **Audits** tab, where you can view all internal and external audits you created in Scrut, along with their statuses and other metadata.

## Overview of the Audit Center

The Audit Center has four key sections:

### Audits

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171313048-lbtxij0hnx-Screenshot-2025-09-19-at-12-24-19.png?fm=auto&auto=compress%2Cformat" alt="" />

This tab provides a comprehensive overview of all the audits you've created in Scrut, displayed in a table. At the top, you'll find status cards reflecting the current state of your audits:

- **Upcoming**: Number of audits scheduled for a future date, with no findings or requests added yet.
- **In Progress**: When auditors begin to add findings or requests to an audit, its status automatically updates to "In Progress." Also, when the audit date goes live, the status automatically changes to "In Progress."
- **Completed**: This status is manually set by you when you [mark an audit as completed](/docs/audit-centre/overview-6/marking-audit-project-completed).

The main table provides essential details for each audit, such as its name, type, scheduled date, observation period, and the entities involved. If you click on any audit listed in the table, you will be directed to the detailed Audit page, where you can see more in-depth information.

<Callout kind="info">
  **Pro Tip!**

  To tailor the data displayed to your needs, utilize the filters located at the top of the table. These filters allow you to sort and refine the audit list based on specific criteria that are relevant to you.
</Callout>

### Requests

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171314375-z74yi7wdsz-Screenshot-2025-09-19-at-12-24-47.png?fm=auto&auto=compress%2Cformat" alt="" />

The Requests tab provides a comprehensive overview of all requests submitted by auditors during audits. At the top of the tab, you will find status cards that categorize the requests into four distinct statuses:

- **Open**: This indicates the number of requests that are still pending submission from the assigned individual (the assignee). These requests have not yet been completed.
- **Needs Review**: This status reflects the number of requests for which the assignee has completed and submitted their work and is awaiting the auditor's review.
- **Needs Revision**: Requests labeled with this status indicate that the auditor has reviewed the submitted work and is requesting specific changes or additional information from the assignee.
- **Closed**: This status shows the number of requests that have been fully completed and finalized, indicating that all necessary actions have been taken.

Below the status cards, a detailed table presents key information for each request, including its name, the person assigned to it (assignee), the date it was created, who created it, the name of the audit it pertains to, and other relevant metadata.

For further actions related to any specific request, click it to go to the request details page, where you can view more information and take the necessary steps.

### Findings

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171315731-75nqavcshoa-Screenshot-2025-09-19-at-12-24-54.png?fm=auto&auto=compress%2Cformat" alt="" />

The Findings tab provides a comprehensive overview of all audit findings recorded by auditors during the audit process. At the top, you will find status cards that display the different stages of these findings. Here's what each status means:

- **Open:** This indicates the number of findings that have been submitted by the auditor and are pending action from the assigned individual.
- **Needs Review:** This category displays findings where the assignee has submitted their work, which is currently awaiting evaluation by the auditor.
- **Needs Revision:** This denotes findings for which the auditor has requested changes or improvements to the submitted documentation or artifacts.
- **Closed:** This shows the number of findings that have been addressed and finalized.

Beneath the status cards, a detailed table presents essential information for each finding. The table includes key details such as the name of the finding, the assignee (the person responsible for taking action on it), the nature of the finding, the relevant department, the creation date, the creator of the finding, and other relevant metadata.

For further actions related to any specific finding, simply click on it, and you will be directed to the findings details page, where you can view more information and take necessary steps as needed.

### Corrective Actions

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171317088-z7tkumbxmh9-Screenshot-2025-09-19-at-12-25-01.png?fm=auto&auto=compress%2Cformat" alt="" />

The corrective actions tab provides a comprehensive overview of all corrective actions created in response to audit findings and requests. At the top of the tab, you’ll find status cards that display the statuses of these actions, such as:

- **Open:** Displays the total number of corrective actions currently open and still pending resolution.
- **Closed:** Indicates the number of corrective actions that have been successfully resolved.
- **High:** Represents the number of corrective actions categorized with a criticality rating of high, highlighting those that require immediate attention.
- **Medium:** Shows the number of corrective actions with a medium criticality rating, which are important but less urgent than high-rated actions.

Beneath the status cards, a detailed table presents essential information for each corrective action. The table includes key details such as the name of the corrective action, the assignee, criticality rating, detection date, source name and type, and other relevant metadata.

For further actions related to any specific corrective action, click on it, and you will be directed to the corrective action details page, where you can view more information and take necessary steps as needed.
