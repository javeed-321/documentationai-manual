---
title: "Create a Ticket for a Corrective Action"
description: "Learn how to create tickets for corrective actions in Scrut for your project management tool."
---

<Callout kind="info">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

You can create a ticket directly in your integrated project management tool from within the Corrective action page. To create a ticket:

1. Go to **Audit → Corrective Action** and open the corrective action for which you want to create a ticket.

2. Click the three-dot icon on the top-right and select **Create Ticket**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171241691-w3gvv30uths-Screenshot-2025-09-17-at-17-58-04.png?fm=auto&auto=compress%2Cformat" alt="" />

3. Enter the ticket details and click **Create**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788171243051-irq3od4bcpn-Screenshot-2025-09-17-at-17-58-44.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Scrut will create the ticket directly in your connected project management tool.

5. You can track its status via the **Tickets** tab in the Corrective Action details page.
