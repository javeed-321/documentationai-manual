<Callout kind="custom">
  **Who can use this feature**

  - Supported on **Foundation, Growth,** and **Scale** plans
</Callout>

In this article, you can learn how to edit or delete risk mitigation tasks.

## Edit a Mitigation Task

1. Sign in to Scrut, and go to **Risk → Risk Management** using the left navigation panel.

2. Go to the **Risk Register** tab and click on the risk for which you want to upload a mitigation task.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164072088-qpfi0598hs7-Screenshot-2025-08-19-at-18-53-50.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. Scroll to the **Mitigation Tasks** tab, and click the mitigation task that you want to edit.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164073539-oz4e9npsoj7-Screenshot-2025-08-19-at-18-54-32.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. You can edit the following fields:

   - Task Name

   - Description

   - Assignee

   - Approver

   - Due Date

   - Department

     <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162537360-drs8zzghyo-Mitigation-Task-Details-Page.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

## Delete a Mitigation Task

<Callout kind="alert">
  **Heads Up!**

  Mitigation tasks that have been completed cannot be deleted.
</Callout>

1. Click the **Delete icon** in the Action column for the task you want to delete.
2. Click **Delete** to confirm.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788165213964-rf33lcanf2-Screenshot-2026-02-24-at-12-30-26.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

<Callout kind="danger">
  **Note**

  Deleting is permanent, and cannot be undone.
</Callout>
