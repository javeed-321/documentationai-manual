The **Scrut - Apollo.io** integration fetches user access data, permissions, and role assignments from your Apollo.io account and sends them to the [Access Review](/docs/access-review-walkthrough) module. This integration enables your organization to maintain comprehensive visibility over user access rights and streamline periodic access reviews for compliance and security.

<Callout kind="alert">
  **Heads Up!**

  The data synced from Apollo.io flows into the **Access Review** module in Scrut.
</Callout>

## Prerequisites

Before starting the integration, ensure you have the following access and permissions:

### Access

- You must be a Scrut Admin (or Contributor with access to the Integrations module)
- You must have permissions to generate an API key in Apollo.io

### Permissions

Scrut requires **read-only access** to the following data in Apollo.io

- User Accounts: View name, email, and user role

<Callout kind="tip">
  **Pro Tip!**

  We recommend logging into your Apollo.io account before starting the integration to avoid doing so later.
</Callout>

## How To Connect Apollo.io With Scrut

### Step 1: Fetch API Key from Apollo.io

1. Log in to your Apollo.io account and click **Admin** **Settings → Integrations**.

2. Find the **API** option and click **Connect**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164287482-wzt5s5rv6fh-Screenshot-2025-09-08-at-19-58-14.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

3. Click **API keys** and click **Create new key**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164288887-xk9u73mfzus-Screenshot-2025-09-08-at-20-00-15.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. Enter the name for your API key**,** such as Scrut, and set it as a master key by toggling on the **Set as master key** slider.

5. Click **Create API key**.

<Callout kind="alert">
  **Note:**

  Refer to this guide for more information on [how to create and manage API keys in Apollo.io](https://docs.apollo.io/docs/create-api-key).

### Step 2: Go To Integrations in Scrut

1. [Sign in to Scrut](https://app.scrut.io/) and click **Integrations** on the left navigation panel.

2. Navigate to the **Integrations Library** tab, and choose **Miscellaneous** in the **Categories** section.

3. Scroll to the **Apollo.io** tile and click **Integrate**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164291720-ua76yu2mt5r-Screenshot-2025-09-08-at-20-42-48.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

4. On the integration page, paste the API key obtained in Step 1.

5. Click **Submit**.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164293081-y4ktfh8dqwp-Screenshot-2025-09-08-at-20-43-23.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

6. Once authorization is done, you’ll see the “**Connected Successfully**” message and the **Connected** status indicator.

   <Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788164295834-z3xnbgfiyg-Screenshot-2025-09-08-at-20-45-04.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

## Synchronization Details

- **Initial Sync**: Upon completing the integration, Scrut will start syncing user data from Apollo.io. This process typically takes a few hours to complete. Check the Audit Log on the Apollo.io integration page in Scrut to review the status.

- **Recurring Sync**: After this, Scrut performs the sync once **every 24 hours** to fetch incremental data such as new users, role changes, and permission updates.

- **Manual Sync**: You can also click the **Sync Now** button to trigger an immediate data refresh.

## Data Fetched from Apollo.io

Scrut fetches the following access-related data points from Apollo.io:

- User Name
- User Email
- User Role

## Viewing Apollo.io Data in Scrut

To view the data fetched from your Apollo.io account, go to the **People → Access → Overview** tab. On this page, you can see the user details for your Apollo.io account.

<Image src="https://blob-cdn.documentation.ai/org-be800fa3-4146-42bb-a54c-66f35fe883a5/doc-4eeb4bca-def5-4b53-9be4-c510946b0c05/1788162134872-3cr460bi62w-image-1757346401680.png?fm=auto&auto=compress%2Cformat" alt="" caption=" " />

To view the data fetched from your Apollo.io account, you’ll need to create an Access Review (or edit an existing one) and include the Apollo.io application in scope. Refer to this guide for step-by-step instructions on [creating an access review](/docs/creating-a-new-access-review).

Follow these steps to create a new access review for Apollo.io:

1. Go to **People → Access Review** and click **Create New**.
2. Enter Review Details: Name, Description, Owner, and Review Days.
3. In step 2, search for and select Apollo.io in the Applications in Scope.
4. Select **Reviewer** and **Approver**.
5. Review the details and click **Save Review**.

From the Access Review page, click Apollo.io to view user details in Scrut.
