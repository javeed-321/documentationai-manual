## Overview

WP Travel Engine doesn't include a built-in drag-and-drop sort order for pricing categories, but you can add this capability using a free WordPress plugin called [Simple Custom Post Order](https://wordpress.org/plugins/simple-custom-post-order/). Once installed and configured, it lets you drag and drop pricing categories to arrange them in any order you prefer.

<Callout kind="info">
  Simple Custom Post Order is a third-party WordPress plugin, not a WP Travel Engine add-on. It works by enabling manual ordering for the post types and taxonomies you select in its settings.
</Callout>

## Prerequisites

- Administrator access to your WordPress dashboard
- WP Travel Engine installed with at least one pricing category created

## Sorting your pricing categories

<Steps title-type="h3">
  <Step title="Install the Simple Custom Post Order plugin">
    Log in to your WordPress dashboard and go to **Plugins > Add New**. In the search bar, type **Simple Custom Post Order**, click **Install Now**, and once installation completes, click **Activate**.

    Alternatively, download it directly from the [WordPress Plugin Directory](https://wordpress.org/plugins/simple-custom-post-order/).
  </Step>

  <Step title="Enable ordering for pricing categories">
    After activation, go to **Settings > SCPOrder**. You'll see a list of the post types and taxonomies supported by your site.

    Check the box next to **Categories**, then click **Save Changes**.
  </Step>

  <Step title="Drag and drop to reorder">
    Go to **Trips > Pricing Categories**. You'll now see a drag-and-drop interface listing your pricing categories.

    Drag and drop the categories to rearrange them in the order you want. The new order saves automatically.
  </Step>
</Steps>

## Verifying the new order

Open any trip that uses pricing categories, or view the pricing widget on the frontend, and confirm the categories now display in the order you set.

<Callout kind="tip">
  If the order doesn't seem to update on the frontend, clear any page or object caching plugin on your site and refresh the trip page.
</Callout>

Contact our [support team](https://wptravelengine.com/support-ticket/) if you run into any issues while setting this up.
