## Overview

A handful of untranslated English words on your travel site might seem minor, but they add up and dilute your site's message if left unaddressed. Loco Translate lets you translate the static text in your theme and plugins into any language, without touching code.

<Callout kind="info" collapsed="false">
  Loco Translate only translates static content — text contained in your theme, plugins, and WordPress core. It can't translate every theme or plugin, since the theme or plugin's developer has to have implemented translation support first. Before you begin, check whether your [travel theme](https://wptravelengine.com/wordpress-travel-themes/) is ready for translation.
</Callout>

## Step 1: Install and activate Loco Translate

<Steps>
  <Step title="Search for the plugin" title-type="p">
    Go to **Plugins → Add New Plugin** from your WordPress dashboard and search for **Loco Translate**.
  </Step>

  <Step title="Install and activate" title-type="p">
    Click **Install Now**, then **Activate** to enable the plugin.
  </Step>
</Steps>

## Step 2: Choose your theme from the list

1. Go to **Loco Translate → Themes** from your WordPress dashboard.
2. Identify the theme you want to translate and click on it. Loco Translate lists both active themes and themes that are only installed.
3. Click **New Language**.
4. Select your target language from the **Choose a language** dropdown.
5. Select where the translation file will be saved.

<Callout kind="tip" collapsed="false">
  Loco Translate offers three save-location options. If you're unfamiliar with WordPress localization, use the **Custom** location recommended by the developer — for example, `wp-content/languages/loco/themes/travel-monster-it_IT.po`.
</Callout>

6. Click **Start Translating** to continue.

## Step 3: Translate the theme

You'll see a list of strings pulled from the theme's template files. Select a string from the list, or use the **Filter Translations** field to search for a specific string — for example, "© Copyright."

<Steps>
  <Step title="Select the source string" title-type="p">
    Click the string you want to translate in the source text box.
  </Step>

  <Step title="Enter your translation" title-type="p">
    Write the translation in the target-language translation box.
  </Step>

  <Step title="Save" title-type="p">
    Click **Save** to apply the change.
  </Step>
</Steps>

## Step 4: Verify the translation of your strings

<Steps>
  <Step title="Open General Settings" title-type="p">
    Go to **Settings → General** on your WordPress dashboard.
  </Step>

  <Step title="Change the site language" title-type="p">
    Scroll to the **Site Language** dropdown and choose the language you just translated into — for example, Italian.
  </Step>

  <Step title="Save changes" title-type="p">
    Click **Save Changes**.
  </Step>

  <Step title="Check the front end" title-type="p">
    Visit the part of your site where the translated string appears — for example, the footer, if you translated "© Copyright" — and confirm it displays correctly.
  </Step>
</Steps>

Repeat this process for every additional string you want to translate: search for the word, enter its translation, and save.

## Step 5: Translate the plugin

The same process applies to translating any plugin, including WP Travel Engine.

1. Go to **Loco Translate → Plugin** from your WordPress dashboard.
2. Locate **WP Travel Engine** in the plugin list and click on it. You'll see any languages the plugin already has translations for, along with how complete each one is (for example, French at 100%, German at 23%, and Hungarian at 72%).
3. Click **New Language** to add a language that isn't listed yet, or click **Edit** next to an existing language to continue an in-progress translation.
4. On the plugin's editor screen, select the language you want to translate into from the **Language** tab.
5. Select where the translation file will be saved.
6. Click **Start Translating**.

To translate specific strings:

1. Use the **Filter Translations** search bar to find a string — for example, "Check Availability."
2. Click the string so the source text appears.
3. Write its translation in the target-language translation box.
4. Click **Save** to apply the change.

Follow Step 4 above to verify the plugin translation is working on the front end.

## Important note: placeholder format specifiers

When translating a plugin or theme, never translate or alter format specifiers and placeholders such as `%s`, `%d`, or `%1$s`. Keep them exactly as they appear in the original string.

### Why this matters

- Placeholders dynamically insert values — like names, dates, or prices — into the translated text.
- Altering or translating a placeholder can break the plugin or theme, causing errors or unexpected behavior.

### Example

- Original: `Hello, %s! Your booking number is %d.`
- Correct translation: `Hola, %s! Su número de reserva es %d.`

<Callout kind="danger" collapsed="false">
  Never rewrite the placeholder itself. `Hola, %S! Su número de reserva es %num.` is incorrect — it changes `%s` to `%S` and `%d` to `%num`, which breaks the dynamic value insertion.
</Callout>

Keeping placeholders unchanged ensures the plugin and theme continue to function correctly across every translation.
