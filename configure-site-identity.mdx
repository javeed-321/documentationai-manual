## What Site Identity controls

The Site Identity settings let you add a logo, site title, tagline, and site icon for your website, along with appearance options for how each of these displays.

You can access these settings from **Appearance > Customize > Site Identity** in your WordPress dashboard.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-11.png" width="340" height="887" alt="Site Identity customizer panel in Travel Monster theme" />

## Available settings

| Setting            | What it does                                                   |
| ------------------ | -------------------------------------------------------------- |
| Logo               | Uploads your site logo to display it in the site header.       |
| Logo Width         | Sets the logo's width across different screen sizes.           |
| Site Title         | Sets your site's title text.                                   |
| Hide Site Title    | Hides the site title text from the site header when enabled.   |
| Tagline            | Sets your site's tagline text.                                 |
| Hide Site Tagline  | Hides the site tagline from the site header when enabled.      |
| Site Icon          | Uploads the icon used as your site's favicon.                  |
| Font Family        | Sets the font family applied to the site title.                |
| Font Size          | Sets the site title's font size across different screen sizes. |
| Line Height        | Sets the line height value for the site title.                 |
| Letter Spacing     | Sets the spacing applied between the site title's letters.     |
| Font Weight        | Sets the font weight for the site title.                       |
| Transform          | Sets the text capitalization style for the site title.         |
| Site Title Color   | Sets the color of the site title text.                         |
| Site Tagline Color | Sets the color of the site tagline text.                       |

<Callout kind="tip">
  If you want your logo to speak for your brand without a text title cluttering the header, enable **Hide Site Title** after uploading your logo — the tagline setting works the same way if you'd rather keep the header focused on just the title.
</Callout>
