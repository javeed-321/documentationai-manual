## What Travelverse is

Travelverse is a free, block-based WordPress theme that supports Full Site Editing, so you can customize your entire site visually instead of editing theme files. Rather than relying on the traditional WordPress Customizer, Travelverse ships its own library of patterns built with Gutenberg blocks and settings.

Activating Travelverse gives you a fully functional website out of the box. You can then edit every page template directly in the Site Editor, giving you complete control over layout and appearance.

Travelverse is also built to work with WP Travel Engine, making it a strong fit for travel blogging and booking sites — you can showcase trips and use WP Travel Engine blocks across any Travelverse template.

For design flexibility, Travelverse supports a wide range of Block Patterns and lets you customize default colors and typography. If you want to start over, you can clear any customization and return a template to its default state.

## Install the Travelverse theme

<Steps title-type="h3">
  <Step title="Download the theme file">
    Download the Travelverse theme installation file.
  </Step>

  <Step title="Log in to WordPress">
    Log in to your WordPress admin dashboard and go to **Appearance > Themes**.
  </Step>

  <Step title="Open the theme uploader">
    Click **Add New**, then click **Upload Theme**.
  </Step>

  <Step title="Upload the theme file">
    Choose the `.zip` file you downloaded, then click **Install Now**.
  </Step>

  <Step title="Activate the theme">
    Once installation finishes, click **Activate**.
  </Step>
</Steps>

<Callout kind="alert">
  On macOS Safari, downloaded `.zip` files sometimes unzip automatically. Make sure the theme file is still in `.zip` format before uploading — if Safari has unzipped it, you'll need to disable that behavior in Safari's preferences first.
</Callout>

## Tour the Travelverse dashboard

Access the dashboard from **Appearance > Travelverse** in your WordPress admin. It gives you one place to manage everything related to the theme, organized into four areas:

| Tab           | What it's for                                                                                                             |
| ------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Dashboard     | Customize your site, and find links to theme documentation and the support channel.                                       |
| Starter Sites | Browse all available Travelverse starter templates.                                                                       |
| Free vs Pro   | Compare what's available in the free theme against the premium [Pattern Engine](/wordpress-themes/pattern-engine) plugin. |
| Settings      | Premium-only customizer shortcuts — Colors, Custom Script, Typography, and Custom CSS. Requires Pattern Engine.           |
