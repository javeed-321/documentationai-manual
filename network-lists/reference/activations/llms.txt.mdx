# Network Lists API Documentation

> Manage common sets of lists used by various Akamai security products and features.

## API Reference: Activations

- [Get activation details](https://techdocs.akamai.com/network-lists/reference/get-activation.md): Provides detailed status for a given activation, including progress on _fast_ activation and other audit information, in addition to information ordinarily available from the [Get activation status](/reference/get-network-list-status) operation.
