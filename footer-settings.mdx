## Overview

Access the footer settings via **Appearance > Customize > General Settings > Footer Settings** in your WordPress dashboard.

## Upper footer

The Upper Footer setting controls the colors used for different elements in the upper footer section.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-33.png" width="342" height="495" alt="Upper footer settings panel in Travel Monster customizer" />

| Setting              | What it does                                                 |
| -------------------- | ------------------------------------------------------------ |
| Background Color     | Sets the background color for the upper footer section.      |
| Text Color           | Sets the color for general text in the upper footer section. |
| Link Hover Color     | Sets the color for link text on hover.                       |
| Widget Heading Color | Sets the color for footer widget titles.                     |

## Bottom footer

The Bottom Footer setting lets you add copyright information and payment labels, and set colors for the bottom footer's elements.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2022/09/1-34.png" width="342" height="495" alt="Bottom footer settings panel in Travel Monster customizer" />

| Setting               | What it does                                                                                         |
| --------------------- | ---------------------------------------------------------------------------------------------------- |
| Footer Copyright Text | Sets the copyright text displayed in the site footer.                                                |
| Payment Label         | Sets the label for the payment section, if you want to showcase accepted payment options.            |
| Payment Image         | Uploads an image showing the payment gateways you want to highlight in the footer's payment section. |
| Background Color      | Sets the background color for the bottom footer section.                                             |
| Text Color            | Sets the color for general text in the bottom footer section.                                        |
| Link Initial Color    | Sets the color for link text in its normal state.                                                    |
| Link Hover Color      | Sets the color for link text on hover.                                                               |
