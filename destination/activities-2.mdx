## Overview

The Destination/Activities 2 widget lets you showcase your Destination, Activity, and Trip Types taxonomies on any page using Elementor.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/activities-4-1024x395.png" width="1024" height="395" alt="Destination/Activities 2 widget rendered on a page" />

## Layout settings

- **Column** – chooses the number of columns to display
- **Gap** – sets the spacing between the rows and columns of the taxonomy box
- **Layouts** – select from three layout options to display trips, each customizing the appearance of the widget

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/layout-6.png" width="800" height="500" alt="Layout options for the Destination/Activities 2 widget" />

## Query settings

- **Select Taxonomy** – choose whether to display Destination, Activities, or Trip Types
- **Show Term by** – choose how the taxonomy is displayed: by default, or by choosing terms from a list
- **Number of Items** – specify the total number of items to display

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/destination-query-2.png" width="800" height="500" alt="Query settings for the Destination/Activities 2 widget" />

## Additional settings

- **Title Tag** – selects the header tag used to display the taxonomy title
- **Show Trip Counts** – displays the number of trips linked to the taxonomy
- **Trip Count Label** – sets a label to display next to the trip count
- **Show View More Button** – displays a "view more" button

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/additional-4.png" width="800" height="500" alt="Additional settings for the Destination/Activities 2 widget" />

## General style settings

- **Background Color** – chooses a background color for the widget section
- **Padding** – adjusts the padding around the content within the widget section
- **Border Radius** – controls the roundness of the corners
- **Border Type** – selects the border type for the widget section
- **Box Shadow** – configures the box shadow effect for the taxonomy boxes within the widget section

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/general-destionation1.png" width="800" height="500" alt="General style settings for the Destination/Activities 2 widget" />
