## Overview

The Destination/Activities Slider 2 widget lets you showcase your Destination, Activity, and Trip Types taxonomies on any page in a carousel layout using Elementor, with an optional call-to-action section.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/activities-6-1024x365.png" width="1024" height="365" alt="Destination/Activities Slider 2 widget rendered on a page" />

## Layout settings

- **Layouts** – select from a variety of layout options to display trips; several layouts are available so you can customize the appearance of the widget

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/layout-5.png" width="800" height="500" alt="Layout options for the Destination/Activities Slider 2 widget" />

## Query settings

- **Select Taxonomy** – choose whether to display Destination, Activities, or Trip Types
- **Show Term by** – choose how the taxonomy is displayed: by default, or by choosing terms from a list
- **Number of Items** – specify the total number of items to display

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/destination-query-2.png" width="800" height="500" alt="Query settings for the Destination/Activities Slider 2 widget" />

## Additional settings

- **CTA Title** – sets a title for the CTA section
- **CTA Content** – provides a description of your work and relevant information
- **CTA Button** – sets a label for the CTA button
- **CTA Title Tag** – selects the title tag for the CTA section
- **Title Tag** – selects the header tag used to display the taxonomy title
- **Show Trip Counts** – displays the number of trips linked to the taxonomy

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/additional-5.png" width="800" height="500" alt="Additional settings for the Destination/Activities Slider 2 widget" />

## Slider settings

- **Slider Number** – sets the number of slides to display at once
- **Space Between Slides** – defines the spacing between each slide, in pixels
- **Autoplay** – enables automatic transitions between slides
- **Autoplay Speed** – sets the time between each slide transition, in milliseconds
- **Loop** – continuously cycles slides after the last one
- **Transition Speed** – adjusts the speed of slide transitions, in milliseconds
- **Slider Arrow** – shows navigation arrows
- **Slider Pagination** – shows dots for navigating between slides

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/slider-4.png" width="800" height="500" alt="Slider settings for the Destination/Activities Slider 2 widget" />

## General style settings

- **Background Color** – chooses a background color for the widget section
- **Padding** – adjusts the padding around the content within the widget section
- **Border Radius** – controls the roundness of the corners
- **Border Type** – selects the border type for the widget section
- **Box Shadow** – configures the box shadow effect for the taxonomy boxes within the widget section

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/general-destionation1.png" width="800" height="500" alt="General style settings for the Destination/Activities Slider 2 widget" />
