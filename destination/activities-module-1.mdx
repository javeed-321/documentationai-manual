## Overview

The Destination/Activities Module 1 widget lets you showcase your Destination, Activity, and Trip Types taxonomies on any page using Elementor.

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/activities-2-1024x375.png" alt="Destination/Activities Module 1 widget rendered on a page" width="1024" height="375" />

## Layout settings

- **Gap** – sets the spacing between the rows and columns of taxonomy
- **Layouts** – select from a variety of layout options to display trips; several layouts are available so you can customize the appearance of the widget

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/layout-3.png" alt="Layout options for the Destination/Activities Module 1 widget" width="800" height="500" />

## Query settings

- **Select Taxonomy** – choose whether to display Destination, Activities, or Trip Types
- **Show Term by** – choose how the taxonomy is displayed: by default, or by choosing terms from a list

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/query-destination-1.png" alt="Query settings for the Destination/Activities Module 1 widget" width="800" height="500" />

## Additional settings

- **Title Tag** – chooses the header tag used to display the taxonomy title
- **Show Trip Counts** – displays the number of trips associated with the taxonomy
- **Trip Count Label** – sets a label to display next to the trip count

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/Additional-3.png" alt="Additional settings for the Destination/Activities Module 1 widget" width="800" height="500" />

## General style settings

- **Background Color** – chooses a background color for the widget section
- **Padding** – adjusts the padding around the content within the widget section
- **Border Radius** – controls the roundness of the corners
- **Border Type** – selects the border type for the widget section
- **Box Shadow** – configures the box shadow effect for the taxonomy boxes within the widget section

<Image src="https://docs.wptravelengine.com/wp-content/uploads/2024/10/general-destionation1.png" alt="General style settings for the Destination/Activities Module 1 widget" width="800" height="500" />
